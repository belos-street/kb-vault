## 核心概念

### 1. 选择器全谱系

#### 基础选择器

```css
/* 元素选择器 */
p { }

/* 类选择器 */
.card { }

/* ID 选择器（优先级高，慎用） */
#header { }

/* 通配符（优先级 0，常用于 reset） */
* { }

/* 属性选择器 */
[type="text"] { }      /* 精确匹配 */
[class^="btn"] { }     /* 以 btn 开头 */
[href$=".pdf"] { }     /* 以 .pdf 结尾 */
[data-state*="open"] { } /* 包含 open */
```

#### 组合器

```css
.card p { }     /* 后代：card 内任意层级的 p */
.card > p { }   /* 子代：仅直接子元素 p */
h2 + p { }      /* 相邻兄弟：紧跟 h2 的第一个 p */
h2 ~ p { }      /* 通用兄弟：h2 之后的所有 p（同级） */
```

#### 状态伪类

```css
a:hover { }          /* 鼠标悬停 */
input:focus { }      /* 获得焦点（鼠标或键盘） */
button:focus-visible { } /* 仅键盘聚焦时显示（可访问性关键） */
button:active { }    /* 按下瞬间 */
input:checked { }    /* 复选/单选被选中 */
button:disabled { }  /* 禁用态 */
```

**`:focus` vs `:focus-visible`**：

```css
/* :focus 鼠标点击也会触发，导致按钮出现难看的焦点环 */
/* :focus-visible 只在键盘导航时触发，鼠标点击不显示 */
.btn:focus-visible {
  outline: 2px solid #4f46e5;
  outline-offset: 2px;
}
```

这是可访问性（a11y）的重要实践：键盘用户需要焦点指示，鼠标用户不需要。

#### 结构伪类

```css
li:first-child { }   /* 第一个子元素 */
li:last-child { }    /* 最后一个子元素 */
li:nth-child(2n) { } /* 偶数位（斑马纹） */
li:nth-child(3n+1) { } /* 第 1、4、7... 个 */
li:nth-of-type(2) { }  /* 同类型中的第 2 个 */
div:empty { }        /* 无任何子节点（含文本） */
```

**`:nth-child` vs `:nth-of-type`**：

```html
<div>
  <p>1</p>
  <span>x</span>
  <p>2</p>
</div>
```

```css
p:nth-child(2) { }    /* 选"第 2 个子元素且是 p"→ 无（第 2 个是 span） */
p:nth-of-type(2) { }  /* 选"第 2 个 p"→ 命中 <p>2</p> */
```

#### 父选择器 :has()（Baseline 2023-12）

`:has()` 是 CSS 期待二十年的"父选择器"——根据子元素的状态选择父元素。

```css
/* 包含图片的卡片加特殊背景 */
.card:has(img) { background: #f9f9f9; }

/* 表单含无效输入时，高亮提交按钮 */
form:has(input:invalid) button[type="submit"] {
  background: #ccc;
  cursor: not-allowed;
}

/* 复选框被选中时，整行高亮（待办列表划线） */
li:has(input:checked) {
  text-decoration: line-through;
  color: #999;
}

/* 空状态检测：列表无子项时显示占位提示 */
.list:not(:has(li))::after {
  content: '暂无数据';
}

/* 布局感知：侧边栏存在时，主内容区收窄 */
.layout:has(.sidebar) .main { width: 70%; }
```

**面试常问**：`:has()` 解决了什么问题？

在它之前，CSS 只能"向下/向后"选择（父选子、兄选弟），无法"向上"。很多交互（如"表单有错误时高亮提交按钮"）必须靠 JS 加 class 实现。`:has()` 让这类状态感知样式可以纯 CSS 完成，性能更好、代码更少。

### 2. 伪元素

伪元素创建"虚拟元素"，用双冒号 `::`：

```css
/* ::before / ::after：在元素内容前后插入（必须有 content） */
.required::after {
  content: ' *';
  color: red;
}

/* 经典清除浮动 */
.clearfix::after {
  content: '';
  display: block;
  clear: both;
}

/* ::marker：自定义列表符号 */
li::marker {
  color: #4f46e5;
  font-size: 1.2em;
}

/* ::selection：选中文本的样式 */
::selection {
  background: #4f46e5;
  color: white;
}

/* ::placeholder：输入框占位符 */
input::placeholder {
  color: #aaa;
}
```

**`::before`/`::after` 是行内元素**，默认 `display: inline`，做装饰图形时记得设 `display: block` 或 `inline-block`。

### 3. 盒模型（Box Model）

每个元素都是一个盒子，由四层组成（从内到外）：

```
┌─────────────────── margin ───────────────────┐
│  ┌────────────── border ──────────────┐      │
│  │  ┌───────── padding ─────────┐     │      │
│  │  │                           │     │      │
│  │  │        content            │     │      │
│  │  │                           │     │      │
│  │  └───────────────────────────┘     │      │
│  └────────────────────────────────────┘      │
└──────────────────────────────────────────────┘
```

#### content-box vs border-box

```css
/* content-box（默认）：width 只算 content */
.box-content {
  box-sizing: content-box;
  width: 200px;
  padding: 20px;
  border: 2px solid;
  /* 实际占宽 = 200 + 20*2 + 2*2 = 244px */
}

/* border-box：width 包含 content + padding + border */
.box-border {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 2px solid;
  /* 实际占宽 = 200px（content 自动压缩为 156px） */
}
```

**为什么全局用 border-box**：

```css
/* 现代 reset 的标配 */
*, *::before, *::after {
  box-sizing: border-box;
}
```

用 `border-box` 后，`width: 50%` 就是真正的 50%，加 padding 不会撑破布局，栅格系统才能正常工作。

**面试常问**：border-box 下，width 包含 margin 吗？

不包含。无论哪种模式，`width` 都不含 margin。margin 是盒子外部的间距。border-box 的 width = content + padding + border。

### 4. margin 折叠（Collapsing Margins）

**垂直方向**上相邻的 margin 会合并为一个（取较大值），而非相加。

#### 三种场景

```css
/* 场景 1：相邻兄弟 */
.a { margin-bottom: 20px; }
.b { margin-top: 30px; }
/* 实际间距 = max(20, 30) = 30px，不是 50px */

/* 场景 2：父子上溢（父无 padding/border/BFC） */
.parent { /* 无 padding-top */ }
.child { margin-top: 20px; }
/* child 的 margin-top 会"穿透"到 parent 外部 */

/* 场景 3：空块（无内容、无 padding/border） */
.empty { margin-top: 10px; margin-bottom: 20px; }
/* 自身上下 margin 折叠为 20px */
```

**注意**：只有**块级方向**的 margin 会折叠。Flex/Grid 容器内、浮动元素、绝对定位元素的 margin **不折叠**。

#### 用 BFC 消除折叠

```css
.parent {
  overflow: hidden; /* 触发 BFC，阻止子元素 margin 穿透 */
}
```

### 5. BFC（块级格式化上下文）

BFC 是一个独立的渲染区域，内部布局不影响外部。

**触发条件**（满足其一）：

```css
overflow: hidden / auto / scroll;  /* 最常用 */
display: flow-root;                /* 最语义化，专为创建 BFC */
display: flex / grid / inline-block;
float: left / right;
position: absolute / fixed;
```

**`display: flow-root`** 是创建 BFC 的"纯净"方式，不像 `overflow: hidden` 会顺带裁剪溢出内容。

**三大应用**：

```css
/* 1. 清除浮动（父元素高度塌陷） */
.container { display: flow-root; } /* 包裹浮动子元素 */

/* 2. 自适应两栏布局 */
.aside { float: left; width: 200px; }
.main { overflow: hidden; } /* BFC 不与浮动重叠 → 自动填满剩余空间 */

/* 3. 防止 margin 穿透 */
.parent { display: flow-root; } /* 子元素 margin-top 不再穿透 */
```

### 6. 逻辑属性（Baseline 2022）

传统属性（`margin-left`、`padding-top`）是**物理方向**，在 RTL（从右到左，如阿拉伯语）或竖排文本中会错位。逻辑属性基于**书写模式**自动适配。

| 物理属性 | 逻辑属性 | 含义 |
|---------|---------|------|
| `margin-left` / `margin-right` | `margin-inline-start` / `margin-inline-end` | 行内方向（水平文本中=左右） |
| `margin-top` / `margin-bottom` | `margin-block-start` / `margin-block-end` | 块方向（水平文本中=上下） |
| `width` | `inline-size` | 行内方向尺寸 |
| `height` | `block-size` | 块方向尺寸 |
| `top`/`right`/`bottom`/`left` | `inset-block-start` 等 / `inset: 0` | 定位偏移 |
| `text-align: left` | `text-align: start` | 文本对齐 |

```css
/* 物理写法：RTL 下箭头方向会错 */
.next { margin-left: 8px; }

/* 逻辑写法：自动适配 LTR/RTL */
.next { margin-inline-start: 8px; }

/* 简写 */
.card {
  margin-block: 16px;    /* 上下 */
  padding-inline: 24px;  /* 左右 */
  inset: 0;              /* top/right/bottom/left 全 0 */
}
```

**面试常问**：逻辑属性有什么用？

让样式与书写方向解耦。同一份 CSS 在 LTR（中文/英文）和 RTL（阿拉伯语/希伯来语）下自动镜像，无需写两套样式，是国际化的基础。

## 常见踩坑点

### 坑 1：:nth-child 选不中目标

```html
<div>
  <h3>标题</h3>
  <p>段落1</p>
  <p>段落2</p>
</div>
```

```css
/* ❌ p:nth-child(1) 选不中任何 p（第 1 个子元素是 h3） */
/* ✅ 用 nth-of-type 按类型计数 */
p:nth-of-type(1) { color: red; } /* 命中"段落1" */
```

### 坑 2：::before 不显示

```css
/* ❌ 缺少 content，伪元素不渲染 */
.icon::before { width: 16px; height: 16px; background: url(...); }

/* ✅ 必须有 content（可为空字符串），且常需设 display */
.icon::before {
  content: '';
  display: inline-block;
  width: 16px;
  height: 16px;
  background: url(...);
}
```

### 坑 3：border-box 下 width 100% 加 margin 溢出

```css
/* border-box 解决了 padding/border 撑破，但 margin 仍会导致溢出 */
.col {
  box-sizing: border-box;
  width: 50%;
  margin: 0 10px; /* 实际占宽 = 50% + 20px → 溢出 */
}

/* ✅ 用 calc 扣除 margin，或用 gap（Flex/Grid） */
.col { width: calc(50% - 20px); }
```

### 坑 4：父元素高度塌陷（浮动子元素）

```css
/* 子元素浮动后脱离文档流，父元素高度为 0 */
.child { float: left; }

/* ✅ 父元素创建 BFC */
.parent { display: flow-root; }
```

## 面试高频问题

### Q1：CSS 有哪些选择器？优先级怎么排？

**答**：分五类——基础（元素/类/ID/属性/通配）、组合器（后代/子代/兄弟）、伪类（状态/结构，含 :has()）、伪元素（::before 等）、通配符。优先级三元组 (ID, CLASS, TAG) 逐位比较：ID 选择器最高，类/属性/伪类次之，标签/伪元素最低。:is()/:has() 取参数最高优先级，:where() 恒为 0。

### Q2：:has() 是什么？解决了什么问题？

**答**：:has() 是父选择器（Baseline 2023-12），根据子元素状态选择父元素，如 `form:has(input:invalid)` 选中含无效输入的表单。它解决了 CSS 长期以来只能向下/向后选择、无法向上选择的问题，让"表单有错误高亮按钮""空列表显示占位"等交互可以纯 CSS 实现。

### Q3：box-sizing 的两种值有什么区别？

**答**：content-box（默认）的 width 只含 content，加 padding/border 会撑大盒子；border-box 的 width 含 content+padding+border，加 padding 会压缩 content 而非撑大盒子。现代项目全局设 border-box，这样 width: 50% 就是真正的 50%，栅格系统才能正常计算。两种模式下 width 都不含 margin。

### Q4：什么是 margin 折叠？怎么避免？

**答**：块级方向上相邻的 margin 会合并为较大值而非相加，有三种场景：相邻兄弟、父子上溢（父无 padding/border/BFC 时子 margin 穿透）、空块自身折叠。避免方法：给父元素创建 BFC（display: flow-root 最语义化）、加 padding/border、或改用 Flex/Grid（容器内 margin 不折叠）。

### Q5：什么是 BFC？有哪些应用？

**答**：BFC（块级格式化上下文）是独立渲染区域，内部布局不影响外部。触发条件包括 overflow 非 visible、display: flow-root/flex/grid、float、绝对定位等。三大应用：清除浮动（解决父高度塌陷）、自适应两栏布局（BFC 不与浮动重叠）、防止 margin 穿透。推荐用 display: flow-root 创建，语义清晰且无副作用。

### Q6：逻辑属性和物理属性有什么区别？

**答**：物理属性（margin-left）绑定绝对方向，逻辑属性（margin-inline-start）绑定书写模式。在 RTL 语言或竖排文本中，逻辑属性会自动镜像适配，物理属性会错位。逻辑属性是国际化的基础，新项目推荐优先使用 margin-inline/block、inset、text-align: start 等。

## 面试回答模板

> **问：说说你对盒模型的理解？**
>
> 每个元素都是一个盒子，由 content、padding、border、margin 四层组成。核心是 box-sizing：content-box（默认）的 width 只算 content，加 padding 会撑大盒子；border-box 的 width 含 content+padding+border，更符合直觉。现代项目会全局设 border-box，保证栅格计算的准确性。margin 比较特殊，无论哪种模式都不计入 width，且垂直方向相邻 margin 会折叠。
>
> **追问：margin 折叠怎么处理？**
>
> 折叠只发生在块级方向，用 BFC 可以消除。最干净的方式是给父元素设 display: flow-root，它专为创建 BFC 设计，不像 overflow: hidden 会裁剪内容。Flex 和 Grid 容器内的 margin 天然不折叠，所以现代布局中这个问题少了很多。

## 练习

### 练习 1：:has() 表单校验

**要求**：用纯 CSS（:has()）实现——表单含 invalid 输入时，提交按钮变灰且不可点击；所有输入有效时按钮高亮

**提示**：`form:has(input:invalid)` 选中含无效输入的表单，配合 `pointer-events: none` 禁用按钮

**预期效果**：输入非法邮箱时按钮灰色不可点，输入合法后按钮变为可点击的主题色

```css
form:has(input:invalid) button[type='submit'] {
  background: #ccc;
  cursor: not-allowed;
  pointer-events: none;
}

form:has(input:valid) button[type='submit'] {
  background: #4f46e5;
  color: white;
}
```

### 练习 2：BFC 两栏布局

**要求**：用 BFC 实现两栏布局——左侧固定 200px（浮动），右侧自适应填满，并解释原理

**提示**：左栏 `float: left`，右栏触发 BFC（overflow: hidden 或 display: flow-root）

**预期效果**：右栏自动避开左栏浮动区域，填满剩余宽度；能口头解释"BFC 不与浮动元素重叠"

```css
.aside {
  float: left;
  width: 200px;
  height: 300px;
  background: #e0e7ff;
}
.main {
  overflow: hidden; /* 触发 BFC，不与浮动重叠 → 自适应 */
  height: 300px;
  background: #f0fdf4;
}
```

### 练习 3：逻辑属性国际化

**要求**：把一个用物理属性写的卡片布局改写为逻辑属性，切换 `writing-mode` 或 `dir="rtl"` 验证适配

**提示**：`margin-left → margin-inline-start`、`padding: 10px 20px → padding-block/inline`、`text-align: left → start`

**预期效果**：在 `dir="rtl"` 下卡片内边距、文本对齐自动镜像，无需改 CSS

```css
.card {
  padding-block: 16px;
  padding-inline: 24px;
  margin-block-end: 12px;
  text-align: start;
  border-inline-start: 4px solid #4f46e5;
}
```
