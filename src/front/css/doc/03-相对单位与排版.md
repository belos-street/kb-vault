## 核心概念

### 1. em 与 rem

```css
/* rem：相对根元素（html）的 font-size，全局一致 */
.title { font-size: 2rem; }   /* = 2 × 根字号（默认 16px）= 32px */

/* em：相对"当前元素"的 font-size（用于 font-size 时相对父级） */
.parent { font-size: 20px; }
.child { font-size: 1.5em; }  /* = 1.5 × 20px = 30px */
```

#### em 的级联陷阱

```html
<div style="font-size: 20px">
  <div style="font-size: 1.5em">      <!-- 30px -->
    <div style="font-size: 1.5em">    <!-- 45px！不是 30px -->
      我越来越大了
    </div>
  </div>
</div>
```

`em` 用于 `font-size` 时相对**父级字号**，嵌套会逐级放大。这是 em 最常见的坑。

#### em 的正确用法：随字号缩放的间距

```css
/* em 用于 padding/margin 时相对"自身" font-size */
.btn {
  font-size: 16px;
  padding: 0.5em 1em; /* 8px 16px，随字号缩放 */
}

.btn-lg {
  font-size: 20px;
  /* padding 自动变为 10px 20px，无需重写 */
}
```

**经验法则**：字号用 `rem`（全局可控），组件内部间距用 `em`（随组件字号缩放）。

#### 关于 62.5% 技巧

```css
/* 历史技巧：html { font-size: 62.5% } 让 1rem = 10px，方便换算 */
/* ❌ 不推荐用于生产： */
/*   1. 破坏用户浏览器字号设置（可访问性） */
/*   2. 与 rem"相对用户偏好"的语义相悖 */
/* ✅ 推荐：保持默认 16px，用 clamp() 做流式根字号 */
```

### 2. 视口单位与 dvh

```css
/* vw/vh：视口宽度/高度的 1% */
.hero { height: 100vh; } /* 问题：移动端地址栏收缩时，100vh 会超出可视区 */
```

#### 移动端 100vh 问题

移动浏览器的地址栏会收缩/展开，但 `100vh` 是**固定值**（地址栏收缩时的高度），导致地址栏展开时内容被遮挡。

```css
/* ✅ 动态视口单位（Baseline 2022） */
.hero { height: 100dvh; } /* dynamic：随地址栏收缩实时变化 */
.hero { height: 100svh; } /* small：地址栏展开时的最小高度（最保守） */
.hero { height: 100lvh; } /* large：地址栏收缩时的最大高度 */
```

| 单位 | 含义 | 适用 |
|------|------|------|
| `svh` | 最小可视高度（地址栏全展开） | 不希望内容被遮挡 |
| `lvh` | 最大可视高度（地址栏全收缩） | 希望占满最大空间 |
| `dvh` | 动态高度（实时跟随） | 全屏 Hero 首选 |

```css
/* 兼容写法 */
.hero {
  height: 100vh;    /* 回退 */
  height: 100dvh;   /* 支持的浏览器覆盖 */
}
```

#### 其他单位

```css
/* %：相对父元素 */
/* ch：相对 "0" 字符的宽度（等宽场景） */
.prose { max-width: 65ch; } /* 正文最佳行宽约 45-75 字符 */

/* ex：相对小写 x 的高度（少用） */
```

#### 单位选择决策树

```
字号           → rem（全局一致，尊重用户设置）
组件内间距     → em（随组件字号缩放）
全屏高度       → dvh（移动端）/ vh（桌面）
正文行宽       → ch（65ch）
栅格/流式尺寸  → % 或 fr（Grid）
```

### 3. 字体与字体栈

```css
body {
  /* 字体栈：按顺序回退，最后用通用族 */
  font-family: 'Inter', 'PingFang SC', 'Microsoft YaHei', system-ui, sans-serif;
}

/* 系统字体栈（无需加载，性能最佳） */
.system {
  font-family: system-ui, -apple-system, 'Segoe UI', Roboto,
    'Helvetica Neue', Arial, 'PingFang SC', 'Microsoft YaHei', sans-serif;
}

/* 等宽字体栈（代码展示） */
code {
  font-family: ui-monospace, 'SF Mono', 'Cascadia Code', Consolas, monospace;
}
```

**要点**：
- 字体名含空格要加引号
- 最后必须以通用族（`sans-serif` / `serif` / `monospace`）兜底
- 中文字体放在西文字体之后（中文优先用西文字体的数字/拉丁，中文回退到中文字体）

### 4. 可变字体（Variable Fonts）

传统字体每个字重（400/500/700）是一个独立文件。可变字体是**单文件**，字重/字宽等属性可连续调节。

```css
@font-face {
  font-family: 'MyVarFont';
  src: url('myfont.woff2') format('woff2-variations');
  font-weight: 100 900; /* 声明可用范围 */
}

.title {
  font-family: 'MyVarFont';
  font-weight: 650; /* 任意值，不限于 400/700 */
}

/* 用 font-variation-settings 精细控制 */
.fancy {
  font-variation-settings: 'wght' 650, 'wdth' 110; /* 字重 650，字宽 110% */
}

/* 可变字体 + transition = 字重动画 */
.nav a {
  font-variation-settings: 'wght' 400;
  transition: font-variation-settings 0.3s;
}
.nav a:hover {
  font-variation-settings: 'wght' 700; /* 平滑加粗，而非跳变 */
}
```

**优势**：单文件覆盖全部字重（体积小）、支持无级字重、可做字重动画。

### 5. @font-face 与字体加载

```css
@font-face {
  font-family: 'CustomFont';
  src: url('font.woff2') format('woff2');
  font-display: swap; /* 关键：加载策略 */
}
```

#### font-display 加载策略

| 值 | 行为 | 适用 |
|----|------|------|
| `auto` | 浏览器默认 | — |
| `block` | 等字体加载完才显示文字（FOIT） | 图标字体 |
| `swap` | 先用回退字体，加载完切换（FOUT） | 正文字体（推荐） |
| `optional` | 网络好才用，否则放弃（不切换） | 装饰字体 |

**FOIT vs FOUT**：
- FOIT（Flash of Invisible Text）：文字不可见等待字体 → 用户看到空白
- FOUT（Flash of Unstyled Text）：先显示回退字体再切换 → 有轻微跳动但内容可见

**性能优化**：

```html
<!-- 预加载关键字体 -->
<link rel="preload" href="/fonts/main.woff2" as="font" type="font/woff2" crossorigin>
```

```css
/* woff2 压缩率最高，现代浏览器全支持 */
src: url('font.woff2') format('woff2');
```

### 6. 排版细节

#### 行高（line-height）

```css
/* ❌ 带单位的行高会被"固化"，子元素继承具体 px 值 */
.parent { font-size: 16px; line-height: 24px; }
.child { font-size: 32px; } /* 行高仍是 24px → 文字重叠 */

/* ✅ 无单位行高是"比例"，子元素继承比例后按自身字号计算 */
.parent { line-height: 1.5; }
.child { font-size: 32px; } /* 行高自动 = 32 × 1.5 = 48px */
```

**经验值**：正文 1.5-1.75，标题 1.1-1.3。

#### font-feature-settings（OpenType 特性）

```css
/* 等宽数字：表格中数字对齐（避免 1 比 0 窄导致抖动） */
.table-num { font-feature-settings: 'tnum'; }

/* 连字：fi/fl 等字母组合美化 */
.prose { font-feature-settings: 'liga'; }

/* 旧式数字：与正文混排的古典数字 */
.classic { font-feature-settings: 'onum'; }
```

```css
/* 更语义化的写法 */
.nums { font-variant-numeric: tabular-nums; } /* 等价于 tnum */
```

#### 其他排版属性

```css
/* 字间距 */
.tracking-wide { letter-spacing: 0.05em; }

/* 文本渲染优化 */
body { text-rendering: optimizeLegibility; }
```

### 7. 文本布局与截断

```css
/* 单行截断 + 省略号 */
.ellipsis {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

/* 多行截断（-webkit-line-clamp） */
.clamp-3 {
  display: -webkit-box;
  -webkit-line-clamp: 3;
  -webkit-box-orient: vertical;
  overflow: hidden;
}

/* 长单词换行（防止 URL 撑破容器） */
.url { overflow-wrap: break-word; }

/* 标题平衡换行（Baseline 2023-2024） */
h1 { text-wrap: balance; }   /* 让多行标题各行长度均衡 */
p { text-wrap: pretty; }     /* 避免段落末尾出现孤字 */
```

**`text-wrap: balance`** 是标题排版神器——自动让多行标题的每行长度接近，无需手动加 `<br>`。

### 8. 流式排版（Fluid Typography）

用 `clamp(min, preferred, max)` 实现字号随视口平滑缩放，**零媒体查询**。

```css
/* clamp(最小值, 偏好值, 最大值) */
h1 {
  /* 偏好值 4vw 随视口缩放，但被限制在 2rem ~ 4rem 之间 */
  font-size: clamp(2rem, 1.5rem + 2.5vw, 4rem);
}

body {
  font-size: clamp(1rem, 0.95rem + 0.25vw, 1.125rem);
}
```

**公式理解**：`preferred = 固定值 + vw 值`。纯 vw 会在小屏过小、大屏过大，加固定值做基准、用 min/max 夹住边界。

```css
/* 流式间距同理 */
.section {
  padding-block: clamp(2rem, 1rem + 4vw, 6rem);
}
```

**面试常问**：clamp() 相比媒体查询的优势？

媒体查询是"阶梯式"变化（断点处跳变），clamp() 是"连续"变化（任意视口都平滑）。流式排版减少了断点数量，代码更简洁，且不会出现"刚好在断点附近布局崩坏"的问题。

## 常见踩坑点

### 坑 1：em 嵌套逐级放大

```css
/* ❌ 三层嵌套后字号失控 */
.l1 { font-size: 1.2em; } /* 19.2px */
.l2 { font-size: 1.2em; } /* 23px */
.l3 { font-size: 1.2em; } /* 27.6px */

/* ✅ 字号统一用 rem */
.l1, .l2, .l3 { font-size: 1.2rem; }
```

### 坑 2：移动端 100vh 内容被遮挡

```css
/* ❌ 地址栏展开时，底部内容被遮住 */
.hero { height: 100vh; }

/* ✅ 用 dvh + vh 回退 */
.hero { height: 100vh; height: 100dvh; }
```

### 坑 3：line-height 带单位导致子元素重叠

```css
/* ❌ 24px 行高被子元素（32px 字号）继承 → 行距不足 */
.parent { line-height: 24px; }

/* ✅ 用无单位比例 */
.parent { line-height: 1.5; }
```

### 坑 4：字体加载导致布局偏移（CLS）

```css
/* ❌ 回退字体与自定义字体尺寸差异大 → 加载完成后文字跳动 */
/* ✅ 用 size-adjust 校准回退字体，或 font-display: optional */
@font-face {
  font-family: 'Fallback';
  src: local('Arial');
  size-adjust: 105%; /* 让回退字体尺寸接近自定义字体 */
}
```

## 面试高频问题

### Q1：em 和 rem 的区别？

**答**：rem 相对根元素（html）字号，全局一致；em 用于 font-size 时相对父级字号（嵌套会级联放大），用于 padding/margin 时相对自身字号。实践上字号用 rem 保证可控，组件内间距用 em 让它随组件字号缩放。

### Q2：移动端为什么要用 dvh 而不是 vh？

**答**：移动浏览器地址栏会收缩/展开，100vh 是固定值（地址栏收缩时的高度），地址栏展开时会超出可视区遮挡内容。dvh 是动态视口高度，实时跟随地址栏变化；svh 是最小高度（保守不遮挡），lvh 是最大高度。全屏 Hero 推荐 100dvh 并保留 100vh 回退。

### Q3：font-display 有哪些值？怎么选？

**答**：block 等字体加载完才显示（FOIT，适合图标字体）；swap 先用回退字体再切换（FOUT，正文推荐，保证内容可见）；optional 网络好才用否则放弃（装饰字体）。核心权衡是"内容可见性"vs"视觉稳定性"，正文优先保证可见性用 swap。

### Q4：什么是可变字体？有什么优势？

**答**：可变字体是单个字体文件包含连续的字重/字宽等变化轴，通过 font-variation-settings 或任意 font-weight 值控制。优势：一个文件覆盖全部字重（体积小于多个静态字体）、支持无级字重、可以做字重过渡动画（font-variation-settings 可 transition）。

### Q5：怎么实现流式排版？

**答**：用 clamp(min, preferred, max)，preferred 写成"固定值 + vw"的形式，如 `clamp(2rem, 1.5rem + 2.5vw, 4rem)`。字号随视口连续缩放，被 min/max 夹住边界，无需媒体查询。相比断点式响应，流式排版更平滑、代码更简洁。

### Q6：line-height 为什么推荐无单位值？

**答**：带单位的行高（如 24px）会被子元素继承为固定值，子元素字号变大时行高不变导致文字重叠。无单位值（如 1.5）是比例，子元素继承比例后按自身字号计算，永远保持合理行距。

## 面试回答模板

> **问：CSS 有哪些常用单位？怎么选择？**
>
> 分相对单位和绝对单位，常用的是相对单位：rem 相对根字号，用于全局字号保证一致性和可访问性；em 相对父级/自身字号，用于组件内间距让它随字号缩放；vw/vh 相对视口，移动端全屏高度要用 dvh 解决地址栏遮挡问题；ch 相对字符宽度，用于限制正文行宽（65ch）。选择原则：字号用 rem、间距用 em、视口相关用 dvh/vw。
>
> **追问：rem 布局怎么尊重用户的字号设置？**
>
> rem 相对的是根字号，而根字号默认跟随用户浏览器设置（16px 是默认值，用户可调大）。只要不强制覆盖 html 的 font-size（或用百分比/clamp 基于它缩放），用户调大字号后整个页面会等比放大，这就是 rem 的可访问性优势。不推荐 62.5% 技巧，因为它破坏了用户设置。

## 练习

### 练习 1：流式字号体系

**要求**：用 clamp() 实现 h1~body 的全站流式字号（零媒体查询），拖拽窗口验证平滑缩放

**提示**：`font-size: clamp(min, base + vw, max)`，标题 vw 系数大、正文小

**预期效果**：从 320px 拖到 1920px，字号连续变化无跳变，且不超过设定的上下限

```css
h1 { font-size: clamp(2rem, 1.5rem + 2.5vw, 3.5rem); }
h2 { font-size: clamp(1.5rem, 1.25rem + 1.5vw, 2.5rem); }
h3 { font-size: clamp(1.25rem, 1.1rem + 0.75vw, 1.75rem); }
body { font-size: clamp(1rem, 0.95rem + 0.25vw, 1.125rem); }
```

### 练习 2：可变字体字重动画

**要求**：接入一个可变字体，用 font-variation-settings 实现导航链接悬停时字重平滑加粗

**提示**：`font-variation-settings: 'wght' 400` → hover 时 700，配合 transition

**预期效果**：悬停时字重连续变化（像"呼吸"一样加粗），而非 400→700 的瞬间跳变

```css
@font-face {
  font-family: 'VarFont';
  src: url('variable.woff2') format('woff2-variations');
  font-weight: 100 900;
}
.nav a {
  font-family: 'VarFont';
  font-variation-settings: 'wght' 400;
  transition: font-variation-settings 0.3s ease;
}
.nav a:hover { font-variation-settings: 'wght' 700; }
```

### 练习 3：dvh 全屏 Hero

**要求**：用 dvh 实现移动端全屏 Hero，对比 100vh 与 100dvh 在地址栏收缩/展开时的表现

**提示**：`height: 100vh; height: 100dvh;` 双声明回退，用手机或 DevTools 设备模拟验证

**预期效果**：地址栏展开时 Hero 底部不被遮挡，收缩时自动占满全屏

```css
.hero {
  height: 100vh;   /* 回退 */
  height: 100dvh;  /* 动态视口高度 */
  display: grid;
  place-items: center;
}
```
