卡片标题

阴影颜色也用相对颜色从主色派生：oklch(from var(--primary) 30% 0.08 h / .15)，换主题时阴影色调自动跟随。

关键点

:root { color-scheme: light; --hue: 265; }

/* light-dark() 在 color-scheme 切换时自动换值，一行顶两份媒体查询 */
--surface: light-dark(oklch(98.5% .008 var(--hue)), oklch(21% .025 var(--hue)));

/* 相对颜色语法：在已有颜色上做增量调整，派生 hover/active 态 */
--primary-hover: oklch(from var(--primary) calc(l - 0.07) c h);

/* color-mix：主色与表面色插值，得到和谐的低饱和度边框 */
--border: color-mix(in oklch, var(--primary) 24%, var(--surface));

/* :has() 读取单选状态 → 改变量，零 JS 主题切换 */
html:has(#hue-teal:checked)  { --hue: 190; }
html:has(#mode-dark:checked) { color-scheme: dark; }

为什么用 oklch 而不是 hsl：oklch 感知均匀，同明度下不同色相的"视觉亮度"一致—— 换色相不会出现"黄色刺眼、蓝色发暗"的问题。
