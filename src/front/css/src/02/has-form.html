:has() 表单校验联动

对应模块 2 练习 1 · Baseline 2023-12 · 整个页面没有一行 JavaScript

试一试

随便填一个不合法的字段（如错误邮箱、短密码），观察按钮变暗、label 与输入框标红； 全部填对后按钮恢复可用。删除内容回到"未填写"状态时不会标红（:placeholder-shown 技巧）。

⚠ 表单还有未通过校验的字段
✓ 校验通过，可以提交

关键点

/* :has() 让 CSS 拥有"父选择器"能力：根据子元素状态反选容器 */
form:has(:invalid) button[type="submit"] {
    opacity: .45;
    pointer-events: none;   /* 纯 CSS 禁用点击 */
}

/* label 感知"下一个兄弟"input 的状态：:has() + 相邻兄弟组合器 */
label:has(+ input:invalid:not(:placeholder-shown)) {
    color: crimson;
}

注意两点：
1. :has() 的优先级取参数中最高者（此处相当于 :invalid 的 0-1-0）；
2. 生产环境中 pointer-events 只是视觉拦截，服务端校验永远不能省。
