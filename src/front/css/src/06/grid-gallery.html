auto-fit + minmax：零媒体查询响应式相册

列数完全由容器宽度决定：repeat(auto-fit, minmax(140px, 1fr))。 缩放窗口观察列数变化；auto-fit 会折叠空轨道，让现有格子拉伸铺满（对比 auto-fill 会保留空位）。

三张卡片的标题/描述长度不同，按钮位置各自为政。

中等标题

用 subgrid：按钮跨卡片严格对齐

grid-template-rows: subgrid

卡片本身成为网格项（跨 3 行）+ 网格容器（行轨道继承父网格）， 标题/描述/按钮分别落入父网格的第 1/2/3 行，行高由所有卡片同层内容中最高的决定。

这段描述也长了不少，需要两行才能显示完，但按钮依然和其他卡片对齐。

中等标题

描述长度居中，按钮位置依然对齐。

/* 父网格定义列；卡片跨 3 行并继承父网格的行轨道 */
.cards { display: grid; grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); }
.card  {
  display: grid;
  grid-row: span 3;             /* 占住 标题/描述/按钮 三行 */
  grid-template-rows: subgrid;  /* 行轨道对齐父网格，而非各自独立 */
}
