@starting-style：弹层的进入/退出动画

对应模块 10 练习 1 · Baseline 2024-08 · 零 JS 补间（dialog 的开关除外）

试一试

两个弹层都有进入 + 退出动画。以前的痛点：display: none 不可过渡， 只能靠 JS 手动管理 class 与时序；现在 @starting-style 提供进入起点， transition-behavior: allow-discrete 让 display 参与过渡，CSS 闭环。

注意退出动画：popover 点击外部（light-dismiss）或再次点击触发按钮时，元素会先播完动画再 display:none。 如果看不到动画，说明浏览器不支持 @starting-style（2024 年前的版本），此时优雅降级为直接显隐。

三态模型

/* ① 基础规则：关闭态 = 退出动画的"目标值" */
[popover] {
  opacity: 0; translate: 0 20px; scale: .95;
  transition: opacity .35s, translate .35s, scale .35s,
              display .35s allow-discrete,   /* 离散属性需要显式放行 */
              overlay .35s allow-discrete;   /* 退出时保持在 top-layer 播完动画 */
}

/* ② 打开态 = 进入动画的"目标值" */
[popover]:popover-open { opacity: 1; translate: 0 0; scale: 1; }

/* ③ @starting-style = 打开瞬间的"起始值"（只作用于首帧渲染） */
@starting-style {
  [popover]:popover-open { opacity: 0; translate: 0 20px; scale: .95; }
}

记忆口诀：进入用 starting-style 定义起点，退出用基础规则定义终点——两者可以不同， 比如从下方滑入、向上方滑出。overlay 属性保证退出动画期间元素仍处于 top-layer。
