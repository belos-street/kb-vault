关键点

/* 1. 父容器声明为"查询容器"（注意：容器自身不响应自己的查询，只有后代响应） */
.slot { container-type: inline-size; }

/* 2. 组件内部用 @container 按容器宽度切换布局 */
@container (min-width: 480px) {
  .card { grid-template-columns: 220px 1fr; }
}

/* 3. resize: horizontal + overflow ≠ visible → 纯 CSS 拖拽改变容器宽度，无需 JS */

选型口诀：页面级响应用媒体查询，组件级响应用容器查询。 断点语义也随之改变——480px 不再是"平板"，而是"这个组件需要的空间"。
