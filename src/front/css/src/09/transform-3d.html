3D 卡片翻转（悬停试试）

正面 · hover 我
背面 · transform 只动画合成层，不重排
.flip       { perspective: 800px; }              /* 景深：值越小透视越强 */
.flip-inner { transform-style: preserve-3d; transition: transform .7s; }
.flip:hover .flip-inner { transform: rotateY(180deg); }
.flip-face  { backface-visibility: hidden; }      /* 背面朝向视线时隐藏 */
.flip-back  { transform: rotateY(180deg); }       /* 背面预先转过去 */

/* 每个面先旋转到对应朝向，再沿自身 Z 轴推出半个边长（90px） */
.front  { transform: translateZ(90px); }
.back   { transform: rotateY(180deg) translateZ(90px); }
.right  { transform: rotateY(90deg)  translateZ(90px); }
.top    { transform: rotateX(90deg)  translateZ(90px); }

/* transform 顺序很关键：先旋转改变坐标系，translateZ 才推向"面的外侧" */
