conic-gradient 环形进度条

对应模块 4 练习 1 · 渐变硬边绘图 + mask 挖空 + @property 让数字可过渡

试一试

拖动滑杆或点击按钮。注意数字是纯 CSS 渲染的（counter + @property），过渡时会平滑"数数"。

关键点

/* 1. 硬边渐变切扇形：第二个色标从同一位置开始 → 无过渡色带 */
background: conic-gradient(#4f6ef7 calc(var(--pct) * 1%), #eee 0);

/* 2. mask 挖空中心变成"环"（比 ::after 盖白圆更通用，不依赖背景色） */
mask: radial-gradient(farthest-side, transparent calc(100% - 17px), #000 calc(100% - 16px));

/* 3. @property 注册类型 → 自定义属性可过渡，counter 才能显示插值中间态 */
@property --pct { syntax: "<integer>"; inherits: true; initial-value: 0; }
.stage { transition: --pct .8s; }
.num::after { counter-reset: pct var(--pct); content: counter(pct) "%"; }

没有 @property 时，自定义属性的变化是瞬时跳变的，transition 无效——这是"渐变/数值动画"的核心前置知识， 模块 11 的 @property 一节会深入。
