# 06 — 菜单、对话框与系统交互

> 对应大纲：应用层 | 预计时间：1 天
> 面试可答：Electron 的菜单系统分三种——应用菜单（macOS 顶部菜单栏 / Windows 窗口菜单）、上下文菜单（右键菜单）和 Dock 菜单。菜单通过 `Menu.buildFromTemplate` 创建，支持快捷键（accelerator）、分隔线、子菜单、复选/单选项。对话框通过 `dialog` 模块调用系统原生对话框，支持打开文件、保存文件、消息提示等。所有这些操作都应在主进程中执行。

---

## 1. 应用菜单（Application Menu）

### 1.1 macOS vs Windows 的菜单差异

```
macOS 菜单栏：
┌──────────────────────────────────────────────────┐
│  🍎  MyApp    File    Edit    View    Window    Help │
└──────────────────────────────────────────────────┘
   ↑ 第一个菜单项会变成应用名（系统行为）

Windows 菜单栏：
┌─────────────────────────────────────┐
│  File    Edit    View    Help        │  ← 嵌在窗口标题栏下方
├─────────────────────────────────────┤
│              窗口内容                │
└─────────────────────────────────────┘
```

### 1.2 创建应用菜单

```typescript
// src/main.ts
import { Menu, app, BrowserWindow } from 'electron';

function createMenu(mainWindow: BrowserWindow) {
  const isMac = process.platform === 'darwin';

  const template: Electron.MenuItemConstructorOptions[] = [
    // macOS：第一个菜单项是应用名
    ...(isMac
      ? [{
          label: app.name,
          submenu: [
            { role: 'about' as const },     // 关于
            { type: 'separator' as const },
            { role: 'services' as const },   // 服务
            { type: 'separator' as const },
            { role: 'hide' as const },       // 隐藏
            { role: 'hideOthers' as const }, // 隐藏其他
            { role: 'unhide' as const },     // 显示全部
            { type: 'separator' as const },
            { role: 'quit' as const },       // 退出
          ],
        }]
      : []),
    {
      label: '文件',
      submenu: [
        {
          label: '新建',
          accelerator: 'CmdOrCtrl+N',
          click: () => mainWindow.webContents.send('menu-action', 'new-file'),
        },
        {
          label: '打开...',
          accelerator: 'CmdOrCtrl+O',
          click: () => mainWindow.webContents.send('menu-action', 'open-file'),
        },
        {
          label: '保存',
          accelerator: 'CmdOrCtrl+S',
          click: () => mainWindow.webContents.send('menu-action', 'save-file'),
        },
        {
          label: '另存为...',
          accelerator: 'CmdOrCtrl+Shift+S',
          click: () => mainWindow.webContents.send('menu-action', 'save-as'),
        },
        { type: 'separator' },
        isMac ? { role: 'close' } : { role: 'quit' },
      ],
    },
    {
      label: '编辑',
      submenu: [
        { role: 'undo' },
        { role: 'redo' },
        { type: 'separator' },
        { role: 'cut' },
        { role: 'copy' },
        { role: 'paste' },
        { role: 'selectAll' },
      ],
    },
    {
      label: '视图',
      submenu: [
        { role: 'reload' },
        { role: 'forceReload' },
        { role: 'toggleDevTools' },
        { type: 'separator' },
        { role: 'resetZoom' },
        { role: 'zoomIn' },
        { role: 'zoomOut' },
        { type: 'separator' },
        { role: 'togglefullscreen' },
      ],
    },
    {
      label: '窗口',
      submenu: [
        { role: 'minimize' },
        { role: 'zoom' },
        ...(isMac
          ? [
              { type: 'separator' as const },
              { role: 'front' as const },
            ]
          : [{ role: 'close' as const }]),
      ],
    },
    {
      label: '帮助',
      submenu: [
        {
          label: '关于 Electron 教程',
          click: () => {
            mainWindow.webContents.send('menu-action', 'show-about');
          },
        },
      ],
    },
  ];

  const menu = Menu.buildFromTemplate(template);
  Menu.setApplicationMenu(menu);
}
```

### 1.3 常用 Role（内置角色）

Electron 内置了大量常用菜单角色，无需自己实现功能：

| Role | 功能 | 快捷键 |
|------|------|--------|
| `undo` | 撤销 | CmdOrCtrl+Z |
| `redo` | 重做 | CmdOrCtrl+Shift+Z |
| `cut` | 剪切 | CmdOrCtrl+X |
| `copy` | 复制 | CmdOrCtrl+C |
| `paste` | 粘贴 | CmdOrCtrl+V |
| `selectAll` | 全选 | CmdOrCtrl+A |
| `reload` | 刷新页面 | CmdOrCtrl+R |
| `forceReload` | 强制刷新 | CmdOrCtrl+Shift+R |
| `toggleDevTools` | 切换 DevTools | F12 |
| `resetZoom` | 重置缩放 | CmdOrCtrl+0 |
| `zoomIn` | 放大 | CmdOrCtrl+= |
| `zoomOut` | 缩小 | CmdOrCtrl+- |
| `togglefullscreen` | 切换全屏 | F11 |
| `minimize` | 最小化 | — |
| `close` | 关闭窗口 | CmdOrCtrl+W |
| `quit` | 退出应用 | — |
| `about` | 关于对话框 | — |
| `hide` | 隐藏应用（macOS） | Cmd+H |

## 2. 上下文菜单（Context Menu / 右键菜单）

### 2.1 主进程创建上下文菜单

```typescript
import { Menu, MenuItem, BrowserWindow } from 'electron';

// 监听渲染进程的右键菜单请求
ipcMain.on('show-context-menu', (_event, contextType: string) => {
  const win = BrowserWindow.fromWebContents(_event.sender);
  if (!win) return;

  let template: Electron.MenuItemConstructorOptions[];

  switch (contextType) {
    case 'editor':
      template = [
        { role: 'cut' },
        { role: 'copy' },
        { role: 'paste' },
        { type: 'separator' },
        { role: 'selectAll' },
      ];
      break;
    case 'file-list':
      template = [
        { label: '重命名', click: () => _event.sender.send('context-action', 'rename') },
        { label: '删除', click: () => _event.sender.send('context-action', 'delete') },
        { type: 'separator' },
        { label: '在文件管理器中打开', click: () => _event.sender.send('context-action', 'reveal') },
      ];
      break;
    default:
      template = [{ role: 'copy' }];
  }

  const menu = Menu.buildFromTemplate(template);
  menu.popup({ window: win });
});
```

### 2.2 渲染进程触发右键菜单

```typescript
// 渲染进程中
document.addEventListener('contextmenu', (e) => {
  e.preventDefault();

  // 判断右键目标类型
  const target = e.target as HTMLElement;
  if (target.closest('.editor')) {
    window.electronAPI.showContextMenu('editor');
  } else if (target.closest('.file-list')) {
    window.electronAPI.showContextMenu('file-list');
  }
});
```

## 3. 系统对话框（Dialog）

### 3.1 打开文件对话框

```typescript
// 主进程
import { dialog, BrowserWindow } from 'electron';

ipcMain.handle('dialog:open-file', async (_event) => {
  const win = BrowserWindow.fromWebContents(_event.sender);
  if (!win) return null;

  const result = await dialog.showOpenDialog(win, {
    title: '打开文件',
    defaultPath: app.getPath('documents'),
    filters: [
      { name: 'Markdown', extensions: ['md', 'markdown'] },
      { name: '文本文件', extensions: ['txt'] },
      { name: '所有文件', extensions: ['*'] },
    ],
    properties: ['openFile'],  // 也可用 ['openDirectory'] 选文件夹
    // 多选：properties: ['openFile', 'multiSelections']
  });

  if (result.canceled) return null;
  return result.filePaths[0];
});
```

### 3.2 保存文件对话框

```typescript
ipcMain.handle('dialog:save-file', async (_event, defaultName?: string) => {
  const win = BrowserWindow.fromWebContents(_event.sender);
  if (!win) return null;

  const result = await dialog.showSaveDialog(win, {
    title: '保存文件',
    defaultPath: path.join(app.getPath('documents'), defaultName ?? 'untitled.md'),
    filters: [
      { name: 'Markdown', extensions: ['md'] },
      { name: '所有文件', extensions: ['*'] },
    ],
  });

  if (result.canceled) return null;
  return result.filePath;
});
```

### 3.3 消息对话框

```typescript
// 信息提示
ipcMain.handle('dialog:info', async (_event, title: string, message: string) => {
  const win = BrowserWindow.fromWebContents(_event.sender);
  await dialog.showMessageBox(win!, {
    type: 'info',
    title,
    message,
    buttons: ['确定'],
  });
});

// 确认对话框（返回用户选择的按钮索引）
ipcMain.handle('dialog:confirm', async (_event, title: string, message: string) => {
  const win = BrowserWindow.fromWebContents(_event.sender);
  const result = await dialog.showMessageBox(win!, {
    type: 'warning',
    title,
    message,
    buttons: ['确定', '取消'],
    defaultId: 0,
    cancelId: 1,
  });
  return result.response === 0; // true = 确定，false = 取消
});

// 错误对话框
ipcMain.handle('dialog:error', async (_event, title: string, message: string) => {
  const win = BrowserWindow.fromWebContents(_event.sender);
  await dialog.showMessageBox(win!, {
    type: 'error',
    title,
    message,
    buttons: ['确定'],
  });
});
```

### 3.4 对话框类型速查

| type 值 | 图标 | 适用场景 |
|---------|------|---------|
| `'info'` | ℹ️ | 信息提示 |
| `'warning'` | ⚠️ | 警告确认 |
| `'error'` | ❌ | 错误提示 |
| `'question'` | ❓ | 提问（默认无图标） |
| `'none'` | 无 | 无图标 |

## 4. 通知系统（Notification）

```typescript
// 主进程
import { Notification } from 'electron';

// 基本通知
new Notification({
  title: '保存成功',
  body: '文件已保存到 Documents 目录',
}).show();

// 带点击事件的通知
const notification = new Notification({
  title: '新版本可用',
  body: 'v2.0.0 已发布，点击查看更新内容',
});

notification.on('click', () => {
  // 点击通知后打开更新页面
  mainWindow.webContents.send('menu-action', 'show-update');
});

notification.on('close', () => {
  console.log('通知已关闭');
});

notification.show();
```

> **注意**：macOS 的通知需要应用签名后才能正常显示。开发阶段未签名时，通知可能不显示或显示为 `electron` 应用的通知。

## 5. 快捷键（Accelerator）

### 5.1 菜单内嵌快捷键

最简单的方式——直接在菜单项中设置 `accelerator`：

```typescript
{
  label: '保存',
  accelerator: 'CmdOrCtrl+S',  // macOS: Cmd+S, Windows/Linux: Ctrl+S
  click: () => { /* ... */ },
}
```

### 5.2 常用快捷键格式

| 按键 | 说明 |
|------|------|
| `CmdOrCtrl` | macOS 上是 Cmd，Windows/Linux 上是 Ctrl |
| `Ctrl` | Ctrl 键 |
| `Shift` | Shift 键 |
| `Alt` | Alt 键（macOS 上是 Option） |
| `Super` | macOS 上是 Cmd，Windows 上是 Win 键 |
| `F1` ~ `F24` | 功能键 |
| `Delete` | 删除键 |
| `Space` | 空格键 |
| `Tab` | Tab 键 |

组合示例：

```typescript
'CmdOrCtrl+N'          // 新建
'CmdOrCtrl+Shift+S'    // 另存为
'CmdOrCtrl+Alt+I'      // 打开 DevTools（自定义）
'CmdOrCtrl+Shift+Z'    // 重做
'CmdOrCtrl+[Shift]+Tab'// 切换标签页
```

## ✏️ 练习

### 练习 1：创建完整的应用菜单

**要求**：
1. 创建包含"文件"、"编辑"、"视图"三个菜单的应用菜单
2. 文件菜单：新建、打开、保存（带快捷键）
3. 编辑菜单：使用内置 role（undo/redo/copy/paste）
4. 视图菜单：DevTools 开关、全屏、缩放

**验收标准**：菜单在 macOS 和 Windows 上都能正常显示，快捷键可以触发对应操作。

### 练习 2：实现文件打开 + 读取

**要求**：
1. 点击"打开"菜单 → 弹出文件选择对话框
2. 选择文件后，通过 IPC 读取文件内容
3. 在渲染进程中显示文件内容

**验收标准**：完整走通"菜单点击 → 对话框 → 文件读取 → 内容显示"的流程。

### 练习 3：实现上下文菜单

**要求**：
1. 在渲染进程中监听 `contextmenu` 事件
2. 右键时通过 IPC 通知主进程弹出上下文菜单
3. 上下文菜单包含：复制、粘贴、全选

**验收标准**：右键弹出自定义菜单，点击菜单项可以触发对应操作。

## 📝 面试回答模板

> **问：Electron 的菜单系统是怎样的？**
>
> Electron 支持三种菜单：应用菜单（Application Menu）、上下文菜单（Context Menu）和系统托盘菜单。应用菜单在 macOS 上显示在屏幕顶部菜单栏，在 Windows 上嵌在窗口标题栏下方。通过 `Menu.buildFromTemplate` 创建菜单模板，支持内置 role（如 copy、paste、undo）和自定义 click 处理器。菜单事件通过 IPC 发送给渲染进程——菜单运行在主进程中，点击后通过 `webContents.send` 通知渲染进程执行对应操作。

> **问：Electron 的对话框怎么用？**
>
> Electron 的 `dialog` 模块调用的是系统原生对话框，包括打开文件、保存文件、消息提示三种。都支持 Promise API（`showOpenDialog`、`showSaveDialog`、`showMessageBox`）。需要注意的是，对话框必须在主进程中调用，渲染进程通过 IPC 发起请求。另外建议传入父窗口参数（`BrowserWindow` 实例），这样对话框会模态地附着在窗口上，用户体验更好。

> **问：macOS 和 Windows 的菜单有什么区别？**
>
> 最大的区别是 macOS 的第一个菜单项会被系统强制替换为应用名称，包含"关于"、"服务"、"隐藏"、"退出"等系统级操作。所以 macOS 需要额外的应用菜单（`app.name`）。另一个区别是退出行为——macOS 关闭所有窗口不退出应用（需要 Cmd+Q 或菜单退出），Windows 关闭最后一个窗口就退出。这些差异需要在代码中用 `process.platform === 'darwin'` 做条件处理。
