# React Native 新手入门教程

> 面向有 React Web 经验的前端工程师，系统掌握 React Native 跨端开发 —— 从选型认知到独立上线 App。

---

## 🎯 学习目标

- 理解跨端技术的四大流派及其核心原理
- 掌握 React Native 的环境搭建、核心组件、导航路由、网络请求、状态管理
- 能调用设备能力（相机、定位、权限）
- 独立完成一个完整 App 的开发、调试与发布
- 面试时能清晰对比 RN / Flutter / 小程序 / Electron 的选型取舍

---

## 📋 前置要求

| 领域 | 要求 |
|------|------|
| React | 熟悉组件、JSX、Hooks（useState / useEffect）、Props |
| JavaScript | ES6+ 语法，Promise / async-await |
| TypeScript | 基础类型定义（可选但推荐） |
| 移动端概念 | 了解 iOS / Android 的基本区别即可 |

## 🆚 跨端技术面试对比总表

| 维度 | React Native | Flutter | 小程序 | Electron | 原生开发 |
|------|-------------|---------|--------|----------|---------|
| **渲染方式** | JS Bridge → Native Widget | Skia 自绘引擎 | WebView + 原生混合 | Chromium + Node.js | 平台原生 API |
| **跨端范围** | iOS / Android / Web | iOS / Android / Web / Desktop | 特定 App 生态内 | Mac / Windows / Linux | 单平台 |
| **性能** | 接近原生（桥接有损耗） | 优秀（自绘引擎） | 中等（WebView 限制） | 较高（资源占用大） | 最佳 |
| **热重载** | ✅ Fast Refresh | ✅ Stateful Hot Reload | ❌ 需编译 | ✅ HMR | ❌ 需编译 |
| **学习成本** | 低（有 React 基础） | 中（需学 Dart） | 低（Web 技术栈） | 低（Web 技术栈） | 高（需双端语言） |
| **生态成熟度** | 高（第三方库丰富） | 较成熟 | 微信生态闭环 | 成熟（npm 全量） | 平台特有 |
| **适用场景** | 跨端 App、MVP 快速验证 | 高性能跨端 App、UI 一致性要求高 | 微信生态内工具/电商 | 桌面端 IDE/工具 | 高性能/平台深度集成 |

## 📝 学习建议

- 按 **认知 → 思维 → 应用 → 工程** 的顺序不可跳，前三层地基打牢了，工程层才不慌
- 每个模块都有 **✏️ 练习**，建议动手敲而不是只看文档
- 遇到红屏不要慌 —— `10-新手高频坑点与解决方案.md` 里收录了最常见的问题
- 如果你对某个模块已经很熟悉，可以直接跳到下一个，但建议扫一眼面试问答部分
