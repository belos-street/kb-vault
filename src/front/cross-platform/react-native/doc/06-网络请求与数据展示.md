# 06 — 网络请求与数据展示

> 对应大纲：应用层 | 预计时间：2 天（含练习）
> 面试可答：RN 内置 fetch API，用法跟 Web 完全一致，但没有浏览器的 CORS 限制。生产项目推荐 Axios + React Query 组合——Axios 管请求层（拦截器/取消/错误处理），React Query 管缓存层（自动缓存/轮询/分页/乐观更新）。列表渲染用 FlatList + 服务端分页，避免一次加载全量数据。

---

## 1. RN 的网络环境

RN 运行在手机端的 JS 引擎中，网络请求跟 Web 几乎一样，但有几个关键差异：

| 维度 | Web 浏览器 | React Native |
|------|-----------|-------------|
| CORS 限制 | 有（跨域需要服务端配合） | **无**（没有浏览器安全沙箱） |
| Cookie | 浏览器自动管理 | 需要手动处理 |
| 证书校验 | 浏览器自动校验 | 可做 SSL Pinning |
| 网络状态 | `navigator.onLine` | `@react-native-community/netinfo` |
| 请求取消 | `AbortController` | 同样支持 |

> **无 CORS 限制**是 RN 的一大优势——你可以直接请求任何 API，不需要代理或后端开 CORS。

## 2. Fetch API

RN 内置 `fetch`，用法跟浏览器完全一致。

### 2.1 GET 请求

```tsx
// 基础 GET
const response = await fetch('https://api.example.com/users');
const users = await response.json();

// 带查询参数
const response = await fetch(
  `https://api.example.com/users?page=${page}&limit=20`
);
const { data, total } = await response.json();
```

### 2.2 POST 请求

```tsx
const response = await fetch('https://api.example.com/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`,
  },
  body: JSON.stringify({ name: 'Alice', email: 'alice@example.com' }),
});

if (!response.ok) {
  throw new Error(`HTTP ${response.status}`);
}

const newUser = await response.json();
```

### 2.3 Fetch 的局限

| 问题 | 说明 |
|------|------|
| 不自动抛错误 | `fetch` 只在网络故障时 reject，HTTP 4xx/5xx 不会 throw |
| 没有拦截器 | 无法统一处理 token 注入、错误提示、日志 |
| 没有请求取消的简洁方案 | 需要手动用 `AbortController` |
| 没有超时控制 | 需要自己实现 `Promise.race` |
| 没有自动重试 | 网络抖动时需要手动重试 |

这些问题在小项目中可以忍受，但生产项目推荐用 **Axios**。

## 3. Axios

### 3.1 安装与基础配置

```bash
npm install axios
```

```tsx
// services/api.ts
import axios from 'axios';

const api = axios.create({
  baseURL: 'https://api.example.com',
  timeout: 10000,
  headers: { 'Content-Type': 'application/json' },
});

// 请求拦截器：统一注入 token
api.interceptors.request.use((config) => {
  const token = getToken(); // 从存储中获取
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// 响应拦截器：统一处理错误
api.interceptors.response.use(
  (response) => response.data,
  (error) => {
    if (error.response?.status === 401) {
      // token 过期，跳转登录
      navigateToLogin();
    }
    return Promise.reject(error);
  }
);

export default api;
```

### 3.2 各种请求方式

```tsx
import api from './services/api';

// GET
const users = await api.get('/users', { params: { page: 1 } });

// POST
const newUser = await api.post('/users', { name: 'Alice' });

// PUT（全量更新）
await api.put('/users/123', { name: 'Alice', email: 'new@example.com' });

// PATCH（部分更新）
await api.patch('/users/123', { name: 'Bob' });

// DELETE
await api.delete('/users/123');
```

### 3.3 请求取消

```tsx
import { useRef, useEffect } from 'react';

function UserProfile({ userId }) {
  const cancelTokenRef = useRef(null);

  useEffect(() => {
    // 取消上一次请求
    cancelTokenRef.current?.abort();
    cancelTokenRef.current = new AbortController();

    fetch(`/users/${userId}`, { signal: cancelTokenRef.current.signal })
      .then((res) => res.json())
      .then(setUser)
      .catch((err) => {
        if (err.name !== 'AbortError') throw err;
      });

    return () => cancelTokenRef.current?.abort();
  }, [userId]);
}
```

### 3.4 Axios 请求取消

Axios v0.22+ 也支持 `AbortController`，写法更简洁：

```tsx
import { useEffect } from 'react';
import api from './services/api';

function UserProfile({ userId }) {
  useEffect(() => {
    const controller = new AbortController();

    api.get(`/users/${userId}`, {
      signal: controller.signal,
    }).then(setUser).catch((err) => {
      if (err.name !== 'CanceledError') throw err;
    });

    return () => controller.abort();
  }, [userId]);
}
```

> React Query 内部已经处理了请求取消和竞态问题，直接用它就不需要手动管理 cancel。

## 4. React Query（TanStack Query）

React Query 是当前 RN 生态中最流行的服务端状态管理方案。它不替代 Axios，而是在 Axios 之上提供**缓存、轮询、分页、乐观更新、后台刷新**等能力。

### 4.1 安装与配置

```bash
npm install @tanstack/react-query
```

```tsx
// App.tsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      retry: 2,                // 失败重试 2 次
      staleTime: 5 * 60 * 1000, // 数据 5 分钟内视为新鲜
      gcTime: 10 * 60 * 1000,   // 缓存 10 分钟后垃圾回收
    },
  },
});

export default function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <NavigationContainer>
        {/* ... */}
      </NavigationContainer>
    </QueryClientProvider>
  );
}
```

### 4.2 useQuery：数据获取

```tsx
import { useQuery } from '@tanstack/react-query';
import api from './services/api';

function UserList() {
  const { data, isLoading, error, refetch, isFetching } = useQuery({
    queryKey: ['users'],          // 缓存的 key
    queryFn: () => api.get('/users'),
  });

  if (isLoading) return <ActivityIndicator />;
  if (error) return <Text>加载失败: {error.message}</Text>;

  return (
    <FlatList
      data={data}
      renderItem={({ item }) => <Text>{item.name}</Text>}
      refreshing={isFetching}
      onRefresh={refetch}
    />
  );
}
```

### 4.3 带参数的查询

```tsx
// 用户详情（依赖 userId 参数）
function useUser(userId: string) {
  return useQuery({
    queryKey: ['user', userId],   // key 带参数，每个用户独立缓存
    queryFn: () => api.get(`/users/${userId}`),
    enabled: !!userId,            // userId 为空时不发请求
  });
}

function UserProfile({ userId }) {
  const { data: user, isLoading } = useUser(userId);

  if (isLoading) return <ActivityIndicator />;
  return <Text>{user.name}</Text>;
}
```

### 4.4 useMutation：数据修改

```tsx
import { useMutation, useQueryClient } from '@tanstack/react-query';

function CreateUserScreen() {
  const queryClient = useQueryClient();

  const mutation = useMutation({
    mutationFn: (newUser) => api.post('/users', newUser),
    onSuccess: () => {
      // 修改成功后，重新获取用户列表
      queryClient.invalidateQueries({ queryKey: ['users'] });
      Alert.alert('成功', '用户已创建');
    },
    onError: (error) => {
      Alert.alert('失败', error.message);
    },
  });

  return (
    <Pressable
      onPress={() => mutation.mutate({ name: 'Alice', email: 'alice@example.com' })}
      disabled={mutation.isPending}
    >
      <Text>{mutation.isPending ? '创建中...' : '创建用户'}</Text>
    </Pressable>
  );
}
```

### 4.5 分页查询

```tsx
import { useInfiniteQuery } from '@tanstack/react-query';

function ArticleList() {
  const {
    data,
    fetchNextPage,
    hasNextPage,
    isFetchingNextPage,
    isLoading,
  } = useInfiniteQuery({
    queryKey: ['articles'],
    queryFn: ({ pageParam = 1 }) => api.get(`/articles?page=${pageParam}`),
    getNextPageParam: (lastPage) => {
      return lastPage.hasMore ? lastPage.nextPage : undefined;
    },
  });

  // 所有页的数据平铺
  const articles = data?.pages.flatMap((page) => page.data) ?? [];

  if (isLoading) return <ActivityIndicator />;

  return (
    <FlatList
      data={articles}
      keyExtractor={(item) => String(item.id)}
      renderItem={({ item }) => <ArticleCard article={item} />}
      onEndReached={() => { if (hasNextPage) fetchNextPage(); }}
      onEndReachedThreshold={0.3}
      ListFooterComponent={
        isFetchingNextPage ? <ActivityIndicator /> : null
      }
    />
  );
}
```

### 4.6 缓存策略

```
数据新鲜度生命周期：

  请求发出 → 数据返回 → staleTime 内（新鲜）→ staleTime 后（过期）→ gcTime 后（清除）
                         直接用缓存           后台 refetch           完全删除

┌─────────────────────────────────────────────────────────┐
│  staleTime: 0（默认）                                    │
│  每次组件挂载都重新请求                                    │
├─────────────────────────────────────────────────────────┤
│  staleTime: 5min                                        │
│  5 分钟内直接用缓存，之后后台静默刷新                       │
├─────────────────────────────────────────────────────────┤
│  gcTime: 10min（默认）                                   │
│  缓存页面 10 分钟后被垃圾回收                              │
└─────────────────────────────────────────────────────────┘
```

| 场景 | staleTime | gcTime |
|------|----------|--------|
| 频繁变化的数据（聊天消息） | `0` | `30s` |
| 偶尔变化的数据（用户列表） | `5min` | `10min` |
| 很少变化的数据（配置/字典） | `30min` | `1h` |
| 不会变的数据（文章详情） | `Infinity` | `Infinity` |

## 5. 错误处理

### 5.1 全局错误处理

```tsx
// services/api.ts
api.interceptors.response.use(
  (response) => response.data,
  (error) => {
    const message = error.response?.data?.message
      ?? error.message
      ?? '网络请求失败';

    // 统一 Toast 提示（ToastAndroid 只在 Android 生效，iOS 需要替代方案）
    if (Platform.OS === 'android') {
      ToastAndroid.show(message, ToastAndroid.SHORT);
    } else {
      Alert.alert('', message); // 或使用 react-native-toast-message 等跨端方案
    }

    // 401 跳登录
    if (error.response?.status === 401) {
      // 清除 token，跳转登录
    }

    return Promise.reject(error);
  }
);
```

import NetInfo from '@react-native-community/netinfo';
import { useEffect, useState } from 'react';

function useNetworkStatus() {
  const [isConnected, setIsConnected] = useState(true);

  useEffect(() => {
    const unsubscribe = NetInfo.addEventListener((state) => {
      setIsConnected(state.isConnected ?? false);
    });

}

import api from './api';
import type { User, CreateUserDTO } from '../types/api';

export const userApi = {
  list: (params?: { page?: number; keyword?: string }) =>
    api.get<{ data: User[]; total: number }>('/users', { params }),

### 6.3 Hook 封装

```tsx
// hooks/useUsers.ts
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';
import { userApi } from '../services/userApi';

export function useUserList(params?: { page?: number; keyword?: string }) {
  return useQuery({
    queryKey: ['users', params],
    queryFn: () => userApi.list(params),
  });
}

export function useUserDetail(id: string) {
  return useQuery({
    queryKey: ['user', id],
    queryFn: () => userApi.detail(id),
    enabled: !!id,
  });
}

export function useCreateUser() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: userApi.create,
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['users'] });
    },
  });
}

export function useDeleteUser() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: userApi.delete,
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['users'] });
    },
  });
}
```

## 8. WebSocket

### 8.1 基础用法

```tsx
import { useEffect, useRef, useState } from 'react';

function useWebSocket(url: string) {
  const ws = useRef<WebSocket | null>(null);
  const [messages, setMessages] = useState<string[]>([]);
  const [isConnected, setIsConnected] = useState(false);

  useEffect(() => {
    ws.current = new WebSocket(url);

    ws.current.onopen = () => setIsConnected(true);
    ws.current.onclose = () => setIsConnected(false);
    ws.current.onmessage = (event) => {
      setMessages((prev) => [...prev, event.data]);
    };
    ws.current.onerror = (error) => {
      console.error('WebSocket error:', error);
    };

    return () => ws.current?.close();
  }, [url]);

  const send = (message: string) => {
    ws.current?.send(message);
  };

  return { messages, isConnected, send };
}

// 使用
function ChatScreen() {
  const { messages, isConnected, send } = useWebSocket('wss://echo.websocket.org');

  return (
    <View style={{ flex: 1 }}>
      <Text>状态: {isConnected ? '已连接' : '未连接'}</Text>
      <FlatList
        data={messages}
        renderItem={({ item }) => <Text>{item}</Text>}
      />
      <Pressable onPress={() => send('Hello!')}>
        <Text>发送</Text>
      </Pressable>
    </View>
  );
}
```

## 📝 面试回答模板

> **问：RN 中怎么做网络请求？跟 Web 有什么区别？**
>
> RN 内置 fetch API，用法跟浏览器完全一样。最大的区别是 RN 没有 CORS 限制，可以直接请求任何 API。生产项目推荐用 Axios，它的拦截器机制方便统一注入 token、处理错误和日志。然后在 Axios 之上用 React Query 管理服务端状态——它提供自动缓存、后台刷新、分页加载、乐观更新等能力，大幅减少了手写 useEffect + useState + loading + error 的样板代码。

> **问：React Query 解决了什么问题？**
>
> 它解决的核心问题是"服务端状态管理"。传统做法中，每个数据获取都要写 useEffect + useState + loading + error，还要处理缓存、竞态、分页、后台刷新等逻辑，代码量很大且容易出 bug。React Query 把这些逻辑封装成声明式的 Hook——useQuery 一行代码就能处理缓存、重试、竞态、后台刷新；useInfiniteQuery 处理分页加载；useMutation 处理数据修改并自动刷新关联缓存。

> **问：怎么处理网络错误和断网场景？**
>
> 三层策略。第一层，Axios 响应拦截器统一处理 HTTP 错误码（401 跳登录、403 提示无权限、500 提示服务器错误）。第二层，React Query 的 retry 配置自动重试（默认 3 次），error 状态在组件中展示错误 UI 和重试按钮。第三层，用 @react-native-community/netinfo 监听网络状态变化，断网时显示离线提示，恢复网络后自动 refetch。
