# 11 — 常用第三方库与生态精选

> 对应大纲：生态速查 | 预计时间：1 天（通读）+ 按需深入
> 面试可答：RN 生态成熟度高，核心场景都有主流方案——导航用 React Navigation，UI 用 NativeBase / RN Paper，网络用 Axios / React Query，动画用 Reanimated，状态管理用 Zustand / Redux Toolkit。

> 本篇为生态速查文档，练习环节省略。建议在实际项目选型时按决策树查阅对应小节。

---

## 1. 选库原则

RN 生态库数量庞大，但质量参差不齐。选库时优先看：

| 维度 | 判断标准 |
|------|----------|
| **维护活跃度** | 最近 3 个月内有 release，issue 有回复 |
| **RN 版本兼容** | 明确支持 New Architecture (Fabric / TurboModules) |
| **双端一致性** | iOS / Android 行为一致，或差异有文档说明 |
| **社区规模** | GitHub star > 1k，npm 周下载 > 10k |
| **TypeScript 支持** | 自带类型定义或有 `@types/*` 包 |

> 不要为了"新"而换库，稳定 > 潮流。一个维护良好的老库远胜于一个 star 增长快但核心开发者只有一个人的新库。

## 2. 导航路由

| 库 | 定位 | 推荐度 |
|-----|------|--------|
| **React Navigation** | JS 实现的导航方案，社区标准 | ⭐⭐⭐⭐⭐ |
| **Expo Router** | 基于 React Navigation 的文件路由（类似 Next.js） | ⭐⭐⭐⭐ |
| **React Native Navigation (Wix)** | 原生实现的导航，性能更好但接入复杂 | ⭐⭐⭐ |

**推荐**：绝大多数项目用 **React Navigation** 就够了。如果你用 Expo 全家桶，Expo Router 的开发体验更好。

```bash
# React Navigation 核心包
npm install @react-navigation/native @react-navigation/native-stack @react-navigation/bottom-tabs
# 必需的 peer dependencies
npm install react-native-screens react-native-safe-area-context
```

## 3. UI 组件库

| 库 | 风格 | 推荐度 |
|-----|------|--------|
| **Tamagui** | 跨端（Web + RN）统一 UI，编译时优化 | ⭐⭐⭐⭐⭐ |
| **gluestack-ui** | Tailwind 风格，NativeBase 团队出品，组件丰富 | ⭐⭐⭐⭐ |
| **React Native Paper (by Callstack)** | Material Design 风格，API 简洁 | ⭐⭐⭐⭐ |
| **NativeBase** | 高度可定制，自带主题系统（维护已放缓，建议评估 gluestack-ui） | ⭐⭐⭐ |
| **Ant Design Mobile RN** | Ant Design 移动版，适合已有 Ant Design 经验的团队 | ⭐⭐⭐ |
| **Shoutem UI** | 简洁风格，组件少但质量高 | ⭐⭐⭐ |

**推荐**：
- 追求 **跨端一致性**（Web + RN 同一套代码）→ Tamagui
- 追求 **组件丰富度 + 定制能力** → gluestack-ui（NativeBase 团队新作，推荐替代 NativeBase）
- 团队已有 **Ant Design** 经验 → Ant Design Mobile RN
- 简单项目 / Material Design 风格 → React Native Paper

## 4. 网络请求与数据管理

| 库 | 定位 | 推荐度 |
|-----|------|--------|
| **Axios** | HTTP 客户端，拦截器/取消请求完善 | ⭐⭐⭐⭐⭐ |
| **React Query (TanStack Query)** | 服务端状态管理（缓存/轮询/分页/乐观更新） | ⭐⭐⭐⭐⭐ |
| **SWR** | 轻量级数据获取 + 缓存（Vercel 出品） | ⭐⭐⭐⭐ |
| **RTK Query** | Redux Toolkit 内置的数据获取方案 | ⭐⭐⭐⭐ |
| **ofetch** | 轻量 fetch 封包（Unjs 出品，Nuxt 默认） | ⭐⭐⭐ |

**推荐组合**：**Axios + React Query** 是当前最主流的搭配。Axios 管请求层，React Query 管缓存层。

```bash
npm install axios @tanstack/react-query
```

> 如果你的 App 已经用了 Redux Toolkit，可以优先考虑 RTK Query，避免引入额外依赖。

## 5. 状态管理

| 库 | 理念 | 推荐度 |
|-----|------|--------|
| **Zustand** | 极简 API，无 boilerplate，支持中间件 | ⭐⭐⭐⭐⭐ |
| **Jotai** | 原子化状态（类似 Recoil 思路） | ⭐⭐⭐⭐ |
| **Redux Toolkit** | 经典方案，大团队/大项目首选 | ⭐⭐⭐⭐ |
| **MobX** | 响应式，适合复杂对象图 | ⭐⭐⭐ |
| **Valtio** | Proxy 响应式，API 极简 | ⭐⭐⭐ |
| **Legend-State** | 高性能响应式，支持持久化 + 同步 | ⭐⭐⭐ |

**推荐**：
- 新项目/小团队 → **Zustand**（学习成本最低，API 最简洁）
- 已有 Redux 经验 / 大团队协作 → **Redux Toolkit**
- 复杂表单 / 大量派生状态 → **Jotai**（原子化粒度更细）

```bash
# Zustand
npm install zustand

# 基础用法
import { create } from 'zustand'

const useStore = create((set) => ({
  count: 0,
  increment: () => set((s) => ({ count: s.count + 1 })),
}))
```

## 6. 动画与手势

| 库 | 定位 | 推荐度 |
|-----|------|--------|
| **React Native Reanimated** | 声明式动画，UI 线程执行，性能极佳 | ⭐⭐⭐⭐⭐ |
| **React Native Gesture Handler** | 原生手势系统，替代 RN 自带 PanResponder | ⭐⭐⭐⭐⭐ |
| **Lottie React Native** | After Effects 动画渲染（Airbnb 出品） | ⭐⭐⭐⭐ |
| **Moti** | 基于 Reanimated 的声明式动画组件 | ⭐⭐⭐⭐ |
| **React Native Skia** | GPU 加速的 2D 绘图（Shopify 出品） | ⭐⭐⭐⭐ |
| **Rive React Native** | 交互式矢量动画（比 Lottie 更强大） | ⭐⭐⭐ |

**推荐**：
- 大多数动画需求 → **Reanimated + Gesture Handler**（这俩几乎是必装的）
- 设计师给 Lottie JSON → **Lottie**
- 复杂自绘 / 游戏 / 数据可视化 → **React Native Skia**

```bash
npm install react-native-reanimated react-native-gesture-handler
```

> Reanimated 需要在 `babel.config.js` 中添加插件：
> ```js
> plugins: ['react-native-reanimated/plugin']
> ```

## 7. 本地存储

| 库 | 定位 | 推荐度 |
|-----|------|--------|
| **AsyncStorage** | 简单 KV 存储（RN 社区维护） | ⭐⭐⭐⭐ |
| **MMKV** | 高性能 KV 存储（微信出品），同步读写 | ⭐⭐⭐⭐⭐ |
| **WatermelonDB** | 关系型数据库，支持同步/离线优先 | ⭐⭐⭐⭐ |
| **SQLite (op-sqlite)** | SQLite 绑定，适合复杂查询 | ⭐⭐⭐⭐ |
| **Secure Storage (expo-secure-store)** | 加密存储（Keychain / Keystore） | ⭐⭐⭐⭐ |

**推荐**：
- 简单配置/缓存 → **MMKV**（比 AsyncStorage 快 30 倍，且同步读写）
- 结构化数据/离线优先 → **WatermelonDB** 或 **SQLite**
- Token/密码等敏感信息 → **Secure Storage**（不要用 KV 存密码）

```bash
# MMKV
npm install react-native-mmkv

import { MMKV } from 'react-native-mmkv'
const storage = new MMKV()
storage.set('user.name', 'Alice')
const name = storage.getString('user.name') // 同步读取，无需 await
```

## 8. 样式方案

| 库 | 定位 | 推荐度 |
|-----|------|--------|
| **StyleSheet（内置）** | RN 原生方案，简单直接 | ⭐⭐⭐⭐ |
| **Nativewind** | Tailwind CSS for RN，编译时转换 | ⭐⭐⭐⭐ |

| **Dripsy** | 响应式主题系统，轻量 | ⭐⭐⭐ |

**推荐**：

- Web 迁移团队 → **Styled Components**（迁移成本最低）

## 9. 表单与输入

| 库 | 定位 | 推荐度 |
|-----|------|--------|
| **React Hook Form** | 性能优秀的表单管理，支持 validation | ⭐⭐⭐⭐⭐ |
| **Formik** | 经典表单方案，API 成熟 | ⭐⭐⭐⭐ |
| **Zod** | Schema 校验（常与 React Hook Form 搭配） | ⭐⭐⭐⭐⭐ |

**推荐**：**React Hook Form + Zod** 是当前最优组合。

```bash
npm install react-hook-form zod @hookform/resolvers

import { useForm } from 'react-hook-form'
import { zodResolver } from '@hookform/resolvers/zod'
import { z } from 'zod'

const schema = z.object({
  email: z.string().email(),
  password: z.string().min(8),
})

const { control, handleSubmit } = useForm({
  resolver: zodResolver(schema),
})
```

## 10. 工具类

| 库 | 定位 | 推荐度 |
|-----|------|--------|
| **date-fns** | 日期处理（tree-shaking 友好） | ⭐⭐⭐⭐⭐ |
| **Lodash** | 通用工具函数（按需引入） | ⭐⭐⭐⭐ |
| **i18next / react-i18next** | 国际化 | ⭐⭐⭐⭐⭐ |
| **React Native Fast Image** | 高性能图片加载（缓存 + 预加载） | ⭐⭐⭐⭐ |

| **React Native SVG** | SVG 渲染 | ⭐⭐⭐⭐ |

**重点推荐**：

```bash

import { FlashList } from '@shopify/flash-list'

<FlashList
  data={items}
  renderItem={({ item }) => <Text>{item.title}</Text>}
  estimatedItemSize={80}
/>
```

## 11. 测试

| 工具 | 定位 | 推荐度 |
|------|------|--------|
| **Jest** | 单元测试 + 快照测试（RN 默认集成） | ⭐⭐⭐⭐⭐ |
| **React Native Testing Library** | 组件测试（行为驱动，非实现细节） | ⭐⭐⭐⭐⭐ |
| **Maestro** | E2E UI 测试（声明式 YAML，易上手） | ⭐⭐⭐⭐ |
| **Detox** | E2E 测试（更底层，控制力强） | ⭐⭐⭐⭐ |
| **Storybook** | 组件库文档 + 可视化测试 | ⭐⭐⭐⭐ |
| **Cypress** | Web 端 E2E（仅用于 Expo Web） | ⭐⭐⭐ |

**推荐组合**：
- 单元 + 组件测试 → **Jest + RN Testing Library**
- E2E 测试 → **Maestro**（新项目首选，学习成本低）或 **Detox**（对原生交互控制更细）

```bash
# 安装 RN Testing Library
npm install @testing-library/react-native
```

```tsx
// __tests__/Button.test.tsx
import { render, fireEvent } from '@testing-library/react-native';

test('按钮点击触发回调', () => {
  const onPress = jest.fn();
  const { getByText } = render(<Pressable onPress={onPress}><Text>点击</Text></Pressable>);
  fireEvent.press(getByText('点击'));
  expect(onPress).toHaveBeenCalledTimes(1);
});
```

## 13. 快速选型决策树

```
需要什么？
├── 导航路由 → React Navigation
├── UI 组件
│   ├── 跨端统一 (Web+RN) → Tamagui
│   ├── 高度可定制 → gluestack-ui
│   └── Material Design 风格 → React Native Paper
├── 数据请求
│   ├── 简单请求 → Axios
│   └── 需要缓存/轮询/分页 → Axios + React Query
├── 状态管理
│   ├── 小项目 → Zustand
│   ├── 大团队/已有 Redux → Redux Toolkit
│   └── 复杂派生状态 → Jotai
├── 动画
│   ├── 基础动画 → Reanimated
│   ├── Lottie 动画 → Lottie
│   └── 自绘/游戏 → Skia
├── 存储
│   ├── 简单 KV → MMKV
│   ├── 结构化数据 → SQLite / WatermelonDB
│   └── 敏感信息 → Secure Storage
├── 列表 → FlashList（替代 FlatList）
├── 表单 → React Hook Form + Zod
└── 测试
    ├── 单元/组件测试 → Jest + RN Testing Library
    └── E2E 测试 → Maestro / Detox
```

## 14. 附：Expo 生态速查

如果你用 Expo 管理项目，很多常用功能已经有官方封装：

| 需求 | Expo 包 |
|------|---------|
| 相机 | `expo-camera` |
| 定位 | `expo-location` |
| 文件系统 | `expo-file-system` |
| 通知 | `expo-notifications` |
| 加密存储 | `expo-secure-store` |
| 生物识别 | `expo-local-authentication` |
| 图片选择 | `expo-image-picker` |
| 图标 | `@expo/vector-icons` |
| 字体 | `expo-font` |
| 音频 | `expo-av` |

> Expo 的优势是不用手动 link 原生模块，`npx expo install` 会自动处理版本兼容。新项目强烈建议从 Expo 开始。
