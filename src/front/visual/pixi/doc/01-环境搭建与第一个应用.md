> 面试可答：PixiJS 是基于 WebGL/WebGPU 的高性能 2D 渲染引擎，采用场景图（Scene Graph）管理显示对象，内置事件系统和纹理批处理。v8 版本采用 `Application.init()` 异步初始化，`app.canvas` 需手动挂载到 DOM。相比原生 Canvas API，PixiJS 自动处理重绘、纹理管理和 GPU 加速，开发者只需操作场景图。

## 1. PixiJS 是什么

### 1.1 项目简介

PixiJS 是一个开源的 2D 渲染引擎，底层基于 **WebGL**（v8 已支持 WebGPU），用于在浏览器中高性能地绘制图形、动画和交互内容。

| 维度 | 说明 |
|------|------|
| **定位** | 2D 渲染引擎（不是游戏框架） |
| **底层技术** | WebGL 2 / WebGPU（v8），自动降级 |
| **渲染方式** | GPU 加速，批处理渲染 |
| **场景管理** | 场景图（Scene Graph），树状结构 |
| **事件系统** | 内置命中检测，类似 DOM 事件 |
| **GitHub** | 44k+ stars |
| **当前版本** | v8.x（2024 年发布） |

### 1.2 为什么用 PixiJS 而不是原生 Canvas

| 对比维度 | 原生 Canvas 2D | PixiJS |
|---------|---------------|--------|
| 渲染后端 | CPU（软件渲染） | GPU（WebGL/WebGPU） |
| 重绘机制 | 每帧 `clearRect` + 全部重绘 | 自动脏矩形检测，只重绘变化的部分 |
| 事件系统 | 需手动计算坐标命中 | 内置命中检测，支持冒泡 |
| 纹理管理 | 手动管理图片加载和缓存 | 自动纹理批处理、图集支持 |
| 对象管理 | 无（只有路径指令） | 场景图，父子变换继承 |
| 大量精灵 | 100+ 就开始掉帧 | 轻松处理 10000+ 精灵 |
| 学习曲线 | API 简单但需自己处理一切 | 需学习场景图和 API |

**一句话总结**：原生 Canvas 适合简单的图表和画板；PixiJS 适合游戏、动画、交互式可视化等需要高性能和复杂场景管理的场景。

### 1.3 典型应用

- **游戏**：2D 游戏（手游、H5 小游戏、微信小游戏）
- **互动**：数据可视化、互动广告、产品配置器
- **教育**：在线教育互动课件
- **创意**：粒子特效、动态背景、视觉艺术

### 1.4 与竞品对比

| 对比维度 | PixiJS | Phaser | Konva | Three.js |
|---------|--------|--------|-------|----------|
| **定位** | 2D 渲染引擎 | 2D 游戏框架 | 2D 画布库 | 3D 渲染引擎 |
| **渲染后端** | WebGL/WebGPU | WebGL/WebGPU | Canvas 2D | WebGL/WebGPU |
| **场景图** | ✅ | ✅ | ✅ | ✅ |
| **事件系统** | ✅ | ✅ | ✅ | 需 Raycaster |
| **物理引擎** | 无（需集成） | 内置 Arcade | 无 | 无 |
| **音效系统** | 无 | 内置 | 无 | 无 |
| **适用场景** | 通用 2D 渲染 | 2D 游戏开发 | 画板/编辑器 | 3D 场景 |
| **灵活度** | 高（渲染层） | 中（游戏层） | 中（画布层） | 高（3D 层） |

> **选型建议**：做游戏选 Phaser（开箱即用）；做通用 2D 渲染选 PixiJS（灵活度高）；做画板/编辑器选 Konva；3D 场景选 Three.js。

## 3. PixiJS v8 核心变化

v8 是一次重大版本更新，API 变化较大。如果你看过 v7 的教程，需要注意以下变化：

| 变化点 | v7 | v8 |
|--------|-----|-----|
| 初始化 | `new Application({ width, height })` | `new Application()` + `await app.init()` |
| Canvas 获取 | `app.view` | `app.canvas` |
| DOM 挂载 | 自动追加到 body | 需手动 `document.body.appendChild(app.canvas)` |
| Graphics API | `beginFill()` / `endFill()` | `fill()` / `stroke()`（链式） |
| 事件模式 | `interactive = true` | `eventMode = 'static'` |
| 包引入 | `import * as PIXI from 'pixi.js'` | `import { Application, Sprite } from 'pixi.js'`（按需引入） |
| 纹理加载 | `PIXI.Loader` | `Assets.load()` |

</body>

### 4.3 JavaScript 入口

```javascript
// main.js
import { Application, Graphics } from 'pixi.js';

async function main() {
  // 1. 创建应用并异步初始化
  const app = new Application();
  await app.init({
    width: 800,
    height: 600,
    background: '#1a1a2e',       // 背景色（v8 支持 CSS 颜色字符串）
    antialias: true,              // 抗锯齿
    resolution: window.devicePixelRatio || 1,  // 分辨率适配
    autoDensity: true,            // 自动适配 CSS 尺寸
  });

  // 2. 手动挂载 Canvas 到 DOM（v8 必需）
  document.body.appendChild(app.canvas);

  // 3. 创建一个红色圆形
  const circle = new Graphics();
  circle.circle(0, 0, 50);       // 定义圆形：圆心 (0,0)，半径 50
  circle.fill(0xff6b6b);         // 填充颜色
  circle.position.set(400, 300); // 放到画布中心
  app.stage.addChild(circle);    // 添加到舞台

  // 4. 创建一个绿色矩形
  const rect = new Graphics();
  rect.rect(-60, -30, 120, 60);  // 定义矩形
  rect.fill(0x4ecdc4);
  rect.position.set(200, 150);
  app.stage.addChild(rect);

  // 5. 创建一个蓝色星形
  const star = new Graphics();
  star.star(0, 0, 5, 80, 40);   // 五角星：5 个角，外半径 80，内半径 40
  star.fill(0x45b7d1);
  star.position.set(600, 400);
  app.stage.addChild(star);

  // 6. 简单动画：让圆形旋转
  app.ticker.add((ticker) => {
    circle.rotation += 0.02 * ticker.deltaTime;
    star.rotation -= 0.01 * ticker.deltaTime;
  });
}

main();
```

## 5. 理解 Application 的三个核心属性

### 5.1 app.canvas

```typescript
app.canvas  // HTMLCanvasElement — PixiJS 渲染的目标 Canvas 元素
```

- v8 中 `app.canvas` 替代了 v7 的 `app.view`
- 需要手动添加到 DOM：`document.body.appendChild(app.canvas)`
- 可以添加到页面中任意容器：`document.getElementById('container').appendChild(app.canvas)`

### 5.2 app.stage

```typescript
app.stage  // Container — 场景图的根容器
```

- 所有显示对象都通过 `app.stage.addChild()` 添加到舞台
- 舞台是场景图的根节点，所有子对象都是它的后代
- 舞台的 `(0, 0)` 点对应 Canvas 的左上角

### 5.3 app.screen

```typescript
app.screen  // Rectangle — 屏幕尺寸信息
app.screen.width   // 800
app.screen.height  // 600
```

- 读取当前画布的尺寸
- 用于居中定位、边界检测等

```javascript
// 将精灵居中显示
sprite.position.set(app.screen.width / 2, app.screen.height / 2);
```

## 8. 常见问题

### 8.1 Canvas 不显示

**原因**：忘记 `document.body.appendChild(app.canvas)`

```javascript
// ❌ v8 中必须手动挂载
const app = new Application();
await app.init({ width: 800, height: 600 });
// 什么都没显示！因为 app.canvas 还没添加到 DOM

// ✅ 正确做法
document.body.appendChild(app.canvas);
```

### 8.2 init() 报错

**原因**：`app.init()` 是异步方法，必须 `await`

```javascript
// ❌ 忘记 await
const app = new Application();
app.init({ width: 800, height: 600 });
// app.stage 是 undefined！

// ✅ 正确做法
await app.init({ width: 800, height: 600 });
```

### 8.3 图片加载不出来

**原因**：直接打开 `file://` 协议的 HTML，图片加载被 CORS 阻止

```bash
# ✅ 使用 HTTP 服务器
npx vite
# 或
npx http-server -p 3000
```

## 📝 面试回答模板

> **问：PixiJS 是什么？和原生 Canvas 有什么区别？**
>
> PixiJS 是基于 WebGL/WebGPU 的 2D 渲染引擎。和原生 Canvas 最大的区别是渲染方式——原生 Canvas 是 CPU 软件渲染，每帧需要 `clearRect` 后全部重绘；PixiJS 是 GPU 加速，自动检测变化的部分只重绘。此外 PixiJS 提供了场景图（类似 DOM 树）、事件系统（类似 DOM 事件）、纹理批处理（减少 GPU 状态切换）等能力，开发者只需操作场景图，渲染引擎自动优化。在处理大量精灵时，PixiJS 可以轻松达到 60fps，而原生 Canvas 在 100+ 对象时就开始掉帧。

> **问：PixiJS v8 有什么变化？**
>
> v8 主要有三个变化：1）初始化改为异步——`new Application()` 后需要 `await app.init()`，不再支持同步构造函数传参；2）Canvas 需手动挂载到 DOM，`app.canvas` 替代了 `app.view`；3）Graphics API 改为形状定义与样式分离的链式写法，`beginFill()`/`endFill()` 改为 `fill()`/`stroke()`。此外 v8 支持 WebGPU 后端，性能进一步提升。

> **问：PixiJS 的 Application 有哪些核心属性？各自的作用是什么？**
>
> 三个核心属性：1）`app.canvas`——HTMLCanvasElement，渲染目标，需要手动挂载到 DOM；2）`app.stage`——Container 类型，场景图的根容器，所有显示对象都通过 `addChild()` 挂到 stage 上才能渲染；3）`app.screen`——Rectangle 类型，包含画布的宽高信息，用于居中定位和边界检测。此外 `app.ticker` 提供帧循环，`app.renderer` 提供底层渲染器引用。
