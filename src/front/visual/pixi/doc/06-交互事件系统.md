# 06 — 交互事件系统

> 对应大纲：模块 6 | 预计时间：1 天
> 面试可答：PixiJS v8 的事件系统基于 `EventBoundary`，用 `eventMode` 取代了旧版的 `interactive`。五种模式（none / passive / auto / static / dynamic）精确控制每个对象是否接收事件、是否参与命中测试。事件从 `stage` 向下冒泡，支持 pointer / mouse / touch 三类指针事件以及自定义事件。容器可以通过 `hitArea` 自定义命中区域（圆形、矩形、多边形）。

---

## 1. eventMode — 五种交互模式

### 1.1 模式详解

v8 用 `eventMode` 取代了 v7 的 `interactive = true/false`，提供更精细的控制。

| 模式 | 接收事件 | 命中检测 | 性能 | 适用场景 |
|------|:---:|:---:|:---:|------|
| `'none'` | ❌ | ❌ | 最好 | 背景、装饰性元素 |
| `'passive'` | ❌ | ❌ | 最好 | 不需要交互的对象（默认） |
| `'auto'` | ✅ | 按子对象决定 | 一般 | 容器（只在有交互子对象时参与检测） |
| `'static'` | ✅ | ✅ | 中等 | 静态 UI（按钮、图标、面板） |
| `'dynamic'` | ✅ | ✅ | 较差 | 频繁移动的对象（玩家、敌机） |

```javascript
import { Sprite } from 'pixi.js';

// 设置交互模式
const button = new Sprite(texture);
button.eventMode = 'static';   // 可以接收点击事件

const bg = new Sprite(bgTexture);
bg.eventMode = 'none';         // 不参与事件检测
```

### 1.2 static vs dynamic 的区别

```javascript
// static：对象不移动时性能更好（PixiJS 缓存命中区域）
const button = new Sprite(texture);
button.eventMode = 'static';

// dynamic：对象频繁移动时需要每帧重新计算命中区域
const player = new Sprite(texture);
player.eventMode = 'dynamic';

app.ticker.add((ticker) => {
  player.x += 5 * ticker.deltaTime;  // 每帧移动
});
```

### 1.3 典型配置

```javascript
// 背景：不参与事件
bg.eventMode = 'none';

// 静态按钮
button.eventMode = 'static';
button.cursor = 'pointer';

// 频繁移动的玩家
player.eventMode = 'dynamic';

// 粒子容器（不需要交互）
particleContainer.eventMode = 'none';

// UI 容器（内部有交互子对象）
uiContainer.eventMode = 'auto';
```

## 2. 事件类型

### 2.1 指针事件（Pointer Events）

PixiJS 统一了鼠标和触摸事件，推荐使用指针事件：

```javascript
const sprite = new Sprite(texture);
sprite.eventMode = 'static';

// 指针进入
sprite.on('pointerenter', (event) => {
  console.log('指针进入');
});

// 指针离开
sprite.on('pointerleave', (event) => {
  console.log('指针离开');
});

// 指针移动
sprite.on('pointermove', (event) => {
  console.log('指针移动', event.global.x, event.global.y);
});

// 按下
sprite.on('pointerdown', (event) => {
  console.log('按下', event.button);  // 0=左键, 1=中键, 2=右键
});

// 释放
sprite.on('pointerup', (event) => {
  console.log('释放');
});

// 点击（按下 + 释放都在同一对象上）
sprite.on('pointertap', (event) => {
  console.log('点击');
});

// 拖拽开始
sprite.on('pointerdown', (event) => {
  sprite.dragging = true;
  sprite.dragOffset = {
    x: event.global.x - sprite.x,
    y: event.global.y - sprite.y,
  };
});
```

### 2.2 鼠标事件（Mouse Events）

```javascript
sprite.on('mousedown', (event) => {});
sprite.on('mouseup', (event) => {});
sprite.on('mousemove', (event) => {});
sprite.on('mouseover', (event) => {});   // 进入（不冒泡）
sprite.on('mouseout', (event) => {});    // 离开（不冒泡）
sprite.on('mouseenter', (event) => {});  // 进入（不冒泡）
sprite.on('mouseleave', (event) => {});  // 离开（不冒泡）
sprite.on('click', (event) => {});
sprite.on('rightclick', (event) => {});
```

### 2.3 触摸事件（Touch Events）

```javascript
sprite.on('touchstart', (event) => {});
sprite.on('touchend', (event) => {});
sprite.on('touchmove', (event) => {});
sprite.on('touchcancel', (event) => {});
```

### 2.4 事件对象（FederatedPointerEvent）

```javascript
sprite.on('pointertap', (event) => {
  // 全局坐标（相对于画布）
  event.global.x;
  event.global.y;

  // 本地坐标（相对于当前对象）
  event.getLocalPosition(sprite);

  // 按钮信息
  event.button;   // 0=左键, 1=中键, 2=右键
  event.buttons;  // 按下的所有按钮（位掩码）

  // 键盘修饰符
  event.ctrlKey;
  event.shiftKey;
  event.altKey;
  event.metaKey;

  // 目标对象
  event.target;       // 事件最初触发的对象
  event.currentTarget; // 当前监听器所属的对象

  // 阻止冒泡
  event.stopPropagation();
});
```

## 3. 事件冒泡与传播

### 3.1 传播路径

事件从 `stage` 向目标对象传播（捕获），再从目标对象向 `stage` 冒泡。

```
捕获阶段（Capture）：stage → container → sprite
目标阶段（Target）：sprite
冒泡阶段（Bubble）：sprite → container → stage
```

### 3.2 冒泡示例

```javascript
const container = new Container();
container.eventMode = 'static';
app.stage.addChild(container);

const sprite = new Sprite(texture);
sprite.eventMode = 'static';
container.addChild(sprite);

// sprite 上的点击事件会冒泡到 container
sprite.on('pointertap', (event) => {
  console.log('sprite 被点击');
});

container.on('pointertap', (event) => {
  console.log('container 收到事件（冒泡）');
});

// 阻止冒泡
sprite.on('pointertap', (event) => {
  event.stopPropagation();  // 不会冒泡到 container
  console.log('sprite 被点击，事件不冒泡');
});
```

### 3.3 容器事件

```javascript
const container = new Container();
container.eventMode = 'static';

// 容器本身也可以接收事件
container.on('pointertap', (event) => {
  console.log('容器被点击');
  console.log('实际点击的是:', event.target);  // 具体的子对象
});
```

## 4. hitArea — 自定义命中区域

### 4.1 为什么需要 hitArea

默认情况下，命中检测基于对象的纹理边界（矩形）。对于不规则形状或不可见的点击区域，需要自定义 hitArea。

```javascript
import { Container, Sprite, Graphics, Circle, Rectangle, Polygon, Ellipse } from 'pixi.js';

// 圆形命中区域
const sprite = new Sprite(texture);
sprite.eventMode = 'static';
sprite.hitArea = new Circle(0, 0, 50);  // 圆心(0,0)，半径50

// 矩形命中区域（可以比纹理大或小）
sprite.hitArea = new Rectangle(-25, -25, 50, 50);

// 椭圆命中区域
sprite.hitArea = new Ellipse(0, 0, 60, 40);

// 多边形命中区域
sprite.hitArea = new Polygon([
  0, -50,    // 顶部
  50, 30,    // 右下
  -50, 30,   // 左下
]);
```

### 4.2 容器命中区域

```javascript
// 给没有纹理的容器设置命中区域
const button = new Container();
button.eventMode = 'static';
button.hitArea = new Rectangle(0, 0, 200, 60);

const bg = new Graphics();
bg.roundRect(0, 0, 200, 60, 8);
bg.fill(0x4ecdc4);
button.addChild(bg);

const label = new Text({ text: 'Click Me', style: { fill: '#fff' } });
label.position.set(100, 30);
label.anchor.set(0.5);
button.addChild(label);

button.on('pointertap', () => {
  console.log('按钮被点击');
});
```

## 6. 实战：拖拽系统

### 6.1 基础拖拽

```javascript
function makeDraggable(sprite) {
  sprite.eventMode = 'static';
  sprite.cursor = 'grab';

  let dragging = false;
  let dragOffset = { x: 0, y: 0 };

  sprite.on('pointerdown', (event) => {
    dragging = true;
    sprite.cursor = 'grabbing';
    const pos = event.global;
    dragOffset.x = pos.x - sprite.x;
    dragOffset.y = pos.y - sprite.y;
    // 提升到最顶层
    sprite.parent.addChild(sprite);
  });

  sprite.on('pointermove', (event) => {
    if (!dragging) return;
    const pos = event.global;
    sprite.x = pos.x - dragOffset.x;
    sprite.y = pos.y - dragOffset.y;
  });

  sprite.on('pointerup', () => {
    dragging = false;
    sprite.cursor = 'grab';
  });

  sprite.on('pointerupoutside', () => {
    dragging = false;
    sprite.cursor = 'grab';
  });
}

// 使用
const ship = new Sprite(shipTexture);
ship.anchor.set(0.5);
ship.position.set(400, 300);
app.stage.addChild(ship);
makeDraggable(ship);
```

### 6.2 带边界限制的拖拽

```javascript
function makeDraggable(sprite, bounds) {
  sprite.eventMode = 'static';
  sprite.cursor = 'grab';

  let dragging = false;
  let dragOffset = { x: 0, y: 0 };

  sprite.on('pointerdown', (event) => {
    dragging = true;
    sprite.cursor = 'grabbing';
    const pos = event.global;
    dragOffset.x = pos.x - sprite.x;
    dragOffset.y = pos.y - sprite.y;
  });

  // 在 stage 上监听 move（避免鼠标移出对象时丢失事件）
  app.stage.on('pointermove', (event) => {
    if (!dragging) return;
    const pos = event.global;
    let newX = pos.x - dragOffset.x;
    let newY = pos.y - dragOffset.y;

    // 边界限制
    if (bounds) {
      newX = Math.max(bounds.x, Math.min(bounds.x + bounds.width, newX));
      newY = Math.max(bounds.y, Math.min(bounds.y + bounds.height, newY));
    }

    sprite.x = newX;
    sprite.y = newY;
  });

  sprite.on('pointerup', () => {
    dragging = false;
    sprite.cursor = 'grab';
  });
}

// 使用：限制在画布范围内
makeDraggable(ship, { x: 0, y: 0, width: 800, height: 600 });
```

## 8. 性能优化

### 8.1 避免不必要的命中检测

```javascript
// ❌ 所有对象都设为 static（大量命中检测开销）
sprites.forEach(s => s.eventMode = 'static');

// ✅ 只有需要交互的对象才开启
sprites.forEach(s => s.eventMode = 'none');
currentActiveSprite.eventMode = 'static';
```

### 8.2 使用 hitArea 减少检测

```javascript
// ❌ 让 PixiJS 用纹理边界做检测（复杂纹理检测慢）
sprite.eventMode = 'static';

// ✅ 用简单的 hitArea（圆形/矩形检测快）
sprite.eventMode = 'static';
sprite.hitArea = new Circle(0, 0, 30);  // 简单形状检测更快
```

### 8.3 批量禁用交互

```javascript
// 暂停界面时禁用所有游戏对象的交互
function disableGameInteraction() {
  gameContainer.children.forEach(child => {
    child.eventMode = 'none';
  });
}

function enableGameInteraction() {
  gameContainer.children.forEach(child => {
    child.eventMode = 'static';
  });
}
```

## 9. 常见问题

### 9.1 点击事件不触发

```javascript
// ❌ 忘记设置 eventMode
const sprite = new Sprite(texture);
sprite.on('pointertap', () => {});  // 不会触发！

// ✅ 设置 eventMode
sprite.eventMode = 'static';
sprite.on('pointertap', () => {});  // 正常触发
```

### 9.2 容器不接收事件

```javascript
// ❌ 容器没有设置 eventMode
const container = new Container();
container.on('pointertap', () => {});  // 不会触发！

// ✅ 设置 eventMode 和 hitArea
container.eventMode = 'static';
container.hitArea = new Rectangle(0, 0, 200, 100);
container.on('pointertap', () => {});  // 正常触发
```

### 9.3 重叠对象的事件

```javascript
// 上层对象会"挡住"下层对象的事件
const topSprite = new Sprite(texture);
topSprite.eventMode = 'static';
topSprite.alpha = 0;  // 透明但仍然接收事件！

// ✅ 不需要交互的透明对象设为 none
topSprite.eventMode = 'none';
```

### 9.4 触摸屏兼容

```javascript
// PixiJS 自动处理触摸和鼠标的差异
// 使用 pointer 事件即可兼容两者
sprite.on('pointerdown', (event) => {
  // event.pointerType === 'mouse' || 'touch' || 'pen'
  console.log('输入类型:', event.pointerType);
});
```

## 10. 方案对比：PixiJS 事件 vs DOM 事件 vs 原生 Canvas

| 特性 | PixiJS 事件 | DOM 事件 | 原生 Canvas 手动检测 |
|------|:---:|:---:|:---:|
| **命中检测** | ✅ 自动（基于场景图） | ✅ 自动（基于 DOM 树） | ❌ 需手动计算坐标 |
| **事件冒泡** | ✅ 沿场景图冒泡 | ✅ 沿 DOM 树冒泡 | ❌ 无冒泡机制 |
| **模式控制** | ✅ 5 种 eventMode 精细控制 | ⚠️ 只有 `pointer-events` CSS | ❌ 无 |
| **自定义命中区域** | ✅ Circle/Rectangle/Polygon | ❌ 受限于元素形状 | ✅ 但需手写判断 |
| **触摸兼容** | ✅ 自动统一 pointer 事件 | ✅ Pointer Events 标准 | ❌ 需分别监听 mouse/touch |
| **性能（大量对象）** | ✅ EventBoundary 优化 | ❌ DOM 节点多时卡顿 | ✅ 最灵活但工作量大 |
| **学习成本** | 中等 | 低 | 高 |

**选择建议**：
- 2D 游戏/可视化 → PixiJS 事件系统，场景图 + 自动命中检测省大量代码
- 网页 UI 交互 → DOM 事件，原生支持最好
- 极致性能/自定义引擎 → 原生 Canvas + 手动 hitTest，完全可控但开发成本高

## 📝 面试回答模板

> **问：PixiJS v8 的 eventMode 有哪几种？怎么选择？**
>
> v8 有 5 种 eventMode：`'none'` 不接收事件也不参与命中检测（背景用）；`'passive'` 不接收事件但子对象可以（默认）；`'auto'` 根据子对象是否有交互来决定是否参与检测（容器用）；`'static'` 接收事件并缓存命中区域（按钮、UI 用）；`'dynamic'` 接收事件但每帧重新计算命中区域（频繁移动的对象用）。选择依据：不需要交互的用 `none`，静态 UI 用 `static`，移动中的对象用 `dynamic`，容器用 `auto`。性能方面，`none` > `passive` > `static` > `dynamic`。

> **问：PixiJS 的事件冒泡和 DOM 事件冒泡一样吗？**
>
> 原理相同，事件从目标对象向 stage 冒泡。区别是 PixiJS 事件冒泡基于场景图树（addChild 关系），DOM 事件冒泡基于 DOM 树。都可以用 `stopPropagation()` 阻止冒泡。PixiJS 还支持捕获阶段（`addEventListener` 的第三个参数），但一般只用冒泡阶段。
