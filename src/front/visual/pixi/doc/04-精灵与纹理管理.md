# 04 — 精灵与纹理管理

> 对应大纲：模块 4 | 预计时间：1 天
> 面试可答：`Sprite` 是 PixiJS 中显示图片的核心类，底层通过 GPU 绘制纹理（Texture）。`Assets.load()` 是 v8 推荐的资源加载方式，支持异步加载、批量加载和缓存管理。纹理复用是性能优化的关键——多个 Sprite 共享同一个 Texture 对象，不额外占用 GPU 显存。精灵图集（Spritesheet）将多张小图合并为一张大图 + JSON 描述，减少纹理切换次数，是游戏开发的标准做法。

---

## 1. 纹理（Texture）基础

### 1.1 什么是纹理

纹理（Texture）是上传到 GPU 的图片数据。在 PixiJS 中，图片需要先加载为 Texture，然后才能被 Sprite 显示。

```
图片文件 (ship.png)
    │
    ▼ 加载
Texture（GPU 纹理）
    │
    ▼ 创建
Sprite（显示对象）
    │
    ▼ addChild
Stage（舞台）
```

### 1.2 Texture vs BaseTexture

| 概念 | 说明 | 类比 |
|------|------|------|
| `BaseTexture` | GPU 中的原始图片数据 | 一张完整的图片文件 |
| `Texture` | BaseTexture 的一个区域（默认是整个图片） | 图片中的一块裁剪区域 |
| `Sprite` | 显示 Texture 的场景图节点 | `<img>` 标签 |

```
BaseTexture（整张图集）
┌──────┬──────┬──────┐
│      │      │      │
│ ship │enemy │bullet│  ← 每个区域是一个 Texture
│      │      │      │
└──────┴──────┴──────┘

Texture = BaseTexture + 裁剪区域 (frame)
```

## 2. Assets.load() — 资源加载

### 2.1 加载单张图片

```javascript
import { Assets, Sprite } from 'pixi.js';

// 异步加载（推荐）
const texture = await Assets.load('images/ship.png');
const ship = new Sprite(texture);
ship.anchor.set(0.5);
ship.position.set(400, 500);
app.stage.addChild(ship);
```

`Assets.load()` 的特点：
- **异步**：返回 Promise，加载完成前不阻塞
- **缓存**：同一 URL 只加载一次，后续调用直接返回缓存
- **自动检测**：根据文件扩展名自动选择加载器（图片、JSON、字体等）

### 2.2 批量加载

```javascript
// 同时加载多张图片
const textures = await Assets.load([
  'images/ship.png',
  'images/enemy.png',
  'images/bullet.png',
  'images/bg.png',
]);

// textures 是一个对象，key 是 URL
const ship = new Sprite(textures['images/ship.png']);
const enemy = new Sprite(textures['images/enemy.png']);
```

### 2.3 带别名加载

```javascript
// 给资源起别名，后续用别名引用
await Assets.load([
  { alias: 'ship', src: 'images/ship.png' },
  { alias: 'enemy', src: 'images/enemy.png' },
  { alias: 'bullet', src: 'images/bullet.png' },
]);

// 用别名获取纹理
const shipTexture = Assets.get('ship');
const enemyTexture = Assets.get('enemy');
```

### 2.4 加载进度

```javascript
// 方式一：使用 Assets.addBundle + loadBundle
Assets.addBundle('game', {
  ship: 'images/ship.png',
  enemy: 'images/enemy.png',
  bullet: 'images/bullet.png',
});

const progress = (progressValue) => {
  console.log(`加载进度: ${(progressValue * 100).toFixed(0)}%`);
};

const textures = await Assets.loadBundle('game', progress);
```

### 2.5 资源管理

```javascript
// 预加载（不立即使用，但缓存到内存）
await Assets.load('images/big-texture.png');

// 卸载资源（释放 GPU 内存）
await Assets.unload('images/big-texture.png');

// 检查资源是否已加载
Assets.has('images/ship.png');  // true/false

// 获取已加载的纹理（不触发加载）
const texture = Assets.get('images/ship.png');
```

## 3. Sprite — 精灵

### 3.1 创建精灵

```javascript
import { Sprite, Texture } from 'pixi.js';

// 方式一：从 Texture 创建（推荐）
const texture = await Assets.load('images/ship.png');
const ship = new Sprite(texture);

// 方式二：Sprite.from()（快捷方式，纹理必须已加载）
const ship = Sprite.from('images/ship.png');

// 方式三：从已加载的纹理创建
const ship = new Sprite(Assets.get('ship'));

// 方式四：空精灵（后续设置纹理）
const sprite = new Sprite();
sprite.texture = await Assets.load('images/ship.png');
```

### 3.2 锚点（Anchor）

锚点决定了精灵的定位和旋转基准点。

```javascript
const sprite = new Sprite(texture);

// 锚点值是 0~1 的比例
sprite.anchor.set(0, 0);    // 左上角（默认）
sprite.anchor.set(0.5, 0.5); // 中心（最常用）
sprite.anchor.set(1, 1);    // 右下角
sprite.anchor.set(0.5, 0);  // 顶部中心（适合标题）
sprite.anchor.set(0.5, 1);  // 底部中心（适合地面物体）

// 单独设置
sprite.anchor.x = 0.5;
sprite.anchor.y = 0.5;
```

```
锚点位置示意图：

(0,0)─────────(0.5,0)─────────(1,0)
  │                │               │
  │                │               │
(0,0.5)───────(0.5,0.5)──────(1,0.5)
  │                │               │
  │                │               │
(0,1)─────────(0.5,1)─────────(1,1)

(0.5, 0.5) = 中心锚点，旋转时围绕中心旋转
```

### 3.3 精灵属性

```javascript
const sprite = new Sprite(texture);

// 位置
sprite.position.set(400, 300);

// 尺寸
sprite.width = 100;    // 设置显示宽度（会改变 scale）
sprite.height = 80;    // 设置显示高度（会改变 scale）

// 缩放
sprite.scale.set(2);         // 等比放大 2 倍
sprite.scale.set(0.5, 1);   // 水平缩小一半

// 旋转
sprite.rotation = Math.PI / 4;  // 45°（弧度）
sprite.angle = 45;              // 45°（角度）

// 透明度
sprite.alpha = 0.5;

// 可见性
sprite.visible = false;

// 色调（v8 新增）
sprite.tint = 0xff0000;     // 染成红色
sprite.tint = 0xffffff;     // 恢复原色
```

### 3.4 纹理切换

```javascript
const shipTexture = await Assets.load('images/ship.png');
const enemyTexture = await Assets.load('images/enemy.png');

const sprite = new Sprite(shipTexture);

// 切换纹理（不创建新对象）
sprite.texture = enemyTexture;

// 切换回原纹理
sprite.texture = shipTexture;
```

## 4. 纹理复用

纹理复用是 PixiJS 性能优化的基础——多个精灵共享同一个 Texture 对象。

### 4.1 为什么纹理复用重要

```
❌ 不复用纹理（每个精灵独立加载）：
  Sprite A → Texture A → BaseTexture A  ← 占用 GPU 内存
  Sprite B → Texture B → BaseTexture B  ← 占用 GPU 内存
  Sprite C → Texture C → BaseTexture C  ← 占用 GPU 内存
  100 个子弹 = 100 份 GPU 纹理

✅ 复用纹理（共享同一个 Texture）：
  Sprite A ─┐
  Sprite B ──┤→ Texture → BaseTexture  ← 只占 1 份 GPU 内存
  Sprite C ─┘
  100 个子弹 = 1 份 GPU 纹理
```

### 4.2 纹理复用代码

```javascript
const bulletTexture = await Assets.load('images/bullet.png');

// 所有子弹共享同一个纹理
for (let i = 0; i < 100; i++) {
  const bullet = new Sprite(bulletTexture);  // 共享纹理
  bullet.position.set(Math.random() * 800, Math.random() * 600);
  app.stage.addChild(bullet);
}

// 验证：纹理对象是同一个
console.log(bullet1.texture === bullet2.texture);  // true
```

### 4.3 纹理裁剪

从一张大图中裁剪出特定区域作为新的 Texture：

```javascript
import { Texture, Rectangle } from 'pixi.js';

const baseTexture = await Assets.load('images/spritesheet.png');

// 裁剪出 (0, 0, 64, 64) 区域
const frame = new Rectangle(0, 0, 64, 64);
const shipTexture = new Texture({ source: baseTexture.source, frame });

// 裁剪出 (64, 0, 64, 64) 区域
const enemyFrame = new Rectangle(64, 0, 64, 64);
const enemyTexture = new Texture({ source: baseTexture.source, frame: enemyFrame });
```

## 5. Spritesheet — 精灵图集

### 5.1 为什么需要图集

将多张小图合并为一张大图（Atlas），好处：

| 优势 | 说明 |
|------|------|
| **减少 GPU 状态切换** | 一次 draw call 绘制多个精灵 |
| **减少 HTTP 请求** | 一次加载整张图集 |
| **减少内存碎片** | 一张大图比多张小图更紧凑 |
| **支持动画帧** | 动画帧序列在图集中连续排列 |

### 5.2 图集文件格式

TexturePacker 生成的图集包含两个文件：

**game.json**（描述文件）：
```json
{
  "frames": {
    "ship.png": {
      "frame": { "x": 0, "y": 0, "w": 64, "h": 64 },
      "sourceSize": { "w": 64, "h": 64 }
    },
    "enemy.png": {
      "frame": { "x": 64, "y": 0, "w": 48, "h": 48 },
      "sourceSize": { "w": 48, "h": 48 }
    },
    "bullet.png": {
      "frame": { "x": 112, "y": 0, "w": 8, "h": 24 },
      "sourceSize": { "w": 8, "h": 24 }
    }
  },
  "meta": {
    "image": "game.png",
    "size": { "w": 256, "h": 256 }
  }
}
```

**game.png**（图集图片）：
```
┌──────┬──────┬────┬─────┐
│      │      │    │     │
│ ship │enemy │bullet│ ···│
│ 64×64│48×48 │8×24 │     │
│      │      │    │     │
└──────┴──────┴────┴─────┘
```

### 5.3 加载图集

```javascript
import { Assets, Sprite, Spritesheet } from 'pixi.js';

// 方式一：Assets.load 自动解析（推荐）
// Assets 会根据 JSON 中的 meta.image 自动加载对应的 PNG
const spritesheet = await Assets.load('images/game.json');

// 直接使用图集中的纹理
const ship = new Sprite(spritesheet.textures['ship.png']);
const enemy = new Sprite(spritesheet.textures['enemy.png']);
const bullet = new Sprite(spritesheet.textures['bullet.png']);

app.stage.addChild(ship, enemy, bullet);
```

```javascript
// 方式二：手动解析
const atlasData = await fetch('images/game.json').then(r => r.json());
const atlasTexture = await Assets.load('images/game.png');
const spritesheet = new Spritesheet(atlasTexture, atlasData);
await spritesheet.parse();

const ship = new Sprite(spritesheet.textures['ship.png']);
```

### 5.4 带别名的图集

```javascript
// 在加载时给图集起别名
await Assets.load({ alias: 'game', src: 'images/game.json' });
const game = Assets.get('game');

const ship = new Sprite(game.textures['ship.png']);
```

### 5.5 动画帧图集

```javascript
// 如果图集包含动画帧序列
// {
//   "frames": {
//     "explosion_001.png": { "frame": {...} },
//     "explosion_002.png": { "frame": {...} },
//     "explosion_003.png": { "frame": {...} },
//     ...
//   }
// }

// 获取动画帧数组
const explosionFrames = spritesheet.animations['explosion'];
// 或手动筛选
const explosionTextures = Object.keys(spritesheet.textures)
  .filter(key => key.startsWith('explosion_'))
  .map(key => spritesheet.textures[key]);
```

## 6. AnimatedSprite — 帧动画

### 6.1 创建帧动画

```javascript
import { AnimatedSprite } from 'pixi.js';

// 从图集获取动画帧
const explosionTextures = spritesheet.animations['explosion'];

// 创建动画精灵
const explosion = new AnimatedSprite(explosionTextures);
explosion.anchor.set(0.5);
explosion.position.set(400, 300);
explosion.animationSpeed = 0.5;  // 动画速度（1 = 每帧切换）
explosion.loop = false;           // 不循环
explosion.onComplete = () => {
  explosion.destroy();  // 播放完毕后销毁
};
app.stage.addChild(explosion);
explosion.play();
```

### 6.2 AnimatedSprite 常用属性和方法

```javascript
// 控制
explosion.play();           // 播放
explosion.stop();           // 停止
explosion.gotoAndPlay(0);   // 从第 0 帧开始播放
explosion.gotoAndStop(3);   // 跳到第 3 帧并停止

// 属性
explosion.animationSpeed = 0.5;  // 速度（默认 1）
explosion.loop = true;           // 是否循环（默认 true）
explosion.currentFrame;          // 当前帧索引
explosion.totalFrames;           // 总帧数
explosion.playing;               // 是否正在播放

// 事件
explosion.onComplete = () => {};           // 播放完成
explosion.onFrameChange = (frame) => {};   // 帧变化
explosion.onLoop = () => {};               // 循环时触发
```

## 7. 常见问题

### 7.1 图片加载失败

```javascript
// ❌ 路径错误
const texture = await Assets.load('ship.png');  // 文件在 images/ 目录下

// ✅ 正确路径
const texture = await Assets.load('images/ship.png');

// ❌ 直接打开 file:// 协议（CORS 限制）
// ✅ 使用 HTTP 服务器（npx vite / npx http-server）
```

### 7.2 纹理未加载就使用

```javascript
// ❌ Sprite.from() 在纹理未加载时会显示空白
const sprite = Sprite.from('images/ship.png');  // 如果纹理未加载，显示空白

// ✅ 确保先加载再使用
await Assets.load('images/ship.png');
const sprite = Sprite.from('images/ship.png');
```

### 7.3 图集加载后找不到纹理

```javascript
// ❌ JSON 文件名和图集中的 frame 名不匹配
// 确保 spritesheet.textures 的 key 和 JSON 中的 frame 名一致

const sprite = new Sprite(spritesheet.textures['ship.png']);  // 需要带扩展名
// 或
const sprite = new Sprite(spritesheet.textures['ship']);      // 取决于 JSON 格式
```

### 7.4 内存泄漏

```javascript
// ❌ 不断加载新纹理而不卸载
for (let i = 0; i < 1000; i++) {
  await Assets.load(`images/frame_${i}.png`);  // 全部缓存在内存中
}

// ✅ 不需要的纹理及时卸载
await Assets.unload('images/frame_0.png');

// ✅ 或使用纹理复用
const texture = await Assets.load('images/sprite.png');
// 100 个精灵共享同一个纹理
```

## 📝 面试回答模板

> **问：PixiJS 中 Texture 和 Sprite 是什么关系？**
>
> Texture 是上传到 GPU 的图片数据，Sprite 是显示 Texture 的场景图节点。一个 Texture 可以被多个 Sprite 共享——这是纹理复用，100 个子弹精灵共享同一个 Texture，GPU 只维护一份纹理数据。创建 Sprite 时传入 Texture，Sprite 只记录纹理引用和显示属性（位置、缩放、旋转），不复制纹理数据。

> **问：什么是精灵图集？为什么需要它？**
>
> 精灵图集是将多张小图合并为一张大图（Atlas），配合 JSON 描述文件记录每张小图的位置和尺寸。好处有三个：1）减少 GPU 纹理切换——同一图集中的精灵可以在一次 draw call 中批量绘制；2）减少 HTTP 请求——一次加载整张图集而不是多张小图；3）减少内存碎片——一张大图比多张小图更紧凑。工具推荐 TexturePacker，输出标准的 JSON + PNG 格式。

> **问：Assets.load() 和直接 new Texture() 有什么区别？**
>
> `Assets.load()` 是异步加载，支持缓存（同一 URL 只加载一次）、批量加载、进度回调、自动检测文件类型。`new Texture()` 是同步创建，需要手动管理 BaseTexture 和加载状态。生产项目统一用 `Assets.load()`，它会处理好缓存、复用和内存管理。
