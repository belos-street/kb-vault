# 03 — 矢量绘图与文本

> 对应大纲：模块 3 | 预计时间：1 天
> 面试可答：`Graphics` 是 PixiJS 的矢量绘图类，无需外部资源即可绘制圆形、矩形、星形、路径等图形。v8 中 Graphics API 采用形状定义与样式分离的写法——先用 `rect()` / `circle()` 定义形状，再用 `fill()` / `stroke()` 设置填充和描边。`Text` 用于显示文字，支持富文本样式、动态更新，底层使用 Canvas 2D 渲染为纹理后由 WebGL 绘制。

---

## 1. Graphics — 矢量绘图

### 1.1 v8 API 核心变化

v7 和 v8 的 Graphics API 差异较大：

| 操作 | v7 | v8 |
|------|-----|-----|
| 填充矩形 | `beginFill(0xff0000); drawRect(0,0,100,50); endFill()` | `rect(0,0,100,50); fill(0xff0000)` |
| 描边矩形 | `lineStyle(2, 0xffffff); drawRect(0,0,100,50)` | `rect(0,0,100,50); stroke({width:2, color:0xffffff})` |
| 多个形状 | 每次 `beginFill` + `endFill` | 每个形状后独立 `fill()` / `stroke()` |
| 圆形 | `drawCircle(0,0,50)` | `circle(0,0,50)` |
| 矩形 | `drawRect(0,0,100,50)` | `rect(0,0,100,50)` |

**核心理念**：v8 将"定义形状"和"设置样式"分离，每个形状可以独立设置填充和描边。

### 1.2 基本形状

```javascript
import { Graphics } from 'pixi.js';

// 矩形
const rect = new Graphics();
rect.rect(0, 0, 200, 100);          // x, y, width, height
rect.fill(0x4ecdc4);                 // 填充青色
rect.stroke({ width: 2, color: 0xffffff });  // 白色描边

// 圆形
const circle = new Graphics();
circle.circle(0, 0, 50);            // centerX, centerY, radius
circle.fill(0xff6b6b);

// 椭圆
const ellipse = new Graphics();
ellipse.ellipse(0, 0, 80, 40);      // centerX, centerY, halfWidth, halfHeight
ellipse.fill(0xffe66d);

// 圆角矩形
const roundedRect = new Graphics();
roundedRect.roundRect(0, 0, 200, 100, 16);  // x, y, w, h, radius
roundedRect.fill(0xa8e6cf);

// 星形
const star = new Graphics();
star.star(0, 0, 5, 80, 40);        // centerX, centerY, points, outerR, innerR
star.fill(0xffd93d);

// 多边形（正多边形用 regularPolygon）
const hexagon = new Graphics();
hexagon.regularPolygon(0, 0, 60, 6);  // centerX, centerY, radius, sides
hexagon.fill(0x6c5ce7);
```

### 1.3 路径绘制

```javascript
const path = new Graphics();

// 三角形
path.moveTo(0, -50);
path.lineTo(50, 50);
path.lineTo(-50, 50);
path.closePath();                   // 闭合路径
path.fill(0xff6348);

// 折线
const line = new Graphics();
line.moveTo(0, 0);
line.lineTo(100, 50);
line.lineTo(200, 20);
line.lineTo(300, 80);
line.stroke({ width: 3, color: 0xffffff });  // 只描边不填充

// 弧线
const arc = new Graphics();
arc.arc(0, 0, 100, 0, Math.PI);    // 圆心, 半径, 起始角度, 结束角度
arc.stroke({ width: 2, color: 0xff6b6b });
```

### 1.4 样式选项

```javascript
// 填充
g.fill(0xff0000);                    // 纯色填充（十六进制）
g.fill('#ff0000');                   // CSS 颜色字符串
g.fill({ color: 0xff0000, alpha: 0.5 });  // 带透明度

// 描边
g.stroke({ width: 2, color: 0xffffff });
g.stroke({ width: 4, color: 0x000000, alpha: 0.8 });
g.stroke({
  width: 3,
  color: 0xff0000,
  cap: 'round',     // 线帽：'butt' | 'round' | 'square'
  join: 'round',    // 连接：'miter' | 'round' | 'bevel'
});

// 清除所有图形
g.clear();
```

### 1.5 多个形状组合

```javascript
// 一个 Graphics 对象可以包含多个形状
const face = new Graphics();

// 脸（大圆）
face.circle(0, 0, 80);
face.fill(0xffeaa7);

// 左眼
face.circle(-25, -20, 10);
face.fill(0x2d3436);

// 右眼
face.circle(25, -20, 10);
face.fill(0x2d3436);

// 嘴巴（弧线）
face.arc(0, 10, 30, 0, Math.PI);
face.stroke({ width: 3, color: 0x2d3436 });
```

```
        ┌─────────┐
       ╱  ●     ●  ╲      ← 两个小圆（眼睛）
      │             │
      │     ‿       │      ← 弧线（嘴巴）
       ╲           ╱
        └─────────┘
           大圆（脸）
```

### 1.6 Graphics 的尺寸与定位

```javascript
const g = new Graphics();
g.rect(0, 0, 200, 100);
g.fill(0xff0000);

// Graphics 的默认锚点在左上角 (0, 0)
g.width;   // 200
g.height;  // 100

// 获取包围盒
const bounds = g.getBounds();
// { x: 0, y: 0, width: 200, height: 100 }

// 居中定位
g.pivot.set(100, 50);              // 设置轴心到中心
g.position.set(400, 300);          // 放到画布中心

// 注意：Graphics 没有 anchor 属性（anchor 是 Sprite/Text 特有的）
// 用 pivot 替代
```

## 2. Text — 文本

### 2.1 创建文本

```javascript
import { Text, TextStyle } from 'pixi.js';

// 方式一：直接传样式对象
const text1 = new Text({
  text: 'Hello PixiJS!',
  style: {
    fontFamily: 'Arial',
    fontSize: 36,
    fill: '#ffffff',
  },
});

// 方式二：使用 TextStyle 对象（可复用）
const style = new TextStyle({
  fontFamily: 'Arial',
  fontSize: 48,
  fontWeight: 'bold',
  fill: '#ffffff',
  stroke: { color: '#000000', width: 4 },  // 描边
  dropShadow: {
    color: '#000000',
    blur: 4,
    distance: 2,
  },
});

const text2 = new Text({ text: 'Score: 0', style });
text2.position.set(10, 10);
```

### 2.2 TextStyle 完整配置

```javascript
const style = new TextStyle({
  // 字体
  fontFamily: 'Arial, sans-serif',
  fontSize: 36,
  fontStyle: 'normal',    // 'normal' | 'italic' | 'oblique'
  fontWeight: 'bold',     // 'normal' | 'bold' | '100'~'900'

  // 填充
  fill: '#ffffff',                    // 纯色
  fill: ['#ff0000', '#00ff00'],       // 渐变（数组）
  fillGradientType: 0,               // 0=线性垂直, 1=线性水平

  // 描边
  stroke: { color: '#000000', width: 4 },
  stroke: { color: '#000000', width: 4, join: 'round' },

  // 阴影
  dropShadow: {
    color: '#000000',
    alpha: 0.5,
    blur: 4,
    distance: 4,
    angle: Math.PI / 4,    // 阴影角度
  },

  // 对齐
  align: 'center',         // 'left' | 'center' | 'right'
  letterSpacing: 2,        // 字间距
  lineHeight: 48,          // 行高
  wordWrap: true,          // 自动换行
  wordWrapWidth: 300,      // 换行宽度

  // 裁剪
  breakWords: false,       // 是否允许在单词中间断行
  trim: false,             // 裁剪透明像素
});
```

### 2.3 动态更新文本

```javascript
const scoreText = new Text({
  text: 'Score: 0',
  style: { fill: '#fff', fontSize: 24 },
});

// 更新文本内容（直接修改 text 属性）
scoreText.text = 'Score: 100';

// 更新样式
scoreText.style.fill = '#ff0000';
scoreText.style.fontSize = 32;

// 整体替换样式
scoreText.style = new TextStyle({ fill: '#00ff00', fontSize: 28 });
```

### 2.4 文本锚点与定位

```javascript
const text = new Text({ text: 'Hello', style: { fill: '#fff', fontSize: 36 } });

// 文本默认锚点在左上角 (0, 0)
text.anchor.set(0.5);   // 居中锚点
text.position.set(400, 300);

// 锚点含义
// (0, 0) — 左上角（默认）
// (0.5, 0.5) — 中心
// (1, 1) — 右下角
// (0.5, 0) — 顶部居中（适合标题）
// (0, 1) — 左下角
```

## 3. BitmapText — 位图文本

当需要显示大量文本（如游戏中的伤害数字、粒子文字）时，`Text` 的性能较差（每帧重新渲染 Canvas 2D 纹理）。`BitmapText` 使用预渲染的字体图集，性能远优于 `Text`。

### 3.1 对比

| 对比维度 | Text | BitmapText |
|---------|------|------------|
| 渲染方式 | 每次更新重新渲染 Canvas 2D | 使用预渲染的字体纹理 |
| 性能 | 文本频繁更新时开销大 | 极高性能（GPU 直接绘制） |
| 字体支持 | 任意系统字体 | 需要预生成字体图集 |
| 样式灵活性 | 高（渐变、阴影、描边） | 有限（颜色和缩放） |
| 适用场景 | UI 文本、标题 | 游戏内大量动态文本 |

### 3.2 使用方式

```javascript
import { BitmapFont, BitmapText } from 'pixi.js';

// 注册位图字体
BitmapFont.install({
  name: 'GameFont',
  style: {
    fontFamily: 'Arial',
    fontSize: 32,
    fill: '#ffffff',
  },
});

// 创建位图文本
const bitmapText = new BitmapText({
  text: 'Damage: -100',
  style: {
    fontName: 'GameFont',
    fontSize: 32,
  },
});
```

## 4. HTMLText — HTML 文本

v8 新增 `HTMLText`，支持在文本中使用 HTML 标签。

```javascript
import { HTMLText } from 'pixi.js';

const htmlText = new HTMLText({
  text: '<b>粗体</b> <i>斜体</i> <span style="color:red">红色</span>',
  style: {
    fontFamily: 'Arial',
    fontSize: 24,
    fill: '#ffffff',
  },
});
```

> **注意**：`HTMLText` 底层用 SVG foreignObject 渲染，性能不如 `Text`，适合少量富文本场景。

## 5. 实战：计分板

综合 Graphics 和 Text 制作一个游戏计分板：

```javascript
import { Application, Graphics, Text, TextStyle, Container } from 'pixi.js';

async function main() {
  const app = new Application();
  await app.init({ width: 800, height: 600, background: '#0f0f23' });
  document.body.appendChild(app.canvas);

  const ui = new Container();
  app.stage.addChild(ui);

  // 1. 计分板背景（圆角矩形 + 半透明）
  const panel = new Graphics();
  panel.roundRect(0, 0, 240, 80, 12);
  panel.fill({ color: 0x000000, alpha: 0.6 });
  panel.stroke({ width: 2, color: 0x4ecdc4 });
  panel.position.set(10, 10);
  ui.addChild(panel);

  // 2. 星星图标（星形 Graphics）
  const star = new Graphics();
  star.star(0, 0, 5, 16, 8);
  star.fill(0xffd93d);
  star.position.set(35, 50);
  ui.addChild(star);

  // 3. 分数文本
  const scoreStyle = new TextStyle({
    fontFamily: 'Arial',
    fontSize: 28,
    fontWeight: 'bold',
    fill: '#ffffff',
  });
  const scoreText = new Text({ text: '0', style: scoreStyle });
  scoreText.anchor.set(0, 0.5);
  scoreText.position.set(60, 50);
  ui.addChild(scoreText);

  // 4. 标题文本
  const titleText = new Text({
    text: 'SCORE',
    style: { fontFamily: 'Arial', fontSize: 14, fill: '#4ecdc4', letterSpacing: 3 },
  });
  titleText.position.set(20, 22);
  ui.addChild(titleText);

  // 5. 动态更新分数
  let score = 0;
  app.ticker.add(() => {
    score += 1;
    scoreText.text = score.toString();
  });
}

main();
```

```
┌──────────────────────────┐
│  SCORE                   │
│  ★ 0                     │  ← 星星图标 + 分数
└──────────────────────────┘
  圆角矩形背景（半透明黑色 + 青色描边）
```

## 6. 常见问题

### 6.1 Graphics 不显示

```javascript
// ❌ 忘记 fill 或 stroke
const g = new Graphics();
g.rect(0, 0, 100, 100);
// 什么都没显示！需要 fill() 或 stroke()

// ✅ 正确做法
g.rect(0, 0, 100, 100);
g.fill(0xff0000);
```

### 6.2 Text 更新后不变化

```javascript
// ❌ 直接修改 style 对象的属性
text.style = { fill: '#ff0000' };  // 不会生效

// ✅ 修改已有 style 的属性
text.style.fill = '#ff0000';

// ✅ 或整体替换
text.style = new TextStyle({ fill: '#ff0000', fontSize: 24 });
```

### 6.3 中文显示异常

```javascript
// 确保字体支持中文
const style = new TextStyle({
  fontFamily: '"Microsoft YaHei", "PingFang SC", Arial, sans-serif',
  fontSize: 24,
  fill: '#ffffff',
});
```

### 6.4 文本模糊

`resolution` 控制 Text 纹理的渲染倍率。默认值为设备像素比（`window.devicePixelRatio`），在大多数情况下自动匹配。但某些场景下需要手动设置：

```javascript
const text = new Text({
  text: 'Hello',
  style: { fill: '#fff', fontSize: 24 },
  resolution: 2,  // 2 倍分辨率渲染
});
```

**为什么需要 resolution？**

```
fontSize: 24 的文字

resolution: 1（默认）
┌──────────────┐
│ ░░▓▓░░       │  ← 用 24px 高的像素绘制
│ ░▓▓▓▓░       │     在 Retina 屏上每个逻辑像素
│ ░░▓▓░░       │     对应 2×2 物理像素 → 模糊
└──────────────┘

resolution: 2
┌──────────────────────┐
│ ░░░░▓▓▓▓░░░░         │  ← 用 48px 高的像素绘制
│ ░░▓▓▓▓▓▓▓▓░░         │     再缩放回 24px 显示
│ ░▓▓▓▓▓▓▓▓▓▓░         │     细节更清晰
│ ░░▓▓▓▓▓▓▓▓░░         │
│ ░░░░▓▓▓▓░░░░         │
└──────────────────────┘
```

| resolution | 效果 | 显存占用 | 适用场景 |
|------------|------|---------|---------|
| 1 | 模糊（尤其在 Retina 屏） | 1× | 不推荐 |
| 2 | 清晰 | 4×（宽高各 2 倍） | 大多数场景（推荐） |
| `window.devicePixelRatio` | 精确匹配设备 | 取决于设备 | 需要像素级精确时 |

**建议**：一般设 `resolution: 2` 即可，在清晰度和显存之间取得平衡。如果应用初始化时已设 `app.init({ resolution: window.devicePixelRatio })`，则 Text 会自动继承全局分辨率，无需单独设置。

## 📝 面试回答模板

> **问：PixiJS 的 Graphics 和原生 Canvas 2D 绘图有什么区别？**
>
> 最大的区别是渲染后端——原生 Canvas 2D 是 CPU 软件渲染，PixiJS 的 Graphics 底层仍然是 WebGL GPU 渲染。Graphics 定义的矢量路径会被编译为 GPU 指令，支持硬件加速。此外 Graphics 对象是场景图的节点，可以参与变换继承、事件检测、遮罩等。不过需要注意，复杂 Graphics（大量路径）的编译开销也不小，如果图形不需要频繁变化，可以用 `cacheAsBitmap` 缓存为位图。

> **问：Text 和 BitmapText 怎么选？**
>
> Text 每次更新都会重新渲染 Canvas 2D 纹理再上传到 GPU，文本频繁变化时开销大。BitmapText 使用预渲染的字体图集，GPU 直接绘制纹理区域，性能极高。选择依据：UI 中的标题、说明文字用 Text（样式丰富、不需要频繁更新）；游戏中的伤害数字、粒子文字、排行榜分数用 BitmapText（大量实例、频繁更新）。

> **问：PixiJS 的 Graphics 性能有什么注意事项？**
>
> Graphics 对象的矢量路径会被编译为 GPU 指令，首次编译有开销，复杂路径（大量 `moveTo`/`lineTo`）编译更慢。三个优化建议：1）静态图形用 `cacheAsBitmap = true` 缓存为位图，避免每帧重新编译；2）频繁变化的图形（如实时波形图）考虑直接操作 Canvas 2D 或用 `ParticleContainer`；3）多个相同形状用纹理缓存——先绘制一个 Graphics，用 `app.renderer.generateTexture(g)` 生成纹理，后续用 Sprite 复用。
