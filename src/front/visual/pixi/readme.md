- 用纯代码绘制图形、管理纹理、处理交互和动画

## 📚 模块详解

### 模块 1：环境搭建与第一个应用（0.5 天）
**面试可答**：如何初始化 PixiJS v8 应用，`Application` 的作用。

- CDN 引入与 npm 安装
- `Application` 初始化：`init({ width, height, background })`
- 理解 `app.canvas`、`app.stage`、`app.screen`
- **练习**：创建画布，设置背景色，添加一个圆形 `Graphics`

---

### 模块 2：场景图与显示对象（1 天）
**面试可答**：`Container` 类似无样式 `<div>`，`addChild` 管理层级。

- `DisplayObject` 公共属性：`x, y, scale, rotation, alpha, visible, width, height`
- `Container` 分组与嵌套，父子变换继承
- 排序与 `zIndex`
- **练习**：制作一个机器人——用圆形/矩形拼出头、身体、四肢，放入一个容器整体移动

---

### 模块 3：矢量绘图与文本（1 天）
**面试可答**：`Graphics` 无需外部资源即可绘制，`Text` 显示文字。

- `Graphics` 方法：`moveTo, lineTo, rect, circle, star, fill, stroke`
- 颜色与透明度，`Graphics` 的尺寸与定位
- `Text` 创建与样式更新（`fontSize`, `fill`, `fontFamily`）
- **练习**：纯代码绘制一个计分板，包含星星图标和数字

---

### 模块 4：精灵与纹理管理（1 天）
**面试可答**：`Sprite` 负责显示图片，`Texture` 是 GPU 纹理，`Assets` 异步加载。

- 使用 `PIXI.Assets.load()` 加载单张图片
- `Sprite.from()` 快捷创建精灵
- 纹理复用：多个精灵共享同一纹理
- 精灵图集概念（了解，可用简单 demo）
- **练习**：加载飞船和敌机图片，分别创建精灵并放置到舞台

---

### 模块 5：动画与 Ticker（1 天）
**面试可答**：`Ticker` 是封装的帧循环，`deltaTime` 实现帧率无关动画。

- `app.ticker.add(callback)` 使用
- 利用 `time.deltaTime` 匀速移动、旋转、缩放对象
- 简单缓动效果（线性插值）
- **练习**：让敌机自动下落，子弹向上飞行，角色带惯性移动

---

### 模块 6：交互事件系统（1 天）
**面试可答**：事件模式类似 DOM，需开启 `eventMode`，底层自动做命中检测。

- 设置 `eventMode = 'static'`（v8 必需）
- 常用事件：`pointertap`, `pointerdown`, `pointermove`, `globalpointermove`
- 全局事件与对象事件的区别
- 点击精灵做出反馈（缩放、变色）
- **练习**：点击敌机爆炸，点击飞船发射子弹

---

### 模块 7：进阶技巧与实战整合（2 天）
**面试可答**：碰撞检测（距离公式）、简单对象池（减少 GC）、滤镜与遮罩。

- 矩形碰撞与圆形碰撞（`Math.sqrt` 距离检测）
- 对象池思想：预先创建子弹/敌机，重复使用而不是频繁新建
- 遮罩（`mask`）实现圆形视野
- 可选：添加 `BlurFilter` 爆炸模糊效果
- **完整游戏制作**：见下方实践项目

---

## 🕹️ 实践项目：飞机大战

**功能清单**（覆盖全部核心 API）：
- 键盘/触摸控制战机移动（事件 + Ticker 动画）
- 敌机波次生成（定时器 + 对象池）
- 子弹发射与回收（对象池 + Ticker）
- 碰撞检测（距离公式 + 爆炸粒子 `Graphics`）
- 分数与生命值 UI（`Text` 动态更新）
- 开始/结束场景（`Container` 切换显示）
- 加分项：音效（`HTMLAudioElement`）、移动端适配

**项目结构建议**：
```
/js
  main.js        // 初始化应用，启动游戏循环
  Player.js      // 玩家类，封装移动、射击
  Enemy.js       // 敌机类，自动下落
  Bullet.js      // 子弹类，对象池静态方法
  Explosion.js   // 粒子特效
  UI.js          // 分数、生命值
```

**制作时间**：5~7 天（每天 1-2 小时），可与模块 7 合并进行。
