> 一名成熟前端工程师快速掌握四款主流视觉库的学习仓库 —— 不求深究原理，但求**面试能答、功能能做、项目能跑**。

| 需求 | 说明 |

## 🗺️ 建议学习路径

按依赖关系，建议按以下顺序学习：

```
Konva.js（最易上手，理解 Canvas 封装）
   ↘
PixiJS（加深 WebGL/渲染循环/对象池理解）
   ↘
D3.js（转向数据驱动思维，SVG 操作）
   ↘
Three.js（进入 3D 领域，承前启后）
```

当然，四个库**相互独立**，也可以按兴趣跳着学。

## 📋 每个子目录的学习模式

每个库的 `readme.md` 统一遵循以下结构：

1. **学习目标** —— 学完能做什么、能答什么
2. **前置要求** —— 需要什么基础
3. **模块详解（6~7 个）** —— 每个模块 = 知识点 + 面试可答 + 动手练习
4. **实践项目** —— 融合全部 API 的完整 Demo
5. **时间线** —— 每天 1~2 小时的日程安排
6. **完成标准** —— 学完的检验标准
7. **面试对比表** —— 与同类库/原生方案的差异

## 🎤 面试场景速记

| 如果面试官问... | 你的回答高亮 |
|----------------|-------------|
| "PixiJS 相比原生 Canvas 有什么优势？" | 场景图 + 自动重绘 + 事件系统 + 对象管理 |
| "D3 和 ECharts 怎么选？" | D3 是底层工具，高度可定制但不封装图表；ECharts 配置驱动，开箱即用 |
| "Konva 适合什么场景？" | 画板、图形编辑器、标注工具——需要拖拽、变换、图层管理 |
| "为什么选 Three.js 而不是直接写 WebGL？" | Three 封装了 WebGL 管线，提供 Scene/Mesh/Material 抽象，开发者无需手写着色器 |
| "了解哪些视觉库？" | 2D 游戏用 PixiJS，数据可视化用 D3.js，交互编辑用 Konva.js，3D 用 Three.js |
