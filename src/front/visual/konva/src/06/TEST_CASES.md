# 06 - 在线白板 功能测试用例

> 逐项检查功能是否正常。预期结果用 ✅ 标记，碰到 Bug 请记录实际结果。

---

## 1. 基础环境

### 1.1 页面加载
- [ ] 用 Live Server 打开 `index.html`，页面正常渲染
- [ ] 左侧工具栏 5 个按钮可见，第一个"选择"按钮高亮（active 状态）
- [ ] 右侧面板显示"图层"标题，下方有一个"主图层"条目
- [ ] 右侧底部 5 个操作按钮可见

### 1.2 窗口自适应
- [ ] 缩放浏览器窗口，画布自动跟随宽高变化

---

## 2. 工具栏切换

### 2.1 点击切换
- [ ] 依次点击每个工具按钮，被点击的按钮高亮，其余取消高亮
- [ ] 切换到"选择"以外的工具时（画笔/矩形/圆形/文字），画布鼠标指针变为 `crosshair`

### 2.2 快捷键切换
- [ ] 按 `V` → 切换到"选择"，`↖` 按钮高亮
- [ ] 按 `P` → 切换到"画笔"，`✏` 按钮高亮
- [ ] 按 `R` → 切换到"矩形"，`▭` 按钮高亮
- [ ] 按 `C` → 切换到"圆形"，`○` 按钮高亮
- [ ] 按 `T` → 切换到"文字"，`T` 按钮高亮

---

## 3. 图形绘制

### 3.1 矩形
- [ ] 切换到矩形工具（`R`）
- [ ] 在画布上按下鼠标并拖拽 → 出现一个半透明蓝色矩形，大小随鼠标变化
- [ ] 松开鼠标 → 矩形固定，填充色半透明蓝色，边框蓝色
- [ ] 绘制一个很小的矩形（< 5px）→ 自动销毁

### 3.2 圆形
- [ ] 切换到圆形工具（`C`）
- [ ] 在画布上按下鼠标并拖拽 → 出现一个半透明红色椭圆
- [ ] 松开鼠标 → 椭圆固定

### 3.3 文字
- [ ] 切换到文字工具（`T`）
- [ ] 点击画布任意位置 → 弹出 prompt 输入框
- [ ] 输入文字后确认 → 画布上出现对应文字
- [ ] 点取消或不输入 → 不创建文字

### 3.4 画笔
- [ ] 切换到画笔工具（`P`）
- [ ] 在画布上按下鼠标并拖拽 → 出现黑色自由曲线
- [ ] 松开鼠标 → 曲线固定，可选中

---

## 4. 选择与交互

### 4.1 选中图形
- [ ] 切换到选择工具（`V`）
- [ ] 点击矩形 → 矩形四角出现 Transformer（缩放/旋转控件）
- [ ] 点击圆形 → Transformer 切换到圆形上
- [ ] 点击文字 → Transformer 切换到文字上
- [ ] 点击画笔绘制的线条 → Transformer 切换到线条上

### 4.2 取消选中
- [ ] 选中一个图形后，点击画布空白区域 → Transformer 消失，选中取消

### 4.3 拖拽
- [ ] 选中一个图形，按住拖拽 → 图形跟随鼠标移动
- [ ] 拖拽到新位置松开 → 图形停在目标位置

### 4.4 缩放/旋转
- [ ] 选中一个矩形，拖拽 Transformer 角上的缩放柄 → 矩形缩放
- [ ] 松开后矩形尺寸正确更新（scale 合并到 width/height，scaleX/scaleY 重置为 1）

### 4.5 鼠标指针
- [ ] 鼠标移到图形上 → 指针变为手形（pointer）
- [ ] 鼠标移出图形 → 指针恢复默认

---

## 5. 删除

### 5.1 快捷键删除
- [ ] 选中一个图形，按 `Delete` 键 → 图形被删除
- [ ] 选中一个图形，按 `Backspace` 键 → 图形被删除
- [ ] 按 Delete 时 Transformer 不应触发删除焦点（在非 input 区域）

### 5.2 空选删除不报错
- [ ] 没有选中任何图形时按 `Delete` → 无任何反应，控制台无报错

---

## 6. 撤销/重做

### 6.1 撤销
- [ ] 绘制一个矩形
- [ ] 按 `Ctrl+Z` → 矩形消失，画布恢复到之前状态
- [ ] 继续按 `Ctrl+Z`（如果还有历史）→ 继续回退

### 6.2 重做
- [ ] 撤销后按 `Ctrl+Y` → 矩形恢复
- [ ] 撤销后按 `Ctrl+Shift+Z` → 同上，重做

### 6.3 多步验证
- [ ] 依次绘制：矩形 → 圆形 → 文字
- [ ] 连续按 `Ctrl+Z` 三次 → 依次删除文字、圆形、矩形
- [ ] 连续按 `Ctrl+Y` 三次 → 依次恢复矩形、圆形、文字

### 6.4 操作后清空 redo
- [ ] 撤销一次
- [ ] 画一个新图形 → 重做栈清空
- [ ] 按 `Ctrl+Y` → 不应恢复之前撤销的内容

### 6.5 拖拽后撤销
- [ ] 绘制一个矩形，拖拽到新位置
- [ ] 按 `Ctrl+Z` → 矩形回到拖拽前的位置

---

## 7. 图层管理

### 7.1 添加图层
- [ ] 点击"＋ 添加图层"按钮 → 图层面板新增"图层 2"条目
- [ ] "图层 2"高亮（当前活跃图层）

### 7.2 切换图层
- [ ] 点击"主图层"条目 → 主图层高亮，图层 2 取消高亮
- [ ] 在新图层上绘制一个矩形 → 矩形属于该图层
- [ ] 切换到另一个图层 → 之前图层的图形不可选中/操作

### 7.3 图层显隐
- [ ] 点击图层条目左侧的 👁 按钮 → 该图层内容隐藏
- [ ] 再次点击 → 内容重新显示

### 7.4 删除图层
- [ ] 点击图层条目右侧的 ✕ 按钮 → 该图层被删除
- [ ] 只剩一个图层时点击 ✕ → 不应被删除（最少保留一个图层）

---

## 8. 导出

### 8.1 导出 PNG
- [ ] 画布上有一些图形
- [ ] 点击"🖼 导出 PNG" → 浏览器下载一个 `whiteboard.png` 文件
- [ ] 打开图片，内容与画布一致

### 8.2 保存项目
- [ ] 点击"💾 保存项目" → 下载 `project.json` 文件
- [ ] 文件内容为合法的 JSON 格式

### 8.3 加载项目
- [ ] 清空画布
- [ ] 点击"📂 加载项目" → 选择刚才保存的 `project.json`
- [ ] 画布恢复到保存前的所有图形和图层的状态
- [ ] 加载后图形可正常选中、拖拽

### 8.4 加载错误处理
- [ ] 加载一个非 JSON 文件 → 弹出"文件格式错误"提示

### 8.5 清空画布
- [ ] 点击"🗑 清空画布" → 弹出确认框
- [ ] 点"确定" → 所有图层内容清空
- [ ] 点"取消" → 画布内容保留

---

## 9. 边界情况

### 9.1 切换工具时清除选中
- [ ] 选中一个图形（Transformer 可见）
- [ ] 切换到矩形/画笔等其他工具 → Transformer 消失

### 9.2 跨图层选中
- [ ] 图层 A 有一个图形，切换到图层 B
- [ ] 点选图层 A 的图形 → 不应被选中

### 9.3 空画布操作
- [ ] 刚加载页面，没画任何东西
- [ ] 按 `Ctrl+Z` → 无任何反应，控制台无报错
- [ ] 点击"加载项目"但无保存数据 → 使用合法 JSON 文件
