📐 Konva 分层架构 & 渲染机制

1. Stage → Layer → Shape 的 DOM 对应关系：

div#root
(容器) → div.konvajs-content
(Konva 内部容器) → canvas
← layer2 (上层) canvas
← layer1 (下层)

每个 Layer 对应一个真实的 <canvas> DOM 元素，后 add 的在上层（类似 z-index）。 上层图形会遮挡下层重叠区域的图形。

2. 为什么不需要写 layer.draw()？

  • 现代 Konva（v7+）已全面自动化渲染——add()、setAttrs() 等操作都会自动通过 requestAnimationFrame 批量渲染
  • draw() 是早期版本的遗留用法，现在仅用于「强制立即渲染」的极少数场景

日常开发中不需要写 draw()，Konva 会自动处理。下面 JS 中全部注释掉了，渲染照样正常。
