> 对应大纲模块 2 | 预计时间：1 天

## 1. 图形类总览

Konva 提供了丰富的内置图形，使用时传入配置对象即可：

| 图形 | 类名 | 核心属性 |
|------|------|---------|
| 矩形 | `Konva.Rect` | `x, y, width, height, cornerRadius` |
| 圆形 | `Konva.Circle` | `x, y, radius` |
| 椭圆 | `Konva.Ellipse` | `x, y, radiusX, radiusY` |
| 线段/路径 | `Konva.Line` | `points, closed, tension` |
| 多边形 | `Konva.Polygon` | `sides, radius` |
| 文本 | `Konva.Text` | `text, fontSize, fontFamily` |
| 图片 | `Konva.Image` | `image`（HTMLImageElement） |
| 环形 | `Konva.Ring` | `innerRadius, outerRadius` |
| 弧线 | `Konva.Arc` | `angle, innerRadius, outerRadius` |
| 路径 | `Konva.Path` | `data`（SVG path data） |
| 星形 | `Konva.Star` | `numPoints, innerRadius, outerRadius` |
| 标签 | `Konva.Label` | 组合 Tag + Text，用于标注 |

## 2. 样式属性

所有图形共享一套样式属性：

### 填充

```js
fill: 'red'               // 颜色名
fill: '#ff0000'           // 十六进制
fill: 'rgb(255, 0, 0)'   // RGB
fill: 'rgba(255,0,0,0.5)' // 半透明
fill: ''                  // 不填充
```

### 描边

```js
stroke: '#333'
strokeWidth: 4
strokeScaleEnabled: false  // 缩放时描边宽度是否跟随
lineCap: 'round'           // 线条端点样式
lineJoin: 'round'          // 线条连接样式
```

### 透明度

```js
opacity: 0.5   // 0 ~ 1，作用于整个图形
fill: 'rgba(255,0,0,0.5)' // 仅填充部分半透明
```

### 阴影

```js
shadowColor: 'black'
shadowBlur: 10
shadowOffsetX: 5
shadowOffsetY: 5
shadowOpacity: 0.5
```

## 3. 各图形详解

### Konva.Rect

```js
new Konva.Rect({
  x: 50,
  y: 50,
  width: 200,
  height: 120,
  fill: '#4A90D9',
  stroke: '#2C5F8A',
  strokeWidth: 4,
  cornerRadius: 10,  // 圆角
});
```

`cornerRadius` 可以是数字（统一圆角）或数组 `[10, 20, 10, 20]`（分别设置四个角）。

### Konva.Circle

```js
new Konva.Circle({
  x: 150,
  y: 150,
  radius: 80,
  fill: '#E74C3C',
});
```

### Konva.Line

```js
// 简单折线
new Konva.Line({
  points: [50, 50, 150, 100, 250, 50],
  stroke: '#2ECC71',
  strokeWidth: 4,
  lineCap: 'round',
  lineJoin: 'round',
});

// 闭合多边形
new Konva.Line({
  points: [50, 100, 150, 50, 250, 100],
  stroke: '#F39C12',
  strokeWidth: 4,
  fill: '#F1C40F',
  closed: true,       // 自动闭合
});

// 曲线（tension 控制平滑度）
new Konva.Line({
  points: [50, 100, 150, 50, 200, 120, 300, 60],
  stroke: '#9B59B6',
  strokeWidth: 4,
  tension: 0.5,       // 0 为直线，1 为最平滑
  lineCap: 'round',
});
```

### Konva.Text

```js
new Konva.Text({
  x: 50,
  y: 50,
  text: 'Hello Konva',
  fontSize: 32,
  fontFamily: 'Arial',
  fill: '#333',
  align: 'center',       // 水平对齐
  verticalAlign: 'middle',// 垂直对齐
  width: 300,            // 需要设置宽度，align 才生效
  height: 100,
  padding: 20,
  textDecoration: 'underline',
  fontStyle: 'bold',     // 'normal', 'bold', 'italic'
  lineHeight: 1.5,
});

// 自动换行
const multiLineText = new Konva.Text({
  x: 50,
  y: 200,
  text: '这是一段很长的文字，会自动换行显示，因为设置了宽度。',
  fontSize: 18,
  width: 300,
  fill: '#666',
});
```

### Konva.Image

```js
const imageObj = new Image();
imageObj.src = 'image.png';
imageObj.onload = () => {
  const image = new Konva.Image({
    x: 50,
    y: 50,
    image: imageObj,
    width: 200,
    height: 150,
  });
  layer.add(image);
  layer.draw();
};
```

> 注意：`Konva.Image` 需要等待图片加载完成后再创建，不像 DOM `<img>` 那样自动处理。

### 快捷方式：`Konva.Image.fromURL()`

```js
Konva.Image.fromURL('image.png', (imageNode) => {
  imageNode.setAttrs({
    x: 50, y: 50,
    width: 200, height: 150,
  });
  layer.add(imageNode);
  layer.draw();
});
```

## 4. 链式调用与方法

Konva 的配置方式有两种，风格任选：

### 构造时传入（推荐初始化时用）

```js
const circle = new Konva.Circle({
  x: 100, y: 100,
  radius: 50,
  fill: 'red',
});
```

### 调用方法修改（推荐动态修改时用）

```js
circle.x(200)
circle.y(200)
circle.radius(80)
circle.fill('blue')
circle.stroke('#333')
circle.strokeWidth(4)

// setAttrs 可以批量设置
circle.setAttrs({
  x: 300,
  y: 300,
  fill: 'green',
})
```

**关键**：大多数属性同时有**构造参数**和**getter/setter 方法**，即 `new Konva.Rect({ x: 100 })` 等价于 `rect.x(100)`，取值也是 `rect.x()`。

## 5. Group 分组

Group 可以把多个图形组合在一起，统一操作：

```js
const group = new Konva.Group({
  x: 100,
  y: 100,
});

const rect = new Konva.Rect({
  x: 0, y: 0,
  width: 100, height: 100,
  fill: 'red',
});

const text = new Konva.Text({
  x: 10, y: 40,
  text: 'Box',
  fontSize: 20,
  fill: 'white',
});

group.add(rect);
group.add(text);
layer.add(group);
layer.draw();

// 统一操作
group.x(200);     // 整体移动
group.rotation(45); // 整体旋转
group.scaleX(2);  // 整体缩放
```

**注意**：Group 中图形的坐标是**相对 Group 的局部坐标**，不是 Stage 的绝对坐标。

## 6. 查找图形

```js
// 按 name 查找（类似 DOM 的 className）
circle.name('myCircle');
layer.findOne('.myCircle');    // 返回第一个
layer.find('.myCircle');       // 返回数组

// 按 id 查找（类似 DOM 的 id）
circle.id('circle1');
layer.findOne('#circle1');

// 按类型查找
layer.find('Circle');          // 返回所有 Circle
```

`findOne` 返回第一个匹配项，`find` 返回所有匹配项的数组。

## 🆚 对比：Konva 图形系统 vs SVG 基本形状

| 维度 | Konva Shape | SVG Element | 原生 Canvas |
|------|------------|-------------|-------------|
| 创建方式 | `new Konva.Rect({...})` | `<rect .../>` | `ctx.fillRect(...)` |
| 修改属性 | `shape.fill('red')` 自动重绘 | `el.setAttribute('fill','red')` | 清空画布重新绘制 |
| 圆角矩形 | `cornerRadius` 原生支持 | `rx`/`ry` 属性 | 需手动计算路径 |
| 文本换行 | 设置 `width` 自动换行 | `<foreignObject>` 或手动 | 完全手动实现 |
| 分组 | `Konva.Group` 统一变换 | `<g>` 标签 | 无原生支持 |
| 图片加载 | 需等 `onload`，`fromURL` 简化 | `<image>` 自动处理 | 需等 `onload` |

## 📝 面试回答模板

> **问：Konva 如何管理图形对象？跟原生 Canvas 有什么不同？**
>
> Konva 把每个图形都封装为独立的对象（Rect、Circle、Line 等），通过 Stage → Layer → Shape 的树形结构管理。原生 Canvas 是过程式绘制——调用 API 画上去就变成像素，无法单独操作某个图形。Konva 的对象模型让我们可以直接修改某个图形的属性（位置、颜色、大小），然后调用 `layer.draw()` 整体重绘，这样就有"对象化操作"的体验。
