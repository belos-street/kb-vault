# 05 - 序列化与导出

> 对应大纲模块 5 | 预计时间：0.5 天
> 面试可答：`toJSON()` 序列化为 JSON，`toDataURL()` 导出图片。

---

## 1. 序列化：`stage.toJSON()`

Konva 可以将整个 Stage 的状态序列化为 JSON 字符串，包含所有图形的位置、尺寸、样式信息。

```js
const stage = new Konva.Stage({
  container: 'root',
  width: 800,
  height: 600,
});

const layer = new Konva.Layer();
stage.add(layer);

const rect = new Konva.Rect({
  x: 100, y: 100,
  width: 200, height: 150,
  fill: '#4A90D9',
  stroke: '#333',
  strokeWidth: 4,
  draggable: true,
});
layer.add(rect);

const circle = new Konva.Circle({
  x: 400, y: 200,
  radius: 80,
  fill: '#E74C3C',
});
layer.add(circle);

// 序列化
const json = stage.toJSON();
console.log(json);
// 输出类似：
// {"attrs":{"width":800,"height":600},"className":"Stage","children":[{
//   "attrs":{},"className":"Layer","children":[{
//     "attrs":{"x":100,"y":100,"width":200,"height":150,...},
//     "className":"Rect","children":[]
//   },{
//     "attrs":{"x":400,"y":200,"radius":80,...},
//     "className":"Circle","children":[]
//   }]
// }]}
```

### 序列化核心规则

- **图形属性**：所有 `setAttrs` 设置的属性都会被序列化
- **className**：记录图形类型（`Rect`、`Circle`、`Text` 等），用于反序列化重建
- **树结构**：完整的 Stage → Layer → Group → Shape 层级关系
- **事件绑定**：**不会**被序列化（需要反序列化后重新绑定）

## 2. 反序列化：`Konva.Node.create()`

```js
// 从 JSON 恢复 Stage
const json = stage.toJSON();
const restoredStage = Konva.Node.create(json, 'root');

// restoredStage 是完全独立的 Stage，包含原来的所有图形
```

### 反序列化后的注意事项

1. **事件丢失**：需要重新绑定事件
2. **需要手动 draw**：反序列化后调用 `restoredStage.find('Layer').forEach(l => l.draw())`
3. **图片资源**：`Konva.Image` 的 `image` 属性不会被序列化（HTMLImageElement 无法 JSON 化），需要单独处理
4. **自定义属性**：如果你的图形上挂了自定义属性，需要确保它们能被 JSON 序列化

### 封装保存/加载

```js
// 保存
function saveProject(stage) {
  const json = stage.toJSON();
  localStorage.setItem('konva-project', json);
}

// 加载
function loadProject(containerId) {
  const json = localStorage.getItem('konva-project');
  if (!json) return null;

  const stage = Konva.Node.create(json, containerId);

  // 重新绑定事件（示例）
  stage.find('.shape').forEach(shape => {
    shape.on('click', () => {
      tr.nodes([shape]);
    });
  });

  // 重新渲染
  stage.find('Layer').forEach(l => l.draw());
  return stage;
}
```

## 4. 导出为图片：`toDataURL()`

```js
// Stage 整体导出
const dataURL = stage.toDataURL();
// 返回: "data:image/png;base64,iVBORw0KGgo..."

// 指定格式与质量
stage.toDataURL({
  mimeType: 'image/jpeg',   // 默认 'image/png'
  quality: 0.9,             // JPEG 质量，0~1
  x: 0, y: 0,              // 裁剪区域
  width: 400, height: 300,
});

// 单个 Layer 导出
const layerURL = layer.toDataURL();
// 只导出一个 Canvas 层的内容

// 单个图形导出
const rectURL = rect.toDataURL();
```

### 导出并下载

```js
function downloadImage(stage, filename = 'canvas.png') {
  const dataURL = stage.toDataURL({ mimeType: 'image/png' });
  const link = document.createElement('a');
  link.href = dataURL;
  link.download = filename;
  link.click();
}
```

### 导出为 Blob（用于上传）

```js
stage.toBlob({
  mimeType: 'image/png',
  quality: 1,
}).then(blob => {
  // 可以上传到服务器
  const formData = new FormData();
  formData.append('image', blob, 'canvas.png');
});
```

## 5. 导出考虑因素

### 图层叠加

如果你有多个 Layer，想要导出**所有 Layer 合并**的图片，只能用 `stage.toDataURL()`。单独 `layer.toDataURL()` 只导出当前 Layer 的内容。

### 背景色

Stage 本身没有背景色属性。如果想导出带背景色的图片，有两种方式：

```js
// 方式 1：在最底层 Layer 添加一个背景矩形
const bgLayer = new Konva.Layer();
const bg = new Konva.Rect({
  x: 0, y: 0,
  width: stage.width(),
  height: stage.height(),
  fill: '#ffffff',
});
bgLayer.add(bg);
stage.add(bgLayer);
bgLayer.moveToBottom();  // 移到最底层

// 方式 2：导出时临时添加背景（不推荐）
```

### 图片资源导出

如果你的画布中包含 `Konva.Image`，导出的 JSON 中图片的 `image` 字段会是 `null`。解决方法是保存图片的 URL 并在加载时重新加载：

```js
// 保存时额外记录图片信息
function saveWithImages(stage) {
  const json = stage.toJSON();
  const images = [];

  stage.find('Image').forEach(img => {
    images.push({
      id: img.id(),
      src: img.getAttr('src'),  // 自定义属性，保存时手动设置
    });
  });

  return { json, images };
}
```

## 6. 持久化方案

### localStorage（适合小项目）

```js
const data = stage.toJSON();
localStorage.setItem('project', data);
// 限制：约 5MB，适用于几百个图形
```

### IndexedDB（适合大型项目）

```js
// 简单的封装
function saveToIndexedDB(key, stage) {
  const json = stage.toJSON();
  const request = indexedDB.open('KonvaProjects', 1);

  request.onupgradeneeded = (e) => {
    const db = e.target.result;
    db.createObjectStore('projects', { keyPath: 'id' });
  };

  request.onsuccess = (e) => {
    const db = e.target.result;
    const tx = db.transaction('projects', 'readwrite');
    tx.objectStore('projects').put({ id: key, data: json });
  };
}
```

### 导出文件下载（适合导出/导入）

```js
function exportToFile(stage) {
  const json = stage.toJSON();
  const blob = new Blob([json], { type: 'application/json' });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = 'project.json';
  a.click();
  URL.revokeObjectURL(url);
}

function importFromFile(stage, containerId) {
  const input = document.createElement('input');
  input.type = 'file';
  input.accept = '.json';
  input.onchange = (e) => {
    const reader = new FileReader();
    reader.onload = (evt) => {
      const json = evt.target.result;
      const newStage = Konva.Node.create(json, containerId);
      newStage.find('Layer').forEach(l => l.draw());
    };
    reader.readAsText(e.target.files[0]);
  };
  input.click();
}
```

## 7. 完整示例：一个带保存/加载的画板

```js
const stage = new Konva.Stage({
  container: 'root',
  width: 800, height: 600,
});
const layer = new Konva.Layer();
stage.add(layer);

// 添加一些图形
layer.add(new Konva.Rect({
  x: 100, y: 100, width: 200, height: 150,
  fill: '#4A90D9', draggable: true,
}));
layer.add(new Konva.Circle({
  x: 400, y: 200, radius: 80,
  fill: '#E74C3C', draggable: true,
}));

// 保存按钮
document.getElementById('saveBtn').onclick = () => {
  const json = layer.toJSON();
  localStorage.setItem('canvas-state', json);
  alert('已保存');
};

// 加载按钮
document.getElementById('loadBtn').onclick = () => {
  const json = localStorage.getItem('canvas-state');
  if (!json) return alert('无保存数据');

  layer.destroyChildren();
  const tempLayer = Konva.Node.create(json);
  tempLayer.children.forEach(child => {
    layer.add(child.clone());  // clone 保留属性
  });
  alert('已加载');
};
```

## ✏️ 练习

实现一个简易画板的保存和加载功能：

**要求**：
1. 创建一个 Stage，包含至少 3 个不同图形（矩形、圆形、文字）
2. 实现"保存"功能：将画布序列化为 JSON 存入 localStorage
3. 实现"加载"功能：从 localStorage 读取并恢复画布
4. 实现"导出"功能：将画布导出为 PNG 图片并下载
5. 加载后重新为图形绑定拖拽事件

**提示**：
```js
// 重新绑定拖拽
loadedLayer.find('Rect,Circle,Text,Line').forEach(shape => {
  shape.draggable(true);
  // 可选：绑定选中事件
  if (shape.getClassName() !== 'Text') {
    shape.on('click', () => console.log('selected', shape.id()));
  }
});
```

**预期效果**：刷新页面后点"加载"能还原之前的画布内容，点"导出"就能下载图片。加载后图形应可正常拖拽。

## 🆚 对比：Konva 序列化 vs fabric.js vs 原生方案

| 维度 | Konva | fabric.js | 原生 Canvas |
|------|-------|-----------|-------------|
| 序列化格式 | JSON | JSON / SVG | 无（需手动提取状态） |
| 反序列化 | `Konva.Node.create(json)` 一行恢复 | `canvas.loadFromJSON(json)` | 无法反序列化 |
| 图片导出 | `toDataURL()` / `toBlob()` | `toDataURL()` / `toSVG()` | `canvas.toDataURL()` |
| 事件保留 | ❌ 不保留，需重新绑定 | ❌ 不保留 | 不适用 |
| 图片资源 | HTMLImageElement 不可序列化，需额外处理 | 同 | 不适用 |
| 持久化 | 配合 localStorage/IndexedDB/文件即可 | 同 | 只能保存像素数据 |

## 📝 面试回答模板

> **问：Konva 的序列化机制是怎么工作的？有什么用？**
>
> Konva 提供了 `stage.toJSON()` 将整个画布状态序列化为 JSON，包含所有图形的位置、尺寸、样式、层级关系。对应的 `Konva.Node.create(json)` 可以从 JSON 重建画布。这对画板类应用非常有用，可以实现：1. 项目的保存与加载（本地存储或服务端）；2. 撤销/重做（保存历史快照）；3. 导出为图片（`toDataURL` 支持 PNG/JPEG）。需要注意的是，事件绑定不会被序列化，需要在重建后重新绑定。
