# 04 - 事件系统

> 对应大纲模块 4 | 预计时间：1 天
> 面试可答：Konva 事件系统类似 DOM，支持冒泡，有精确的像素级命中检测。

---

## 1. 事件绑定

Konva 使用 `on()` / `off()` 绑定和移除事件，语法与 jQuery/DOM 类似：

```js
shape.on('click', (e) => {
  console.log('clicked', e.target);
});

shape.off('click');               // 移除所有 click 事件
shape.off('click', handlerFn);    // 移除指定处理函数
```

### 支持的事件类型

| 事件 | 说明 |
|------|------|
| `click` | 单击 |
| `dblclick` | 双击 |
| `mouseover` / `mouseout` | 鼠标移入/移出 |
| `mousemove` | 鼠标在图形上移动 |
| `mousedown` / `mouseup` | 鼠标按下/释放 |
| `mouseenter` / `mouseleave` | 进入/离开（不冒泡） |
| `wheel` | 滚轮 |
| `touchstart` / `touchend` / `touchmove` | 触摸事件 |
| `pointerdown` / `pointerup` / `pointermove` | 指针事件（统一鼠标+触摸） |
| `dragstart` / `dragmove` / `dragend` | 拖拽事件 |
| `transformstart` / `transformmove` / `transformend` | 变换事件 |

### `mouseover/mouseout` vs `mouseenter/mouseleave`

这是面试容易被追问的细节。两者区别在于**是否冒泡**：

| 事件对 | 冒泡 | 触发时机 |
|--------|:--:|------|
| `mouseover` / `mouseout` | ✅ 冒泡 | 鼠标进入/离开图形**及其子元素**边界都会触发 |
| `mouseenter` / `mouseleave` | ❌ 不冒泡 | 仅在鼠标进入/离开**该图形自身**时触发一次 |

```js
const group = new Konva.Group({ width: 200, height: 200 });
const rect = new Konva.Rect({ x: 20, y: 20, width: 100, height: 100, fill: 'red' });
group.add(rect);

// 鼠标从外部移入 rect 时：
rect.on('mouseover', () => console.log('rect over'));   // ✅ 触发
rect.on('mouseenter', () => console.log('rect enter'));  // ✅ 触发
group.on('mouseover', () => console.log('group over'));  // ✅ 触发（冒泡）
group.on('mouseenter', () => console.log('group enter'));// ❌ 不触发（不冒泡）
```

**使用建议**：
- **`mouseover/mouseout`**：需要子元素也能触发父级事件时使用（如 Group 中的任何子元素 hover 都要高亮 Group 边框）
- **`mouseenter/mouseleave`**：只需要关心自己边界、不想被子元素干扰时使用（如精确判断鼠标是否在某个图形上方做工具提示）

## 2. 事件对象 e

```js
shape.on('click', (e) => {
  e.target;           // 实际触发事件的图形
  e.currentTarget;    // 绑定事件的图形（冒泡时不同）
  e.evt;              // 原生 DOM 事件对象
  e.type;             // 事件类型 'click'
  
  // 原生事件信息
  e.evt.clientX;      // 鼠标屏幕 X
  e.evt.clientY;      // 鼠标屏幕 Y
  
  // Konva 坐标
  const pos = shape.getStage().getPointerPosition();
  pos.x;              // 鼠标在 Stage 中的 X
  pos.y;              // 鼠标在 Stage 中的 Y
});
```

## 3. 事件冒泡

Konva 的事件会沿着图形树向上冒泡：**Shape → Group → Layer → Stage**。

```js
const layer = new Konva.Layer();
const group = new Konva.Group();
const rect = new Konva.Rect({ x: 0, y: 0, width: 100, height: 100, fill: 'red' });

group.add(rect);
layer.add(group);
stage.add(layer);

// 所有层级都能收到 click
rect.on('click', (e) => console.log('rect', e.target === e.currentTarget));
group.on('click', (e) => console.log('group', e.target === e.currentTarget));
layer.on('click', (e) => console.log('layer', e.target === e.currentTarget));
stage.on('click', (e) => console.log('stage', e.target === e.currentTarget));

// 点击红色矩形，输出：
// rect  true      （e.target === rect）
// group false     （e.target 仍是 rect）
// layer false
// stage false
```

### 阻止冒泡

```js
rect.on('click', (e) => {
  e.cancelBubble = true;   // 阻止继续冒泡
  // 或者
  // e.evt.stopPropagation();
});
```

## 4. 鼠标悬停效果

```js
rect.on('mouseover', () => {
  rect.fill('#E74C3C');
});

rect.on('mouseout', () => {
  rect.fill('#4A90D9');
});
```

### 更优雅的方式：用 `setAttrs` 批量更新

```js
rect.on('mouseover', () => {
  rect.setAttrs({
    fill: '#E74C3C',
    scaleX: 1.1,
    scaleY: 1.1,
    shadowBlur: 10,
  });
});

rect.on('mouseout', () => {
  rect.setAttrs({
    fill: '#4A90D9',
    scaleX: 1,
    scaleY: 1,
    shadowBlur: 0,
  });
});
```

## 5. Stage 全局事件

有些事件需要绑定在 Stage 上，比如画布级别的事件：

```js
// 空白区域点击
stage.on('click', (e) => {
  if (e.target === stage) {
    console.log('点击了画布空白区域');
    tr.nodes([]);           // 取消选中
  }
});

// 全局鼠标移动
stage.on('mousemove', (e) => {
  const pos = stage.getPointerPosition();
  // 实时获取鼠标位置
});

// 键盘事件（需要在 DOM 上监听）
document.addEventListener('keydown', (e) => {
  if (e.key === 'Delete' || e.key === 'Backspace') {
    // 删除选中的图形
    const selected = tr.nodes();
    selected.forEach(node => node.destroy());
    tr.nodes([]);
  }
});
```

## 6. 鼠标样式

根据交互状态，动态切换鼠标样式提升体验：

```js
rect.on('mouseover', () => {
  stage.container().style.cursor = 'pointer';
});

rect.on('mouseout', () => {
  stage.container().style.cursor = 'default';
});

// 拖拽时显示 grab
rect.on('mousedown', () => {
  stage.container().style.cursor = 'grabbing';
});
rect.on('mouseup', () => {
  stage.container().style.cursor = 'pointer';
});
```

更标准的方式是在图形上设置 `hoverStyle`，但更通用的方案就是在 `mouseover`/`mouseout` 中手动管理 `cursor`。

## 7. 碰撞检测

Konva 用 `getIntersection()` 检测某个位置是否有图形：

```js
stage.on('mousemove', (e) => {
  const pos = stage.getPointerPosition();
  // 检测该位置是否有图形
  const target = stage.getIntersection(pos);
  
  if (target) {
    // 鼠标悬停在某个图形上
    console.log('hovering:', target.name());
  }
});
```

`getIntersection` 按照**显示层级倒序**检测（最上层优先），找到第一个匹配的图形返回。

**注意**：Stage 默认只检测当前鼠标下的图形，`getIntersection` 是手动检测任意坐标。

## 8. 实战：点击选中 + 高亮 + 变换

这是白板项目最核心的交互模式：

```js
const stage = new Konva.Stage({
  container: 'root',
  width: 800, height: 600,
});
const layer = new Konva.Layer();
stage.add(layer);

const tr = new Konva.Transformer();
layer.add(tr);

function createShape(x, y, color) {
  const shape = new Konva.Rect({
    x, y,
    width: 120, height: 80,
    fill: color,
    draggable: true,
    name: 'shape',
  });

  // 鼠标悬停效果
  shape.on('mouseover', () => {
    document.body.style.cursor = 'pointer';
    shape.setAttrs({
      shadowBlur: 10,
      shadowColor: 'rgba(0,0,0,0.3)',
    });
  });

  shape.on('mouseout', () => {
    document.body.style.cursor = 'default';
    if (!tr.nodes().includes(shape)) {
      shape.setAttrs({
        shadowBlur: 0,
      });
    }
  });

  // 点击选中
  shape.on('click', (e) => {
    e.cancelBubble = true;   // 阻止冒泡到 Stage
    tr.nodes([shape]);
  });

  // 拖拽同步 Transformer
  shape.on('dragmove', () => {
    tr.nodes([shape]);       // Transformer 自动跟随
  });

  layer.add(shape);
  return shape;
}

// 点击空白取消选择
stage.on('click', (e) => {
  if (e.target === stage) {
    tr.nodes([]);
    shape.setAttrs({ shadowBlur: 0 }); // 恢复阴影
  }
});

createShape(100, 100, '#4A90D9');
createShape(300, 200, '#E74C3C');
createShape(500, 300, '#2ECC71');
```

## ✏️ 练习

实现图形拖拽配合事件反馈：

**要求**：
1. 创建 3 个不同颜色的矩形
2. 点击矩形时高亮（加粗边框 + 阴影）
3. 点击空白区域取消所有高亮
4. 拖拽结束时在控制台打印新位置
5. 鼠标移入图形时变成手形指针
6. 双击矩形时删除该图形

**提示**：
```js
// 双击删除
rect.on('dblclick', () => {
  rect.destroy();  // 从画布移除
});
```

**预期效果**：三个矩形可以独立交互，选中高亮、双击删除、拖拽记录位置。移入任意矩形时光标变为手形。

## 🆚 对比：Konva 事件系统 vs DOM 事件 vs 原生 Canvas

| 维度 | Konva | DOM | 原生 Canvas |
|------|-------|-----|-------------|
| 事件绑定 | `shape.on('click', fn)` | `el.addEventListener('click', fn)` | 无，需手动计算坐标 |
| 事件冒泡 | Shape → Group → Layer → Stage | 元素 → 父元素 → document | 无 |
| 命中检测 | 像素级精确命中（基于图形路径） | 矩形包围盒 | 手动 `isPointInPath()` |
| 拖拽事件 | `dragstart/dragmove/dragend` 内置 | 需手动实现 | 需手动实现 |
| 事件移除 | `shape.off('click')` | `el.removeEventListener(...)` | 不适用 |
| 阻止冒泡 | `e.cancelBubble = true` | `e.stopPropagation()` | 不适用 |

## 📝 面试回答模板

> **问：Konva 的事件系统是怎么工作的？和 DOM 事件有什么异同？**
>
> Konva 的事件系统在设计上参照了 DOM 事件模型。相同点：支持 `on()`/`off()` 绑定移除、事件冒泡（Shape → Group → Layer → Stage）、`e.target` 和 `e.currentTarget` 区分、`cancelBubble` 阻止冒泡。不同点：Konva 不是基于 DOM 树，而是基于自己的场景图做命中检测，当事件发生时，Konva 从最上层的图形开始检测鼠标位置是否在图形区域内，找到后触发事件并向上冒泡。这也是为什么 Konva 能做到像素级精确命中。
