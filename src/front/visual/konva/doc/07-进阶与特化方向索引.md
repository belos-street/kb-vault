# 07 - 进阶方向索引

> 基础六篇以外的特化方向，用到时知道有这个概念即可，无需深究。

---

| 方向 | 用途 | 相关 API / 关键词 |
|------|------|-------------------|
| 自定义图形 | 内置图形不够用时绘制任意形状 | `Konva.Shape`、`_sceneFunc`、`sceneFunc` |
| 滤镜 | 给图形加模糊、灰度、亮度等特效 | `Konva.Filters`、`filter`、`cache()` |
| 动画 | 属性渐变、帧循环动画 | `Konva.Tween`、`Konva.Animation`、`to()` |
| 文本进阶 | 富文本、沿路径排版 | `Konva.TextPath`、`letterSpacing`、`textDecoration` |
| 性能优化 | 数千图形场景下的渲染加速 | `cache()`、`hitFunc`、`listening: false`、`clipFunc`、`layer.clone()` |
| 移动端适配 | 多点触控、手势识别、容器自适应 | `touchstart/touchend`、`pointer` 事件、`container` resize |
| 框架集成 | 在 React / Vue 中使用 Konva | `react-konva`、`vue-konva` |
| 服务端渲染 | Node.js 端生成图片 | `node-canvas` + Konva |
| TypeScript | 类型安全的 Konva 开发 | `@types/konva`、`konva` 自带声明 |

---

> 这些方向不需要提前学，等项目中遇到具体需求时再查阅对应文档即可。核心思路始终是"用到了再查"，不在入门阶段增加负担。
