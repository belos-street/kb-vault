# 03 - 变换与拖拽

> 对应大纲模块 3 | 预计时间：1 天
> 面试可答：`draggable: true` 启用拖拽，`Transformer` 实现缩放旋转。

---

## 1. 拖拽（Draggable）

Konva 最实用的功能之一：设置 `draggable: true` 即可让图形被鼠标拖拽。

### 基本拖拽

以下代码假设已有 `stage` 和 `layer`（参见 01 篇）：

```js
const rect = new Konva.Rect({
  x: 100, y: 100,
  width: 200, height: 150,
  fill: '#4A90D9',
  draggable: true,       // 开启拖拽
});
layer.add(rect);
```

就这么简单，用户现在可以按住矩形拖动了。

### 拖拽事件

```js
rect.on('dragstart', () => {
  console.log('开始拖拽', rect.x(), rect.y());
});

rect.on('dragmove', () => {
  console.log('拖拽中', rect.x(), rect.y());
});

rect.on('dragend', (e) => {
  console.log('结束拖拽', rect.x(), rect.y());
  // e.target 是当前拖拽的对象
});
```

### 约束拖拽范围

```js
// 限制在矩形区域内拖拽
rect.draggable(true);
rect.dragBoundFunc((pos) => {
  return {
    x: Math.max(0, Math.min(500, pos.x)),
    y: Math.max(0, Math.min(300, pos.y)),
  };
});
```

`dragBoundFunc` 接收 Konva 计算的目标位置，你可以返回修正后的位置。常用于：
- 限制在画布范围内
- 吸附到网格
- 沿 x 或 y 轴锁定

```js
// 仅水平拖拽
rect.dragBoundFunc((pos) => {
  return {
    x: pos.x,
    y: rect.y(),  // 锁定 y 不变
  };
});
```

### Group 拖拽

拖拽在 Group 上同样生效，拖拽 Group 会带动所有子元素一起移动：

```js
const group = new Konva.Group({
  x: 100, y: 100,
  draggable: true,
});

// 子元素坐标是相对于 Group 的
group.add(new Konva.Rect({ x: 0, y: 0, width: 100, height: 100, fill: 'red' }));
group.add(new Konva.Text({ x: 10, y: 40, text: 'Drag me', fill: 'white' }));
```

## 2. Transformer（变换控件）

`Transformer` 是 Konva 的重要功能，它为图形添加可拖拽的控制手柄，支持缩放、旋转。

### 基本用法

```js
// 1. 创建 Transformer
const tr = new Konva.Transformer();

// 2. 添加到 Layer
layer.add(tr);

// 3. 绑定到一个节点
tr.nodes([rect]);
```

此时矩形周围会出现 8 个缩放手柄 + 1 个旋转手柄，用户可以直接拖拽操作。

> **注意**：Transformer 负责缩放和旋转，`draggable` 负责拖拽移动，两者需要**分别开启**。如果只绑定 Transformer 而不设 `draggable: true`，图形只能缩放旋转但不能被鼠标拖拽移动位置。

### 动态切换目标

```js
// 选中某个图形
tr.nodes([rect]);

// 选中多个图形
tr.nodes([rect1, rect2, circle1]);

// 取消选中
tr.nodes([]);
```

实际应用中，通常点击某个图形时绑定 Transformer，点击空白区域取消。

### Transformer 配置

```js
const tr = new Konva.Transformer({
  // 节点配置
  nodes: [],
  
  // 启用/禁用功能
  enabledAnchors: ['top-left', 'top-right', 'bottom-left', 'bottom-right'],
  // 可选：'top-left', 'top-center', 'top-right',
  //        'middle-left', 'middle-right',
  //        'bottom-left', 'bottom-center', 'bottom-right'
  
  // 外观
  borderStroke: '#4A90D9',
  borderStrokeWidth: 2,
  anchorFill: '#fff',
  anchorStroke: '#4A90D9',
  anchorSize: 10,
  anchorCornerRadius: 2,
  
  // 功能
  rotateEnabled: true,        // 是否允许旋转
  keepRatio: false,           // 缩放时是否保持宽高比
  rotateAnchorOffset: 30,     // 旋转手柄距边框的距离
  boundBoxFunc: (oldBox, newBox) => {
    // 限制最小尺寸
    if (newBox.width < 20 || newBox.height < 20) {
      return oldBox;
    }
    return newBox;
  },
});
```

## 3. Transformer 缩放后的尺寸修正

当同时使用 Transformer 和拖拽时，需要注意 Transform 会改变节点的 `scaleX` / `scaleY`：

```js
rect.on('transformend', () => {
  // Transformer 缩放时会改变 scaleX/scaleY，但不改变 width/height
  // 通常在 transformend 时"修正"尺寸
  const width = rect.width() * rect.scaleX();
  const height = rect.height() * rect.scaleY();
  
  rect.setAttrs({
    width,
    height,
    scaleX: 1,
    scaleY: 1,
  });
});
```

这个模式很重要：缩放完后把 scale 的变动合并到实际尺寸中，避免重复缩放累积偏差。

## 4. 手动变换（不通过 Transformer）

除了 Transformer，你也可以直接操作变换属性：

```js
// 旋转
rect.rotation(45);              // 顺时针 45 度
rect.rotation(rect.rotation() + 5); // 逐帧旋转

// 缩放
rect.scaleX(2);
rect.scaleY(1.5);

// 位移
rect.x(200);
rect.y(100);

// 偏移中心点
rect.offsetX(rect.width() / 2);   // 以中心为旋转原点
rect.offsetY(rect.height() / 2);
```

`offsetX` / `offsetY` 是经常被忽略但很重要的属性，它改变旋转和缩放的原点。

## 5. 完整示例：多图形选中/拖拽/变换

这是白板项目中反复使用的模式：

```js
const stage = new Konva.Stage({
  container: 'root',
  width: 800, height: 600,
});
const layer = new Konva.Layer();
stage.add(layer);

const tr = new Konva.Transformer();
layer.add(tr);

// 创建可交互图形
function createShape(x, y) {
  const shape = new Konva.Rect({
    x, y,
    width: 100, height: 100,
    fill: Konva.Util.getRandomColor(),
    draggable: true,
    name: 'shape',
  });

  shape.on('click', () => {
    tr.nodes([shape]);
  });

  // 拖拽后 Transformer 跟随
  shape.on('dragstart', () => {
    tr.nodes([shape]);
  });

  layer.add(shape);
  return shape;
}

// 点击空白取消选择
stage.on('click', (e) => {
  if (e.target === stage) {
    tr.nodes([]);
  }
});

createShape(100, 100);
createShape(300, 200);
```

// 提示步骤

## 🆚 对比：Konva 拖拽/变换 vs 原生方案

| 维度 | Konva | fabric.js | 原生 Canvas |
|------|-------|-----------|-------------|
| 拖拽 | `draggable: true` 一行搞定 | `canvas.on('mouse:move', ...)` | 需手动追踪 mousedown/move/up |
| 缩放控件 | `Transformer` 即插即用 | 内置 controls | 无，需手动绘制手柄 |
| 旋转控件 | `Transformer` 带旋转手柄 | 内置旋转 | 无 |
| 约束范围 | `dragBoundFunc` 回调 | `canvas.on('object:moving', ...)` | 手动判断坐标 |
| 缩放后处理 | `transformend` 中修正 scale→尺寸 | 类似 | 不适用 |
| 分组变换 | Group 整体变换 | Group 整体变换 | 无 |

## 📝 面试回答模板

> **问：Konva 怎么实现拖拽和缩放？**
>
> 拖拽只需设置 `draggable: true`，Konva 底层会处理鼠标/触摸事件的坐标映射和位置更新。如果需要可视化缩放旋转，使用 `Konva.Transformer` 组件，它提供 8 个缩放手柄和 1 个旋转手柄，绑定到目标节点后用户可以直接拖拽操作。Transformer 缩放时改变的是 `scaleX`/`scaleY`，在实际应用中通常会在 `transformend` 事件中将缩放合并到实际尺寸，避免累积偏差。
