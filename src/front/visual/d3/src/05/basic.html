D3 模块 5 - 基础过渡动画（Transition）

1. 基本过渡（transition）

使用 transition() 创建过渡动画，duration() 设置持续时间

核心 API：selection.transition().duration(ms).attr(name, value)
// 基本过渡 d3.select('#circle') .transition() .duration(1000) .attr('cx', 400);

2. 延迟动画（delay）

使用 delay() 设置动画延迟时间

3. 属性动画类型

对位置、大小、颜色、透明度等属性做动画

4. 多元素过渡

对多个元素同时应用过渡动画
