D3 模块 5 - 链式过渡动画（Chained Transitions）

1. 基本链式过渡

使用多个 transition() 按顺序执行动画

链式过渡：每次调用 .transition() 会创建新的过渡，前一个结束后自动开始下一个
// 链式过渡：移动 → 变色 → 变大 rect.transition() .duration(500) .attr('x', 300) .transition() .duration(300) .attr('fill', 'red') .transition() .duration(300) .attr('width', 80).attr('height', 80);

2. 多阶段动画

实现复杂的多阶段动画序列

3. 交错动画（Staggered Animation）

使用 delay((d, i) => i * 100) 实现瀑布式入场效果

4. 同步与异步过渡

多个元素同时执行 vs 依次执行

5. 实际应用：脉冲动画

使用链式过渡实现脉冲效果（放大 → 缩小 → 放大...）

6. 实际应用：进度条动画

使用过渡动画实现进度条效果
