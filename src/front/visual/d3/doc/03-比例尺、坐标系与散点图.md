## 📖 核心概念

### 1. 什么是比例尺（Scale）？

比例尺是 D3 中**最核心的工具之一**，它负责将**数据值**映射为**视觉属性**（如像素坐标、颜色、大小等）。

```
数据域 (Domain)          视觉域 (Range)
[0, 100]                 [0, 500]
   ↓                         ↓
  数据值  ──── 比例尺 ────→  像素值
   50    ──── scale ────→   250
```

**为什么需要比例尺？**

假设你有一组数据 `[10, 50, 100, 500, 1000]`，想画柱状图。直接用数据值作为柱子高度会导致：
- 最大的柱子 1000px 高，超出 SVG 区域
- 最小的柱子 10px 高，几乎看不见

比例尺的作用就是**将任意范围的数据，映射到你指定的视觉范围内**。

## 🔧 常用比例尺详解

### 1. `d3.scaleLinear()` — 线性比例尺

最基础的比例尺，将连续数值映射到连续的视觉属性。

```javascript
const scale = d3.scaleLinear()
    .domain([0, 100])   // 数据域：数据范围
    .range([0, 500]);   // 视觉域：像素范围

scale(50);   // → 250
scale(0);    // → 0
scale(100);  // → 500
scale(150);  // → 750（超出 domain 也会外推）
```

**关键特性**：
- **线性映射**：数据值与输出值成正比
- **支持外推**：超出 domain 范围的值会按比例继续映射
- **支持反向**：range 可以比 domain 大或小

```javascript
// 反向映射（数据越大，像素越小）
const reverseScale = d3.scaleLinear()
    .domain([0, 100])
    .range([500, 0]);

reverseScale(0);    // → 500
reverseScale(100);  // → 0
```

**常用方法**：

```javascript
const scale = d3.scaleLinear().domain([0, 100]).range([0, 500]);

scale(50);           // → 250，正向映射
scale.invert(250);   // → 50，反向推算
scale.domain();      // → [0, 100]，获取数据域
scale.range();       // → [0, 500]，获取视觉域
scale.clamp(true);   // 启用钳制，超出范围的值会被限制在边界
scale(150);          // → 500（钳制后不会超出 range）
```

**面试常问**：`scaleLinear` 的 `domain` 和 `range` 分别代表什么？
- `domain` 是**输入范围**（数据值的范围）
- `range` 是**输出范围**（视觉属性的范围，如像素）

---

### 2. `d3.scaleBand()` — 序数比例尺（带宽度）

专门用于**柱状图**等离散分类数据，将离散值映射到等宽的区间。

```javascript
const scale = d3.scaleBand()
    .domain(['A', 'B', 'C', 'D', 'E'])  // 离散的分类值
    .range([0, 500])                     // 总宽度
    .padding(0.2);                       // 柱子之间的间距比例

scale('A');           // → 0，返回该分类的起始 x 坐标
scale('B');           // → 100
scale.bandwidth();    // → 80，返回每个柱子的宽度
scale.step();         // → 100，返回每个步长（包含间距）
```

**与 `scaleLinear` 的区别**：

| 特性 | `scaleLinear` | `scaleBand` |
|------|---------------|-------------|
| 输入类型 | 连续数值 | 离散分类 |
| 输出类型 | 单个值 | 起始坐标 + 宽度 |
| 适用场景 | 散点图、折线图 | 柱状图 |
| 间距控制 | 无 | `padding()` |

**柱状图典型用法**：

```javascript
const data = [
    { name: 'A', value: 30 },
    { name: 'B', value: 80 },
    { name: 'C', value: 45 }
];

const xScale = d3.scaleBand()
    .domain(data.map(d => d.name))
    .range([0, 400])
    .padding(0.2);

const yScale = d3.scaleLinear()
    .domain([0, 100])
    .range([300, 0]);

svg.selectAll('rect')
    .data(data)
    .enter()
    .append('rect')
    .attr('x', d => xScale(d.name))      // 使用 scaleBand 获取 x 坐标
    .attr('y', d => yScale(d.value))     // 使用 scaleLinear 获取 y 坐标
    .attr('width', xScale.bandwidth())   // 获取柱子宽度
    .attr('height', d => 300 - yScale(d.value));
```

### 3. `d3.scaleOrdinal()` — 序数比例尺（颜色映射）

将离散值映射到离散的输出值，常用于**颜色映射**。

```javascript
const colorScale = d3.scaleOrdinal()
    .domain(['苹果', '香蕉', '橙子'])
    .range(['#e74c3c', '#f1c40f', '#e67e22']);

colorScale('苹果');   // → '#e74c3c'
colorScale('香蕉');   // → '#f1c40f'
colorScale('葡萄');   // → '#e74c3c'（超出 domain 后会循环）
```

**内置颜色方案**：

D3 提供了多种预设的颜色方案，适合不同场景：

```javascript
// 分类颜色（适合柱状图、饼图）
const category10 = d3.scaleOrdinal(d3.schemeCategory10);

// 表格颜色（适合需要高对比度的场景）
const tableau10 = d3.scaleOrdinal(d3.schemeTableau10);

// 配对颜色（适合成对的数据）
const paired = d3.scaleOrdinal(d3.schemePaired);
```

**示例：为柱状图添加颜色**：

```javascript
const colorScale = d3.scaleOrdinal(d3.schemeCategory10);

svg.selectAll('rect')
    .data(data)
    .enter()
    .append('rect')
    .attr('fill', (d, i) => colorScale(i));  // 每个柱子不同颜色
```

---

### 4. `d3.scaleTime()` — 时间比例尺

专门处理**时间序列数据**，将 Date 对象映射到像素位置。

```javascript
const timeScale = d3.scaleTime()
    .domain([new Date('2024-01-01'), new Date('2024-12-31')])
    .range([0, 800]);

timeScale(new Date('2024-06-15'));  // → 约 400（半年的位置）
```

**时间比例尺的 domain 必须是 Date 对象**：

```javascript
// ❌ 错误：使用字符串
d3.scaleTime().domain(['2024-01-01', '2024-12-31']);

// ✅ 正确：使用 Date 对象
d3.scaleTime().domain([new Date('2024-01-01'), new Date('2024-12-31')]);
```

**配合 `d3.timeParse` 解析数据**：

```javascript
// 解析 CSV 中的日期字符串
const parseTime = d3.timeParse('%Y-%m-%d');
const date = parseTime('2024-01-15');  // → Date 对象

// 完整流程
const data = [
    { date: '2024-01-01', value: 100 },
    { date: '2024-02-01', value: 150 },
    { date: '2024-03-01', value: 120 }
];

const xScale = d3.scaleTime()
    .domain(d3.extent(data, d => parseTime(d.date)))
    .range([0, 600]);
```

## 📐 坐标轴（Axis）

D3 提供了自动生成坐标轴的工具，基于比例尺创建。

### 坐标轴类型

| 方法 | 说明 | 适用场景 |
|------|------|----------|
| `d3.axisBottom(scale)` | 底部 X 轴（刻度向下） | 横轴 |
| `d3.axisTop(scale)` | 顶部 X 轴（刻度向上） | 横轴（图表顶部） |
| `d3.axisLeft(scale)` | 左侧 Y 轴（刻度向左） | 纵轴 |
| `d3.axisRight(scale)` | 右侧 Y 轴（刻度向右） | 纵轴（图表右侧） |

### 创建坐标轴

```javascript
const svg = d3.select('#chart')
    .append('svg')
    .attr('width', 600)
    .attr('height', 400);

const margin = { top: 20, right: 30, bottom: 40, left: 50 };
const width = 600 - margin.left - margin.right;
const height = 400 - margin.top - margin.bottom;

const g = svg.append('g')
    .attr('transform', `translate(${margin.left},${margin.top})`);

// 创建比例尺
const xScale = d3.scaleLinear().domain([0, 100]).range([0, width]);
const yScale = d3.scaleLinear().domain([0, 100]).range([height, 0]);

// 创建坐标轴
const xAxis = d3.axisBottom(xScale);
const yAxis = d3.axisLeft(yScale);

// 添加 X 轴
g.append('g')
    .attr('transform', `translate(0,${height})`)
    .call(xAxis);

// 添加 Y 轴
g.append('g')
    .call(yAxis);
```

**注意**：Y 轴的 `range` 是 `[height, 0]`（反向），因为 SVG 的 Y 轴向下增长。

### 自定义坐标轴

```javascript
// 设置刻度数量
const xAxis = d3.axisBottom(xScale).ticks(5);

// 设置刻度格式
const yAxis = d3.axisLeft(yScale)
    .tickFormat(d => `${d}%`);  // 添加百分号

// 设置刻度大小
const xAxis = d3.axisBottom(xScale)
    .tickSize(10)      // 刻度线长度
    .tickPadding(5);   // 刻度与标签的间距

// 隐藏刻度线
const xAxis = d3.axisBottom(xScale)
    .tickSize(0)
    .tickPadding(10);
```

## 🎨 实战：带坐标轴的散点图

### 完整示例代码

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>D3 散点图</title>
    <script src="https://d3js.org/d3.v7.min.js"></script>
    <style>
        body { font-family: sans-serif; }
        .dot { fill: steelblue; stroke: #333; stroke-width: 1px; }
        .dot:hover { fill: orange; }
        .axis text { font-size: 12px; }
        .axis path, .axis line { fill: none; stroke: #333; }
    </style>
</head>
<body>
    <div id="chart"></div>
    <script>
        // 数据
        const data = [
            { x: 10, y: 20, label: 'A' },
            { x: 30, y: 50, label: 'B' },
            { x: 50, y: 35, label: 'C' },
            { x: 70, y: 80, label: 'D' },
            { x: 90, y: 60, label: 'E' }
        ];

        // SVG 尺寸
        const width = 600;
        const height = 400;
        const margin = { top: 20, right: 30, bottom: 40, left: 50 };

        // 创建 SVG
        const svg = d3.select('#chart')
            .append('svg')
            .attr('width', width)
            .attr('height', height);

        // 创建绘图区域
        const g = svg.append('g')
            .attr('transform', `translate(${margin.left},${margin.top})`);

        // 计算实际绘图区域尺寸
        const innerWidth = width - margin.left - margin.right;
        const innerHeight = height - margin.top - margin.bottom;

        // 创建比例尺
        const xScale = d3.scaleLinear()
            .domain([0, 100])
            .range([0, innerWidth]);

        const yScale = d3.scaleLinear()
            .domain([0, 100])
            .range([innerHeight, 0]);

        // 创建坐标轴
        const xAxis = d3.axisBottom(xScale).ticks(5);
        const yAxis = d3.axisLeft(yScale).ticks(5);

        // 添加 X 轴
        g.append('g')
            .attr('class', 'axis x-axis')
            .attr('transform', `translate(0,${innerHeight})`)
            .call(xAxis);

        // 添加 Y 轴
        g.append('g')
            .attr('class', 'axis y-axis')
            .call(yAxis);

        // 绘制散点
        g.selectAll('.dot')
            .data(data)
            .enter()
            .append('circle')
            .attr('class', 'dot')
            .attr('cx', d => xScale(d.x))
            .attr('cy', d => yScale(d.y))
            .attr('r', 8)
            .attr('fill', 'steelblue');
    </script>
</body>
</html>
```

## ⚠️ 常见踩坑点

### 1. Y 轴方向搞反

```javascript
// ❌ 错误：Y 轴向下增长（SVG 默认方向）
const yScale = d3.scaleLinear()
    .domain([0, 100])
    .range([0, height]);  // 数据越大，y 坐标越大（越靠下）

// ✅ 正确：Y 轴向上增长（图表标准方向）
const yScale = d3.scaleLinear()
    .domain([0, 100])
    .range([height, 0]);  // 数据越大，y 坐标越小（越靠上）
```

### 2. 坐标轴位置错误

```javascript
// ❌ 错误：X 轴在顶部
g.append('g').call(xAxis);

// ✅ 正确：X 轴在底部
g.append('g')
    .attr('transform', `translate(0,${height})`)
    .call(xAxis);
```

### 3. 比例尺 domain 顺序与 range 不匹配

```javascript
// ❌ 错误：domain 和 range 方向不一致
const scale = d3.scaleLinear()
    .domain([100, 0])   // 从大到小
    .range([0, 500]);   // 从小到大

// ✅ 正确：方向一致
const scale = d3.scaleLinear()
    .domain([100, 0])
    .range([500, 0]);   // 也是从大到小
```

### 4. 时间比例尺使用字符串

```javascript
// ❌ 错误
const scale = d3.scaleTime()
    .domain(['2024-01-01', '2024-12-31']);

// ✅ 正确
const scale = d3.scaleTime()
    .domain([new Date('2024-01-01'), new Date('2024-12-31')]);
```

## 🆚 D3 比例尺 vs 其他库

| 维度 | D3 | ECharts | Chart.js |
|------|-----|---------|----------|
| 灵活性 | 极高，可自定义任何映射 | 中等，配置项有限 | 中等 |
| 学习成本 | 高，需理解 domain/range | 低，配置即可 | 低 |
| 时间处理 | `scaleTime` + `timeParse` | 自动识别 | 需要 moment.js |
| 颜色方案 | `scaleOrdinal` + 内置方案 | 配置 `color` 数组 | 配置 `backgroundColor` |

**面试回答**：D3 的比例尺是最灵活的，`scaleLinear`、`scaleBand`、`scaleOrdinal`、`scaleTime` 覆盖了几乎所有数据映射需求。ECharts 和 Chart.js 虽然更易用，但定制能力有限。如果需要非线性映射（如对数比例尺 `scaleLog`）或自定义插值，D3 是唯一选择。

## 📝 面试回答模板

> **问：解释一下 D3 的比例尺是什么？**
>
> 比例尺是 D3 的核心工具，负责将**数据域**（Domain）映射到**视觉域**（Range）。例如 `scaleLinear([0, 100], [0, 500])` 会将数据值 50 映射为像素值 250。
>
> 常用比例尺有四种：
> - `scaleLinear`：连续数值映射（如散点图坐标）
> - `scaleBand`：离散分类映射（如柱状图 x 轴）
> - `scaleOrdinal`：离散值到离散值映射（如颜色）
> - `scaleTime`：时间序列映射（如折线图 x 轴）
>
> **追问：scaleLinear 和 scaleBand 有什么区别？**
> `scaleLinear` 处理连续数值，输出单个值；`scaleBand` 处理离散分类，输出起始坐标 + 宽度，专门用于柱状图。

> **问：D3 坐标轴怎么实现？**
>
> D3 提供 `axisBottom()`、`axisLeft()` 等方法，基于比例尺自动生成坐标轴。典型用法是：
> ```javascript
> const xAxis = d3.axisBottom(xScale).ticks(5);
> g.append('g')
>     .attr('transform', `translate(0,${height})`)
>     .call(xAxis);
> ```
> 坐标轴会自动根据比例尺的 domain 生成刻度和标签。
