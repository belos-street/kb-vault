## 🔧 核心概念一：transition() 基本用法

### 什么是 transition？

`transition()` 是 D3 提供的动画系统，它会在指定时间内平滑地将属性从当前值过渡到目标值。

```javascript
// 直接设置属性（无动画）
selection.attr('r', 50);

// 使用过渡动画设置属性
selection.transition().attr('r', 50);
```

### 核心 API

| API | 用途 | 示例 |
|-----|------|------|
| `selection.transition()` | 创建过渡对象 | `d3.select('circle').transition()` |
| `.duration(ms)` | 动画持续时间 | `.duration(1000)` |
| `.delay(ms)` | 动画延迟时间 | `.delay(200)` |
| `.ease(fn)` | 缓动函数 | `.ease(d3.easeBounce)` |
| `.attr(name, value)` | 动画属性 | `.attr('r', 50)` |
| `.style(name, value)` | 动画样式 | `.style('opacity', 1)` |

### 基本示例

```javascript
// 1. 基本过渡
d3.select('#circle1')
    .transition()
    .duration(1000)
    .attr('cx', 200)
    .attr('r', 30)
    .attr('fill', 'red');

// 2. 带延迟的过渡
d3.select('#circle2')
    .transition()
    .duration(500)
    .delay(300)
    .attr('cy', 150);

// 3. 使用缓动函数
d3.select('#circle3')
    .transition()
    .duration(800)
    .ease(d3.easeBounce)
    .attr('cy', 200);
```

## 🔧 核心概念二：缓动函数（Easing Functions）

缓动函数控制动画的节奏感，让动画更自然。

### 常用缓动函数

| 缓动函数 | 效果 | 适用场景 |
|----------|------|----------|
| `d3.easeLinear` | 匀速 | 默认，适合进度条 |
| `d3.easeCubic` | 三次方缓动 | 平滑加速减速 |
| `d3.easeBounce` | 弹跳效果 | 强调落地感 |
| `d3.easeElastic` | 弹性效果 | 强调弹动感 |
| `d3.easeBack` | 回弹效果 | 超出目标后回弹 |
| `d3.easeSin` | 正弦缓动 | 柔和的呼吸感 |

### 缓动函数对比

```javascript
// 匀速（线性）
.transition().duration(1000).ease(d3.easeLinear)
    .attr('cx', 400);

// 弹跳效果
.transition().duration(1000).ease(d3.easeBounce)
    .attr('cx', 400);

// 弹性效果
.transition().duration(1000).ease(d3.easeElastic)
    .attr('cx', 400);
```

### 带参数的缓动

```javascript
// 弹跳次数（默认 3）
.ease(d3.easeBounce.amplitude(1.5))

// 弹性周期（默认 0.3）
.ease(d3.easeElastic.period(0.4))

// 回弹强度（默认 1.70158）
.ease(d3.easeBack.overshoot(2))
```

## 🔧 核心概念三：属性动画类型

### 1. 位置动画

```javascript
// 水平移动
selection.transition().duration(500)
    .attr('cx', newX);

// 垂直移动
selection.transition().duration(500)
    .attr('cy', newY);

// 使用 transform 移动
selection.transition().duration(500)
    .attr('transform', `translate(${x}, ${y})`);
```

### 2. 大小动画

```javascript
// 圆的半径
selection.transition().duration(500)
    .attr('r', newRadius);

// 矩形高度
selection.transition().duration(500)
    .attr('height', newHeight)
    .attr('y', newY);  // 配合 y 坐标调整
```

### 3. 颜色动画

```javascript
// 填充颜色
selection.transition().duration(500)
    .attr('fill', '#e74c3c');

// 描边颜色
selection.transition().duration(500)
    .attr('stroke', '#2ecc71');

// 样式颜色
selection.transition().duration(500)
    .style('background-color', 'blue');
```

### 4. 透明度动画

```javascript
// 渐显
selection.transition().duration(500)
    .attr('opacity', 1);

// 渐隐
selection.transition().duration(500)
    .attr('opacity', 0);

// 使用 style 设置
selection.transition().duration(500)
    .style('opacity', 0.5);
```

## 🔧 核心概念四：链式过渡（Chained Transitions）

链式过渡允许你按顺序执行多个动画。

### 基本链式过渡

```javascript
d3.select('#circle')
    // 第一阶段：向右移动
    .transition()
    .duration(500)
    .attr('cx', 200)
    // 第二阶段：向下移动
    .transition()
    .duration(500)
    .attr('cy', 200)
    // 第三阶段：变大
    .transition()
    .duration(500)
    .attr('r', 40);
```

### 带延迟的链式过渡

```javascript
d3.selectAll('circle')
    // 所有圆先变红
    .transition()
    .duration(300)
    .attr('fill', 'red')
    // 然后变大
    .transition()
    .duration(300)
    .attr('r', 30)
    // 最后恢复
    .transition()
    .duration(300)
    .attr('fill', 'steelblue')
    .attr('r', 15);
```

### 交错动画（Staggered Animation）

```javascript
d3.selectAll('rect')
    .transition()
    .duration(500)
    .delay((d, i) => i * 100)  // 每个元素延迟 100ms
    .attr('height', d => yScale(d.value))
    .attr('y', d => innerHeight - yScale(d.value));
```

## 🔧 核心概念五：过渡与数据更新

### Enter-Update-Exit 模式下的过渡

```javascript
function updateBars(newData) {
    // 更新比例尺
    xScale.domain(newData.map(d => d.name));
    yScale.domain([0, d3.max(newData, d => d.value)]);

    // 数据绑定
    const bars = g.selectAll('.bar').data(newData, d => d.name);

    // Enter：新元素入场动画
    bars.enter()
        .append('rect')
        .attr('class', 'bar')
        .attr('x', d => xScale(d.name))
        .attr('y', innerHeight)
        .attr('width', xScale.bandwidth())
        .attr('height', 0)
        .attr('fill', '#3498db')
        .merge(bars)  // 合并 Enter 和 Update
        .transition()
        .duration(500)
        .attr('x', d => xScale(d.name))
        .attr('y', d => yScale(d.value))
        .attr('width', xScale.bandwidth())
        .attr('height', d => innerHeight - yScale(d.value));

    // Exit：元素退场动画
    bars.exit()
        .transition()
        .duration(300)
        .attr('y', innerHeight)
        .attr('height', 0)
        .attr('opacity', 0)
        .remove();
}
```

### 动画过渡的属性

| 属性 | Enter 动画 | Update 动画 | Exit 动画 |
|------|-----------|------------|----------|
| 位置 (y) | 从底部升起 | 平滑移动到新位置 | 下降到底部 |
| 大小 (height) | 从 0 增长 | 平滑变化 | 缩小到 0 |
| 颜色 (fill) | 渐显 | 颜色渐变 | 渐隐 |
| 透明度 (opacity) | 从 0 到 1 | 保持 1 | 从 1 到 0 |

## 🔧 核心概念六：过渡事件

### 监听过渡状态

```javascript
const t = d3.select('#circle')
    .transition()
    .duration(1000)
    .attr('r', 50);

// 过渡开始时
t.on('start', function() {
    console.log('过渡开始');
});

// 过渡结束时
t.on('end', function() {
    console.log('过渡结束');
});

// 过渡中断时
t.on('interrupt', function() {
    console.log('过渡被中断');
});
```

### 中断过渡

```javascript
// 立即中断过渡（停在当前位置）
d3.select('#circle').interrupt();

// 中断并开始新过渡
d3.select('#circle')
    .interrupt()
    .transition()
    .duration(500)
    .attr('r', 20);
```

## 🆚 D3 vs CSS 动画对比

| 维度 | D3 transition | CSS animation |
|------|---------------|---------------|
| 控制精度 | 精细控制每个属性 | 有限，依赖关键帧 |
| 数据绑定 | 直接绑定数据 | 需手动计算 |
| 复杂动画 | 链式过渡支持 | 需多步骤动画 |
| 性能 | SVG/Canvas 优化 | 浏览器优化 |
| 学习曲线 | 陡峭 | 平缓 |
| 适用场景 | 数据驱动的动画 | UI 交互动画 |

**面试回答**：D3 的 transition 系统与数据绑定紧密集成，可以基于数据值动态计算动画参数。CSS 动画更适合简单的 UI 状态变化，而 D3 动画更适合复杂的数据可视化场景。

## ⚠️ 常见踩坑点

### 1. 过渡属性必须是数值类型

```javascript
// ❌ 错误：fill 不支持过渡（是字符串）
selection.transition().attr('fill', 'red');

// ✅ 正确：使用 style 或颜色插值
selection.transition().attr('fill', d3.interpolateRgb('blue', 'red'));
```

### 2. 忘记设置 duration

```javascript
// ❌ 错误：duration 默认 250ms，可能太快
selection.transition().attr('r', 50);

// ✅ 正确：明确设置 duration
selection.transition().duration(500).attr('r', 50);
```

### 3. 链式过渡中丢失过渡对象

```javascript
// ❌ 错误：每次 transition() 返回新对象
selection.transition().duration(300).attr('cx', 100);
selection.transition().duration(300).attr('cy', 100);  // 同时执行

// ✅ 正确：使用链式调用
selection.transition().duration(300).attr('cx', 100)
    .transition().duration(300).attr('cy', 100);  // 顺序执行
```

### 4. 过渡中修改 DOM

```javascript
// ❌ 错误：过渡中直接修改属性
selection.transition().duration(500).attr('r', 50);
selection.attr('r', 20);  // 立即生效，覆盖过渡

// ✅ 正确：使用 interrupt 或等待过渡结束
selection.transition().duration(500).attr('r', 50)
    .on('end', () => selection.attr('fill', 'red'));
```

## 📝 面试回答模板

> **问：D3 的 transition 是如何工作的？**
>
> D3 的 transition 系统通过 `selection.transition()` 创建过渡对象，它会记录属性的起始值和目标值，然后在 `duration()` 指定的时间内平滑插值。
>
> 核心机制：
> 1. **插值器**：自动检测属性类型（数值、颜色、字符串）并选择合适的插值器
> 2. **缓动函数**：通过 `ease()` 控制动画节奏
> 3. **链式过渡**：支持按顺序执行多个动画
>
> **追问：如何实现交错动画？**
> 使用 `delay((d, i) => i * 100)` 为每个元素设置递增的延迟时间，实现瀑布式入场效果。

> **问：D3 动画和 CSS 动画有什么区别？**
>
> D3 动画与数据绑定紧密集成，可以基于数据值动态计算动画参数（如根据数据大小设置延迟）。CSS 动画更适合简单的 UI 状态变化，而 D3 动画更适合复杂的数据可视化场景。
>
> **追问：什么时候用 D3 动画，什么时候用 CSS？**
> 如果动画需要基于数据值（如柱状图高度、折线图路径），用 D3 transition。如果是简单的 hover 效果、颜色变化，用 CSS 更高效。

> **问：如何中断正在进行的过渡？**
>
> 使用 `selection.interrupt()` 可以立即中断过渡，元素停在当前位置。也可以链式调用新的 transition 来替换当前过渡：
> ```javascript
> selection.interrupt()
>     .transition()
>     .duration(500)
>     .attr('r', 20);
> ```

            .transition().duration(500)

    });

### 练习 2：缓动函数对比

**要求**：创建多个圆形，使用不同的缓动函数同时移动，观察效果差异

**提示**：
- 创建 5 个圆形，垂直排列
- 每个圆形使用不同的缓动函数
- 使用相同的 duration 和 delay

**预期效果**：5 个圆形以不同节奏同时到达终点

```javascript
const easings = [
    { name: 'Linear', fn: d3.easeLinear },
    { name: 'Bounce', fn: d3.easeBounce },
    { name: 'Elastic', fn: d3.easeElastic },
    { name: 'Back', fn: d3.easeBack },
    { name: 'Cubic', fn: d3.easeCubic }
];

easings.forEach((e, i) => {
    svg.append('circle')
        .attr('cx', 50).attr('cy', 50 + i * 60).attr('r', 15)
        .attr('fill', color(i))
        .transition().duration(1000).ease(e.fn)
        .attr('cx', 350);
});
```

### 练习 4：柱状图数据更新动画

**要求**：实现一个柱状图，支持动态更新数据并带有平滑过渡动画

**提示**：
- 使用 Enter-Update-Exit 模式
- Enter 的元素从底部升起
- Update 的元素平滑移动到新位置
- Exit 的元素下降到底部并消失

**预期效果**：点击"更新数据"按钮后，柱子平滑地更新高度和位置

```javascript
function updateChart() {
    // 生成新数据
    const newData = data.map(d => ({
        name: d.name,
        value: Math.floor(Math.random() * 80 + 20)
    }));

    // 更新比例尺
    yScale.domain([0, d3.max(newData, d => d.value)]);

    // 数据绑定
    const bars = g.selectAll('.bar').data(newData, d => d.name);

    // Enter + Update
    bars.enter()
        .append('rect')
        .attr('class', 'bar')
        .attr('x', d => xScale(d.name))
        .attr('y', innerHeight)
        .attr('width', xScale.bandwidth())
        .attr('height', 0)
        .merge(bars)
        .transition()
        .duration(500)
        .attr('y', d => yScale(d.value))
        .attr('height', d => innerHeight - yScale(d.value));

    // Exit
    bars.exit()
        .transition()
        .duration(300)
        .attr('y', innerHeight)
        .attr('height', 0)
        .remove();
}
```

### 练习 5：交错入场动画

**要求**：创建一组圆形，实现依次入场的动画效果

**提示**：
- 使用 `delay((d, i) => i * 100)` 设置递增延迟
- 使用 `ease(d3.easeCubic)` 让动画更平滑
- 可以从不同方向入场（从左、从右、从上、从下）

**预期效果**：圆形依次从底部升起，形成波浪式入场效果

```javascript
svg.selectAll('circle')
    .data(data)
    .enter()
    .append('circle')
    .attr('cx', (d, i) => 50 + i * 60)
    .attr('cy', innerHeight)
    .attr('r', 0)
    .attr('fill', 'steelblue')
    .transition()
    .duration(500)
    .delay((d, i) => i * 100)
    .ease(d3.easeCubic)
    .attr('cy', d => yScale(d.value))
    .attr('r', 20);
```
