## 🔧 图表类型一：柱状图（Bar Chart）

柱状图是最基础的图表类型，使用 `rect` 元素 + `scaleBand` 比例尺实现。

### 核心 API

| API | 用途 |
|-----|------|
| `d3.scaleBand()` | 将分类数据映射到等宽区间 |
| `d3.scaleLinear()` | 将数值映射到像素高度 |
| `rect` | SVG 矩形元素，表示柱子 |

### 完整实现

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>D3 柱状图</title>
    <script src="https://d3js.org/d3.v7.min.js"></script>
    <style>
        body { font-family: sans-serif; }
        .bar { fill: steelblue; cursor: pointer; }
        .bar:hover { fill: orange; }
        .axis text { font-size: 12px; }
    </style>
</head>
<body>
    <div id="chart"></div>
    <script>
        // 数据
        const data = [
            { name: 'A', value: 30 },
            { name: 'B', value: 80 },
            { name: 'C', value: 45 },
            { name: 'D', value: 60 },
            { name: 'E', value: 20 }
        ];

        // SVG 尺寸
        const width = 600;
        const height = 400;
        const margin = { top: 20, right: 30, bottom: 40, left: 50 };

        // 创建 SVG
        const svg = d3.select('#chart')
            .append('svg')
            .attr('width', width)
            .attr('height', height);

        // 创建绘图区域
        const g = svg.append('g')
            .attr('transform', `translate(${margin.left},${margin.top})`);

        // 计算实际绘图区域尺寸
        const innerWidth = width - margin.left - margin.right;
        const innerHeight = height - margin.top - margin.bottom;

        // 创建比例尺
        const xScale = d3.scaleBand()
            .domain(data.map(d => d.name))
            .range([0, innerWidth])
            .padding(0.2);

        const yScale = d3.scaleLinear()
            .domain([0, d3.max(data, d => d.value)])
            .range([innerHeight, 0]);

        // 创建坐标轴
        const xAxis = d3.axisBottom(xScale);
        const yAxis = d3.axisLeft(yScale).ticks(5);

        // 添加 X 轴
        g.append('g')
            .attr('class', 'axis x-axis')
            .attr('transform', `translate(0,${innerHeight})`)
            .call(xAxis);

        // 添加 Y 轴
        g.append('g')
            .attr('class', 'axis y-axis')
            .call(yAxis);

        // 绘制柱子
        g.selectAll('.bar')
            .data(data)
            .enter()
            .append('rect')
            .attr('class', 'bar')
            .attr('x', d => xScale(d.name))
            .attr('y', d => yScale(d.value))
            .attr('width', xScale.bandwidth())
            .attr('height', d => innerHeight - yScale(d.value))
            .attr('rx', 4);  // 圆角

        // 添加数值标签
        g.selectAll('.bar-label')
            .data(data)
            .enter()
            .append('text')
            .attr('class', 'bar-label')
            .attr('x', d => xScale(d.name) + xScale.bandwidth() / 2)
            .attr('y', d => yScale(d.value) - 5)
            .attr('text-anchor', 'middle')
            .attr('fill', '#333')
            .attr('font-size', '12px')
            .text(d => d.value);
    </script>
</body>
</html>
```

### 关键点解析

1. **scaleBand 的 padding**：控制柱子之间的间距
   ```javascript
   .padding(0.2)  // 20% 的间距
   ```

2. **柱子高度计算**：`innerHeight - yScale(d.value)`
   - `yScale(d.value)` 返回的是柱子顶部的 y 坐标
   - 柱子底部在 `innerHeight`（即 y=0 的位置）

3. **圆角**：`rx` 属性让柱子有圆角效果

## 🔧 图表类型二：折线图（Line Chart）

折线图使用 `path` 元素 + `d3.line()` 路径生成器实现。

### 核心 API

| API | 用途 |
|-----|------|
| `d3.line()` | 路径生成器，将数据点转换为 SVG 路径 |
| `d3.area()` | 面积生成器，用于填充区域 |
| `path` | SVG 路径元素，表示线条 |
| `d3.curveMonotoneX` | 平滑曲线插值 |

### 路径生成器原理

`d3.line()` 将数据点数组转换为 SVG 路径的 `d` 属性：

```javascript
const line = d3.line()
    .x(d => xScale(d.date))
    .y(d => yScale(d.value));

const pathData = line(data);
// 输出类似: "M0,200L50,150L100,180L150,120..."
```

### 完整实现

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>D3 折线图</title>
    <script src="https://d3js.org/d3.v7.min.js"></script>
    <style>
        body { font-family: sans-serif; }
        .line { fill: none; stroke: steelblue; stroke-width: 2px; }
        .area { fill: steelblue; opacity: 0.2; }
        .dot { fill: steelblue; stroke: white; stroke-width: 2px; }
        .dot:hover { fill: orange; }
        .axis text { font-size: 12px; }
    </style>
</head>
<body>
    <div id="chart"></div>
    <script>
        // 数据
        const data = [
            { date: '2024-01', value: 100 },
            { date: '2024-02', value: 150 },
            { date: '2024-03', value: 120 },
            { date: '2024-04', value: 180 },
            { date: '2024-05', value: 160 },
            { date: '2024-06', value: 200 }
        ];

        // 解析日期
        const parseTime = d3.timeParse('%Y-%m');
        const formatDate = d3.timeFormat('%Y-%m');

        // SVG 尺寸
        const width = 600;
        const height = 400;
        const margin = { top: 20, right: 30, bottom: 50, left: 60 };

        // 创建 SVG
        const svg = d3.select('#chart')
            .append('svg')
            .attr('width', width)
            .attr('height', height);

        // 创建绘图区域
        const g = svg.append('g')
            .attr('transform', `translate(${margin.left},${margin.top})`);

        // 计算实际绘图区域尺寸
        const innerWidth = width - margin.left - margin.right;
        const innerHeight = height - margin.top - margin.bottom;

        // 创建比例尺
        const xScale = d3.scaleTime()
            .domain(d3.extent(data, d => parseTime(d.date)))
            .range([0, innerWidth]);

        const yScale = d3.scaleLinear()
            .domain([0, d3.max(data, d => d.value)])
            .range([innerHeight, 0]);

        // 创建路径生成器
        const line = d3.line()
            .x(d => xScale(parseTime(d.date)))
            .y(d => yScale(d.value))
            .curve(d3.curveMonotoneX);  // 平滑曲线

        // 创建面积生成器
        const area = d3.area()
            .x(d => xScale(parseTime(d.date)))
            .y0(innerHeight)
            .y1(d => yScale(d.value))
            .curve(d3.curveMonotoneX);

        // 添加坐标轴
        g.append('g')
            .attr('class', 'axis')
            .attr('transform', `translate(0,${innerHeight})`)
            .call(d3.axisBottom(xScale).ticks(6).tickFormat(d3.timeFormat('%m月')));

        g.append('g')
            .attr('class', 'axis')
            .call(d3.axisLeft(yScale).ticks(5));

        // 绘制面积
        g.append('path')
            .datum(data)
            .attr('class', 'area')
            .attr('d', area);

        // 绘制折线
        g.append('path')
            .datum(data)
            .attr('class', 'line')
            .attr('d', line);

        // 绘制数据点
        g.selectAll('.dot')
            .data(data)
            .enter()
            .append('circle')
            .attr('class', 'dot')
            .attr('cx', d => xScale(parseTime(d.date)))
            .attr('cy', d => yScale(d.value))
            .attr('r', 5);
    </script>
</body>
</html>
```

### 关键点解析

1. **d3.line() 链式调用**：
   ```javascript
   const line = d3.line()
       .x(d => xScale(parseTime(d.date)))  // x 坐标映射
       .y(d => yScale(d.value))             // y 坐标映射
       .curve(d3.curveMonotoneX);           // 曲线插值
   ```

2. **曲线插值类型**：
   - `d3.curveLinear`：直线连接（默认）
   - `d3.curveMonotoneX`：单调平滑曲线
   - `d3.curveBasis`：B 样条曲线
   - `d3.curveCardinal`：Cardinal 样条

3. **面积填充**：使用 `d3.area()` 生成器，设置 `y0` 为底部基线

## 🔧 图表类型三：饼图（Pie Chart）

饼图使用 `d3.pie()` 计算角度 + `d3.arc()` 绘制扇形。

### 核心 API

| API | 用途 |
|-----|------|
| `d3.pie()` | 将数据转换为角度信息（startAngle, endAngle） |
| `d3.arc()` | 根据角度信息绘制扇形路径 |
| `d3.interpolate` | 颜色插值 |

### 饼图原理

```
原始数据: [30, 80, 45, 60, 20]
    ↓
d3.pie() 计算角度
    ↓
[{startAngle: 0, endAngle: 0.8}, ...]
    ↓
d3.arc() 生成路径
    ↓
SVG path 元素
```

### 完整实现

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>D3 饼图</title>
    <script src="https://d3js.org/d3.v7.min.js"></script>
    <style>
        body { font-family: sans-serif; }
        .slice { cursor: pointer; stroke: white; stroke-width: 2px; }
        .slice:hover { opacity: 0.8; }
        .label { font-size: 12px; fill: white; text-anchor: middle; }
    </style>
</head>
<body>
    <div id="chart"></div>
    <script>
        // 数据
        const data = [
            { name: 'Chrome', value: 65 },
            { name: 'Firefox', value: 15 },
            { name: 'Safari', value: 10 },
            { name: 'Edge', value: 7 },
            { name: '其他', value: 3 }
        ];

        // SVG 尺寸
        const width = 500;
        const height = 500;
        const radius = Math.min(width, height) / 2 - 40;

        // 创建 SVG
        const svg = d3.select('#chart')
            .append('svg')
            .attr('width', width)
            .attr('height', height);

        // 创建绘图区域（居中）
        const g = svg.append('g')
            .attr('transform', `translate(${width / 2},${height / 2})`);

        // 创建颜色比例尺
        const color = d3.scaleOrdinal(d3.schemeCategory10);

        // 创建饼图生成器
        const pie = d3.pie()
            .value(d => d.value)
            .sort(null);  // 不排序，保持数据顺序

        // 创建弧形生成器
        const arc = d3.arc()
            .innerRadius(0)      // 内半径（0 为实心饼图）
            .outerRadius(radius); // 外半径

        // 创建标签弧形生成器
        const labelArc = d3.arc()
            .innerRadius(radius * 0.6)
            .outerRadius(radius * 0.6);

        // 计算饼图数据
        const pieData = pie(data);

        // 绘制扇形
        const slices = g.selectAll('.slice')
            .data(pieData)
            .enter()
            .append('g')
            .attr('class', 'slice');

        slices.append('path')
            .attr('d', arc)
            .attr('fill', (d, i) => color(i))
            .attr('stroke', 'white')
            .attr('stroke-width', 2);

        // 添加标签
        slices.append('text')
            .attr('class', 'label')
            .attr('transform', d => `translate(${labelArc.centroid(d)})`)
            .text(d => `${d.data.name} (${d.data.value}%)`);
    </script>
</body>
</html>
```

### 环形图（Donut Chart）

只需修改 `arc` 的 `innerRadius`：

```javascript
const arc = d3.arc()
    .innerRadius(radius * 0.5)  // 设置内半径
    .outerRadius(radius);
```

### 关键点解析

1. **d3.pie() 配置**：
   ```javascript
   const pie = d3.pie()
       .value(d => d.value)  // 指定值访问器
       .sort(null);          // 不排序（保持数据顺序）
   ```

2. **arc.centroid()**：返回弧形的中心点，用于定位标签

3. **排序**：`.sort(null)` 保持数据原始顺序，`.sort(d3.descending)` 按值降序排列

## ⚠️ 常见踩坑点

### 1. 柱状图高度计算错误

```javascript
// ❌ 错误：直接用数据值作为高度
.attr('height', d => d.value)

// ✅ 正确：用比例尺计算高度
.attr('height', d => innerHeight - yScale(d.value))
```

### 2. 折线图日期解析失败

```javascript
// ❌ 错误：直接使用字符串
const xScale = d3.scaleTime()
    .domain(['2024-01', '2024-12']);

// ✅ 正确：先解析为 Date 对象
const parseTime = d3.timeParse('%Y-%m');
const xScale = d3.scaleTime()
    .domain(d3.extent(data, d => parseTime(d.date)));
```

### 3. 饼图标签重叠

```javascript
// ❌ 问题：小扇形的标签会重叠
slices.append('text')
    .attr('transform', d => `translate(${arc.centroid(d)})`);

// ✅ 解决：使用外层弧形计算标签位置，或只显示大扇形的标签
const labelArc = d3.arc()
    .innerRadius(radius * 0.8)
    .outerRadius(radius * 0.8);

slices.append('text')
    .attr('transform', d => `translate(${labelArc.centroid(d)})`)
    .text(d => d.data.value > 5 ? d.data.name : '');  // 只显示大于 5% 的标签
```

### 4. 折线图曲线插值选择

```javascript
// ❌ 问题：默认直线连接不够平滑
const line = d3.line()
    .x(d => xScale(d.date))
    .y(d => yScale(d.value));

// ✅ 解决：使用平滑曲线
const line = d3.line()
    .x(d => xScale(d.date))
    .y(d => yScale(d.value))
    .curve(d3.curveMonotoneX);  // 单调平滑曲线
```

## 🆚 D3 vs ECharts vs Chart.js 图表实现对比

| 维度 | D3 | ECharts | Chart.js |
|------|-----|---------|----------|
| 柱状图实现 | 手动创建 `rect` | 配置 `series.type: 'bar'` | 配置 `type: 'bar'` |
| 折线图实现 | 手动创建 `path` + `d3.line()` | 配置 `series.type: 'line'` | 配置 `type: 'line'` |
| 饼图实现 | 手动创建 `path` + `d3.arc()` | 配置 `series.type: 'pie'` | 配置 `type: 'pie'` |
| 定制能力 | 极高 | 中等 | 中等 |
| 代码量 | 多（100+ 行） | 少（20-30 行配置） | 少（20-30 行配置） |
| 动画控制 | 精细控制每个属性 | 配置项控制 | 配置项控制 |

**面试回答**：D3 需要手动创建 SVG 元素并绑定数据，代码量大但定制能力强。ECharts 和 Chart.js 只需配置即可生成图表，适合快速开发。如果需要高度定制的可视化效果（如自定义形状、复杂交互），D3 是首选；如果是标准业务图表，ECharts 更高效。

## 📝 面试回答模板

> **问：D3 如何实现柱状图？**
>
> D3 实现柱状图的核心是 `scaleBand` + `rect` 元素。具体步骤：
> 1. 使用 `d3.scaleBand()` 创建 x 轴比例尺，将分类数据映射到等宽区间
> 2. 使用 `d3.scaleLinear()` 创建 y 轴比例尺，将数值映射到像素高度
> 3. 使用 `selectAll('rect').data().enter().append('rect')` 创建柱子
> 4. 设置 `x`、`y`、`width`、`height` 属性
>
> **追问：scaleBand 和 scaleLinear 有什么区别？**
> `scaleBand` 处理离散分类，输出起始坐标 + 宽度；`scaleLinear` 处理连续数值，输出单个值。柱状图的 x 轴用 `scaleBand`，y 轴用 `scaleLinear`。

> **问：D3 如何实现折线图？**
>
> D3 折线图使用 `d3.line()` 路径生成器。它将数据点数组转换为 SVG 路径的 `d` 属性：
> ```javascript
> const line = d3.line()
>     .x(d => xScale(d.date))
>     .y(d => yScale(d.value))
>     .curve(d3.curveMonotoneX);  // 平滑曲线
>
> svg.append('path')
>     .datum(data)
>     .attr('d', line)
>     .attr('fill', 'none')
>     .attr('stroke', 'steelblue');
> ```
>
> **追问：曲线插值有哪些类型？**
> 常用的有 `curveLinear`（直线）、`curveMonotoneX`（单调平滑）、`curveBasis`（B 样条）、`curveCardinal`（Cardinal 样条）。`curveMonotoneX` 最常用，因为它保证曲线不会超出数据范围。

> **问：D3 如何实现饼图？**
>
> D3 饼图使用 `d3.pie()` + `d3.arc()`：
> 1. `d3.pie()` 将数据转换为角度信息（startAngle, endAngle）
> 2. `d3.arc()` 根据角度信息生成扇形路径
> 3. 使用 `path` 元素绘制每个扇形
>
> 环形图只需设置 `arc.innerRadius()` 为非零值。
>
> **追问：如何让饼图按大小排序？**
> `d3.pie().sort(d3.descending)` 会按值降序排列。

## 🧪 练习题

### 练习 1：动态柱状图

**要求**：实现一个柱状图，支持动态添加/删除柱子

**提示**：
- 使用 `data.push()` 添加数据
- 使用 `data.pop()` 删除数据
- 使用 Enter-Update-Exit 模式更新 DOM

**预期效果**：点击按钮后柱子平滑添加/删除

```javascript
let data = [
    { name: 'A', value: 30 },
    { name: 'B', value: 80 },
    { name: 'C', value: 45 }
];

function addBar() {
    const newName = String.fromCharCode(65 + data.length);
    data.push({ name: newName, value: Math.random() * 80 + 10 });
    updateBars();
}

function removeBar() {
    if (data.length > 0) {
        data.pop();
        updateBars();
    }
}

function updateBars() {
    xScale.domain(data.map(d => d.name));

    const bars = g.selectAll('.bar')
        .data(data, d => d.name);

    bars.enter()
        .append('rect')
        .attr('class', 'bar')
        .attr('x', d => xScale(d.name))
        .attr('y', innerHeight)
        .attr('width', xScale.bandwidth())
        .attr('height', 0)
        .attr('fill', 'steelblue')
        .merge(bars)
        .transition()
        .duration(500)
        .attr('x', d => xScale(d.name))
        .attr('y', d => yScale(d.value))
        .attr('width', xScale.bandwidth())
        .attr('height', d => innerHeight - yScale(d.value));

    bars.exit()
        .transition()
        .duration(300)
        .attr('y', innerHeight)
        .attr('height', 0)
        .remove();
}
```

### 练习 2：带 Tooltip 的折线图

**要求**：在折线图上添加 Tooltip，鼠标悬停显示数据详情

**提示**：
- 使用 `mouseover` 和 `mouseout` 事件
- 创建一个绝对定位的 `div` 作为 Tooltip
- 使用 `d3.pointer()` 获取鼠标位置

**预期效果**：鼠标悬停在数据点上时，显示数值信息

```javascript
// 创建 Tooltip
const tooltip = d3.select('body')
    .append('div')
    .style('position', 'absolute')
    .style('background', 'rgba(0,0,0,0.8)')
    .style('color', 'white')
    .style('padding', '8px 12px')
    .style('border-radius', '4px')
    .style('font-size', '12px')
    .style('pointer-events', 'none')
    .style('opacity', 0);

// 添加数据点
g.selectAll('.dot')
    .data(data)
    .enter()
    .append('circle')
    .attr('class', 'dot')
    .attr('cx', d => xScale(parseTime(d.date)))
    .attr('cy', d => yScale(d.value))
    .attr('r', 6)
    .on('mouseover', function(event, d) {
        tooltip.style('opacity', 1)
            .html(`${d.date}<br/>数值: ${d.value}`)
            .style('left', (event.pageX + 10) + 'px')
            .style('top', (event.pageY - 30) + 'px');
    })
    .on('mouseout', function() {
        tooltip.style('opacity', 0);
    });
```

### 练习 4：组合图表

**要求**：在一个图表中同时显示柱状图和折线图

**提示**：
- 使用同一套坐标系
- 柱子用 `rect`，折线用 `path`
- 可以使用双 Y 轴（左右不同刻度）

**预期效果**：柱子表示实际值，折线表示趋势线

```javascript
// 数据
const data = [
    { month: '1月', actual: 100, target: 120 },
    { month: '2月', actual: 150, target: 130 },
    { month: '3月', actual: 120, target: 140 },
    { month: '4月', actual: 180, target: 150 },
    { month: '5月', actual: 160, target: 160 }
];

// 左 Y 轴（柱状图）
const yScaleLeft = d3.scaleLinear()
    .domain([0, 200])
    .range([innerHeight, 0]);

// 右 Y 轴（折线图）
const yScaleRight = d3.scaleLinear()
    .domain([0, 200])
    .range([innerHeight, 0]);

// 绘制柱子
g.selectAll('.bar')
    .data(data)
    .enter()
    .append('rect')
    .attr('class', 'bar')
    .attr('x', d => xScale(d.month))
    .attr('y', d => yScaleLeft(d.actual))
    .attr('width', xScale.bandwidth())
    .attr('height', d => innerHeight - yScaleLeft(d.actual))
    .attr('fill', 'steelblue');

// 绘制折线
const line = d3.line()
    .x(d => xScale(d.month) + xScale.bandwidth() / 2)
    .y(d => yScaleRight(d.target))
    .curve(d3.curveMonotoneX);

g.append('path')
    .datum(data)
    .attr('fill', 'none')
    .attr('stroke', 'orange')
    .attr('stroke-width', 2)
    .attr('d', line);
```
