## 🔧 核心概念一：力导向图（Force-Directed Graph）

### 什么是力导向图？

力导向图是一种基于物理模拟的图布局算法，常用于展示节点之间的关系网络（如社交网络、知识图谱）。

### 核心 API

| API | 用途 | 示例 |
|-----|------|------|
| `d3.forceSimulation(nodes)` | 创建力模拟 | `d3.forceSimulation(data.nodes)` |
| `d3.forceLink(links)` | 连接力（弹簧） | `.force('link', d3.forceLink(links).id(d => d.id))` |
| `d3.forceManyBody()` | 电荷力（排斥/吸引） | `.force('charge', d3.forceManyBody().strength(-200))` |
| `d3.forceCenter(x, y)` | 中心力 | `.force('center', d3.forceCenter(cx, cy))` |
| `d3.forceCollide(radius)` | 碰撞力 | `.force('collide', d3.forceCollide(30))` |
| `simulation.on('tick', handler)` | 每帧更新 | `.on('tick', ticked)` |
| `d3.drag()` | 拖拽行为 | `selection.call(d3.drag())` |

### 力的类型详解

#### 1. 连接力（forceLink）

模拟节点之间的弹簧连接，保持边的长度。

```javascript
const linkForce = d3.forceLink(links)
    .id(d => d.id)           // 指定节点 ID 字段
    .distance(100)           // 目标距离
    .strength(0.5);          // 强度 (0~1)
```

#### 2. 电荷力（forceManyBody）

模拟带电粒子，负值排斥（默认），正值吸引。

```javascript
const chargeForce = d3.forceManyBody()
    .strength(-200)          // 负值 = 排斥
    .distanceMax(500);       // 最大作用距离
```

#### 3. 中心力（forceCenter）

将所有节点拉向中心点。

```javascript
const centerForce = d3.forceCenter(width / 2, height / 2);
```

#### 4. 碰撞力（forceCollide）

防止节点重叠。

```javascript
const collideForce = d3.forceCollide()
    .radius(d => d.r + 2)    // 碰撞半径
    .strength(0.7);          // 强度
```

### 力导向图完整实现

```javascript
const nodes = [
    { id: 'A', group: 1 },
    { id: 'B', group: 1 },
    { id: 'C', group: 2 },
    { id: 'D', group: 2 }
];

const links = [
    { source: 'A', target: 'B' },
    { source: 'B', target: 'C' },
    { source: 'C', target: 'D' }
];

const simulation = d3.forceSimulation(nodes)
    .force('link', d3.forceLink(links).id(d => d.id).distance(100))
    .force('charge', d3.forceManyBody().strength(-200))
    .force('center', d3.forceCenter(width / 2, height / 2))
    .force('collide', d3.forceCollide(20));

// 绘制连线
const link = svg.selectAll('line')
    .data(links)
    .enter().append('line')
    .attr('stroke', '#999')
    .attr('stroke-width', 1.5);

// 绘制节点
const node = svg.selectAll('circle')
    .data(nodes)
    .enter().append('circle')
    .attr('r', 10)
    .attr('fill', d => color(d.group));

// Tick 回调：每帧更新位置
simulation.on('tick', () => {
    link.attr('x1', d => d.source.x)
        .attr('y1', d => d.source.y)
        .attr('x2', d => d.target.x)
        .attr('y2', d => d.target.y);

    node.attr('cx', d => d.x)
        .attr('cy', d => d.y);
});
```

### 拖拽交互

```javascript
const drag = d3.drag()
    .on('start', (event, d) => {
        if (!event.active) simulation.alphaTarget(0.3).restart();
        d.fx = d.x;
        d.fy = d.y;
    })
    .on('drag', (event, d) => {
        d.fx = event.x;
        d.fy = event.y;
    })
    .on('end', (event, d) => {
        if (!event.active) simulation.alphaTarget(0);
        d.fx = null;
        d.fy = null;
    });

node.call(drag);
```

### 关键属性说明

| 属性 | 含义 |
|------|------|
| `d.x`, `d.y` | 当前位置（由模拟计算） |
| `d.fx`, `d.fy` | 固定位置（拖拽时设置） |
| `d.vx`, `d.vy` | 速度 |
| `simulation.alpha()` | 当前"温度"（0~1） |
| `simulation.alphaTarget()` | 目标温度 |
| `simulation.restart()` | 重新启动模拟 |
| `simulation.stop()` | 停止模拟 |

## 🔧 核心概念二：树图（Tree Diagram）

### 什么是树图？

树图用于展示层级数据结构，如文件目录、组织架构、决策树等。

### 核心 API

| API | 用途 | 示例 |
|-----|------|------|
| `d3.hierarchy(data)` | 创建层级数据 | `d3.hierarchy(treeData)` |
| `d3.tree()` | 树布局 | `d3.tree().size([w, h])` |
| `d3.cluster()` | 聚类布局（叶节点对齐） | `d3.cluster().size([w, h])` |
| `node.descendants()` | 获取所有节点 | `root.descendants()` |
| `node.links()` | 获取所有连接 | `root.links()` |
| `d3.linkHorizontal()` | 水平连接路径 | `d3.linkHorizontal().x(d => d.y).y(d => d.x)` |

### 层级数据格式

```javascript
const treeData = {
    name: 'CEO',
    children: [
        {
            name: 'CTO',
            children: [
                { name: '前端', value: 10 },
                { name: '后端', value: 15 }
            ]
        },
        {
            name: 'CFO',
            children: [
                { name: '财务', value: 8 }
            ]
        }
    ]
};
```

### 树图完整实现

```javascript
const treeLayout = d3.tree().size([height - 40, width - 200]);
const root = d3.hierarchy(treeData);
treeLayout(root);

// 绘制连线
const linkPath = d3.linkHorizontal()
    .x(d => d.y)
    .y(d => d.x);

svg.selectAll('.link')
    .data(root.links())
    .enter().append('path')
    .attr('class', 'link')
    .attr('fill', 'none')
    .attr('stroke', '#999')
    .attr('d', linkPath);

// 绘制节点
const node = svg.selectAll('.node')
    .data(root.descendants())
    .enter().append('g')
    .attr('class', 'node')
    .attr('transform', d => `translate(${d.y},${d.x})`);

node.append('circle').attr('r', 6).attr('fill', '#3498db');
node.append('text')
    .attr('dx', d => d.children ? -12 : 12)
    .attr('dy', 4)
    .attr('text-anchor', d => d.children ? 'end' : 'start')
    .text(d => d.data.name);
```

## 🆚 力导向图 vs 树图对比

| 维度 | 力导向图 | 树图 |
|------|----------|------|
| 适用数据 | 网状关系（图结构） | 层级关系（树结构） |
| 布局方式 | 物理模拟（动态） | 算法计算（静态） |
| 交互特点 | 可拖拽、动态调整 | 展开/折叠 |
| 典型场景 | 社交网络、知识图谱 | 文件目录、组织架构 |
| 性能 | 节点多时需优化 | 稳定 |

**面试回答**：力导向图适合展示节点之间的复杂关系网络，通过物理模拟自动计算最优布局。树图适合展示层级结构，布局由算法确定，节点位置固定。

## ⚠️ 常见踩坑点

### 1. 力模拟不收敛

```javascript
// ❌ 错误：没有设置 alphaTarget，模拟可能过早停止
simulation.alphaTarget(0);

// ✅ 正确：给足够的"冷却时间"
simulation.alphaDecay(0.02);  // 默认 0.0228
```

### 2. 节点位置超出 SVG

```javascript
// ❌ 错误：没有边界约束
node.attr('cx', d => d.x);

// ✅ 正确：添加边界约束
node.attr('cx', d => Math.max(r, Math.min(width - r, d.x)));
```

### 3. 树图节点文字重叠

```javascript
// ❌ 错误：固定字号
node.append('text').attr('font-size', '14px');

// ✅ 正确：根据层级调整字号
node.append('text')
    .attr('font-size', d => d.depth === 0 ? '16px' : '12px');
```

### 4. 节点拖拽后不恢复

```javascript
// ❌ 错误：拖拽结束后位置不释放
.on('end', (event, d) => {
    // d.fx 和 d.fy 仍然有值，节点被固定
});

// ✅ 正确：清除固定位置
.on('end', (event, d) => {
    d.fx = null;
    d.fy = null;
});
```

## 📝 面试回答模板

> **问：D3 力导向图的原理是什么？**
>
> D3 的力导向图基于物理模拟，通过 `d3.forceSimulation()` 创建一个模拟器，包含多种力：
> - `forceLink`：连接力，模拟弹簧
> - `forceManyBody`：电荷力，模拟排斥
> - `forceCenter`：中心力，防止节点飘远
> - `forceCollide`：碰撞力，防止重叠
>
> 模拟器每帧计算节点位置，直到"冷却"（alpha → 0）。

> **问：力导向图和树图有什么区别？**
>
> - 力导向图：适合网状关系，布局由物理模拟决定，节点可拖拽
> - 树图：适合层级结构，布局由算法确定，支持展开/折叠

> **问：如何优化力导向图的性能？**
>
> 1. 减少节点数量（聚合/抽样）
> 2. 使用 Canvas 代替 SVG
> 3. 降低 `alphaDecay` 值
> 4. 使用 `simulation.stop()` 在不可见时暂停
