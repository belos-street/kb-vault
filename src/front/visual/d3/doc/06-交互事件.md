## 🔧 核心概念一：事件绑定（on）

### 基本用法

```javascript
// 绑定单个事件
selection.on('click', function(event, d) {
    console.log('点击了', d);
});

// 绑定多个事件
selection
    .on('mouseover', handleMouseOver)
    .on('mouseout', handleMouseOut)
    .on('click', handleClick);
```

### D3 v7 事件传递

**重要**：D3 v7 已移除 `d3.event`，事件通过回调参数传递。

```javascript
// ❌ D3 v6 及之前（已废弃）
selection.on('click', function(d) {
    console.log(d3.event);  // 通过 d3.event 获取事件
});

// ✅ D3 v7（推荐）
selection.on('click', function(event, d) {
    console.log(event);  // 第一个参数是事件对象
    console.log(d);      // 第二个参数是绑定的数据
});
```

### 核心 API

| API | 用途 | 示例 |
|-----|------|------|
| `selection.on(type, handler)` | 绑定事件 | `.on('click', handler)` |
| `selection.on(type, null)` | 移除事件 | `.on('click', null)` |
| `event` | 事件对象（第一个参数） | `event.target`、`event.pageX` |
| `d` | 绑定的数据（第二个参数） | `d.value`、`d.name` |

## 🔧 核心概念二：常用事件类型

### 鼠标事件

| 事件 | 触发时机 | 常用场景 |
|------|----------|----------|
| `click` | 鼠标点击 | 选中元素、触发操作 |
| `dblclick` | 鼠标双击 | 编辑、放大 |
| `mouseover` | 鼠标移入 | 高亮、显示 Tooltip |
| `mouseout` | 鼠标移出 | 取消高亮、隐藏 Tooltip |
| `mousemove` | 鼠标移动 | 跟踪鼠标位置 |
| `mousedown` | 鼠标按下 | 拖拽开始 |
| `mouseup` | 鼠标松开 | 拖拽结束 |

### 触摸事件（移动端）

| 事件 | 触发时机 | 常用场景 |
|------|----------|----------|
| `touchstart` | 触摸开始 | 移动端点击 |
| `touchmove` | 触摸移动 | 移动端拖拽 |
| `touchend` | 触摸结束 | 移动端松开 |

### 其他事件

| 事件 | 触发时机 | 常用场景 |
|------|----------|----------|
| `mouseenter` | 鼠标进入（不冒泡） | 精确进入检测 |
| `mouseleave` | 鼠标离开（不冒泡） | 精确离开检测 |
| `contextmenu` | 右键菜单 | 自定义右键菜单 |

## 🔧 核心概念三：事件对象（event）

### 常用属性

```javascript
selection.on('click', function(event, d) {
    // 事件目标
    const target = event.target;           // 触发事件的 DOM 元素
    const tagName = event.target.tagName;  // 元素标签名

    // 鼠标位置（相对于页面）
    const pageX = event.pageX;
    const pageY = event.pageY;

    // 鼠标位置（相对于视口）
    const clientX = event.clientX;
    const clientY = event.clientY;

    // 鼠标位置（相对于 SVG）
    const [svgX, svgY] = d3.pointer(event, svg.node());

    // 修饰键
    const isShift = event.shiftKey;
    const isCtrl = event.ctrlKey;
    const isAlt = event.altKey;

    // 阻止默认行为
    event.preventDefault();

    // 阻止事件冒泡
    event.stopPropagation();
});
```

### d3.pointer() 获取 SVG 坐标

```javascript
// 获取相对于 SVG 的坐标
const [x, y] = d3.pointer(event);

// 获取相对于指定元素的坐标
const [x, y] = d3.pointer(event, svg.node());
```

## 🔧 核心概念四：Tooltip 实现

### Tooltip 是什么？

Tooltip 是鼠标悬停时显示的数据提示框，用于展示详细信息。

### 实现思路

1. 创建一个隐藏的 `div` 元素作为 Tooltip
2. 在 `mouseover` 事件中显示 Tooltip 并设置内容
3. 在 `mousemove` 事件中更新 Tooltip 位置
4. 在 `mouseout` 事件中隐藏 Tooltip

### 完整实现

```javascript
// 1. 创建 Tooltip
const tooltip = d3.select('body')
    .append('div')
    .attr('class', 'tooltip')
    .style('position', 'absolute')
    .style('background', 'rgba(0,0,0,0.8)')
    .style('color', 'white')
    .style('padding', '8px 12px')
    .style('border-radius', '4px')
    .style('font-size', '12px')
    .style('pointer-events', 'none')
    .style('opacity', 0);

// 2. 绑定事件
selection
    .on('mouseover', function(event, d) {
        // 显示 Tooltip
        tooltip.style('opacity', 1)
            .html(`<strong>${d.name}</strong><br/>值: ${d.value}`);
    })
    .on('mousemove', function(event) {
        // 更新位置
        tooltip
            .style('left', (event.pageX + 10) + 'px')
            .style('top', (event.pageY - 30) + 'px');
    })
    .on('mouseout', function() {
        // 隐藏 Tooltip
        tooltip.style('opacity', 0);
    });
```

### Tooltip 样式优化

```css
.tooltip {
    position: absolute;
    background: rgba(0, 0, 0, 0.85);
    color: white;
    padding: 8px 12px;
    border-radius: 4px;
    font-size: 12px;
    pointer-events: none;  /* 防止 Tooltip 遮挡鼠标事件 */
    box-shadow: 0 2px 8px rgba(0, 0, 0, 0.3);
    transition: opacity 0.2s;
    z-index: 1000;
}

.tooltip::after {
    content: '';
    position: absolute;
    bottom: -6px;
    left: 50%;
    transform: translateX(-50%);
    border-left: 6px solid transparent;
    border-right: 6px solid transparent;
    border-top: 6px solid rgba(0, 0, 0, 0.85);
}
```

## 🔧 核心概念五：高亮与选中效果

### 高亮效果（Hover）

```javascript
selection
    .on('mouseover', function(event, d) {
        // 高亮当前元素
        d3.select(this)
            .transition().duration(200)
            .attr('fill', '#e74c3c')
            .attr('stroke', '#c0392b')
            .attr('stroke-width', 3);

        // 降低其他元素透明度
        selection.filter(item => item !== d)
            .transition().duration(200)
            .attr('opacity', 0.3);
    })
    .on('mouseout', function() {
        // 恢复所有元素
        selection
            .transition().duration(200)
            .attr('fill', '#3498db')
            .attr('stroke', 'none')
            .attr('stroke-width', 0)
            .attr('opacity', 1);
    });
```

### 选中效果（Click）

```javascript
let selectedElement = null;

selection.on('click', function(event, d) {
    // 取消之前的选中
    if (selectedElement) {
        d3.select(selectedElement)
            .attr('stroke', 'none')
            .attr('stroke-width', 0);
    }

    // 选中当前元素
    selectedElement = this;
    d3.select(this)
        .attr('stroke', '#f39c12')
        .attr('stroke-width', 3);
});
```

## 🔧 核心概念六：事件委托

### 什么是事件委托？

将事件绑定到父元素，通过事件冒泡处理子元素的事件。

```javascript
// ❌ 直接绑定（性能差）
circles.forEach(circle => {
    circle.on('click', handleClick);
});

// ✅ 事件委托（性能好）
svg.on('click', function(event) {
    const target = event.target;
    if (target.tagName === 'circle') {
        const d = d3.select(target).datum();
        handleClick(event, d);
    }
});
```

## 🆚 D3 vs CSS 交互对比

| 维度 | D3 事件 | CSS 伪类 |
|------|---------|----------|
| 控制精度 | 精细控制每个属性 | 有限，依赖选择器 |
| 数据绑定 | 直接访问绑定数据 | 无数据概念 |
| 复杂交互 | 支持条件判断、动画 | 有限 |
| 性能 | 需手动优化 | 浏览器优化 |
| 学习曲线 | 陡峭 | 平缓 |
| 适用场景 | 数据驱动的交互 | 简单 hover 效果 |

**面试回答**：D3 事件与数据绑定紧密集成，可以在事件处理函数中直接访问绑定的数据，实现复杂的数据驱动交互。CSS 伪类更适合简单的 UI 状态变化。

## ⚠️ 常见踩坑点

### 1. 忘记 D3 v7 事件传递方式

```javascript
// ❌ D3 v6 及之前
selection.on('click', function(d) {
    console.log(d3.event);  // 已废弃
});

// ✅ D3 v7
selection.on('click', function(event, d) {
    console.log(event);  // 第一个参数是事件对象
});
```

### 2. Tooltip 遮挡鼠标事件

```javascript
// ❌ 错误：Tooltip 会遮挡鼠标事件
tooltip.style('pointer-events', 'auto');

// ✅ 正确：让 Tooltip 不响应鼠标事件
tooltip.style('pointer-events', 'none');
```

### 3. 事件处理函数中 this 指向

```javascript
// ❌ 箭头函数中 this 指向外部
selection.on('click', (event, d) => {
    console.log(this);  // 指向外部作用域
});

// ✅ 普通函数中 this 指向当前元素
selection.on('click', function(event, d) {
    console.log(this);  // 指向当前 DOM 元素
    d3.select(this).attr('fill', 'red');
});
```

### 4. 鼠标位置计算错误

```javascript
// ❌ 错误：使用 pageX/pageY 可能有偏移
tooltip
    .style('left', event.pageX + 'px')
    .style('top', event.pageY + 'px');

// ✅ 正确：加上偏移量
tooltip
    .style('left', (event.pageX + 10) + 'px')
    .style('top', (event.pageY - 30) + 'px');
```

## 📝 面试回答模板

> **问：D3 如何实现 Tooltip？**
>
> D3 实现 Tooltip 的核心思路：
> 1. 创建一个隐藏的 `div` 元素
> 2. 在 `mouseover` 事件中显示并设置内容
> 3. 在 `mousemove` 事件中更新位置
> 4. 在 `mouseout` 事件中隐藏
>
> **追问：D3 v7 和 v6 事件处理有什么区别？**
> D3 v7 移除了 `d3.event`，事件通过回调参数传递。第一个参数是事件对象，第二个参数是绑定的数据。

> **问：D3 如何实现高亮效果？**
>
> 使用 `on('mouseover')` 和 `on('mouseout')` 事件：
> 1. `mouseover` 时：改变当前元素的样式（颜色、描边）
> 2. 同时降低其他元素的透明度
> 3. `mouseout` 时：恢复所有元素的样式
>
> **追问：如何实现选中效果？**
> 使用一个变量记录选中元素，点击时取消之前的选中，选中当前元素。

> **问：什么是事件委托？D3 中如何使用？**
>
> 事件委托是将事件绑定到父元素，通过事件冒泡处理子元素的事件。在 D3 中，可以将事件绑定到 SVG 容器，然后通过 `event.target` 判断触发事件的元素。

### 练习 3：高亮与选中效果

**要求**：实现点击柱子高亮，再次点击取消选中

**提示**：
- 使用变量记录选中状态
- 使用 `stroke` 和 `stroke-width` 实现高亮
- 使用 `opacity` 实现其他元素淡化

**预期效果**：点击柱子时高亮，其他柱子变淡；再次点击取消

```javascript
let selectedIndex = -1;

bars.on('click', function(event, d, i) {
    if (selectedIndex === i) {
        // 取消选中
        selectedIndex = -1;
        bars.attr('opacity', 1).attr('stroke', 'none');
    } else {
        // 选中当前
        selectedIndex = i;
        bars.attr('opacity', (item, idx) => idx === i ? 1 : 0.3)
            .attr('stroke', (item, idx) => idx === i ? '#f39c12' : 'none')
            .attr('stroke-width', (item, idx) => idx === i ? 3 : 0);
    }
});
```

### 练习 4：鼠标跟踪效果

**要求**：实现鼠标移动时，显示十字准线和最近的数据点信息

**提示**：
- 使用 `mousemove` 事件获取鼠标位置
- 使用 `d3.bisector` 找到最近的数据点
- 绘制十字准线

**预期效果**：鼠标移动时，显示十字准线和对应数据点信息

```javascript
svg.on('mousemove', function(event) {
    const [mx, my] = d3.pointer(event);
    const x0 = xScale.invert(mx);
    const bisect = d3.bisector(d => d.date).left;
    const idx = bisect(data, x0, 1);
    const d0 = data[idx - 1];
    const d1 = data[idx];
    const d = x0 - d0.date > d1.date - x0 ? d1 : d0;

    // 更新十字准线
    crosshairV.attr('x1', xScale(d.date)).attr('x2', xScale(d.date));
    crosshairH.attr('y1', yScale(d.value)).attr('y2', yScale(d.value));

    // 更新 Tooltip
    tooltip.style('opacity', 1)
        .html(`${d.date}<br/>值: ${d.value}`)
        .style('left', (event.pageX + 10) + 'px')
        .style('top', (event.pageY - 30) + 'px');
});
```
