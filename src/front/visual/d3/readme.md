---

## 🎯 学习目标
- 理解 D3 的核心理念：数据驱动 DOM、比例尺、坐标系
- 掌握常用图表的实现方式（柱状图、折线图、饼图、散点图、力导向图）
- 能独立完成数据可视化需求

## 📋 前置要求
- 熟悉 JavaScript ES6+（解构、箭头函数、数组方法）
- 有 DOM 操作基础

## 📚 模块详解

### 模块 1：SVG 基础与 D3 核心理念（1 天）
**面试可答**：D3 的核心是数据驱动 DOM，`selectAll + data + enter` 是灵魂三件套。

- SVG 热身：基本元素（rect、circle、line、path、text、g）、viewBox
- D3 是什么：Data-Driven Documents
- 与 ECharts/Chart.js 的区别：D3 是底层工具，高度可定制
- 选择器：`d3.select()`、`d3.selectAll()`
- **练习**：用纯 SVG 画几个图形，再用 D3 创建 10 个不同颜色的圆

---

### 模块 2：数据绑定与 Update 模式（1 天）
**面试可答**：`enter` 处理新增元素、`update` 处理更新、`exit` 处理删除。

- `selection.data()` 数据绑定原理
- Enter-Update-Exit 模式
- `merge()` 合并选择集
- **练习**：动态添加/删除柱状图柱子，理解 enter 和 exit

---

### 模块 3：比例尺、坐标系与散点图（1 天）
**面试可答**：比例尺将数据域映射到视觉域，如 `scaleLinear` 将数值映射为像素。

- `d3.scaleLinear()` 线性比例尺
- `d3.scaleBand()` 序数比例尺（柱状图）
- `d3.scaleOrdinal()` 颜色比例尺
- `d3.scaleTime()` 时间比例尺
- 坐标轴：`d3.axisBottom()`、`d3.axisLeft()`
- **练习**：用 scaleLinear + circle 实现散点图，附带坐标轴

---

### 模块 4：路径类图表（柱状图、折线图、饼图）（1.5 天）
**面试可答**：柱状图用 rect、折线图用 path、饼图用 arc。

- 柱状图：`rect` + `scaleBand`
- 折线图：`d3.line()` 生成路径
- 饼图：`d3.pie()` + `d3.arc()`
- **练习**：实现三种基础图表

---

### 模块 5：过渡动画（1 天）
**面试可答**：D3 内置过渡系统，`transition()` 可对任何属性做动画。

- `selection.transition()` 基本用法
- `duration()`、`delay()`、`ease()` 缓动函数
- 属性动画：位置、大小、颜色、透明度
- 链式过渡
- **练习**：柱状图数据更新时带平滑动画

---

### 模块 6：交互事件（1 天）
**面试可答**：D3 用 `on()` 绑定事件，常用于 tooltip 和高亮效果。

- `selection.on('click', handler)`
- 常用事件：`mouseover`、`mouseout`、`click`、`mousemove`
- Tooltip 实现思路
- 高亮与选中效果
- **练习**：鼠标悬停显示数据详情

---

### 模块 7：高级图表与实战整合（2 天）
**面试可答**：力导向图用于关系网络、树图用于层级数据。

- 力导向图：`d3.forceSimulation()`
- 树图/层次结构：`d3.tree()`
- **完整项目**：见下方实践项目

> **注意**：D3 v7 已移除 `d3.event`，事件通过回调参数传递。看老教程时注意这一点。

## 🕹️ 实践项目：数据大屏

**功能清单**（覆盖全部核心 API）：
- 柱状图：产品销量排名（带动画）
- 折线图：月度趋势（带 tooltip）
- 饼图：市场占比分布
- 散点图：用户分布（带缩放）

```
  LineChart.js   // 折线图模块
  PieChart.js    // 饼图模块
  ScatterChart.js // 散点图模块
  utils.js       // 比例尺、格式化工具
```

**制作时间**：3 天（每天 1-2 小时）

## 🆚 D3 vs ECharts 面试对比

| 维度 | D3 | ECharts |
|------|-----|---------|
| 定位 | 底层可视化工具库 | 高层开箱即用图表库 |
| 学习曲线 | 陡峭 | 平缓 |
| 定制能力 | 极高 | 中等 |
| 适用场景 | 高度定制、复杂交互 | 常规业务图表 |
| 渲染方式 | SVG/Canvas/HTML | Canvas/SVG |
| 数据驱动 | 手动管理 DOM | 配置驱动 |
