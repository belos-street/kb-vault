## 2. packages 目录职责地图

`facebook/react` 是 monorepo，主线阅读只涉及 5 个包。**推荐阅读顺序 = 表格行序**：符号 → 调度器 → reconciler 主体 → 宿主绑定。

| 顺序 | 包                                                                                                     | 职责一句话                                                                       | 推荐入口（函数级）                                                                                                                                                                                                                                                                                                                                                                                               |
| ---- | ------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | [packages/shared](https://github.com/facebook/react/tree/main/packages/shared)                         | 跨包共享的极小公共件：符号表、对象池、字符串标记                                 | [ReactSymbols.js](https://github.com/facebook/react/blob/main/packages/shared/ReactSymbols.js)（element 的 transitional 符号在这里定义）                                                                                                                                                                                                                                                                         |
| 2    | [packages/scheduler](https://github.com/facebook/react/tree/main/packages/scheduler)                   | 独立的优先级任务队列 + 时间片调度器，与 React 无任何耦合                         | [forks/Scheduler.js](https://github.com/facebook/react/blob/main/packages/scheduler/src/forks/Scheduler.js) 的 `workLoop` 与 `shouldYieldToHost`；[SchedulerMinHeap.js](https://github.com/facebook/react/blob/main/packages/scheduler/src/SchedulerMinHeap.js)                                                                                                                                                  |
| 3    | [packages/react](https://github.com/facebook/react/tree/main/packages/react)                           | 公共 API 面：jsx/createElement/hooks 的「前端」，hooks 调用转发到当前 dispatcher | [jsx-runtime.js](https://github.com/facebook/react/blob/main/packages/react/jsx-runtime.js) → [ReactJSXElement.js](https://github.com/facebook/react/blob/main/packages/react/src/jsx/ReactJSXElement.js)；[ReactStartTransition.js](https://github.com/facebook/react/blob/main/packages/react/src/ReactStartTransition.js)                                                                                     |
| 4    | [packages/react-reconciler](https://github.com/facebook/react/tree/main/packages/react-reconciler)     | Fiber 核心：workLoop、diff、提交、hooks、lane，宿主无关                          | [ReactFiberWorkLoop.js](https://github.com/facebook/react/blob/main/packages/react-reconciler/src/ReactFiberWorkLoop.js)（`renderRootConcurrent` / `commitRootImpl`）起步，按 §3 映射表逐个文件深入                                                                                                                                                                                                              |
| 5    | [packages/react-dom-bindings](https://github.com/facebook/react/tree/main/packages/react-dom-bindings) | react-dom 的宿主实现：DOM 配置、事件委托、hydration                              | [ReactFiberConfigDOM.js](https://github.com/facebook/react/blob/main/packages/react-dom-bindings/src/client/ReactFiberConfigDOM.js)；[events/](https://github.com/facebook/react/tree/main/packages/react-dom-bindings/src/events) 目录（入口 `ReactDOMEventListener.js`）；`createRoot` 出口在 [ReactDOMClient.js](https://github.com/facebook/react/blob/main/packages/react-dom/src/client/ReactDOMClient.js) |

> 💡 阅读建议：`ReactFiberWorkLoop.js` 有数千行，别通读——先只读 `workLoopConcurrentByScheduler` / `performWorkOnRoot` / `commitRootImpl` 三个函数，它们分别对应 mini-react 里你已经写过的 `workLoopConcurrent` / `performConcurrentWorkOnRoot` / `commitRoot`。

## 5. 延伸方向（不在本系列展开）

每个方向一句话定位 + 一个官方入口，需要时再深入：

- **RSC（React Server Components）**：组件在服务端运行、产物是序列化的 UI 描述而非 HTML——把「虚拟 DOM 可序列化」推到极致：[Server Components](https://react.dev/reference/rsc/server-components)
- **SSR 与流式渲染**：`renderToPipeableStream` 按 Suspense 边界分块吐 HTML，服务端复用同一套组件树：[react-dom/server](https://react.dev/reference/react-dom/server)
- **选择性 Hydration**：流式 SSR 下浏览器「先到先 hydrate」，高优先级边界可打断低优先级 hydration——React 18 三大特性之一：[React 18 发布公告](https://react.dev/blog/2022/03/29/react-v18)
- **React DevTools 协议**：DevTools 与渲染器之间的通信桥，inspect/profiling 数据全从这里来：[packages/react-devtools](https://github.com/facebook/react/tree/main/packages/react-devtools)
