# 软件工程学习大纲（教材体系 + 工程实践）

> 前半部分对齐经典教材体系（Sommerville / Pressman），覆盖过程模型、需求工程、软件设计、测试、项目管理；后半部分面向工程实践，覆盖架构模式、DDD、CI/CD、重构、分布式系统。兼顾 Tech Lead 技术决策与跨角色协作（需求评审、项目管理）所需的知识体系。

## 🎯 学习目标

完成本模块学习后，你应该能够：

**教材体系（Part I）**
1. 理解主流过程模型（瀑布、增量、螺旋、敏捷）的适用场景与权衡
2. 掌握需求工程全流程：获取 → 分析 → 规格说明 → 验证 → 管理，能主导需求评审
3. 理解软件设计方法论：结构化设计 vs 面向对象设计，模块化/耦合/内聚原则
4. 建立系统化测试观：测试策略、用例设计方法、测试管理
5. 理解项目估算、进度规划、风险管理、质量保证的基本方法

**工程实践（Part II）**
6. 理解设计模式如何服务于架构决策，能在架构场景中组合运用模式（单个模式详见 [design-patterns/](../design-patterns/)）
7. 掌握分层架构、六边形架构、微服务拆分的权衡与适用场景；能设计 RESTful/GraphQL API
8. 理解 DDD 战术/战略设计，能在真实项目中划分限界上下文
9. 设计 CI/CD 流水线 + 可观测性体系（日志/指标/链路追踪），使用代码度量驱动重构决策
10. 理解分布式系统基础：CAP、一致性模型、缓存策略、限流、消息队列、幂等性设计
11. 理解 Web 安全工程基础：OWASP Top 10、认证/授权模式、输入验证
12. 能主导技术方案评审，输出架构决策记录（ADR）
