# 软件工程学习大纲（教材体系）

> 对齐经典教材体系（Sommerville / Pressman），覆盖过程模型、需求工程、软件设计、面向对象设计与 UML、测试、项目管理、软件质量保证与配置管理。其中需求工程与项目管理部分为 Tech Lead 跨角色协作（需求评审、与产品/PM 协作）提供直接支撑。

## 🎯 学习目标

完成本模块学习后，你应该能够：

1. 理解主流过程模型（瀑布、增量、螺旋、敏捷）的适用场景与权衡
2. 掌握需求工程全流程：获取 → 分析 → 规格说明 → 验证 → 管理，能主导需求评审
3. 理解软件设计方法论：结构化设计 vs 面向对象设计，模块化/耦合/内聚原则
4. 建立系统化测试观：测试策略、用例设计方法、测试管理
5. 理解项目估算、进度规划、风险管理、质量保证的基本方法
