# LC128 - Longest Consecutive Sequence

> [题目链接](https://leetcode.cn/problems/longest-consecutive-sequence/) | 分类：哈希 | 难度：中等

## 题目

给定未排序整数数组 `nums`，找出数字连续的最长序列的长度。要求时间复杂度 O(n)。

## 思路演进

### 解法一：排序（直觉）

排序后遍历，统计连续递增段长度。

- 时间 O(n log n)，空间 O(1)
- 问题：不满足题目 O(n) 要求

### 解法二：哈希集合 + 只从序列起点开始（最优）

将所有数放入 Set。对每个数 `num`，只有当 `num - 1` 不在 Set 中时（说明它是某段连续序列的起点），才开始向后计数 `num+1, num+2, ...`。

- 时间 O(n)，空间 O(n)
- 核心优化：每个数最多被访问两次（一次判断起点，一次被计数），总体线性

## 技巧

- **只从起点开始**：`if (!set.has(num - 1))` 是关键剪枝，避免重复计数
- 用 Set 而非 Map：只需判断存在性，不需要存额外信息
- 通用模式：「哈希表实现 O(1) 查找 + 条件过滤避免重复工作」

## 复杂度对比

| 方法 | 时间 | 空间 | 适用场景 |
|------|------|------|---------|
| 排序 | O(n log n) | O(1) | 不要求 O(n) 时最简单 |
| **哈希集合（采用）** | O(n) | O(n) | 面试首选，满足题目要求 |

## 面试口述

> 排序是 O(n log n)，不满足要求。用 HashSet 存所有数，
> 关键优化：只对"序列起点"（即 num-1 不存在的数）向后延伸计数，
> 每个数最多被访问两次，总体 O(n)。

## 易错点

- 必须先判断 `num - 1` 是否存在再开始计数，否则退化为 O(n²)
- 重复元素：Set 自动去重，无需额外处理
- 空数组返回 0，单元素返回 1
