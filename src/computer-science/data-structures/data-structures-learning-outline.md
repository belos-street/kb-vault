## 📖 各章知识点细化

### 第 1 章：绪论

- 数据结构三要素：
  - 逻辑结构：集合、线性、树形、图状
  - 存储结构：顺序、链式、索引、散列
  - 数据的运算
- 算法的基本概念与特征（有穷性、确定性、可行性、输入、输出）
- **时间复杂度**：
  - 大 O 表示法
  - 常见阶： $O(1) < O(\log n) < O(n) < O(n \log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)$
  - 最好/最坏/平均复杂度
- **空间复杂度**：原地工作 $O(1)$、递归栈空间

### 第 2 章：线性表

- 线性表的定义与基本操作（InitList、Length、LocateElem、GetElem、ListInsert、ListDelete）
- 顺序表：
  - 随机访问 $O(1)$
  - 插入/删除平均移动 $n/2$ 个元素
  - 动态分配（静态数组 vs 动态数组）
- 链表：
  - 单链表（带头/不带头结点）
  - 双链表
  - 循环链表（单向循环、双向循环）
  - 静态链表
- **408 算法题高频**：
  - 链表逆置
  - 合并两个有序链表
  - 删除倒数第 k 个结点（快慢指针）
  - 找中间结点

### 第 3 章：栈和队列

- 栈：
  - LIFO 特性
  - 顺序栈、链栈
  - 共享栈（双端栈）
  - 应用：括号匹配、表达式求值（中缀 → 后缀）、递归消除、函数调用栈
- 队列：
  - FIFO 特性
  - 顺序队列（假溢出问题）
  - **循环队列**：队满/队空判断（牺牲一个单元 vs 设 size 变量 vs 设 tag 标志）
  - 链队列
  - 双端队列
- 栈和队列的应用：
  - 表达式求值（后缀表达式计算）
  - 层序遍历（队列）
  - 括号匹配（栈）

### 第 4 章：串

- 串的定义与存储（定长、堆分配、块链）
- 模式匹配：
  - 朴素匹配（BF）： $O(mn)$
  - **KMP 算法**：
    - next 数组的含义与构造
    - nextval 数组（优化）
    - 匹配过程模拟
    - 时间复杂度 $O(m+n)$

### 第 5 章：树与二叉树

- 树的基本概念（度、深度、层次、双亲、孩子、兄弟）
- 二叉树：
  - 性质（叶子与度 2 结点关系、第 i 层最多结点数、深度为 k 的最多结点数）
  - 特殊二叉树：满二叉树、完全二叉树、BST、AVL
  - 存储：顺序存储、链式存储（二叉链表、三叉链表）
- **遍历**：
  - 先序、中序、后序（递归 + 非递归）
  - 层序遍历（队列辅助）
  - 由遍历序列构造二叉树（中序 + 先序/后序/层序）
- 线索二叉树：
  - 线索化过程
  - 线索二叉树的遍历
- 树、森林与二叉树的转换
- 树的应用：
  - **哈夫曼树**（最优二叉树）：构造过程、WPL 计算
  - **哈夫曼编码**：前缀编码、编码长度计算
  - 并查集（Union-Find）

### 第 6 章：图

- 图的基本概念：
  - 有向/无向、完全图、连通图、强连通图
  - 度（入度/出度）、边数与度的关系
  - 稀疏图 vs 稠密图
- 图的存储：
  - 邻接矩阵（适合稠密图）
  - 邻接表（适合稀疏图）
  - 十字链表（有向图）、邻接多重表（无向图）
- **图的遍历**：
  - BFS（广度优先）：队列 + 访问标记
  - DFS（深度优先）：递归/栈 + 访问标记
  - 遍历序列的应用（连通分量、生成树）
- 图的应用：
  - **最小生成树**：Prim（适合稠密）、Kruskal（适合稀疏）
  - **最短路径**：Dijkstra（单源、非负权）、Floyd（多源）
  - **拓扑排序**：AOV 网、检测环
  - **关键路径**：AOE 网、最早/最晚发生时间、关键活动
- 408 综合题高频：给定图，写出遍历序列、求 MST、求最短路径

### 第 7 章：查找

- 顺序查找与折半查找：
  - 折半查找判定树、ASL 计算
- 树型查找：
  - **二叉排序树（BST）**：插入、删除、查找
  - **平衡二叉树（AVL）**：LL、RR、LR、RL 四种旋转
  - **B 树（B-Tree）**：m 阶 B 树性质、插入分裂、删除合并
  - B+ 树（了解，与数据库索引关联）
- 散列表（哈希表）：
  - 哈希函数构造（除留余数法）
  - 冲突处理：开放定址法（线性探测、二次探测）、链地址法
  - 查找成功/不成功的 ASL 计算
  - 装填因子与查找效率

### 第 8 章：排序

- 插入排序：
  - 直接插入： $O(n^2)$，稳定
  - 折半插入： $O(n^2)$，稳定
  - 希尔排序： $O(n^{1.3})$，不稳定
- 交换排序：
  - 冒泡排序： $O(n^2)$，稳定
  - **快速排序**：平均 $O(n \log n)$，最坏 $O(n^2)$，不稳定
- 选择排序：
  - 简单选择： $O(n^2)$，不稳定
  - **堆排序**： $O(n \log n)$，不稳定（大根堆/小根堆、建堆、调整）
- 归并排序： $O(n \log n)$，稳定，空间 $O(n)$
- 基数排序： $O(d(n+r))$，稳定
- **外部排序**：
  - 多路归并
  - 败者树
  - 置换-选择排序（生成初始归并段）
  - 最佳归并树（哈夫曼思想）
- **排序算法综合比较**（408 必考）：
  - 时间复杂度（最好/平均/最坏）
  - 空间复杂度
  - 稳定性
  - 适用场景

## ❓ 408 高频真题考点

1. **链表操作**：逆置、合并、删除特定结点（算法设计题常客）
2. **由遍历序列确定二叉树**：中序 + 先序/后序 → 唯一确定
3. **哈夫曼树与编码**：构造过程、WPL、编码唯一性
4. **图的遍历序列**：给定邻接表，写出 DFS/BFS 序列
5. **最短路径/MST**：Dijkstra 每步选择、Prim/Kruskal 过程
6. **AVL 树插入调整**：判断旋转类型并画出调整后结果
7. **B 树插入/删除**：分裂与合并过程
8. **排序算法比较**：给定场景选最优排序、判断稳定性
9. **外部排序**：归并趟数计算、最佳归并树

## 📝 学习建议

1. **数据结构是 408 分值最高的科目**（45 分），必须重点投入
2. **算法设计题是拉分关键**：第 41 题每年必考 13 分（设计思想 4 分 + 代码 7 分 + 复杂度 2 分），通常基于线性表（含数组）或树，要求手写 C 或 C++ 代码（官方题干两种均认可）
3. **排序和树是选择题重灾区**：排序算法比较表必须烂熟于心
4. **图的部分重理解**：不需要背代码，但要能手算 Dijkstra/Prim/Kruskal 的每一步
5. **KMP 是难点但分值低**：理解 next 数组含义即可，不必过度纠结
6. **外部排序近年考频增加**：败者树、置换-选择、最佳归并树要掌握
7. **多画多写**：数据结构靠画图理解，算法靠手写记忆，不能只看不练
