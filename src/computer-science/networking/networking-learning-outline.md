## 🎯 学习目标

完成本模块学习后，你应该能够：

1. 描述 TCP/IP 五层模型各层的功能与协议
2. 能计算时延、带宽-时延积、信道利用率等关键性能指标
3. 掌握数据链路层的帧封装、差错控制、介质访问控制（CSMA/CD）
4. 理解网络层 IP 编址、子网划分、路由算法
5. 掌握 TCP 连接管理（三次握手/四次挥手）、可靠传输、拥塞控制
6. 理解应用层协议（DNS、HTTP、FTP、SMTP）的工作机制
7. 能分析给定场景下的报文交互过程（含报文首部字段分析）

## 📖 各章知识点细化

### 第 1 章：计算机网络体系结构

- 计算机网络的概念、组成、功能
- 分类：LAN、MAN、WAN；按拓扑分类
- **主要性能指标**（408 选择题高频，2025 年综合题考过时延计算）：
  - 速率（带宽）与吞吐量
  - 四种时延：发送时延、传播时延、处理时延、排队时延
  - 带宽-时延积 = 传播时延 × 信道带宽
  - RTT（往返时间）、丢包率
  - 信道利用率（与停-等/GBN 效率联动，见第 3 章）
- 分层模型：
  - OSI 七层 vs TCP/IP 五层（重点掌握五层）
  - 各层功能：应用层 → 传输层 → 网络层 → 数据链路层 → 物理层
- 协议三要素：语法、语义、同步
- 接口与服务：SAP、PDU（协议数据单元）
- 封装与解封装过程

### 第 2 章：物理层

- 通信基础：
  - 数据通信模型（源 → 发送器 → 信道 → 接收器 → 目的）
  - 基本概念：信道、信号、带宽、码元、波特、速率
  - 奈奎斯特定理：极限数据传输速率 = $2W \log_2 V$
  - 香农定理：极限信息传输速率 = $W \log_2(1 + S/N)$
  - 电路交换、报文交换与分组交换的对比（时延、利用率、适用场景）
  - 数据报与虚电路（无连接 vs 面向连接的网络服务）
- 编码与调制：
  - 数字数据 → 数字信号：NRZ、曼彻斯特编码、差分曼彻斯特
  - 数字数据 → 模拟信号：ASK、FSK、PSK、QAM
- 传输介质：双绞线、同轴电缆、光纤、无线
- 物理层接口特性：机械特性、电气特性、功能特性、过程特性
- 物理层设备：中继器、集线器（Hub）

### 第 3 章：数据链路层

- 封装成帧与透明传输：
  - 字符计数法、字符填充、零比特填充
- 差错控制：
  - 检错编码：奇偶校验、CRC 循环冗余校验
  - 纠错编码：海明码
- 流量控制与可靠传输：
  - 停-等协议
  - 后退 N 帧（GBN）
  - 选择重传（SR）
  - 滑动窗口机制
- 介质访问控制（MAC）：
  - 静态划分信道：FDMA、TDMA、WDM（波分）、CDMA
  - 随机访问：ALOHA（纯/时隙）、CSMA（1-坚持/非坚持/p-坚持）
  - **CSMA/CD**（以太网核心）：争用期、最小帧长、最大传输距离
  - CSMA/CA（无线局域网）：RTS/CTS、NAV
  - 轮询访问：令牌传递协议
- 局域网：
  - 以太网帧格式（IEEE 802.3）：最小帧长 64B、前导码不计入帧长
  - MAC 地址（48 位）
  - IEEE 802.11 无线局域网：MAC 帧（三个地址字段）、基础结构模式与自组织模式（2022 综合题考过帧地址）
  - 交换机工作原理（自学习、转发、过滤）
  - VLAN（虚拟局域网）
- PPP 协议：帧格式、链路建立过程
- 数据链路层设备：网桥、交换机

### 第 4 章：网络层

- 网络层功能：异构网络互连、路由选择、分组转发、拥塞控制
- SDN 基本概念（控制面与数据面分离，了解即可）
- IPv4：
  - IP 数据报格式（版本、首部长度、TTL、协议字段）
  - **IPv4 分片与重组**：MTU、标识字段、片偏移、MF/DF 标志
  - **IP 地址分类**：A/B/C/D/E 类
  - **子网划分与 CIDR**：子网掩码、前缀长度、超网
  - 特殊地址：网络地址、广播地址、环回地址、私有地址
  - NAT（网络地址转换）
- IPv6：
  - IPv6 主要特点、128 位地址、表示法
  - IPv4 → IPv6 过渡：双栈、隧道
- 移动 IP：
  - 概念：归属地址、转交地址、归属代理、外地代理
  - 通信过程：间接路由与三角路由（隧道技术）
- 路由算法与协议：
  - 静态路由 vs 动态路由
  - RIP（距离向量算法、跳数、最大 15 跳）
  - OSPF（链路状态算法、Dijkstra、区域划分）
  - BGP（路径向量、AS 间路由）
  - 层次路由：自治系统 AS、域内路由与域间路由
- 路由器：
  - 路由表与转发过程
  - 最长前缀匹配
- ICMP：
  - 差错报告（目的不可达、超时、重定向）
  - 询问报文（ping、traceroute）
- ARP：IP → MAC 地址解析
- DHCP：动态主机配置（DORA 四步）
- IP 组播：组播概念、D 类组播地址（224.0.0.0/4）、IGMP 组播管理

### 第 5 章：传输层

- 传输层功能：进程间通信、复用与分用
- UDP：
  - 无连接、不可靠、面向报文
  - UDP 首部格式（源端口、目的端口、长度、校验和）
  - 适用场景：DNS、视频流、实时通信
- TCP：
  - 面向连接、可靠传输、面向字节流
  - TCP 报文段格式（序号、确认号、窗口、标志位）
  - **连接管理**：
    - 三次握手（SYN → SYN+ACK → ACK）
    - 四次挥手（FIN → ACK → FIN → ACK）
    - TIME_WAIT（2MSL）的作用
  - **可靠传输机制**：
    - 序号与确认
    - 超时重传
    - 快速重传（3 个重复 ACK）
    - 流量控制（滑动窗口）
  - **拥塞控制**：
    - 慢开始（cwnd 指数增长）
    - 拥塞避免（cwnd 线性增长）
    - 快恢复（ssthresh 减半，cwnd = ssthresh）
    - 拥塞窗口 vs 发送窗口（发送窗口 = min(rwnd, cwnd)）
- 端口号：知名端口（0-1023）、注册端口、动态端口

### 第 6 章：应用层

- 网络应用模型：C/S、P2P、混合
- DNS（域名系统）：
  - 域名层次结构（根 → 顶级域 → 二级域）
  - 解析流程：递归查询 + 迭代查询
  - DNS 报文格式
  - DNS 使用 UDP（查询）和 TCP（区域传送）
- WWW：
  - WWW 的概念与组成结构（URL、页面、超链接）
  - HTTP（超文本传输协议）：
    - HTTP/1.0 vs HTTP/1.1（持久连接、管道化）
    - 请求方法：GET、POST、PUT、DELETE、HEAD
    - 状态码：1xx/2xx/3xx/4xx/5xx
    - Cookie 与 Session
    - HTTPS = HTTP + TLS/SSL
- FTP（文件传输协议）：
  - 控制连接（21 端口）+ 数据连接（20 端口）
  - 主动模式 vs 被动模式
- 电子邮件：
  - 电子邮件系统组成结构（用户代理、邮件服务器、协议）
  - 电子邮件格式与 MIME（支持二进制与非 ASCII 内容）
  - SMTP（发送，25 端口）
  - POP3（接收，110 端口）/ IMAP（143 端口）
- DHCP 应用层视角（与第 4 章呼应）

## 📐 高频计算题型

| 题型 | 涉及章节 | 关键公式/方法 |
|------|---------|--------------|
| 时延计算 | 第 1 章 | 总时延 = 发送时延 + 传播时延 + 处理时延 + 排队时延；带宽-时延积 = 传播时延 × 带宽 |
| 信道容量计算 | 第 2 章 | 奈奎斯特： $C = 2W \log_2 V$；香农： $C = W \log_2(1+S/N)$ |
| CRC 校验计算 | 第 3 章 | 模 2 除法，生成多项式 |
| 最小帧长计算 | 第 3 章 | 最小帧长 = 2 × 传播时延 × 数据传输速率 |
| 信道利用率 | 第 3 章 | 停-等： $U = \frac{T_{send}}{T_{send} + RTT + T_{ack}}$；GBN/SR 与发送窗口相关 |
| 子网划分 | 第 4 章 | 借主机位做子网位、计算可用主机数 |
| 路由表匹配 | 第 4 章 | 最长前缀匹配 |
| TCP 拥塞窗口 | 第 5 章 | 慢开始/拥塞避免/快恢复的 cwnd 变化 |

## ❓ 408 高频真题考点

1. **子网划分与 CIDR**：给定 IP 和掩码，判断网络地址、广播地址、可用主机数
2. **路由聚合**：多个子网聚合为超网
3. **TCP 三次握手/四次挥手**：各标志位状态、为什么不能两次握手
4. **TCP 拥塞控制**：给定事件序列，画出 cwnd 变化图
5. **CSMA/CD**：最小帧长、争用期计算
6. **HTTP 与 DNS**：URL 解析全过程（DNS → TCP → HTTP）
7. **ARP 工作过程**：ARP 请求/应答的广播与单播
8. **滑动窗口**：GBN 与 SR 的窗口大小限制
9. **IP 分片**：给定分片参数，计算片偏移、MF/DF、各片长度（2018 综合题）
10. **NAT 地址转换**：私有地址与公网地址转换、分组转换过程追踪（2019/2020 综合题）
11. **报文首部字段分析**：给定报文，识别 TTL、协议字段、端口号等（2011/2012 综合题）

## 📝 学习建议

1. **网络层和传输层是核心**：占 408 网络分值约 60%，子网划分和 TCP 机制几乎每年必考
2. **协议要画图**：三次握手、四次挥手、DNS 解析流程，画出来比背文字有效 10 倍
3. **子网划分靠练**：这是纯计算题，做 10 道真题就能熟练
4. **拥塞控制要理解状态机**：慢开始 → 拥塞避免 → 快恢复，记住触发条件和 cwnd 变化规则
5. **应用层偏记忆**：端口号、协议特点记住即可，不需要深入实现细节
6. **与实操结合**：学完理论后用 `wireshark` 抓包看真实报文，理解会更深
