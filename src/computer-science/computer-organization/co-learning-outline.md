## 📖 各章知识点细化

### 第 1 章：计算机系统概述

- 计算机发展历程（电子管 → 晶体管 → 集成电路 → 超大规模）
- 冯·诺依曼体系结构：
  - 五大部件：运算器、控制器、存储器、输入、输出
  - 存储程序、按地址访问、顺序执行
- 计算机硬件组成：
  - CPU = 运算器 + 控制器
  - 主存 = MAR + MDR + 存储体
  - 数据通路：单总线/多总线/专用通路
- 计算机软件：系统软件、应用软件
- **性能指标**（408 必考）：
  - 主频、时钟周期
  - CPI（每条指令平均时钟周期数）
  - MIPS、MFLOPS
  - 执行时间 = 指令数 × CPI × 时钟周期
  - CPU 时间 vs 用户时间 vs 系统时间
- 摩尔定律与 Amdahl 定律

### 第 2 章：数据的表示和运算

- 进位计数制与转换（二、八、十、十六）
- 定点数表示：
  - 原码、反码、补码、移码
  - 表示范围（n 位补码： $-2^{n-1}$ ~ $2^{n-1}-1$ ）
  - 0 的表示（补码唯一）
- **定点数运算**：
  - 补码加减法： $[X+Y]_补 = [X]_补 + [Y]_补$
  - 溢出判断：双符号位法、进位判断法
  - 移位运算（算术移位、逻辑移位）
  - 乘法（Booth 补码一位乘）
  - 除法（恢复余数法、加减交替法）
- **浮点数表示（IEEE 754）**：
  - 单精度（32 位）：1 符号 + 8 阶码 + 23 尾数
  - 双精度（64 位）：1 符号 + 11 阶码 + 52 尾数
  - 阶码用移码（偏置值 127/1023）
  - 规格化、非规格化、特殊值（0、∞、NaN）
  - 浮点数加减运算（对阶 → 尾数运算 → 规格化 → 舍入）
- 数据的存储：
  - 大端（Big-Endian）vs 小端（Little-Endian）
  - int 与 float 的强制类型转换（精度丢失、溢出）
- 数据校验：
  - 奇偶校验
  - 海明码（检错纠错）
  - CRC 循环冗余校验

### 第 3 章：存储系统

- 存储器层次结构：寄存器 → Cache → 主存 → 辅存
- 主存储器：
  - SRAM vs DRAM（刷新机制）
  - 存储芯片容量计算
  - **主存扩展**：位扩展、字扩展、字位同时扩展
  - 存储芯片与 CPU 的连接（地址线、数据线、片选）
- **高速缓冲存储器（Cache）**：
  - 局部性原理
  - Cache 基本结构（Cache 行、标记、有效位）
  - **映射方式**：
    - 直接映射：主存块号 mod Cache 行数
    - 全相联映射：任意放置
    - 组相联映射：组间直接、组内全相联
  - **地址结构划分**（408 综合题高频）：标记 + 组号/行号 + 块内地址
  - 替换算法：随机、FIFO、LRU
  - 写策略：写直达（Write-Through）、写回（Write-Back）
  - **Cache 总容量计算**：(有效位 + 脏位 + 标记位 + 数据位) × 行数（408 综合题常考）
  - 命中率与平均访问时间计算
- 虚拟存储器：
  - 页式、段式、段页式（与 OS 呼应）
  - TLB（快表）：虚拟地址 → 物理地址的翻译缓存
  - 地址转换过程：虚拟地址 → TLB/页表 → 物理地址 → Cache/主存（缺页时访问磁盘）
  - 最坏访存次数分析（TLB 命中/缺失 × Cache 命中/缺失 × 是否缺页）
- 并行存储器：
  - 双端口 RAM
  - 多模块交叉编址（低位交叉、高位交叉）

### 第 4 章：指令系统

- 指令格式：
  - 操作码 + 地址码
  - 零地址、一地址、二地址、三地址指令
  - 操作码编码：定长、扩展操作码（Huffman 思想）
- **寻址方式**（408 选择题高频）：
  - 立即寻址
  - 直接寻址
  - 间接寻址（一次/多次间接）
  - 寄存器寻址
  - 寄存器间接寻址
  - 基址寻址（基址寄存器 + 偏移）
  - 变址寻址（变址寄存器 + 偏移）
  - 相对寻址（PC + 偏移）
- 指令类型：
  - 数据传送、算术逻辑、移位、转移、输入输出
- CISC vs RISC：
  - 指令数量、长度、寻址方式、流水线适配

### 第 5 章：中央处理器

- CPU 的功能与结构：
  - 运算器：ALU、累加器、状态寄存器
  - 控制器：PC、IR、MAR、MDR、CU
- 指令执行过程：
  - 取指 → 译码 → 执行 → 访存 → 写回
  - 各阶段数据流：取指（PC→MAR→M→MDR→IR，PC+1→PC）、间址、执行、中断
  - 指令周期、机器周期、时钟周期
- 数据通路：
  - 单总线结构、多总线结构、专用通路
  - 数据流动路径分析
- **指令流水线**（408 综合题高频）：
  - 流水线基本概念（段数、周期、吞吐率、加速比、效率）
  - 时空图绘制
  - 流水线性能计算：
    - 执行时间 = $(k + n - 1) \times \Delta t$ （k 段流水、n 条指令）
    - 加速比 = 顺序时间 / 流水时间
  - 流水线冒险：
    - 结构冒险（资源冲突）
    - 数据冒险（RAW/WAR/WAW）→ 转发/旁路、暂停
    - 控制冒险（分支）→ 延迟槽、分支预测
- 控制单元设计：
  - 硬布线控制器（组合逻辑）
  - 微程序控制器（微指令、微地址、微命令）
  - 水平型 vs 垂直型微指令

### 第 6 章：总线

- 总线概念与分类：
  - 片内总线、系统总线（数据/地址/控制）、通信总线
  - 总线带宽 = 总线宽度 × 总线频率
- 总线仲裁：
  - 集中式：链式查询、计数器定时、独立请求
  - 分布式
- 总线定时：
  - 同步定时（统一时钟）
  - 异步定时（握手协议：不互锁、半互锁、全互锁）
- 总线标准：PCI、USB（了解）

### 第 7 章：输入/输出系统

- I/O 系统概述：
  - I/O 接口（端口、地址编址：统一/独立）
  - I/O 控制方式演进
- **程序查询方式**：CPU 轮询，效率低
- **中断方式**：
  - 中断概念与分类（内中断/外中断）
  - 中断向量（中断服务程序入口地址）
  - 中断响应条件：中断允许触发器开、有中断请求、无更高中断优先级、当前指令执行完毕
  - 中断请求、判优、响应、处理、返回
  - 中断屏蔽字与优先级
  - 中断处理过程（保护现场 → 执行服务程序 → 恢复现场 → 中断返回）
  - 多重中断（中断嵌套）
- **DMA 方式**：
  - DMA 控制器（DMAC）
  - 预处理 → 数据传输 → 后处理
  - 与 CPU 的交互：停止 CPU 访问、周期挪用、交替访问
  - DMA vs 中断（数据块传输 vs 字节传输）
- **通道方式**：
  - 通道 = 专用 I/O 处理器
  - 通道程序（通道命令字 CCW）
  - 通道类型：字节多路、数组多路、选择通道
- I/O 与 OS 的关联：系统调用 → 设备驱动 → 中断/DMA（与 operating-system 第 9 章呼应）

## 📐 高频计算题型

| 题型 | 涉及章节 | 关键公式/方法 |
|------|---------|--------------|
| 性能指标计算 | 第 1 章 | 执行时间 = 指令数 × CPI × 时钟周期；Amdahl 定律 |
| 补码运算与溢出 | 第 2 章 | 双符号位判断溢出 |
| IEEE 754 编解码 | 第 2 章 | 拆分为符号/阶码/尾数，计算真值 |
| 主存扩展与连接 | 第 3 章 | 芯片数 = (总字数/芯片字数) × (总位数/芯片位数) |
| Cache 地址划分 | 第 3 章 | 标记位数 = 主存地址位数 - 组号位数 - 块内地址位数 |
| Cache 命中率 | 第 3 章 | 平均访问时间 = h × tc + (1-h) × tm（或含访盘时间） |
| 扩展操作码 | 第 4 章 | 短操作码为长操作码留空间 |
| 流水线性能 | 第 5 章 | 执行时间 = (k+n-1) × Δt；加速比 = nk / (k+n-1) |
| 总线带宽 | 第 6 章 | 带宽 = 宽度(B) × 频率(Hz)，宽度以字节为单位（若按 bit 计需 ÷8，与第 6 章正文口径一致） |
| 中断/DMA 时间 | 第 7 章 | DMA 周期挪用对 CPU 的影响 |

## ❓ 408 高频真题考点

1. **IEEE 754**：给定十六进制编码，求真值；给定十进制数，求编码
2. **补码加减与溢出**：判断运算结果是否溢出
3. **Cache 地址划分**：给定主存容量、Cache 容量、块大小、组数，求各字段位数
4. **Cache 命中率与平均访问时间**：含 TLB 的多级存储访问时间计算
5. **主存与 CPU 连接**：画连线图（地址线、数据线、片选信号）
6. **寻址方式判断**：给定指令格式和操作数，判断有效地址
7. **流水线时空图**：给定指令序列，画时空图、计算执行时间和加速比
8. **流水线冒险**：判断数据冒险位置，给出转发/暂停方案
9. **中断与 DMA**：中断响应条件、DMA 与 CPU 的工作方式比较

## 📝 学习建议

1. **数据表示和存储系统是核心**：占 408 计组分值约 50%，IEEE 754 和 Cache 几乎每年必考
2. **计算题是得分重点**：补码运算、Cache 地址划分、流水线性能计算都是固定套路，练熟即可
3. **流水线要会画时空图**：这是综合题的标配，画出图后计算就是数格子
4. **寻址方式靠对比记忆**：列表比较各寻址方式的有效地址计算方法
5. **I/O 部分偏理解**：中断/DMA/通道的区别是选择题常客，记住各自特点和适用场景
6. **与 OS 联动学习**：虚拟存储、中断机制在计组和 OS 中都会考，一起学效率更高
7. **不要纠结电路细节**：408 考的是工作原理和定量分析，不需要设计具体电路
