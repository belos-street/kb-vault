# C 语言入门教程（408 数据结构备考向）

> 面向有 JS/TS/Go/Rust 经验的 408 考研备考者，用最短路径恢复 408 数据结构所需的 C 语法 —— 指针、结构体、动态内存，能手写算法设计题的标准答案风格代码。

---

## 🎯 学习目标

- 明确 408 算法设计题的官方要求："采用 C 或 C++ 语言描述算法，关键之处给出注释"
- 用已有语言经验快速恢复 C 基础：类型、控制流、函数、递归
- 掌握指针与数组 —— 读懂、写出 408 数据结构代码的入场券
- 掌握 struct + typedef + malloc/free，能写严蔚敏/王道风格的链表、树结点定义
- 能按三问格式（设计思想 → 带注释代码 → 复杂度分析）手写完整的 408 算法题

## 🤔 为什么选 C（而不是 C++/Python）

- 408 综合应用题算法题的官方题干固定为："根据设计思想，**采用 C 或 C++ 语言描述算法**，关键之处给出注释"（2019/2020/2025 等年份真题均如此）
- 配套教材严蔚敏《数据结构》（**C 语言版**）、王道考研辅导书、真题解析的代码风格全部是 C（struct + 指针 + malloc）
- Python/Java 等语言不被接受；伪代码存在扣分风险，C 是最稳的选择
- C++ 也可以，但没必要为考试额外学 C++ 特性；一个注意点：严蔚敏教材所谓"C 语言版"实际混用了 C++ 引用语法（形参 `&`），两种写法阅卷都认，纯 C 用二级指针替代，详见第 3 章

## 📝 学习建议

- **不要钻 C 的黑暗角落**（未定义行为大全、复杂声明解析、宏技巧）：408 只用 C 的核心子集，够用就走
- 数据结构模块的代码风格与本教程保持一致：typedef + 结构体指针 + malloc
- 第 2、3 章的练习建议全部手写一遍，再进入 [数据结构模块](../../computer-science/data-structures/data-structures-learning-outline.md) 第 2 章"线性表"
- 复习阶段以王道《数据结构》的代码为准，本教程负责让你在翻开王道前没有语法障碍

### 与其他语言的核心差异速查

| 概念 | C | TypeScript | Go | Rust |
|------|---|-----------|-----|------|
| 内存管理 | 手动 malloc/free | GC | GC | 所有权 + 借用 |
| null | `NULL`（宏，本质是 0） | `null` / `undefined` | `nil` | 无（`Option<T>`） |
| 字符串 | `char` 数组 + `\0` 终止符 | 不可变 string | 不可变 string | `&str` / `String` |
| 数组 | 定长、不带长度信息 | 可变长 Array | slice 带长度 | Vec 带长度 |
| 传参语义 | 一律传值（指针需显式） | 引用类型按共享 | 切片/map 共享 | 移动/借用规则 |
| 泛型 | 无（宏或 void* 模拟） | ✅ | ✅ 1.18+ | ✅ trait bound |
| 编译 | gcc/clang 编译为原生二进制 | 转译为 JS | 编译为二进制 | 编译为二进制 |
