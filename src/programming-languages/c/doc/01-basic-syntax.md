## 1.1 编译环境

macOS 自带 clang（`xcode-select --install` 后可用），408 备考写 C 只需要单文件编译：

```bash
clang hello.c -o hello && ./hello     # 或 gcc hello.c -o hello && ./hello
```

- 源文件后缀 `.c`，头文件后缀 `.h`
- 编译报错从上往下读，第一个错误通常才是根因
- VS Code 装 **C/C++** 扩展（微软官方，提供补全与调试）

## 1.2 程序结构

```c
#include <stdio.h>   // 预处理：引入标准输入输出库（printf 在里面）

int main() {         // 入口函数，返回 int（0 表示正常退出）
    printf("Hello, C!\n");
    return 0;
}
```

**三点注意**：
1. `#include` 是预处理指令，不是 import，只是把头文件内容文本式地复制进来
2. C 语句以 `;` 结尾，代码块用 `{}`（和 JS/Go 一致）
3. 注释：`//` 单行、`/* */` 多行。**408 算法题要求"关键之处给出注释"，写代码时就要养成注释习惯**

## 1.3 变量与基本类型

```c
int n = 10;              // 整数，最常用
char c = 'A';            // 字符，本质是 1 字节整数（ASCII 码 65）
float f = 3.14f;         // 单精度浮点（注意 f 后缀）
double d = 3.14;         // 双精度浮点，浮点字面量默认类型
```

| 类型 | 典型宽度 | 取值范围 | 408 用途 |
|------|---------|---------|---------|
| `char` | 1 字节 | $-128 \sim 127$ | 字符、ASCII、串一章的存储 |
| `short` | 2 字节 | $-32768 \sim 32767$ | 计组计算题常客（如 short 溢出） |
| `int` | 4 字节 | $-2^{31} \sim 2^{31}-1$ | 默认选择，算法题数据都用它 |
| `long long` | 8 字节 | $-2^{63} \sim 2^{63}-1$ | 防溢出场景（累加大数） |
| `float` / `double` | 4 / 8 字节 | IEEE 754 | 与计组浮点表示联考 |

**408 提示**：类型宽度是数据结构与计组的联考考点（如"32 位机上 int 占 4 字节"），上表要背。`sizeof(int)` 返回类型占用的字节数。

C 没有内置 `bool`（C99 需 `#include <stdbool.h>`），考试代码常用 `int` 的 0/1 代替，或直接用 `bool`（阅卷都认）。

## 1.4 常量与宏

```c
#define MAXSIZE 100      // 宏：预处理期文本替换，408 定义表容量的标准写法
const int N = 10;        // const 变量（只读）
```

408 数据结构代码里定义容量几乎都用 `#define MaxSize 100` 这一种风格，保持一致即可。

## 1.5 运算符：与 JS/Go 的差异点

```c
int a = 5 / 2;      // = 2，整数除法直接截断（不是 2.5！JS 里 5/2=2.5）
int b = -5 / 2;     // = -2，向零截断
int c = 5 % 2;      // = 1，取余；余数符号跟被除数走：-5 % 2 = -1
int d = 5 / 2.0;    // = 2.5，有 double 参与则为浮点除法
```

| 要点 | 说明 |
|------|------|
| `==` vs `=` | 判断相等用 `==`，`=` 是赋值（C 里 `if (x = 5)` 是合法赋值，考试别写） |
| 逻辑短路 | `&&` `\|\|` 与 JS 一致，短路特性会考 |
| `i++` / `++i` | 先用后加 / 先加后用；**考试代码不要写 `a[i++]++` 这种嵌套自增** |
| 优先级 | 只需记住：算术 > 关系 > 逻辑 > 赋值，拿不准就加括号 |

## 1.6 控制流

```c
// if —— 与 JS 一致
if (x > 0) { /* ... */ } else if (x < 0) { /* ... */ } else { /* ... */ }

// switch —— 注意 fall-through！不加 break 会穿透到下一个 case
switch (op) {
    case '+': printf("add"); break;
    case '-': printf("sub"); break;
    default:  printf("unknown");
}

// for / while / do-while —— 语法与 JS 一致
for (int i = 0; i < n; i++) { /* ... */ }   // C99 起 for 内可声明 i
while (p != NULL) { /* ... */ }             // 链表遍历的标准形态
do { /* ... */ } while (cond);              // 至少执行一次
```

`break` 跳出循环/switch，`continue` 跳过本次迭代 —— 与 JS 一致。

## 1.7 函数

```c
// 返回类型在前；建议先声明（原型）后定义
int add(int a, int b) {
    return a + b;
}

int main() {
    int s = add(3, 4);    // 7
    return 0;
}
```

| 特性 | C | 对比 |
|------|---|------|
| 参数传递 | **只有传值**（复制一份） | JS 对象是共享引用，C 想改外部变量必须用指针（第 2 章） |
| 默认参数 / 重载 | 都没有 | 所以 408 函数签名都是全参数显式写出 |
| 返回多个值 | 不支持 | 用指针参数带回结果（第 2 章） |

**作用域考点**：`static` 修饰的局部变量只初始化一次，函数退出后值保留（选择题考过）：

```c
void counter() {
    static int cnt = 0;   // 只在第一次调用时初始化
    cnt++;
    printf("%d\n", cnt);  // 依次输出 1, 2, 3...
}
```

## 1.8 递归（408 核心）

```c
// 两要素：终止条件 + 递推式
int fact(int n) {
    if (n == 0) return 1;      // 终止条件（缺了就是无限递归 → 栈溢出）
    return n * fact(n - 1);    // 递推式
}
```

**与数据结构第 1 章的联动**：递归的时间/空间复杂度分析是必考技能：

- `fact(n)`：调用 $n + 1$ 次，时间 $O(n)$；**递归深度 $n$，空间也是 $O(n)$**（递归调用栈）
- 朴素斐波那契 `fib(n) = fib(n-1) + fib(n-2)`：时间 $O(2^n)$（重复计算），是复杂度分析的经典例子
- 后续二叉树的所有递归遍历、归并排序的分治，都是这个模式

## 1.9 输入输出速查

```c
printf("%d\n", n);        // 整数
printf("%c\n", c);        // 字符
printf("%.2f\n", d);      // 浮点保留 2 位
printf("%s\n", s);        // 字符串（char 数组）

scanf("%d", &n);          // 注意 & —— 要传入变量的地址
scanf("%d%d", &a, &b);    // 一次读两个
```

为什么 `scanf` 要加 `&`？因为函数只能拿到参数的副本，想把读到的值写回 `n`，必须把 `n` 的地址传进去 —— 这就是第 2 章指针传参的雏形。

## 📝 练习

**1. 求和函数**（基础）
- 要求：写函数 `int sum(int n)` 返回 $1 + 2 + \cdots + n$，main 中调用并打印 `sum(100)`
- 提示：for 循环 + 累加器
- 预期效果：输出 5050

**2. 递归调用次数**（联动复杂度）
- 要求：手推 `fib(5)`（朴素斐波那契）一共发生多少次函数调用
- 提示：画递归树，每个结点是一次调用
- 预期效果：得出 15 次，并理解为什么是指数级

**3. static 行为判断**（选择题风格）
- 要求：写出 1.7 节 `counter()` 连续调用三次的输出
- 提示：static 变量不随函数结束销毁
- 预期效果：1 2 3

## 🎯 考点速查

- 类型宽度表（char 1 / short 2 / int 4 / long long 8 / float 4 / double 8），与计组联考
- 整数除法截断：`5/2 == 2`；`-5/2 == -2`（向零）
- `switch` 不加 `break` 会 fall-through
- `static` 局部变量只初始化一次
- 递归两要素（终止条件 + 递推式）；递归深度 = 空间复杂度
