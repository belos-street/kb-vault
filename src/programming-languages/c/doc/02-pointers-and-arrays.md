## 2.1 数组

```c
int a[5];                    // 未初始化，值是垃圾值（考试代码必须初始化）
int b[5] = {1, 2, 3};        // 部分初始化，其余自动补 0 → {1,2,3,0,0}
int c[] = {1, 2, 3};         // 编译器推导长度为 3
int m[3][4];                 // 二维数组：3 行 4 列
```

| 要点 | 说明 |
|------|------|
| 下标从 0 开始 | 与 JS 一致 |
| **不检查越界** | `a[100]` 不会报错，是未定义行为；考试代码自己管好边界 |
| 长度是编译期信息 | 运行期拿不到数组长度（没有 `.length`） |
| 二维数组行优先存储 | `m[i][j]` 的地址 = 首地址 + $(i \times 4 + j) \times$ 元素大小 —— 计组/DS 顺序存储的联考考点 |

## 2.2 数组作函数参数（408 签名为什么总带 n）

```c
// 这两种写法完全等价：数组参数退化为指针
int sum(int a[], int n) { /* ... */ }
int sum(int *a, int n) { /* ... */ }

// 函数内部拿不到数组长度，所以必须显式传 n
int total = 0;
for (int i = 0; i < n; i++) total += a[i];
```

**结论**：408 算法题凡是以数组为存储结构的函数，签名一定是 `f(int A[], int n)` 的形态 —— 不是习惯问题，是 C 语言机制决定的。

## 2.3 指针基础

```c
int x = 10;
int *p = &x;     // &x：取 x 的地址；p 是"指向 int 的指针"
*p = 20;         // *p：解引用，通过地址访问变量 → x 变成 20
```

| 概念 | 说明 |
|------|------|
| `&x` | 取地址：得到 x 在内存中的位置 |
| `*p` | 解引用：访问 p 所指地址里的值 |
| 指针大小 | 32 位机上任何指针都是 4 字节（计组考点） |
| `NULL` | 空指针，表示"不指向任何东西"；判空写 `if (p == NULL)` |

**指针类型的作用**：`int *p` 的类型告诉编译器 `*p` 按 int（4 字节）来读写，`p + 1` 按 4 字节步进。类型错了，步长和解引用就全错了。

## 2.4 指针与数组：一对双胞胎

```c
int a[5] = {1, 2, 3, 4, 5};
int *p = a;          // 数组名退化为指向首元素的指针（a == &a[0]）

a[2]  ⟺  *(a + 2)    // 下标访问的本质就是指针算术
p[2]  ⟺  *(p + 2)    // 指针也可以用下标
p++;                 // p 前进一个元素（不是 1 字节！按 int 步进 4 字节）
```

**双指针模板**（数据结构[第 2 章（线性表）](../../../computer-science/data-structures/doc/02-linear-list.md)快慢指针的雏形）：

```c
// 找数组最大值：p 遍历，max 记录
int find_max(int a[], int n) {
    int *max = a;              // max 指向当前最大值所在元素
    for (int *p = a + 1; p < a + n; p++) {
        if (*p > *max) max = p;
    }
    return *max;
}
```

## 2.5 指针传参 = 引用传递（本章最重要）

C 只有传值，想修改调用方的变量，就把**它的地址**传进去：

```c
// ❌ 失败版：交换的是两份副本，main 里的 a、b 不变
void swap_wrong(int x, int y) {
    int t = x; x = y; y = t;
}

// ✅ 正确版：传入地址，通过解引用修改原变量
void swap(int *x, int *y) {
    int t = *x; *x = *y; *y = t;
}

int main() {
    int a = 3, b = 5;
    swap(&a, &b);     // 传地址
    printf("%d %d", a, b);   // 5 3
    return 0;
}
```

| 传参方式 | 写法 | 效果 | 类比 |
|---------|------|------|------|
| 传值 | `f(int x)` | 函数内改 x 不影响外面 | JS 传数字 |
| 指针传参 | `f(int *p)` + 调用 `f(&x)` | 函数内 `*p = ...` 修改原变量 | JS 传对象引用（但 C 要显式） |

## 2.6 二级指针与 C++ 引用（严蔚敏教材的秘密）

想修改**指针本身**（比如让头指针指向新结点），需要传指针的地址，即二级指针：

```c
void make_null(int **pp) {
    *pp = NULL;        // 修改外部的指针
}

int *p = &x;
make_null(&p);         // p 变成 NULL
```

严蔚敏教材里常见的 `void InitList(SqList &L)` 中的 `&L` 是 **C++ 引用**（不是 C！）。两种风格对照：

| 需求 | C++ 引用写法（教材/王道常见） | 纯 C 写法 |
|------|------------------------------|----------|
| 修改元素值 | `void f(int &x)` | `void f(int *x)` |
| 修改指针/表 | `void f(LNode *&L)` | `void f(LNode **L)` |

**考试两种都认**，本仓库数据结构代码统一用 C++ 引用风格（与王道一致），但你要知道纯 C 的等价写法。

## 2.7 字符串：char 数组 + '\0'

```c
char s1[] = "abc";     // 数组：{'a','b','c','\0'}，长度 4，内容可改
char *s2 = "abc";      // 指针指向字符串字面量，存于只读区

s1[0] = 'x';           // ✅ 合法
s2[0] = 'x';           // ❌ 未定义行为（常考陷阱：字面量不可改）
```

| 函数（`<string.h>`） | 作用 | 注意 |
|---------------------|------|------|
| `strlen(s)` | 求长度（不含 `\0`） | `sizeof(s1)` = 4，`strlen(s1)` = 3 |
| `strcpy(dst, src)` | 复制（含 `\0`） | dst 必须够长 |
| `strcmp(a, b)` | 比较 | 相等返回 0（不是 true！） |
| `strcat(dst, src)` | 拼接 | dst 必须够长 |

逐字符遍历模板（串一章 KMP 的基础）：

```c
for (int i = 0; s[i] != '\0'; i++) { /* 处理 s[i] */ }
```

## 🎯 考点速查

- 数组参数退化为指针 → 函数签名必带长度 `n`
- `a[i]` ⟺ `*(a+i)`；指针 `+1` 按元素大小步进
- 传值改不了外部变量；`f(&x)` + `*p = ...` 才可以
- 修改指针本身用二级指针（纯 C）或引用（C++）
- 字符串 = char 数组 + `'\0'`；`char *s = "abc"` 内容不可改
- 二维数组行优先：`m[i][j]` 地址 = 首地址 + $(i \times 列数 + j) \times$ 元素大小
