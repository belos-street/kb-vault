# 账号、登录与安全设置

## 支持的登录方式

支持手机号验证码、邮箱密码、企业微信扫码、飞书扫码与 SSO 单点登录（Team 及以上版本）。SSO 需管理员在「组织设置 → 身份认证」中配置。

## 忘记密码

在登录页点击「忘记密码」，通过绑定手机号或邮箱重置。若账号已开启仅扫码登录，请使用管理员在后台生成的应急登录链接。

## 两步验证

支持 TOTP 动态口令（Google Authenticator、1Password 等）。开启后每次新设备登录需输入 6 位动态码。恢复码只展示一次，请妥善保存。

## 异常登录处理

系统检测到异地或新设备登录时会要求二次验证，并向账号邮箱发送提醒。若非本人操作，请立即修改密码并在「安全中心 → 登录设备」中踢出其他设备。

## 账号注销

注销申请提交后有 30 天冷静期，期间可撤销。注销将删除全部笔记与附件，且不可恢复，请提前导出数据。
