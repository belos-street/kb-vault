# 发票开具与对公转账

## 发票类型

支持开具增值税普通发票（电子）与增值税专用发票（电子）。专票需先完成企业实名认证，并提供一般纳税人资格证明。

## 开票流程

在「账单中心 → 发票管理」选择订单，填写抬头、税号、邮箱后提交。普通发票 1 个工作日内开出；专用发票 3 个工作日内审核开出。

## 发票红冲与重开

发票开出后 90 天内可申请红冲重开，每月最多 2 次。跨月红冲需要财务人工审核。已用于报销的发票请先与本单位财务确认。

## 对公转账

企业客户可选择对公转账付款。提交订单后系统生成带唯一附言码的收款账户信息，转账附言必须填写该附言码，否则无法自动核销，需人工对账（1~3 个工作日）。

## 合同与报价单

年度合同客户可申请盖章版报价单与合同。请联系客户成功经理，或在控制台提交「商务咨询」工单。
