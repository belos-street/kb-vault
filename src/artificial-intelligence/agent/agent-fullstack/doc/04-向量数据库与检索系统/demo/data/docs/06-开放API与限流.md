# 开放 API 与限流规则

## 认证方式

开放 API 使用 Personal Access Token（PAT）认证，请求头为 `Authorization: Bearer <token>`。Token 在「设置 → 开发者 → 访问令牌」创建，创建时仅展示一次。

## 限流规则

按令牌维度限流：默认 600 请求/分钟、突发 60 请求/秒。响应头 `X-RateLimit-Remaining` 返回剩余额度，超限返回 429 并附带 `Retry-After`。

## 幂等性

写接口支持 `Idempotency-Key` 请求头，同一 key 在 24 小时内重复提交返回首次结果，不会重复创建资源。建议对创建笔记、上传附件等接口使用。

## Webhook

支持订阅笔记创建、更新、删除事件。Webhook 采用至少一次投递，接收方需按 `event_id` 去重。投递失败按指数退避重试 5 次，全部失败后进入死信队列。

## 版本策略

API 使用日期版本号（如 `2026-01-01`）。旧版本至少维护 12 个月，弃用前 90 天通过邮件与公告通知。
