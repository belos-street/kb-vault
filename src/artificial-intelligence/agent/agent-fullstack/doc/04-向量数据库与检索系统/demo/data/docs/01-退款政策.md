# 退款与取消订阅政策

## 适用范围

本政策适用于云雀 Pro、云雀 Team 两个付费版本的自助退款申请。企业版（Enterprise）合同客户按合同条款执行，不适用本政策。

## 七天无理由退款

首次购买任一付费版本后七天内，可申请全额退款，无需说明理由。同一账号或同一企业主体仅享受一次首购退款。

## 续费与升级订单

续费订单在扣款后 48 小时内可申请退款；升级产生的差价按未使用天数折算退回。已开具增值税专用发票的订单，需先完成发票红冲再退款。

## 退款到账时间

退款原路退回。微信、支付宝渠道 1~3 个工作日到账；对公转账渠道 5~10 个工作日到账。退款发起后可在「账单中心 → 退款记录」查看进度。

## 不可退款的情形

账号因违反服务条款被封禁、超出七天窗口期的续费订单、已消耗的加油包与短信包，以及通过非官方渠道购买的激活码，均不支持退款。
