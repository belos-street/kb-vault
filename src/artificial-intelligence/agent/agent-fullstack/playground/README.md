# AI Agent 练习场（Playground）

> 这不是 demo 合集，而是一套**可自动判分的练习册**。
> 每题一个目录：你实现一个东西，`bun test` 通过就算过关。

## 为什么单独做这个

- **demo 是「看懂了」，练习是「写出来」**。照抄 demo 只能建立眼熟，不能建立可提取的记忆。
- **离线可跑**：假模型 + 本地向量，零 Key、零费用、结果确定。
- **测试即规格**：验收标准写在测试里，不靠感觉。
- **不给参考答案**：只给三层提示，逼你自己把 API 取出来。

## 快速开始

```bash
cd playground
bun install
bun test
```

刚开始全部标红是正常的，因为 `src/index.ts` 里只有 `throw new Error('TODO')`。

## 做题规则

1. **先关文档**。只读题目的 API 签名和验收标准。
2. **先写注释再写代码**：把流程写成 5 行情景注释，再逐行翻译。
3. **不许改** `shared/` 和 `*.test.ts`；测试是契约，不是草稿。
4. **卡住先要提示**，不要直接搜实现。按顺序要：提示 1（方向）→ 提示 2（关键 API）→ 提示 3（伪代码）。
5. **通过不等于掌握**：第二天换个业务把同一结构重写一遍，才算过关。

## 目录说明

```
playground/
├── shared/                  # 只读基础设施
│   ├── scripted-model.ts    # 脚本化假模型：按剧本返回 tool_call / final
│   └── embed.ts             # 确定性本地向量（哈希词袋，非真实语义）
├── ch01-foundations/
│   ├── 00-attention/        # README + src/index.ts + index.test.ts
│   ├── 03-react-agent/
│   └── 05-mini-rag/
└── README.md
```

跨目录引用统一用 `@/...`（在 `tsconfig.json` 的 `paths` 里配置），例如 `@/shared/scripted-model`。

## 错误卡片

每次卡住，只记一行，不抄整段代码：

| 我想做什么       | 我当时写了什么                   | 正确写法                     | 为什么错                                |
| ---------------- | -------------------------------- | ---------------------------- | --------------------------------------- |
| 例：给节点加记忆 | `new MemorySaver()` 传给 addNode | `.compile({ checkpointer })` | checkpointer 是编译期选项，不是节点选项 |

复盘时只看这张表，比重读文档快得多。

## 复盘节奏

- **当天**：闭卷写完并通过测试。
- **第 2 天**：换一个业务场景，重写核心 30 行。
- **第 7 天**：从空文件重写，并用 90 秒讲清「为什么这样设计」。
- **每周**：手抄一次自己的 cheatsheet，只抄这周真正用过的签名。
