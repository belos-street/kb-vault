## 🧭 使用方法

1. **顺序**：学完一章 → 做该章文内练习 → 做本目录该章"基础" → 隔天做"强化" → "真题级"留到本章二刷时做；
2. **限时**：基础题 5-8 分钟/题，强化题 10-15 分钟/题，真题级解答题 15-25 分钟/题，综合卷整卷 60 分钟；
3. **纪律**：先判断题型、选定方法再动笔（对照各章决策流程图）；解答题写全步骤——数二大题按步骤给分；
4. **验算**：做完必验算（特征向量代回 $A\xi = \lambda\xi$ 、通解回代、 $Q^TAQ$ 抽查），把验算养成下意识动作；
5. **答案分离**：全部答案与解析统一放在各文件末尾，做题时不要往前翻。

### 难度分层标准

| 层级 | 定位 | 特征 |
|------|------|------|
| **基础**（B1-B4） | 巩固本章公式与标准流程 | 单知识点、数字友好、套流程可解 |
| **强化**（S1-S4） | 考场中档题 | 多性质综合、含参数讨论、需选对方法 |
| **真题级**（T1-T2） | 真题/真题改编难度 | 抽象证明、跨章综合、大题完整链路 |

### 题型标注

- **选择 / 填空**：数二线代的"一分钟题"，练速度与辨析；
- **解答**：练大题步骤规范，必须写全过程；
- **证明**：练抽象推理语言（作差转齐次、夹逼定秩、反证等）。
