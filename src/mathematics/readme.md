# 数学

> 面向软件开发者的数学笔记。不追求数学专业的理论严密性，而是聚焦**对编程、AI/ML、图形学、面试最有价值的数学分支**。

---

## 目录说明

| 目录 | 涵盖内容 | 对开发者的价值 |
|------|---------|---------------|
| **linear-algebra/** | 矩阵、向量、线性变换、特征值与特征向量、SVD、PCA | AI/ML/Agent embedding 基础、图形学变换矩阵、3D 渲染 |
| **calculus/** | 函数与极限、导数与微分、积分、微分方程、多元微积分、级数 | 梯度下降（反向传播核心）、优化理论、数值计算 |
| **probability-statistics/** | 概率论基础、分布、期望/方差、贝叶斯、假设检验、A/B 测试 | ML 评估指标、置信区间、数据分析、面试高频 |
| **discrete-mathematics/** | 图论、逻辑与证明、组合数学、数论基础 | 算法设计（图算法）、D3 力导向图、游戏碰撞检测、密码学 |

---

## 学习建议

1. **不需要从头到尾学完再编程**。用到哪查到哪，保持"学了就能用"的节奏
2. calculus 的梯度下降直接关联 AI/ML 的优化器；linear-algebra 的矩阵运算直接关联 embedding 和神经网络
3. 概率统计对 A/B 测试和分析工程师面试至关重要
4. 离散数学是算法设计的基础，尤其图论和组合数学
