## 2. 5 种路由器

| 路由器 | 导入 | 特点 |
|--------|------|------|
| RegExpRouter | `hono/router/reg-exp-router` | 最快：静态查表 + 单次正则 |
| SmartRouter | `hono/router/smart-router` | 默认调度器（RegExp + Trie） |
| TrieRouter | `hono/router/trie-router` | Trie 树，全模式兼容兜底 |
| LinearRouter | `hono/router/linear-router` | 注册 O(1)，适合每次冷启动重建 |
| PatternRouter | `hono/router/pattern-router` | 最小实现，体积优先 |

用法与原理见 [02-路由系统](./02-路由系统.md)；官方文档：[Routing](https://hono.dev/docs/api/routing)。
