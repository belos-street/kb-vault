# L03：动词分类

> 学完本讲你能：**从动词的四组分类维度直接推出英语的五大基本句型** —— 从此句型不是背出来的，是推出来的。

---

## 1. 为什么需要这个概念

很多人背句型靠硬记：「主谓宾、主谓双宾、主谓宾补……」背了就混，换个词就不会。其实句型根本不用背 —— **动词需要什么成分，句子就得给什么成分，句型是动词「逼」出来的**。

所以在 L01 的推导链里，动词是原点：先看懂动词属于哪一类，句型骨架自动浮出水面。

---

## 2. 核心概念与规则

### 2.1 动词的四组分类维度

分类不是四个并列清单，而是四个观察角度，各管一件事：

| 维度 | 分类 | 问的问题 | 用途 |
|------|------|---------|------|
| ① 按「宾语」 | 及物（transitive）/ 不及物（intransitive） | 动作要不要落在对象上？ | **推五大句型** |
| ② 按「动静」 | 动作动词（dynamic）/ 状态动词（stative） | 是做一件事，还是处于一种状态？ | 决定能不能用进行时 |
| ③ 按「完整度」 | 完全（complete）/ 不完全（incomplete） | 光有主谓，句子完不完整？ | 决定要不要补语 |
| ④ 按「句中角色」 | 谓语动词 / 非谓语动词 | 能不能独立当谓语？ | 长句拆解第一法则 |

### 2.2 维度①③联手：从动词分类推出五大句型（全合集招牌推导）

核心逻辑一条：

> **动词分及物 / 不及物 / 系动词三族，每族「索要」的成分不同，索要完就补齐 —— 于是句子自然长成五种骨架。**

| 动词类型 | 后面要什么 | 句型公式 | 例句 |
|---------|-----------|---------|------|
| 不及物动词 | 什么都不要 | 主 + 动 | `The rabbit sleeps.` |
| 单及物动词 | 一个宾语 | 主 + 动 + 宾 | `The rabbit likes carrots.` |
| 双及物动词 | 间宾 + 直宾 | 主 + 动 + 间宾 + 直宾 | `The wolf gave the rabbit a carrot.` |
| 复杂及物动词 | 宾语 + 宾补 | 主 + 动 + 宾 + 宾补 | `The rabbit considers the carrot delicious.` |
| 系动词 | 表语（主补） | 主 + 系 + 表 | `The carrot is in the room.` |

补两个判定公式：

- **不完全**：`The rabbit eats the carrot delicious.` ❌ —— eat 及物但「完全」，宾语后加补语就画蛇添足；consider 是「不完全及物」，少了 smart 句子不成立（`The rabbit considers you.` ≠ 原意）。
- **系动词属于「不完全不及物」**：它不需要宾语，但需要表语把主语「说完整」。

常见动词归位（判断句型先查这张表）：

| 类别 | 常见动词 | 备注 |
|------|---------|------|
| 不及物 | sleep / run / come / go / arrive / die | 后不接宾语 |
| 单及物 | eat / like / see / find / want | 后接一个宾语 |
| 双及物 | give / teach / send / tell / offer | 人 + 物两个宾语 |
| 复杂及物 | consider / make / find / call / keep | 宾语后必须有补语 |
| 系动词 | be / look / become / seem / feel | 后接表语 |

### 2.3 维度②：状态动词决定能不能用进行时

| 类别 | 常见动词 | 典型表现 |
|------|---------|---------|
| 动作动词 | eat / run / write / kill | 可用进行时：`The rabbit is eating.` |
| 状态动词 | like / know / have / seem / own | 一般不用进行时：`The rabbit likes carrots.` ✅ / `is liking` ❌ |

### 2.4 维度④：谓语 vs 非谓语

一个简单句只有一个谓语动词；多出来的动词要么进从句（L11），要么变非谓语（L06）：

`The rabbit eating a carrot sees the wolf.` —— 两个动词不能都当谓语，`eating` 退为非谓语（现在分词），`sees` 才是谓语。

## 3. 例句精讲：从动词推出五个句型

用兔子叙事把五型各演一遍：

1. **主 + 动**：`The rabbit runs.` —— run 不及物，不索要宾语，到 runs 就完整。
2. **主 + 动 + 宾**：`The rabbit eats a carrot.` —— eat 单及物，必须有一个「吃的东西」才完整。
3. **主 + 动 + 间宾 + 直宾**：`The wolf gives the rabbit a carrot.` —— give 双及物，两个宾语各司其职：the rabbit（给谁，间宾）、a carrot（给什么，直宾）。
4. **主 + 动 + 宾 + 宾补**：`The rabbit makes the wolf angry.` —— make 复杂及物，angry 不是修饰 make，而是补充说明 the wolf 的状态；去掉 angry，`The rabbit makes the wolf` 就残缺。
5. **主 + 系 + 表**：`The wolf looks hungry.` —— look 是系动词，hungry 描述主语 the wolf，不是「看起来地饿」。

一条龙验证推导链：`The wolf gave the rabbit a carrot that looked delicious.` —— 先找动词：gave（双及物 → 第 3 型）、looked（系动词 → 第 5 型，从句内部用）。**动词定句型，一步到位。**

同一批动词在不同句里换身份，句型跟着换：

| 句子 | 动词用法 | 句型 |
|------|---------|------|
| `The rabbit runs.` | run 不及物 | 第 1 型 |
| `The rabbit runs a carrot shop.` | run 单及物（经营） | 第 2 型 |
| `The carrot smells sweet.` | smell 系动词 | 第 5 型 |
| `The rabbit smells the carrot.` | smell 单及物（闻） | 第 2 型 |
| `The rabbit considers the wolf dangerous.` | consider 复杂及物 | 第 4 型 |

## 4. 常见坑

- ⚠️ **及物 / 不及物是「用法」不是「死身份」**：很多词两栖 —— `The rabbit runs fast.`（vi.）/ `The rabbit runs a store.`（vt.）。判别要看具体句子，不看单词表。
- ⚠️ **间宾和直宾别认错**：间宾 = 人（接收者），直宾 = 物（内容）。`give you a carrot` = `give a carrot to you`，能用 to/for 还原的双宾语结构才成立（详见 L23）。
- ⚠️ **宾补 ≠ 双宾语**：`consider you smart`（you 和 smart 是「你很聪明」的主谓关系）≠ `give you a carrot`（you 和 carrot 互不相干）。判别法：中间能不能加 be（you are smart ✅ → 宾补）。
- ⚠️ **状态动词用进行时**：`I am knowing the answer.` ❌；但少数状态动词转动作义时可以：`The rabbit is having a carrot.`（have = 吃，动作）✅。
- ⚠️ **系动词后接形容词不接副词**：`The rabbit looks hungry.` ✅ / `hungrily` ❌ —— 详见 L09。

---

## 5. 一句话总结

> 动词按宾语需求分及物 / 不及物 / 系动词三族，按完整度决定要不要补语 —— 两两组合，英语的五大句型就是这么「推」出来的，动词定句型。

## 6. 随堂练习

**B1（选择）**：`The rabbit painted the door green.` 属于哪个句型？
- A. 主 + 动
- B. 主 + 动 + 宾
- C. 主 + 动 + 间宾 + 直宾
- D. 主 + 动 + 宾 + 宾补

**B2（填空）**：判断句型 —— `The wolf howled all night.` 属于五大句型中的第 ____ 型（填数字）。

**B3（判断）**：指出句中 grow 的用法差异：`The carrot grows in the soil.` 与 `The rabbit grows sleepy.` —— 前者是 ____ 动词，后者是 ____ 动词。

**S1（改错）**：`The rabbit ate the carrot delicious.` 有语病，找出并改正（可改变谓语动词）。

**S2（翻译）**：把「狼留给兔子一根胡萝卜。」翻成英文。

---

## 7. 参考答案与解析

- **B1**：**D**。paint 是复杂及物动词，green 是补充说明 the door 的宾补（the door is green 成立，符合「加 be 测试」），故是主 + 动 + 宾 + 宾补。
- **B2**：**1**。howled 不及物、后面不要宾语也不用补语，主 + 动即完整。
- **B3**：前者是**不及物**（自「生长」义，后接介词短语，无宾语），后者是**系动词**（「变得」，sleepy 作表语说明主语）。
- **S1**：原句错在 eat 是完全及物动词，宾语后加补语画蛇添足 → 改为 `The rabbit found the carrot delicious.`（find 复杂及物，delicious 作宾补）。
- **S2**：`The wolf left the rabbit a carrot.`（或 `The wolf left a carrot for the rabbit.`）。leave 是双及物动词：the rabbit 是间宾（接收者），a carrot 是直宾（内容），能用 for 还原即双宾语成立。
