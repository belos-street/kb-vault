# L05：动词语气

> 学完本讲你能：**分清陈述 / 祈使 / 虚拟三种核心语气**，并拿下虚拟语气两大场景 —— 与事实相反的假设（if 从句时态退移）和愿望 / 请求 / 建议 / 命令后的特殊形式。

---

## 1. 为什么需要这个概念

时态说的是「动作何时发生」，语气说的是「**说话人对这句话的态度**」：是陈述事实、发号施令，还是说一件与事实不符的事。中文靠「如果、但愿、请」等虚词表达这些态度，英语则把态度直接刻进动词形式 —— 所以虚拟语气看起来「时态错乱」，其实每一处退移都有意义。

全合集做减法：语气只讲**陈述 / 祈使 / 虚拟**三种核心；疑问、条件、感叹语气属于句子分类层面的概念，略讲（详见 L23）。

---

## 2. 核心概念与规则

### 2.1 三种核心语气一览

| 语气 | 作用 | 动词形式 | 例 |
|------|------|---------|----|
| 陈述语气（indicative） | 描述现实 / 事实 | 正常时态 | `The rabbit eats a carrot.` |
| 祈使语气（imperative） | 命令 / 请求 / 建议 | 动词原形 | `Eat the carrot!` |
| 虚拟语气（subjunctive） | 与事实相反 / 愿望 / 要求 | 时态退移或原形 | `If the rabbit had a carrot, …` |

### 2.2 祈使语气：一个公式讲完

`祈使句 = 第二人称 + 一般现在时去掉 you + 动词原形`

| 还原 | 祈使 | 说明 |
|------|------|------|
| You eat the carrot. | `Eat the carrot!` | 肯定：原形开头 |
| You don't eat the carrot. | `Don't eat the carrot!` | 否定：Don't + 原形 |
| You come here. | `Come here, everybody!` | 对象常省，必要时补呼语 |

### 2.3 虚拟语气 A：与事实相反的假设（if 从句的时态退移）

核心规律一条：**假设得越远，动词退得越狠**。

| 假设对象 | if 从句 | 主句 | 例 |
|---------|--------|------|----|
| 与现在相反 | 一般过去时（be 用 were） | would / could / might + do | `If the rabbit were a wolf, it would eat meat.` |
| 与将来相反 | 一般过去时 / were to + do / should + do | would / could / might + do | `If the wolf should come, the rabbit would run.` |
| 与过去相反 | 过去完成时 had done | would / could / might + have done | `If the rabbit had eaten the carrot, it would not have been hungry.` |

两个记忆点：
- 退移方向：`现在 → 过去 → 过去完成`，主句的 would 系只是「标志」，不再表将来。
- 与现在相反时 be 统一用 `were`：`If I were you, …` 是固定写法。

省略 if 的倒装（书面语高频）：

| 原句 | 倒装（省 if） |
|------|--------------|
| `If the rabbit were a wolf, …` | `Were the rabbit a wolf, …` |
| `If the wolf should come, …` | `Should the wolf come, …` |
| `If the rabbit had eaten the carrot, …` | `Had the rabbit eaten the carrot, …` |

规律：were / should / had 提到主语前，if 消失，意思不变。

### 2.4 虚拟语气 B：愿望 / 请求 / 建议 / 命令

| 场景 | 结构 | 退移规则 | 例 |
|------|------|---------|----|
| wish 表愿望 | wish + 从句 | 与现在相反 → 过去时；与过去相反 → had done；将来愿望 → would + do | `The rabbit wishes it had a carrot.` / `wishes it had eaten one.` / `wishes the wolf would leave.` |
| would rather | would rather + 从句 | 同 wish 前两档 | `The rabbit would rather the wolf left.` |
| 建议 / 命令 / 要求 | demand / suggest / order / insist / require + that 从句 | `(should) + 动词原形` | `The wolf ordered that the rabbit (should) give up the carrot.` |

---

## 3. 例句精讲

> `If the wolf had not eaten the carrot, the rabbit would be full now.`

这是**错综时间条件句**：if 从句谈过去（had not eaten，与过去相反），主句谈现在（would be full now，与现在相反）—— 从句和主句各自按自己的时间退移，不必强求一致。

再串一遍三种语气：
1. 陈述：`The rabbit ate the carrot.` —— 客观陈述事实。
2. 祈使：`Eat the carrot!` = `You eat the carrot.` 去掉 you 的命令版。
3. 虚拟（现在相反）：`If the rabbit ate nothing, it would die.` —— ate 是退移形式，说话人默认「兔子其实有东西吃」。
4. 虚拟（过去相反）：`If the rabbit had eaten nothing, it would have died.` —— 幸好吃过了，所以没死。

B 类场景同样串一遍（愿望 / 命令）：
1. wish + 现在相反：`The rabbit wishes the wolf were far away.` —— 事实是狼就在眼前，所以退移成 were。
2. wish + 过去相反：`The rabbit wishes it had hidden the carrot.` —— 事实上当时没藏，已无法改变。
3. wish + 将来愿望：`The rabbit wishes the wolf would leave.` —— 希望将来会发生，用 would + do。
4. 命令 / 要求：`The wolf demanded that the rabbit (should) hand over the carrot.` —— that 从句用 (should) + 动词原形，should 可省。
5. would rather：`The rabbit would rather the wolf stayed away.` —— 从句退移成过去时，表示「宁愿对方不做」。

---

## 4. 常见坑

- ⚠️ **if 引导的不都是虚拟**：真实条件句用正常时态 —— `If the wolf comes tomorrow, the rabbit will run.`（真的可能来）；`If the wolf came tomorrow, the rabbit would run.`（认为狼来不了）。看说话人信不信，不看 if 本身。
- ⚠️ **主将从现的 if 不是虚拟**：条件 / 时间状语从句用一般现在时表将来（见 L04），那是真实假设，别见到 would 才叫虚拟。
- ⚠️ **虚拟里 would / could / might 的分工**：would 表「就会」、could 表「就能」、might 表「也许会」，可以互换但含义微调，别一律背成 would。
- ⚠️ **suggest 两个意思两套语法**：「建议」用 `(should) do`（虚拟）；「暗示」用正常时态 —— `The look on the wolf's face suggested that it was angry.` ✅。
- ⚠️ **wish 后不能接 will**：`The rabbit wishes the wolf will leave.` ❌ → `would leave.` ✅。
- ⚠️ **疑问 / 条件 / 感叹语气不必深挖**：它们是句子分类的视角（L23），没有额外的动词变形规则，别当成第四种「重要语气」去背。

---

## 5. 一句话总结

> 语气 = 说话人的态度：陈述讲事实、祈使用原形、虚拟玩退移 —— 越与事实相反，动词退得越狠；建议命令用 (should) + 原形。

## 6. 随堂练习

**B1（选择）**：如果我是兔子，我就不和狼说话。（选最符合「与现在事实相反」的一句）
- A. If I am a rabbit, I don't talk to the wolf.
- B. If I was a rabbit, I won't talk to the wolf.
- C. If I were a rabbit, I wouldn't talk to the wolf.
- D. If I were a rabbit, I won't talk to the wolf.

**B2（填空）**：`The rabbit wishes it ____ (find) the carrot yesterday.`（用所给词的正确形式填空）

**S1（改错）**：`If the wolf would come tomorrow, the rabbit would leave.` 有语病，找出并改正。

**S2（翻译）**：把「狼命令兔子交出胡萝卜。」翻成英文（用 demand 或 order，注意从句动词形式）。

---

## 7. 参考答案与解析

- **B1**：**C**。与现在事实相反：if 从句退移为一般过去时（be 统一用 were），主句用 would + 原形，三处形式必须配套。
- **B2**：**had found**。yesterday 表明愿望针对「当时没找到、已无法改变」的过去，wish + 与过去相反用过去完成时。
- **S1**：原句错在虚拟 if 从句不加 would → 改为 `If the wolf came tomorrow, the rabbit would leave.`（与将来可能性相反，从句用一般过去时，或用 should come / were to come）。
- **S2**：`The wolf demanded that the rabbit (should) give up the carrot.`。demand / order 属「建议命令」类，that 从句用 (should) + 动词原形，should 可省。
