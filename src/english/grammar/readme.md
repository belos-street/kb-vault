> 从零打造系统语法体系 —— 参考 B 站 UP 主「英语兔」《英语语法精讲合集》（BV1XY411J7aG）的课程设计，结合其公开视频内容重写的知识库版讲义。
> 学完本合集你能：**拥有一个「动词中心、推导式」的语法认知框架**，任何长句都能拆回简单句。

---

## 🎯 设计哲学（为什么这样编排）

1. **动词中心**：英语语法的核心是动词。全合集从动词出发，推出五大句型 → 句子成分 → 十大词性 → 句法专题，是一条**推导链**，不是并列的知识点清单。
2. **优先学「英语有、中文没有」的用法**：语序相同的部分（多数词性、简单句法）放后面速过；英语独有的东西（时态、语气、非谓语、从句）先讲透。
3. **语法为造句服务**：任何长句都能拆成最短的简单句；简单句 = 「什么 + 怎么样」= 主语 + 谓语。一切概念都落回「能造句、能拆句」。
4. **做减法**：语气只讲陈述 / 祈使 / 虚拟三种核心；疑问、条件、感叹语气略讲。低频考点（如 16 种时态里的罕见组合）点到为止。
5. **统一叙事语料**：贯穿 rabbit / carrot / wolf 的兔子吃胡萝卜叙事（致敬原课风格），降低概念切换成本。

## 📖 每讲结构模板

每讲 = 一个 md 文件，统一结构：

```markdown
# Lxx：<讲名>
> 一句话学习目标

## 1. 为什么需要这个概念
## 2. 核心概念与规则（表格 + 例句）
## 3. 例句精讲（兔子叙事贯穿）
## 4. 常见坑
## 5. 一句话总结
## 6. 随堂练习（3~5 题）
## 7. 参考答案与解析（文末分离）
```

- **例句风格**：以 rabbit / carrot / wolf 叙事为主，技术 / 日常语料为辅
- **规则表达**：能用表格不用长段落，能给公式不给散文（如 `4 时间 × 4 态 = 16 时态`）
- **随堂练习**：命题走 exam-item-toolkit 口径 —— B（基础）/ S（强化）/ T（真题级）分层，题型含选择（四选项 `A. / B. / C. / D.`）、填空、改错、翻译、拆句；**题目与答案分离**，答案与解析统一放文末；命题零重复（不照抄正文例句），设计即核验（≥2 条独立依据确认答案）

## 📚 延伸阅读（权威参考）

- *The Cambridge Grammar of the English Language*（CGEL, Huddleston & Pullum）—— 现代英语语法的权威参考巨著，术语口径与本合集「句子成分 ≠ 词类」「复杂句 / 并列句」体系同源
- *A Comprehensive Grammar of the English Language*（Quirk et al.）—— 规则密集型经典，适合查证时态、虚拟、主谓一致等规则细节
- *English Grammar in Use*（Raymond Murphy, Cambridge）—— 配套练习册首选，可与本合集各讲「随堂练习」互补

> 规则密集讲（L04 时态 / L14 名词复数 / L28 主谓一致等）的细则以上述参考书为深挖入口；本合集重体系与推导，查阅级细节交由工具书。
