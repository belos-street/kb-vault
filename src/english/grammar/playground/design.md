# 设计规范（design.md）· Trae 双主题

> 适用：语法学习平台（文本密集、读 + 练、PC + 移动端）
> 主题基调：**Trae 风格**——白绿（light）/ 黑绿（dark）双主题；布局沿用瑞士极简主义（Lexio design.md 同源语汇，去掉红色信号色改绿色系）。
> 本文档是 `src/styles.css` 的唯一设计依据，改样式先改这里。
> 色值为取色基准（Trae 品牌绿基调），T14 视觉走查时可微调，但**令牌结构不变**。

---

## 1. 为什么是「瑞士布局 × Trae 双主题」

- **字体即界面**：80% 的内容是讲义正文与例句，排版驱动设计与「读 + 判」场景契合
- **双主题**：长时间学习场景需要夜间模式；白绿 / 黑绿共用同一套结构，只换颜色令牌
- **零装饰**：无阴影、无渐变——学习工具要的是「内容说话」
- **绿色 = 唯一信号色**：正确 / 进度 / 主 CTA / 当前位置全部走绿系，中性色管层级

## 2. 设计令牌（Design Tokens）

### 2.1 颜色（CSS variables，双主题两套值）

| 令牌              | light（白绿） | dark（黑绿） | 用途                                         |
| ----------------- | ------------- | ------------ | -------------------------------------------- |
| `--c-bg`          | `#FFFFFF`     | `#0E1210`    | 画布（近黑绿，非纯黑）                       |
| `--c-fg`          | `#171C19`     | `#E6EDE9`    | 正文 / 结构边框                              |
| `--c-muted`       | `#F0F5F2`     | `#1A211D`    | 次级背景（当前句底、进度槽、verdict 底）     |
| `--c-line`        | `#D5E0DA`     | `#2A332E`    | 分隔线 / 弱边框                              |
| `--c-accent`      | `#00A870`     | `#2BE3A0`    | **唯一信号色**：正确、进度、主 CTA、当前位置 |
| `--c-accent-fg`   | `#FFFFFF`     | `#0E1210`    | accent 底上的文字                            |
| `--c-accent-soft` | `#DFF5EA`     | `#123527`    | accent 弱底（徽标、hover 底）                |
| `--c-warn`        | `#B45309`     | `#F59E0B`    | 错误判定 / 失效提示（仅此一处暖色）          |

> 语义映射：**正确 = 绿，错误 = 暖橙**。不引入红色/蓝色信号，保持「绿系 + 中性 + 单一暖色」。
> 主题切换：`html[data-theme='dark']` 覆盖令牌；跟随系统 `prefers-color-scheme` + 手动覆盖，选择存 localStorage。

### 2.2 字体

| 令牌 | 值                                                                                       |
| ---- | ---------------------------------------------------------------------------------------- |
| 家族 | `Inter` → 回退 `-apple-system, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif` |
| 标题 | 800，`letter-spacing: -0.02em`                                                           |
| 标签 | 700，`letter-spacing: 0.08em`（小号大写标签）                                            |
| 正文 | 400 / 500，正文区 16~18px，行高 2（段落式讲义）                                          |
| 例句 | 英文例句 500 + `JetBrains Mono` 回退等宽（中英视觉区分，英文不缩进）                     |

### 2.3 形状与结构

| 令牌 | 值                                                             |
| ---- | -------------------------------------------------------------- |
| 圆角 | `2px`（近直角，Trae 现代感微量圆角）                           |
| 边框 | `1px solid var(--c-line)` 常规；强调块 `2px solid var(--c-fg)` |
| 阴影 | **无**。深度来自层级与弱底色                                   |

### 2.4 动效

- `transition: background-color 150ms linear, color 150ms linear, border-color 150ms linear`
- 交互反馈 = 颜色变化（绿系互换），不用缩放弹性动画；`prefers-reduced-motion` 下关闭过渡

## 3. 组件规格

| Class                          | 规格                                                                   |
| ------------------------------ | ---------------------------------------------------------------------- |
| `.card`                        | bg 画布 + 1px line 边框，padding 20px（移动）/ 28px（桌面）            |
| `.btn`                         | 1px 边框矩形，hover 转 accent-soft 底；min-height 44px（触控）         |
| `.btn.primary`                 | accent 底 + accent-fg 字                                               |
| `.btn.ok` / `.btn.bad`         | 判定语义：ok = 绿系、bad = warn 暖色                                   |
| `input / textarea`             | 1px line 边框，focus 边框转 accent，无 glow；字号 ≥16px（防 iOS 缩放） |
| `.badge`                       | 进度徽标：accent-soft 底小标签（未开始 / x/y / ✓ 全对）                |
| `.lesson-item`                 | 讲条目块级左对齐，当前讲 accent 左边条（2px）                          |
| `.para`                        | 讲义自然段：`text-align: justify`，`text-indent: 2em`，行高 2          |
| `.example`                     | 英文例句块：弱底 + 左边条，英文不缩进；中文解说随段落                  |
| `.pitfall`                     | 常见坑条目：保留讲义原文 ⚠️（内容 emoji 原样渲染），弱底块             |
| `.verdict.ok` / `.verdict.bad` | 判定回显：绿框 ✓ / 暖框 ✗                                              |
| `.verdict.info`                | 参考答案 / 中性提示（muted 底）                                        |
| `.progress`                    | muted 槽 + accent 填充                                                 |
| `.theme-toggle`                | 页头日 / 月图标切换（lucide Sun / Moon）                               |

## 4. 页面结构

- 页头：`语法学习平台`（800 字重）+ 讲次副标题（muted 承载）+ 主题切换 + 返回目录
- 内容列：单列流式，`max-width: 860px` 居中
- 区块间距：卡片间 16px（移动）/ 24px（桌面）

## 5. 响应式断点（移动端优先）

| 断点           | 行为                                                     |
| -------------- | -------------------------------------------------------- |
| base（<768px） | 单列；按钮块级拉伸；正文 16px；卡片 padding 20px         |
| ≥768px         | 正文 17px；卡片 padding 28px；目录列表双列 metadata 对齐 |
| ≥1024px        | 正文 18px；卡片 padding 32px；hover 态全量启用           |

> 触控目标 ≥44×44px。

## 6. 可访问性

- 正文对比 ≥ 7:1（light: #171C19 on #FFFFFF；dark: #E6EDE9 on #0E1210）
- accent 绿仅用于 ≥15px 加粗、图标、色块与边框，不做小号正文色
- `:focus-visible` 2px accent 外框
- 语义标签保持：nav / section / ol / button；主题切换按钮带 `aria-label`

## 7. 内容与 UI 图标的边界

- UI 图标一律 lucide-react SVG（目录、切换、判定、主题），**UI 层禁 emoji**
- 讲义内容里的 ⚠️ 等表情**保留原样渲染**（内容数据，不替换不剥离）
