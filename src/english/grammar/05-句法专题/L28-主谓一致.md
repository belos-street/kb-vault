# L28：主谓一致

> 学完本讲你能：**在任何「主语长得奇怪」的句子里定准谓语的单复数** —— 三大原则定方向，陷阱表逐个拆。

---

## 1. 为什么需要这个概念

主谓一致（subject-verb agreement）只有一句话规则：**主语单数配单数谓语，主语复数配复数谓语**。但真实句子里主语常被修饰语拉长、被集体名词搅浑、被就近原则改写，单复数一眼看不准。写作里主谓不一致是最扎眼的低级错误之一，考试也专挖这块。

三大原则先定方向：

| 原则 | 判定依据 | 适用场景 |
|------|---------|---------|
| 语法一致 | 主语的**语法形式**（单复数） | 大多数情况 |
| 意义一致 | 主语的**实际含义**（整体还是成员） | 集体名词、the + 形容词 |
| 就近 / 就远 | 谓语只看**靠近（或远离）的那个名词** | there be、or 系列、with 系列 |

---

## 2. 核心概念与规则

### 2.1 语法一致（默认原则）

主语的语法形式定谓语：

| 主语 | 谓语 | 例 |
|------|------|----|
| 单数名词 | 单数 | The rabbit **eats** carrots. |
| 复数名词 | 复数 | The rabbits **eat** carrots. |
| 不可数名词 | 单数 | The water **is** clean. |

### 2.2 意义一致（看整体还是成员）

| 主语 | 看作整体 → 单数 | 看作成员 → 复数 |
|------|----------------|----------------|
| family / team / committee / class / crowd | The family **is** big.（一个家庭） | The family **are** having dinner.（家人们各自在吃） |
| the + 形容词 | —— | The old **are** respected.（一类人，用复数） |
| 集体名词 people / police / cattle | —— | The police **are** coming.（本身复数） |

### 2.3 就近原则（谓语看最近的名词）

| 结构 | 例 |
|------|----|
| there be | There **is** a carrot and two apples.（近的是 a carrot） |
| either…or | Either the rabbit or the wolf **is** wrong. |
| neither…nor | Neither the wolf nor the rabbits **are** here. |
| not only…but also | Not only the rabbit but also the wolf **eats** carrots. |

### 2.4 就远原则（谓语只看最前面的主语）

with / along with / together with / as well as / except / but 引出的部分**不影响谓语**：

- `The rabbit, as well as the wolves, **is** hungry.`（谓语跟 The rabbit 单数）
- `The carrots, together with the apples, **are** on the table.`（谓语跟 The carrots 复数）

### 2.5 陷阱表（逐个记）

| 陷阱 | 规则 | 例 |
|------|------|----|
| each / every + 名词 | 主语一律单数 | Every rabbit **likes** carrots. / Each of the rabbits **is** fat. |
| one of + 复数名词 | 谓语单数（主语是 one） | One of the rabbits **is** white. |
| the number of / a number of | the number of → 单数；a number of → 复数 | The number of carrots **is** large. / A number of rabbits **are** here. |
| 形式复数实为单数 | news / physics / maths / politics → 单数 | The news **is** good. |
| and 连接同一人 / 物 | 一个冠词 → 单数；两个冠词 → 复数 | The writer and teacher **is** here.（一人）/ The writer and the teacher **are** here.（两人） |
| 不定式 / 动名词 / 从句作主语 | 一般单数 | Eating carrots **is** healthy. |
| 时间 / 金钱 / 距离作整体 | 一般单数 | Ten minutes **is** enough. |

---

## 3. 例句精讲

兔子叙事里埋陷阱，逐句定谓语：

1. `The rabbit, as well as two wolves, ___ (be) hungry.` → **is**（就远，跟 The rabbit）
2. `Neither the wolf nor the rabbits ___ (be) right.` → **are**（就近，跟 the rabbits）
3. `One of the carrots that ___ (be) on the table ___ (be) mine.` → 前空 **are**（that 的先行词 carrots 复数，定语从句谓语跟先行词），后空 **is**（主语 One 单数）—— 一句两个一致关系，分开判。
4. `The number of wolves ___ (be) falling, but a number of rabbits ___ (be) coming.` → **is** / **are**（the number of 表数量值，单数；a number of = many，复数）
5. `The rabbit and doctor ___ (be) my friend.` → **is**（一个冠词 = 一只兔子兼医生，同一人）

---

## 4. 常见坑

- ⚠️ **被修饰语带偏**：`The box of carrots **is** heavy.` 谓语跟 The box（单数），不跟 carrots —— 先划掉 of 介词短语，主语核心立现。
- ⚠️ **there be 一律用 are**：`There **are** a carrot on the table.` ❌ →就近看 a carrot，用 is。
- ⚠️ **one of 后的定语从句谓语**：`One of the rabbits that **is** fat` ❌ —— that 指 rabbits，从句谓语用复数 are；只有 the only one of 结构里才用单数：`the only one of the rabbits that **is** fat`。
- ⚠️ **each / every 作同位语**：`The rabbits each **have** a carrot.` each 在主语后作同位语时谓语跟主语（复数）；`Each of the rabbits **has** one.` 才是单数。
- ⚠️ **and 同一人判据**：看冠词数量 —— 一个冠词 = 一人两职（单数），两个冠词 = 两人（复数）。

---

## 5. 一句话总结

> 语法一致是默认，意义一致看「整体还是成员」，就近管 there be 和 or 系列、就远管 with / as well as 系列 —— 陷阱题先抓主语核心，再套原则，谓语单复数一定一个准。

## 6. 随堂练习

**B1（选择）**：`There ______ some apples and a pear on the table.`

- A. is
- B. are
- C. has
- D. have

**B2（填空）**：`Each of the rabbits ______ (have) a small carrot.`（用所给动词的正确形式填空）

**S1（改错）**：The number of the wolves are getting smaller and smaller. 找出主谓一致错误并改正。

**S2（辨析）**：`The rabbit family ______ (be) having dinner together in the hole.` 用 is 还是 are？再各造一个 family 用另一个数的句子。

---

## 7. 参考答案与解析

- **B1**：**B**。there be 用就近原则，靠近谓语的是 some apples（复数），故用 are；has/have 不能用于 there be。
- **B2**：**has**。each of + 复数名词作主语，主语核心是 each（单数），谓语用单数 has。
- **S1**：`are` → `is`。the number of 表「数量」这个整体值，谓语用单数（a number of 才接复数谓语）。
- **S2**：**are**。此处强调家人们各自在吃饭（成员，不是家庭整体），用复数 are；「另一个数」的句子：The rabbit family is a big one.（家庭整体，用单数 is）。
