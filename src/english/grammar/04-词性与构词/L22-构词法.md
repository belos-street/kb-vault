# L22：构词法

> 学完本讲你能：**靠规律批量扩词** —— 用派生（前缀表意、后缀定词性）、转化、合成、缩略、混成五种方法，把认识的词变成一串词。

---

## 1. 为什么需要这个概念

词汇量不够，靠一个个硬背永远追不上。英语单词有**构词规律**：知道 happy，就能推出 unhappy（不高兴）、happiness（幸福）、happily（高兴地）—— 一个词根长出一串词。这就是构词法（word formation）的价值：

> **构词法 = 扩词的杠杆：背 1 个词，得一串词。**

这也是「授人以渔」的最后一讲：语法管句子怎么搭，构词法管词汇怎么长。

---

## 2. 核心概念与规则

### 2.1 五大构词方式总览

| 方式 | 定义 | 例 |
|------|------|----|
| 派生（derivation） | 词根 + 前缀 / 后缀 | happy → unhappy / happiness |
| 转化（conversion） | 词形不变、词性转用 | clean（形）→ clean（动） |
| 合成（compounding） | 两词相加成新词 | black + board → blackboard |
| 缩略（shortening） | 截短完整词 | laboratory → lab |
| 混成（blending） | 两词各取一半拼合 | smoke + fog → smog |

### 2.2 派生：前缀表意，后缀定词性

常用前缀（改变词义，词性基本不变）：

| 前缀 | 含义 | 例 |
|------|------|----|
| un- | 不 / 相反 | unhappy, unfair |
| re- | 再 / 重新 | rewrite, return |
| dis- | 不 / 分开 | disagree, disappear |
| in- / im- | 不 | impossible, informal |
| mis- | 错误地 | mistake, misunderstand |
| pre- | 前 / 预先 | preview, prepare |
| over- | 过度 | overeat, overwork |
| inter- | 之间 | international |

常用后缀（改变词性）：

| 后缀 | 词性 | 例 |
|------|------|----|
| -tion / -ment / -ness / -ity | 名词 | action, movement, happiness, safety |
| -er / -or | 名词（人 / 物） | teacher, actor |
| -ly | 副词（部分形容词） | quickly, happily |
| -ful / -less / -ous / -able | 形容词 | careful, careless, famous, eatable |
| -y / -al / -ic | 形容词 | rainy, natural, basic |
| -ize / -ify | 动词 | realize, simplify |
| -en | 动词 | widen, shorten |

### 2.3 转化：词形不变，词性搬家

| 转化方向 | 例 |
|---------|----|
| 名词 → 动词 | water（水）→ **water** the carrots（浇水） |
| 动词 → 名词 | walk → take a **walk** / look → have a **look** |
| 形容词 → 动词 | clean（干净）→ **clean** the room |
| 形容词 → 名词 | the **rich** / the **young**（L12 已见） |

### 2.4 合成：两词拼一词

| 类型 | 例 |
|------|----|
| 名词 + 名词 | blackboard, looking-glass（古体）, homework |
| 形容词 + 名词 | blackboard, greenhouse |
| 动词 + 名词（宾） | pickpocket, breakwater |
| 副词 + 动词 | output, income |

> 合成词的含义多半能从两半猜出，但也有陷阱：greenhouse（温室）≠ 绿色的房子。

### 2.5 缩略与混成

| 方式 | 全称 → 新词 |
|------|------------|
| 截短 | laboratory → lab, telephone → phone, advertisement → ad, examination → exam |
| 首字母缩略 | UFO（Unidentified Flying Object）, VIP |
| 混成 | smoke + fog → **smog**, breakfast + lunch → **brunch**, carrot + orange → （造词练习） |

## 3. 例句精讲

**① 一个词根长一串**

> The **careful** rabbit **carefully** hid the carrot with great **care**.

care（名）→ careful（形容词）→ carefully（副词）→ 一句话三种词性，靠后缀切换：-ful 定形容词、-ly 定副词。

**② 前缀改意思、后缀改词性**

> The wolf was **unhappy** about the **disappearance** of the carrot.

un-（不）+ happy → unhappy（还是形容词）；dis-（分开）+ appear → disappear（动）；-ance 后缀把它变成名词 disappearance。

**③ 转化 + 合成**

> The rabbit **watered** the flowers near the **blackboard**.

water 名转动（浇水）；blackboard 形 + 名合成 —— 同一句话两个构词法。

---

## 4. 常见坑

- ⚠️ **后缀定词性被忽略**：写句子时只顾词义不顾词性，如 `He runs very quick.` —— quick 是形容词，修饰动词要 quickly（-ly 后缀管词性）。
- ⚠️ **前缀也改词性**：en- 是例外（en- + 形容词 → 动词：enlarge, enrich），别以为前缀一律不变词性。
- ⚠️ **-ly 后缀的词性双面性**：名词 + -ly 可以是形容词（friendly, lovely, lively），不是副词（L18 已埋伏笔）。
- ⚠️ **合成词按字面猜**：greenhouse（温室）、looking-glass（镜子）等含义整体化，不能拆字面。
- ⚠️ **混成词乱造**：混成词是约定俗成的（smog, brunch），不能自己现场拼一个就当正式词汇。

---

## 5. 一句话总结

> 构词法 = 扩词杠杆：派生靠前缀表意、后缀定词性，转化靠词性搬家，合成靠两词相加 —— 记住「后缀 → 词性」对照表，词汇量翻倍不用背。

## 6. 随堂练习

**B1（选择）**：The ______ of the carrot surprised the wolf.
- A. disappear
- B. disappearance
- C. disappeared
- D. disappearing

**B2（填空）**：The ______（care）rabbit hid the carrots very ______（care）.（用括号内词的正确形式）

**B3（选择）**：blackboard（黑板）与 smog（烟雾）分别是哪种构词法？
- A. blackboard 转化；smog 派生
- B. blackboard 合成；smog 混成
- C. blackboard 混成；smog 合成
- D. blackboard 合成；smog 缩略

**S1（改错）**：找出并改正句中错误：The wolf's disappear was quick, and the rabbit moved very quick to the hole.

**S2（翻译）**：把中文翻成英文：不开心的狼友好地笑了，兔子高兴地离开了。（提示：派生词 un- / -ly 形容词 / -ly 副词）

---

## 7. 参考答案与解析

- **B1**：**B**。主语位置要名词，-ance 后缀把动词 disappear 变成名词 disappearance；disappeared 是过去分词、disappearing 是动名词，均不合「the … of」结构。
- **B2**：**careful；carefully**。-ful 后缀定形容词（修饰名词 rabbit），-ly 后缀定副词（修饰动词 hid）。
- **B3**：**B**。black = 形容词 + board = 名词 → 合成词；smoke + fog 各取一半 → smog 混成词。
- **S1**：disappear → **disappearance**（主语要用名词，-ance 定词性）；very quick → **very quickly**（修饰动词 moved 用副词，-ly 定词性）。
- **S2**：The unhappy wolf smiled in a friendly way, and the rabbit left happily. un- 前缀表「不」仍为形容词（unhappy）；friendly 是 -ly 结尾的形容词（in a friendly way）；happily 是 -ly 副词修饰 left。
