## 1. 背景与目标

68 课微课（每课 1 个语法点 + 兔叙事课文 + 词汇 + 练习）需要「学 + 练」一体平台。内容以 `lesson.md`（课本）为唯一手写源，构建期产出 `lesson.json`，平台只读消费（单源管线，plan.md §1.2 / §3）。

**最小闭环**：选课 → 课文 → 词汇 → 精讲 → 练习（三段递进）→ 小测 → 深读跳讲义 → 记录进度 → 下一课。

## 2. 用户与场景

- 唯一用户：作者本人（画像：有词汇量、语法基础弱的成人，plan.md §1.1）
- 场景：桌面 + 移动；每课 20~30 分钟「学 + 练」闭环；复习时直接进练习段

## 3. 范围

**P0（M1 + M2 交付）**：

- 单源管线：lesson.md 七件套模板 → 解析 → lesson.json → 校验（CI 常驻）
- 试点内容：U01L01–L05 五课七件套成文
- 平台 v1：F1~F7 全部（导航 / 课文 / 词汇 / 操练 / 小测 / 深读 / 进度），Trae 双主题

**P1（后补）**：拼写模块、TTS 朗读、跨课复习队列调度（错题 → 后续课小测自动混入）、小测间隔复习题自动选题（试点期由内容侧手工混入）

**不做**：内容在线编辑、账号体系、云端同步、后端服务、TTS 以外的音频

## 4. 功能需求

### F1 课程导航（P0）

- 单元 → 课两级列表（9 单元 68 课全景，**目录源自 syllabus.json**；可学内容按 lesson.json 构建期自动发现）——**混合数据源规则**：
  - **已上线课**（有 lesson.json）：可点入学习，显示进度徽标
  - **未上线课**（仅在 syllabus.json，内容未产出）：**第四态徽标「未上线」，置灰不可点**——68 课路线图全景可见（循序渐进的可视化），不隐藏
- 徽标四态：**未上线（置灰）/ 未开始 / x/y 题 / ✓ 全对**（全部判定且全为 ✓）
- 「继续学习」直达上次课（无历史时隐藏）；上一课 / 下一课切换（仅在已上线课间）
- 新增课零代码接入（构建期从 lessons/ 目录自动发现 → 自动点亮）；单元尾部可显示「本单元 x/y 课已上线」

### F2 课文阅读（P0）

- 承载七件套 ①本课目标 + ②课文：逐句中英对照、段落式（首行缩进两字符）、两端对齐
- 本课语法点高亮句（`highlight` 标记）视觉突出，点开显示「为什么这么写」注解
- TTS 朗读（2026-10-18 补齐）：点句播放单句 + 「自动播放」逐句连播（滚动跟随 + 当前句高亮）；切课自动停；speechSynthesis 不可用时隐藏入口降级纯阅读

### F3 词汇表（P0）

- 词卡列表：word / 音标 / 词性 / 释义 / 课文例句 / 常用搭配（五要素全展示）
- 词卡浏览 + 例句英文等宽渲染；拼写训练属 P1，不在本版
- 数据来自 `vocab[]`，与课文例句互链（例句定位到课文原句）
- TTS（2026-10-18 补齐）：点词头播单词、点例句播例句（兼定位课文原句），播放态高亮跟随

### F4 操练（P0 · 承载 ④精讲 + ⑤练习）

- **④ 精讲卡**置于本 tab 顶部（保动线：词汇 → 精讲 → 练习）：规则 + 2~3 例句（`notes` 渲染）
- **⑤ 练习三段递进**，题量 5~7：
  - 理解（2~3 题，choice 机判）：课文理解单选
  - 操练（2~3 题，**drill 新题型**，机判）：句型替换——模板句 + 替换槽 + 提示词，逐槽填入后按归一化比对（槽级多可接受答案任一匹配，题级全槽对才 ✓）
  - 产出（1~2 题，自判）：造句 / 仿写 / 复述——输入草稿 → 揭示 `sample` 参考 → 显式 ✓/✗
- **答案可见性**（沿用 grammar-play Q7 裁定）：解析与参考逐题解锁，作答后才展开；禁一键看全
- 判分口径全部复用 grammar-play `normalize.ts`（大小写 / 空白 / 标点不敏感、无词干还原、「不填」合法空、题粒度全对才 ✓）

### F5 小测（P0 · 承载 ⑥）

- 4~6 题混合（**全机判：`kind ∈ choice / fill`**，不含自判题），本课点 + 间隔复习题（试点期由内容侧手工混入 2 题，来源上一课 / 三课前）
- 判分 + 错题清单（跳转原题）；「重置本轮」
- 错题进复习队列：P1 跨课调度（试点期仅记录，不做调度）

### F6 深读跳转（P0 · 承载 ⑦）

- 每课 `deepDive: { refs: [{ ref, title, hint }] }`：每条渲染为讲义跳转链接（ref → 跳转、title → 定位文案、hint → 深挖提示）
- 跳转目标 = **VitePress 站点讲义静态页**（`/kb-vault/english/grammar/…`，subhead 锚点定位到对应小节），不是 grammar-play
- hint（「什么情况下值得深挖」）随链接展示；入口在精讲卡末尾 + 小测汇总后各一处

### F7 学习进度持久化（P0）

- 复用 grammar-play `ProgressStore` 契约（localStorage 后端 + 不可用降级单会话）
- 按课存：每题判定（机判 ✓/✗ + 自判结果）、上次课、`dataVersion`
- **dataVersion 口径**（沿用）：题号集合 + 各题（题干 + 答案）内容指纹——失配整课判定清空、状态回「未开始」+ 提示
- 目录徽标由判定记录计算，不单独存计数

## 5. 数据契约（lesson.md 七件套 → lesson.json）

### 5.1 lesson.md 模板（唯一手写源，格式即解析契约）

```markdown
# U01L03：第 1 型 · 主 + 动：什么都不用加
> 学完本课你能：…

## 1. 本课目标
（一句话：今天只学 1 个点）
## 2. 课文
（段落式叙事；本课点高亮句用标记注明 + 「为什么这么写」注解）
## 3. 词汇表
（表格：word / 音标 / 词性 / 释义 / 课文例句 / 搭配，8~12 行）
## 4. 语法点精讲
（薄讲：规则 + 2~3 例句）
## 5. 练习
### 5.1 理解（choice）
### 5.2 操练（drill）
### 5.3 产出（自判，含参考 sample）
## 6. 小测
（4~6 题，题号 B/S 分层，答案分离）
## 7. 深读
（refs: Gnn + hint）
```

- 练习 / 小测的**题目与答案分离**：统一走**文末答案区**（与 grammar 讲义同款，`## 8. 参考答案` 或文末分离块——T1 定稿模板时二选一收口，倾向文末答案区）；选择题 `A. / B. / C. / D.` 编号行格式；markdown 格式（禁 HTML 折叠标签）

### 5.2 lesson.json 字段（构建产物，schema 校验）

| 字段 | 来源节 | 校验 |
|------|--------|------|
| `id` / `title` / `goal` | 标题行 / ① | id 匹配 `U\d{2}L\d{2}` |
| `reading: { sentences: [{en, zh, highlight?, note?}] }` | ② | 句数 > 0 |
| `vocab: [{ word, phonetic, pos, meaning, example, collocations }]` | ③ | 8~12 词；**课文例句列必须引课文原句**（全称断言：`example ∈ reading 句`，平台据此互链定位原句——U01L03 实测 11 词全合规，可判） |
| `notes` | ④ | ≥ 1（Lexio 继承字段，必含） |
| `practice: [{ kind, … }]` | ⑤ | `kind ∈ choice / drill / produce`；**`output` 不是字段名**——指 `practice` 中 `kind: "produce"` 的题段（Lexio 继承口径的落位）；校验 = produce 项 ≥ 1 且每项 `sample` ≥ 1 |
| `quiz: Question[]` | ⑥ | 4~6 题；题号讲内唯一；**`kind ∈ choice / fill`**（小测全机判，不含自判题——「✓ 全对」徽标口径依赖此裁定） |
| `deepDive: { refs: [{ ref, title, hint }] }` | ⑦ | 每条 ref 自带 title（讲义 §小节 定位）+ hint；ref 匹配 `G\d{2}` 且在 G01–G29 内 |
| `dataVersion` | 构建期 | 题号集合 + 题干/答案指纹（grammar-play 同口径） |

- `validate` = 解析产物 **schema 校验 + 不变量断言**（上表校验列），不是 md↔json 双源对账（单源，plan.md §3）；**md 格式违约 / 解析失败 / schema 不变量破 = 构建红**，常驻 CI 测试
- 编号约定：课号 `UxxLnn` 全局连续（正则 `U\d{2}L\d{2}` 锁两位）；讲义引用一律 `Gnn`（G01–G29，正则 `G\d{2}`）

## 6. 共享规则（跨模块统一口径）

| 规则 | 口径 |
|------|------|
| 判分归一化 | 复用 grammar-play `normalize.ts`：大小写 / 首尾空白 / 内部空白折叠 / 标点不敏感；无词干还原；空内多可接受答案任一匹配；「不填」空合法（空串 / ∅ / 「不填」字样） |
| 题粒度判定 | 全部空/槽对才 ✓（空/槽级结果随解析展示） |
| 答案可见性 | 逐题解锁（作答后展开该题解析/参考）；禁一键看全部答案 |
| 自判题 | 输入 → 揭示参考（sample / 解析）→ 显式 ✓ / ✗ 才计入统计 |
| drill 题型 | 模板句 + 替换槽 + 提示词；逐槽归一化比对；题级全槽对才 ✓ |
| 复现豁免 | U01L01–L04 无旧点可复现，间隔复习题从 U01L05 起启用（plan.md §2.3） |
| 编号 | `U\d+L\d+` = 课；`G\d+` = 讲义；工具解析互不误伤 |

## 7. 非功能需求与约束

| 项 | 要求 |
|----|------|
| 技术栈 | Bun + Vite + React + TS strict + oxlint / oxfmt（仓库 Demo 统一栈） |
| 数据流 | md 单源 → 构建期 lesson.json → 平台只读；内容更新 = 重新构建 |
| 一致性 | 解析器 fixture 单测 + schema 不变量 CI 测试，构建前执行 |
| UI | Trae 双主题（白绿 / 黑绿）、瑞士极简布局、响应式（PC + 移动）、lucide 图标、正文两端对齐 + 首行缩进两字符 |
| 依赖纪律 | 运行时依赖仅 react / react-dom / zod / lucide-react；不引 md 运行时解析库、状态库 |
| 部署 | GitHub Pages `/kb-vault/grammar-course/`；排除清单**只用精确路径**（`**/playground/**` 误杀教训）；CI 门禁 build-data → validate → check → test → build |
