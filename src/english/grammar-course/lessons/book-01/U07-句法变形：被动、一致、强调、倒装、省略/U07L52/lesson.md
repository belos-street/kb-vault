# U07L52：被动语态：be + done 与各时态

> 学完本课你能：**能把任意时态的主动句改成被动句**。

---

## 1. 本课目标

今天只学一个点：**被动语态的构成与各时态形式**。主动句讲「谁做了什么」，被动句把受事（被做的东西）提上主语位，公式是 `受事主语 + be + 过去分词（done）`。be 是时态的挂点：一般现在 `is / are + done`、一般过去 `was / were + done`、一般将来 `will be + done`、现在完成 `has / have been + done`——主动句怎么变时态，be 就怎么变，done 永远不变，所以任意时态的主动句都能改成被动句。谓语 = 动词 + TAM（时 / 态 / 气）的整体，被动句里这个整体就是「be（随时态变形）+ done」。施动者（by 短语）不知道或不重要就省，只有强调「谁做的」才留。U06L44 预告过 be + done 的最小定义，今天正式立定义。

## 2. 课文

- A strange rumor is going around in the forest these days.{★ 被动基本形对照：a rumor 是「被讲」的，但「流传」英语顺说 go around，不写被动 is told；被动基本形 = be + 过去分词，谁讲的不重要}
  森林里这些天流传着一个奇怪的传言。
- The rumor says the wolf broke the window of Carrot Home last winter.
  传言说，去年冬天狼打碎了 Carrot Home 的窗户。
- The fact was reported by two birds this morning.{★ by 短语保留：施动者 two birds 值得点名，强调「谁说的」才用 by 引出}
  这件事今天早上由两只鸟报告了出来。
- The birds confirmed the fact, and now the whole forest knows it.
  两只鸟证实了这件事，现在整个森林都知道了。

- The window was broken last winter.{★ 一般过去被动：was / were + done——过去被做的事，施动者不明就省掉 by}
  窗户去年冬天被打碎了。
- A new wall was built in the garden in spring.
  春天，园子里砌起了一堵新墙。
- A new sign has been put up this week.{★ 现在完成被动：has / have been + done——到现在已经被做完}
  这周，新招牌已经挂了起来。
- Two new tables will be delivered to Carrot Home tomorrow.
  两张新桌子明天会被送到 Carrot Home。
- All the work will be finished before the wolf comes.
  所有的活儿都会在狼来之前干完。

- The wolf was caught near the shop last winter, but the sheep explained everything.
  去年冬天，狼在小店附近被抓，但绵羊把一切都解释清楚了。
- The wrong number in the story was corrected quickly.{★ by 短语省略：谁纠正的不重要、不言自明——施动者不明或不重要就直接省}
  故事里那个错的数字很快就被纠正了。
- The wolf was not angry and smiled instead.
  狼没有生气，反而笑了。
- The wolf will be invited to the big dinner tomorrow.
  明天，狼会被邀请来参加大餐。
- Everyone in the forest loves the true story.
  森林里人人都喜欢这个真实的故事。

## 4. 语法点精讲

**规则**：被动语态 = `受事主语 + be（随时态变形）+ 过去分词（done）`，焦点是「什么东西怎么样了」，而不是「谁做的」。变被动三步：①主动句的宾语提为主语；②按主动句的时态和新主语的单复数定 be（`is made` / `was made` / `will be made` / `has been made`）；③动词变过去分词（done）。**by 短语（施动者）一留三省**：施动者不知道、不重要、不言自明就省（`The window was broken.`）；只有强调「谁做的」才留（`The fact was reported by two birds.`）。

例句（✅ 正确 / ❌ 错误对照）：

- ✅ `The carrot is made into soup every day. / The carrot was made yesterday. / The carrot has been made.` —— 被动随时态变形：be 变，done 不变
- ❌ `The window broken last winter. / The window was broke last winter.` —— 被动句不能缺 be；过去分词是 broken 不是 broke
- ✅ `The fact was reported by two birds. / The window was broken.` —— 施动者值得点名才留 by，否则省

## 5. 练习

### 5.1 理解（选择）

**B1（选择）**：「The window was broken last winter.」为什么用被动语态？
- A. 焦点在「窗户怎么样了」，谁打碎的不明、不重要
- B. 句子要强调「谁打碎了窗户」，用被动才能把施动者说清楚
- C. window 是受事、当了主语就必须用被动，这句话写不成主动句
- D. 句子讲的是将来

**B2（选择）**：「A new sign has been put up this week.」是哪种形式？
- A. 一般过去被动：was / were + done
- B. 现在完成被动：has / have been + done
- C. 一般将来被动：will be + done
- D. 一般现在被动：is / are + done

### 5.2 操练（替换）

**P1（操练）**：The rabbit eats the carrot every day. → The carrot ______ every day.（提示：eat）

**P2（操练）**：The wolf broke the window last winter. → The window ______ last winter.（提示：break）

**P3（操练）**：The rabbit has made the soup. → The soup ______.（提示：make）

### 5.3 产出（自判）

**S1（产出）**：用 eat / break / make 各写一个被动句（时态自选），其中 1 句保留 by 短语、其余省略，并说出 by 留或省的理由。

## 8. 参考答案与解析

- **B1**：**A**。被动句的焦点是受事「窗户怎么样了」；打碎窗户的人不明、不重要，所以用被动并省掉 by 短语。B 说反了——想点名「谁做的」才留 by 短语或干脆用主动句；C 因果倒置——受事当主语是选被动的结果而非理由，主动句 `The wolf broke the window.` 同样成立；D 与 last winter 的过去时间矛盾。
- **B2**：**B**。has been + done 是现在完成被动——到现在已经被做完；was / were + done 是一般过去，will be + done 是一般将来。
- **P1**：**is eaten**。一般现在被动：受事 the carrot 是单数，be 用 is，eat 的过去分词是 eaten。
- **P2**：**was broken**。一般过去被动：be 用 was，break 的过去分词是 broken。
- **P3**：**has been made**。现在完成被动：have / has been + done，make 的过去分词是 made。
- **S1**：参考：**The carrot is eaten every day. / The window was broken by the wolf last winter. / The soup has been made.**（be + done 齐全、时态对即可）。by 短语只在强调「谁做的」时保留，其余可省。
- **Q1**：**B**。被动 = 受事主语 + be + 过去分词：be 随时态变形，done 才是被动的标志。
- **Q2**：**by**。by 短语引出施动者：The fact was reported by two birds；施动者不明或不重要就整个省掉。
- **Q3**：**C**。will be + done 是一般将来被动——明天将要被送来的桌子。
- **Q4**：**C**。break 的过去分词是 broken，和 was 一起构成一般过去被动（be + done）；A 把 was / broken 看成两个并列谓语，B 误当主系表，D 误当后置定语（`The window broken last winter.` 缺 be 不成立，定语写法和被动写法不能混）。
- **Q5**：**A**。独立主格「名词 + 分词」本质是状语从句的简化（Weather permitting …）（U06L51）。
- **Q6**：**to bring**。「打算做、还没做的事」跟在 promise 后用 to do：promises to bring（U06L45）。
