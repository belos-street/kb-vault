# U07L59：连词收口：并列、从属与「不同时现」

> 学完本课你能：**能把句子接得顺、接得对，写作中连词零病句**。

---

## 1. 本课目标

连词是句子的连接件：长句 = 简单句的并列或嵌套。今天把连接件收口成三类：**并列连词**（fanboys 七兄弟 for / and / nor / but / or / yet / so，各标一种逻辑关系）、**从属连词**（because / although / when / if 引导从句，让分句挂到主句上）、**关联连词**（both … and / not only … but also / either … or / neither … nor / not … but 成对使用、两边平行）。最后收两组**「不同时现」铁律**——`although × but`、`because × so`：这是中文「虽然…但是…」「因为…所以…」直译的第一大病句，一句话只能留一个连接件。

---

## 2. 课文

- The wolf stays at the shop, and the little sheep brings the best carrots.{★ 并列连词 and：顺承关系——fanboys 七兄弟 for / and / nor / but / or / yet / so 各标一种逻辑}
  狼留在店里，小绵羊带来最好的胡萝卜。
- The forest was quiet before, but today every animal comes.
  森林从前很安静，可今天每只动物都来了。
- Hurry, or the soup will get cold.
  快点，不然汤就凉了。
- Nobody leaves early, for the day is too good to miss.
  谁也不愿早走，因为这样的好日子不容错过。

- Both the wolf and the little sheep work at the shop.{★ 关联连词 both … and：成对使用，两边结构平行——词对词、句对句}
  狼和小绵羊都在店里干活。
- The rabbit is not only a good cook but also a good friend.
  兔子不光是个好厨师，还是个好朋友。
- Either the wolf tells the story or the little sheep does.{★ either … or：成对使用——谓语就近一致细则在 U07L55 收口}
  要么狼来讲这个故事，要么小绵羊讲。
- Neither the wolf nor the rabbit wants any gift.
  狼和兔子都不想要什么礼物。

- Although the day is long, nobody feels tired.{★ 不同时现铁律其一：although 从属连词一出现，同句的 but 必须删——「虽然…但是…」只留一个}
  虽然这一天很长，谁也不觉得累。
- Because everyone knows the truth, the forest feels light.{★ 铁律其二：because 不配 so——「因为…所以…」只留一个连接件，要 so 就删 because}
  因为人人都知道了真相，森林都轻快起来。
- The wolf tells the truth about the old days, and everyone believes him.
  狼讲了过去那些日子的真相，大家都相信他。
- The animals greet the wolf with loud cheers and joy.
  动物们用热烈的欢呼迎接狼。
- Now everyone trusts the wolf and the little shop.
  如今人人都信任狼和这家小店。
- The animals honor the wolf as a proud partner of Carrot Home.
  动物们把狼敬为 Carrot Home 骄傲的合伙人。
- The big dinner starts, and Carrot Home will certainly stay open forever.
  大餐开始了，Carrot Home 一定会永远开下去。

## 4. 语法点精讲

**规则**：连词三类各管一摊。**并列连词** = fanboys 七兄弟 **for / and / nor / but / or / yet / so**：and 顺承、but / yet 转折、or 选择或「否则」、so 结果、for 原因（书面）、nor「也不」（后面倒装）——连接地位平等的词、短语或分句。**从属连词**（because / although / when / if / while）引导从句，让分句降级挂在主句上。**关联连词**成对使用（both … and / not only … but also / either … or / neither … nor / not … but），两边结构必须平行（词对词、句对句），either … or / neither … nor 的谓语**就近一致**（细则在 U07L55 收口）。**两组「不同时现」铁律**（本课收口）：①`Although the wolf ran fast, the rabbit escaped.` ✅ / `Although …, but …` ❌；②`Because the carrot was gone, the rabbit cried.` ✅ / `Because …, so …` ❌。原因：although / because 是从属连词，but / so 是并列连词，一句话只能有一个连接件撑骨架——写完自查：见 although / because，就删同句的 but / so。

例句（✅ 正确 / ❌ 错误对照）：

- ✅ `Although the day is long, nobody feels tired.` —— 只留 although，中文习惯里的「但是」被吞掉
- ✅ `Everyone knows the truth, so the forest feels light.` —— 只留 so 表结果
- ❌ `Because everyone knows the truth, so the forest feels light.` —— because × so 同现，删掉一个（留 because 或留 so 都行）

## 5. 练习

### 5.1 理解（选择）

**B1（选择）**：下面哪句是「不同时现」病句？
- A. Although the day is long, nobody feels tired.
- B. The day is long, but nobody feels tired.
- C. Because everyone knows the truth, so the forest feels light.
- D. The forest feels light, for everyone knows the truth.

**B2（选择）**：「The rabbit is not only a good cook but also a good friend.」为什么对？
- A. not only 可以单独用
- B. but also 可以单独用
- C. not only … but also 成对使用，两边结构平行（表语对表语）
- D. not only … but also 只能连接单词

### 5.2 操练（替换）

**P1（操练）**：The day is long, ______ nobody feels tired.（提示：转折关系）

**P2（操练）**：Everyone knows the truth, ______ the forest feels light.（提示：结果关系）

**P3（操练）**：______ the wolf ______ the little sheep work at the shop.（提示：关联连词前段, 关联连词后段）

### 5.3 产出（自判）

**S1（产出）**：用 but、so、for 各连接一组句子写 3 句，再用 both … and 与 not only … but also 各造一句写 2 句，写完自查两组「不同时现」。

## 8. 参考答案与解析

- **B1**：**C**。because（从属连词）与 so（并列连词）同现是「不同时现」病句；A 只留 although、B 只留 but、D 用 for 表原因，都只用了一个连接件。
- **B2**：**C**。关联连词必须成对使用（not only … but also），且两边结构平行：good cook 对 good friend（表语对表语）。
- **P1**：**but（或 yet）**。前后是转折关系，but / yet 两个并列连词都标转折，写哪个都对；注意全句只有这一个连接件，不再加 although。
- **P2**：**so**。前因后果，用 so 表结果；前面不再加 Because。
- **P3**：**Both；and**。两者都：both … and 成对使用，两边结构平行（the wolf 对 the little sheep）。
- **S1**：参考：**The day is long, but nobody feels tired. / Everyone knows the truth, so the forest feels light. / The wolf stays, for the shop needs him. / Both the wolf and the little sheep work at the shop. / The rabbit is not only a good cook but also a good friend.**（连词对、成对使用、无「不同时现」病句即可）。
- **Q1**：**B**。一句话只留一个连接件：A 的 although × but、C 的 because × so、D 的 although × so 都是「不同时现」病句。
- **Q2**：**so**。fanboys = for / and / nor / but / or / yet / so 七兄弟，so 表结果。
- **Q3**：**C**。both … and 成对使用、两边平行，both…and 连接并列主语用复数（狼和小绵羊两者），谓语用 work；A 的 works 误用单数，B、D 拆开或换错连词。
- **Q4**：**but**。铁律其一：although 不配 but——「虽然…但是…」只留 although，或只留 but。
- **Q5**：**B**。so / not 替代整个从句：I hope not = I hope that the wolf will not leave（U07L58）。
- **Q6**：**强调**。It was … that 去掉后 The wolf gave the recipe 仍成立，是强调句（U07L56）。
