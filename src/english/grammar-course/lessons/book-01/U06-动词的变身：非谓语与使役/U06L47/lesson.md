# U06L47：现在分词 vs 过去分词：主动与被动的脸

> 学完本课你能：**能选对分词作定语，不写 the broken by the wolf carrot**。

---

## 1. 本课目标

今天学两张「形容词脸」的非谓语：**分词**。判断只看主动被动：**现在分词 doing = 主动 / 进行**（`the sleeping rabbit`——兔子自己在睡）、**过去分词 done = 被动 / 完成**（`the broken carrot`——胡萝卜被弄断）。位置规则：**单个分词作定语前置**（`the shining lamp`），**分词短语整体后置**（`the wall painted last week`）；分词还能作状语、补语。检验法：名词自己发出动作 → doing；名词承受动作 → done。doing 当名词用见 U06L46；to do 见 U06L45；`be + done` 表被动的正式定义见 U07L52；感官动词后接 do / doing / done 的特殊规则见 U06L50。

## 4. 语法点精讲

**规则**：分词是「形容词 / 副词脸」的非谓语，选脸只看主动被动：**现在分词 doing = 主动 / 进行**——名词自己发出动作（`the sleeping rabbit` 兔子自己在睡）；**过去分词 done = 被动 / 完成**——名词承受动作（`the broken carrot` 胡萝卜被弄断）。边界：不及物动词的 done 只表完成、没有被动义（`fallen leaves` 落下的叶子）。**位置**：单个分词作定语放名词**前**（`the shining lamp`）；分词短语要**整体后置**（`the wall painted last week`）；分词还可作状语（`Painted last week, the wall looks bright.`）和补语。检验法：名词自己干 → doing；名词被干 → done。最典型的病句：`the broken by the wolf carrot` ❌——分词短语被劈开塞进名词中间；要说 `the carrot broken by the wolf` ✅，短语整体后置。

例句（✅ 正确 / ❌ 错误对照）：

- ✅ `the sleeping rabbit / the broken carrot` —— doing 主动、done 被动，单个分词作定语前置
- ✅ `the wall painted last week` —— 分词短语整体后置作定语
- ❌ `the broken by the wolf carrot` —— 分词短语不能劈开塞进名词中间，要整体后置

## 5. 练习

### 5.1 理解（选择）

**B1（选择）**：「the sleeping rabbit」为什么用 sleeping？
- A. rabbit 是被动的
- B. 现在分词表主动 / 进行：兔子自己在睡
- C. sleeping 是名词
- D. 作定语必须用 -ing

**B2（选择）**：「the broken carrot」为什么用 broken？
- A. 过去分词表被动 / 完成：胡萝卜被弄断了
- B. broken 表主动：胡萝卜自己发出「断」的动作
- C. done 只表完成、不表被动：只是说「断了」
- D. 作定语只能用 done

### 5.2 操练（替换）

**P1（操练）**：The lamp shines in the window. → The ______ lamp in the window is new.（提示：-ing 主动进行）

**P2（操练）**：The rabbit hires a worker. → The ______ worker starts on the weekend.（提示：done 被动完成）

**P3（操练）**：The lamp shines in the window. The door was painted yesterday. → The ______ lamp and the ______ door look nice.（提示：-ing 主动, done 被动）

### 5.3 产出（自判）

**S1（产出）**：用现在分词、过去分词各造 2 个定语：各 1 个单个分词前置、1 个分词短语后置，并说出每个是主动还是被动。

## 8. 参考答案与解析

- **B1**：**B**。sleep 是 rabbit 自己发出的动作：现在分词 sleeping 表主动 / 进行，作定语前置。
- **B2**：**A**。carrot 承受「弄断」这个动作：过去分词 broken 表被动 / 完成。broken 不表主动——胡萝卜是承受方，不是发出动作的一方；done 的核心是被动，不只是「完成」。
- **P1**：**shining**。lamp 自己在发光——主动 / 进行用现在分词 shining，单个分词前置。
- **P2**：**hired**。worker 是被雇的——被动 / 完成用过去分词 hired。
- **P3**：**shining；painted**。lamp 主动发光用 -ing，door 被漆用 done；两个都是单个分词前置。
- **S1**：参考：**The sleeping wolf is on the floor. / The lamp shining in the window is new. / The broken hammer is on the table. / The wall painted last week looks bright.**（分词与主动 / 被动对上即可）。单个分词前置、分词短语后置写对即可。
- **Q1**：**A**。sleeping 是主动（兔子在睡），broken 是被动（胡萝卜被弄断）——doing 主动、done 被动。
- **Q2**：**被动**。过去分词 done 表被动 / 完成：胡萝卜承受「断」。
- **Q3**：**B**。「被狼弄断的胡萝卜」= 胡萝卜承受「弄断」，用 done 且短语整体后置：the carrot broken by the wolf；A 把短语劈开塞进名词中间，C 用 -ing 表主动（胡萝卜在弄断别人），D 主动被动与位置都不对。
- **Q4**：**前**。单个分词作定语前置：the sleeping rabbit；分词短语才整体后置。
- **Q5**：**B**。look forward to 的 to 是介词，介词后必接 doing（U06L46）。
- **Q6**：**done**。非谓语三张脸：to do / doing / done（U06L44）。
