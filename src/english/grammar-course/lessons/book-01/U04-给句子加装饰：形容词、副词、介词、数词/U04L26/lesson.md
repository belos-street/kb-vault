# U04L26：比较级与最高级：变化规则

> 学完本课你能：**能造出任意常见形容词的比较级、最高级形式**。

---

## 1. 本课目标

今天只学一个点：**形容词的比较级、最高级怎么变**。要说「更……」和「最……」，英语靠形容词自己变形：单音节和部分双音节加 `-er / -est`（big → bigger → biggest），音节多的形容词用 `more / most`（important → more important），还有几个必须背的不规则变化（good → better → best）。本课只练**形式**；怎么拿这些形式做比较（than / as … as / the + 最高级 + 范围）是下一课 U04L27 的事。

---

## 2. 课文

- The rabbit goes to the market with the wolf.
  兔子和狼一起去市场。
- Carrot Home needs a bigger table and a longer shelf.{★ 加 -er：单音节比较级——big 双写 g 再加 -er，long 直接加 -er}
  Carrot Home 需要一张更大的桌子和一条更长的架子。
- Mother sheep sells the cheapest and sweetest carrots.{★ 加 -est：最高级形式——cheap、sweet 都直接加 -est}
  绵羊妈妈卖的胡萝卜最便宜、最甜。
- The wolf picks a nicer wooden box for his bread.
  狼给他的面包挑了一个更漂亮的木盒。
- The rabbit wants a lighter bag and a smaller sign.
  兔子想要一个更轻的袋子和一块更小的招牌。

- The little sheep carries a heavy bag, and the rabbit takes a heavier one.{★ 辅音 + y 变 -ier：heavy → heavier，不用 heavyer}
  小绵羊背着沉袋子，兔子拿了一个更沉的。
- The rabbit thinks about the more expensive wooden table.{★ more + 原级：音节多的形容词——expensive → more expensive，不说 expensiver}
  兔子在考虑那张更贵的木桌。
- The rabbit chooses the more useful shelf for the little shop.
  兔子为小店挑了更实用的架子。
- Mother sheep cooks the most delicious soup.
  绵羊妈妈煮出最美味的汤。

- The wolf says better soup brings more customers.{★ 不规则：good → better，many / much → more——没有规律，必须背}
  狼说更好的汤会带来更多顾客。
- The weather is worse today, but the market is busy.
  今天天气更差，但市场很忙。
- The little sheep gets the best apples for the shop.
  小绵羊为店里挑了最好的苹果。
- The rabbit writes every new form on a piece of paper.
  兔子把每张新单子写在一张纸上。
- The wolf helps to carry the heavy boxes home.
  狼帮忙把沉箱子搬回家。
- The two friends walk home with their new things.
  两个朋友带着新东西走回家。

## 4. 语法点精讲

**规则**：比较级（更……）和最高级（最……）有两种变法。**加 -er / -est**：单音节和部分双音节（big → bigger → biggest、long → longer → longest），注意三个拼写关：以 e 结尾加 -r / -st（nice → nicer → nicest）；「辅音 + y」把 y 变 i 再加 -ier / -iest（heavy → heavier → heaviest）；重读闭音节双写末尾辅音（big → bigger → biggest）。**用 more / most**：音节多的形容词不加 -er，前面加 more / most（important → more important → most important、expensive → more expensive）——判断看**音节数**，不看词长。**双音节怎么判**：双音节 -y / -er / -le / -ow 结尾多加 -er / -est，其余双音节与多音节用 more / most；双音节词拿不准时，用 more / most 总是安全。**不规则变化必须背**：good → better → best、bad → worse → worst、many / much → more → most、little → less → least。比较的用法（than / as … as / the + 最高级 + 范围）见 U04L27。

例句（✅ 正确 / ❌ 错误对照）：

- ✅ `big → bigger → biggest` —— 单音节，双写 g 再加 -er / -est
- ❌ `big → biger / more bigger` —— biger 少双写一个 g；more bigger 是「-er 和 more 双重叠加」，都错
- ✅ `important → more important → most important` —— 音节多，用 more / most

## 6. 小测

**Q1（填空）**：big 是单音节、要双写末尾辅音，它的最高级是 ______。

**Q2（选择）**：哪组形式全部正确？
- A. happyer / happyest
- B. happier / happiest
- C. more happy / most happy
- D. happyer / happiest

**Q3（填空）**：good 的最高级是 ______。

**Q4（选择）**：不规则变化「bad → ______ → worst」的空格是：
- A. badder
- B. worst
- C. worse
- D. more bad

## 8. 参考答案与解析

- **B1**：**A**。「辅音 + y」结尾要 y 变 i 再加 -er：happy → happier，不是 happyer，也不用 more。
- **B2**：**C**。important 音节多，比较级用 more + 原级；big / happy / nice 都是短词加 -er（bigger / happier / nicer）。
- **P1**：**bigger**。单音节 big 重读闭音节双写末尾 g 再加 -er。
- **P2**：**more useful**。useful 音节多，比较级用 more + 原级，不说 usefuller。
- **P3**：**worse**。bad 的比较级不规则：bad → worse → worst，必须背。
- **S1**：参考：**heavy → heavier → heaviest；useful → more useful → most useful；good → better → best**（变化对即可；造句合理即可）。
- **Q1**：**biggest**。双写末尾 g 再加 -est：big → bigger → biggest。
- **Q2**：**B**。「辅音 + y」变 -ier / -iest：happy → happier → happiest；A、D 的 happyer 少变 y，C 的 more happy 是错的。
- **Q3**：**best**。good 的不规则变化：good → better → best。
- **Q4**：**C**。bad → worse → worst，不规则，必须背。
- **Q5**：**B**。bright and warm 站系动词 is 后说明主语——表语岗位（U04L25）。
- **Q6**：**visited（或 came to）**。yesterday 是过去时间标志，事情已结束用一般过去时（U03L23）。
