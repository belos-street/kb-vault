# U08L64：虚拟语气 I：if 从句的时态退移

> 学完本课你能：**能造与现在 / 过去事实相反的假设句（If I were a rabbit, …）**。

---

## 1. 本课目标

本单元主线是虚拟语气的**时态后退**（讲义 §2.3 叫「时态退移」）：话说得越「不真实」，动词往过去退得越狠。今天专攻 if 从句的两档：**与现在事实相反**（if + 一般过去时、be 统一用 were，主句 would + 动词原形）和**与过去事实相反**（if + had done，主句 would have done）。记住本质：过去形式在这里不表过去，表「不真实」；再防一个坑——if 不自动等于虚拟，真实条件句用正常时态。

---

## 2. 课文

- The wolf is innocent, but some animals still pretend they saw him last night and imagine all kinds of stories.
  狼是清白的，可还是有些动物假装说昨晚看见了他，还想象出各种各样的故事。
- "If the wolf were the thief, he would not help us," says the rabbit.{★ 与现在事实相反：if 从句用过去式、be 统一 were，主句 would + 动词原形}
  「要是狼是小偷，他就不会帮我们了，」兔子说。

- "If the wolf had taken the carrots, he would have run away at once," says the rabbit.{★ 与过去事实相反：if 从句 had done，主句 would have done——要退就一起退}
  「要是狼拿走了那些胡萝卜，他早就跑了，」兔子说。
- "It is impossible to blame anyone before the search is over."
  「搜查结束之前，谁也不能怪。」

- "Not every if talks about reality," says the wolf.
  「不是每个 if 都在说现实，」狼说。
- `If you need help, call me` is a real condition, and the wolf means every word.{★ 真实条件句用正常时态：if 不自动等于虚拟——看说话人信不信这句话}
  `If you need help, call me` 是真实条件句，狼说的每个字都是认真的。
- "Only foolish animals believe every rumor, and we need facts, otherwise the rumors will never stop."
  「只有愚蠢的动物才会信每一条传言；我们需要事实，不然传言永远停不下来。」
- "A past form shows the idea is far from the truth," answers the old sheep.{★ 时态后退的本质：用过去形式表达「不真实」——时态管的是态度，不只是时间}
  「过去形式说明这个想法离真相很远，」老绵羊回答。
- "Let's watch the shop together tonight and keep it safe."
  「今晚我们一起看守小店，把它看好了。」

## 4. 语法点精讲

**规则**：虚拟语气的主线是**时态后退**（讲义 §2.3 叫「时态退移」）：假设得越不真实，动词往过去退得越狠。**与现在事实相反**：`if + 一般过去时`（be 统一用 `were`），主句 `would / could / might + 动词原形`（`If I were a rabbit, I would smell the missing carrots anywhere.`）；**与过去事实相反**：`if + had done`，主句 `would / could / might + have done`（`If I had seen the thief, I would have called everyone.`）——从句和主句一起退。本质一句话：**过去形式在这里不表过去，表「不真实」**，would 也只是标志、不再表将来。最后防一个坑：if 不自动等于虚拟——真实条件句用正常时态（`If you need help, call me.`，说话人信这句话能成真），看说话人信不信，不看 if 本身。按窄口径说：谓语 = 动词 + 时态、情态那套词形的整体，`would + 原形` / `would have + done` 都是虚拟句谓语整体的形态。

例句（✅ 正确 / ❌ 错误对照）：

- ✅ `If I were a rabbit, I would smell the missing carrots anywhere.` —— 与现在相反：if 从句过去式（be 用 were），主句 would + 原形
- ✅ `If I had seen the thief, I would have called everyone.` —— 与过去相反：had done + would have done，两处一起退
- ❌ `If I was a rabbit, I will smell the missing carrots.` —— 虚拟里 be 统一用 were；主句 will 不退，要写 would

## 5. 练习

### 5.1 理解（选择）

**B1（选择）**：「If the wolf were the thief, he would not help us.」这句话的意思是？
- A. 狼真的是小偷，而且他没帮忙
- B. 与现在事实相反的假设——说话人认为狼不是小偷
- C. 狼明天会不会帮忙还不一定
- D. 狼昨晚拿走了胡萝卜

**B2（选择）**：与过去事实相反的虚拟句，从句和主句怎么配？
- A. if 从句用一般过去时，主句 would do
- B. if 从句用 had done，主句 would have done
- C. if 从句用 will do，主句 had done
- D. 两处都用动词原形

### 5.2 操练（替换）

**P1（操练）**：The wolf is not the thief. → If the wolf ______ the thief, he would not help us.（提示：be 的虚拟形式）

**P2（操练）**：The rabbit did not lock the door. → If the rabbit ______ the door with the new key, nobody would have taken the carrots.（提示：lock 的过去完成）

**P3（操练）**：I don't know the answer, and I don't tell anyone. → If I ______ the answer, I ______ everyone.（提示：know, tell）

### 5.3 产出（自判）

**S1（产出）**：围绕「谁拿了胡萝卜」造两组假设句：一组与现在事实相反（if + 过去式，主句 would do），一组与过去事实相反（if + had done，主句 would have done）。

## 8. 参考答案与解析

- **B1**：**B**。与现在事实相反的虚拟：if 从句过去式（be 用 were），主句 would + 原形——说话人默认狼不是小偷，只是假设。
- **B2**：**B**。与过去事实相反：if 从句 had done，主句 would have done，从句主句一起退。
- **P1**：**were**。与现在事实相反的虚拟里 be 统一用 were（If I were … 是固定写法）。
- **P2**：**had locked**。与过去事实相反，if 从句退到过去完成时：had + 过去分词 locked。
- **P3**：**knew；would tell**。与现在事实相反：if 从句用过去式 knew，主句 would + 动词原形 tell。
- **S1**：参考：**If I were the thief, I would run away. / If the rabbit had locked the door, nobody would have taken the carrots.**（两处退移配套即可）。
- **Q1**：**B**。were + would 是与现在事实相反的假设；A 是真实条件句，C 是与过去事实相反，D 是陈述句。
- **Q2**：**have done**。would have + 过去分词 = would have done，配 if 从句的 had done。
- **Q3**：**B**。虚拟里与现在相反的 be 统一用 were，是固定写法，跟主语单复数无关。
- **Q4**：**过去**。时态后退的本质：过去形式不表过去，表「不真实」。
- **Q5**：**was counting；had finished**。过去进行 = was / were + doing（count → was counting）；在过去时点之前已完成的动作用过去完成 had + 过去分词（finish → had finished）——虚拟句的 had done 就是从这套过去形态退出来的（U03L21）。
- **Q6**：**A**。现在完成时连着现在，last winter 这类纯过去时间断了这条线——已结束的过去用一般过去时 worked（U03L22）。
