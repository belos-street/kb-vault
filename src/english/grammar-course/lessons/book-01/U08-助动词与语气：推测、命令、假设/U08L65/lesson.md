# U08L65：虚拟语气 II：愿望、建议、命令后的从句

> 学完本课你能：**能表达愿望与建议（I wish it had found the carrot.）**。

---

## 1. 本课目标

今天收两种「假话」的尾巴：**愿望**和**建议 / 命令**。wish 后的从句照旧时态后退：与现在事实相反用一般过去时（`I wish I knew who took the carrots.`），与过去事实相反用 had done（`I wish it had found the carrot.`）。suggest / demand / order / insist / require 这类「建议、要求、命令」动词后的 that 从句一律 `(should) + 动词原形`，should 可省。最后收两个书面高频件：**混合条件句**（从句主句各退各的时间）和**省略 if 的倒装**（`Had we asked the mouse to watch the shop, …`），呼应 U07L57 的虚拟倒装。

## 2. 课文

- The rabbit's memory of last night is not clear.
  兔子对昨晚的记忆已经不那么清楚了。
- "I wish I knew who took the carrots," says the rabbit.{★ wish + 过去式：与现在事实相反的愿望——现在不知道，know 退成 knew}
  「真希望我知道是谁拿走了那些胡萝卜，」兔子说。
- "I wish it had found the carrot," says the rabbit.{★ wish + had done：与过去事实相反的愿望——刚才没找到，已无法改变}
  「真希望它刚才找到了那根胡萝卜，」兔子说。
- "If only we had left it on the road," says the wolf.
  「要是我们当初把它留在路上就好了，」狼说。

- The wolf suggests that everyone (should) search the forest.{★ suggest 后的 that 从句用 (should) + 动词原形——should 可省，省了动词也是原形}
  狼建议大家都去森林里搜一搜。
- The old sheep demands that nobody (should) say "thief".
  老绵羊要求：谁也不许说「小偷」。
- The rabbit insists that every animal (should) help.
  兔子坚持要求每只动物都来帮忙。
- The rules require that everyone (should) tell the truth.
  店里的规矩要求人人都说实话。

- "If the rabbit had locked the door with the new key, the carrots would still be here," says the wolf.{★ 混合条件句：if 从句退到过去（had locked），主句谈现在（would still be）——从句主句各退各的时间}
  「要是兔子昨晚用新钥匙锁了门，那些胡萝卜现在还在这儿呢，」狼说。
- "Had we asked the mouse to watch the shop, the carrots would still be here," adds the little sheep.{★ 省略 if 的倒装：Had 提到主语前 = If we had asked——同 U07L57 的虚拟倒装，书面常用}
  「要是我们请老鼠来看店，那些胡萝卜现在还在这儿呢，」小绵羊补充说。
- "We will not forget this day," says the rabbit.
  「我们不会忘记这一天，」兔子说。
- The rabbit is grateful and shares the last carrot with everyone.
  兔子很感激，把最后一根胡萝卜分给了大家。

## 4. 语法点精讲

**规则**：wish 后的从句照旧**时态后退**：与现在事实相反用**一般过去时**（`I wish I knew who took the carrots.`），与过去事实相反用 **had done**（`I wish it had found the carrot.`）。**建议 / 命令 / 要求**类动词（suggest / demand / order / insist / require）后的 that 从句用 **`(should) + 动词原形`**：should 可省，但动词永远是原形（`The wolf suggests that everyone (should) search the forest.`，不写 searches）。**混合条件句**：从句和主句各退各的时间——`If the rabbit had locked the door with the new key, the carrots would still be here.`（从句谈过去 had locked，主句谈现在 would be）；**省略 if 的倒装**：were / had / should 提到主语前（`Had we asked the mouse to watch the shop, …`），if 消失、意思不变，书面常用，呼应 U07L57。两个坑：suggest 表「暗示」时不退移（`The look suggested that it was angry.`）；wish 后不接 will。按窄口径说：谓语 = 动词 + TAM（时 / 态 / 气）的整体，`knew` / `had found` 是退移后的谓语形态，`(should) do` 则是原形形态。

例句（✅ 正确 / ❌ 错误对照）：

- ✅ `I wish I knew who took the carrots.` / ✅ `I wish it had found the carrot.` —— wish + 过去式（现在愿望）/ had done（过去愿望）
- ✅ `The wolf suggests that everyone (should) search the forest.` —— (should) + 动词原形，search 不加 s
- ✅ `Had we asked the mouse to watch the shop, the carrots would still be here.` —— 省略 if 的倒装，还原 If we had asked the mouse to watch the shop（这是混合条件句：从句退过去、主句按现在结果退移；讲义称错综时间条件句）

## 5. 练习

### 5.1 理解（选择）

**B1（选择）**：「I wish it had found the carrot.」表达什么？
- A. 希望它将来能找到胡萝卜
- B. 对过去的愿望——事实上当时没找到
- C. 命令它去找胡萝卜
- D. 它已经找到了胡萝卜

**B2（选择）**：「The wolf suggests that everyone (should) search the forest.」的从句动词为什么用 search？
- A. everyone 是复数
- B. suggest / demand / order 类动词后的 that 从句用 (should) + 动词原形
- C. 一般现在时第三人称要加 s
- D. forest 是复数

### 5.2 操练（替换）

**P1（操练）**：I don't know who took the carrots. → I wish I ______ who took the carrots.（提示：know 的过去式）

**P2（操练）**：The mouse did not find the dropped carrot. → I wish the mouse ______ the dropped carrot.（提示：find 的过去完成）

**P3（操练）**：Everyone searches the forest. → The wolf suggests that everyone ______ the forest.（提示：suggest 后的从句形态）

### 5.3 产出（自判）

**S1（产出）**：用 wish 造一个与现在事实相反的愿望句和一个与过去事实相反的愿望句，再用 suggest 或 demand 写一句「建议 / 要求」（that 从句用 (should) + 动词原形）。

**S2（产出）**：仿写句群：用本单元学的 2~3 个句型（wish + 过去式 / had done、suggest / demand + (should) + 动词原形、混合条件句 if + had done, … would be）写一个 3 句以上的句群，写兔子许愿、提议搜寻、掉在路上的那根胡萝卜失而复得的一幕（只写路上那根，不写失窃案结局）；句与句之间用连接词（then / and / so / but）或指代（she / it / them）衔接，不写孤立造句。

## 8. 参考答案与解析

- **B1**：**B**。wish + had done 是与过去事实相反的愿望——刚才没找到，已无法改变。
- **B2**：**B**。suggest / demand / order / insist / require 后的 that 从句用 (should) + 动词原形，跟主语无关。
- **P1**：**knew**。wish + 过去式 = 与现在事实相反的愿望，know 退成 knew。
- **P2**：**had found**。wish + had done = 与过去事实相反的愿望，find 退成 had found。
- **P3**：**search**。suggest 后的 that 从句用 (should) + 动词原形，should 省了动词也不加 s。
- **S1**：参考：**I wish I knew who took the carrots. / I wish it had found the carrot. / The rabbit suggests that everyone (should) search the forest.**（wish 两档退移、(should) + 原形对即可）。
- **S2**：参考：**The rabbit wishes that she had locked the door last night. / She suggests that everyone should search the forest before dark. / The little mouse finds the dropped carrot on the road, and it brings it back to Carrot Home. / If the mouse had not looked again, the dropped carrot would still be on the road.**（句型对、句数达标、有衔接手段，三档自判即可）。
- **Q1**：**B**。had done 是与过去事实相反的愿望；A 用过去式 knew，是与现在事实相反。
- **Q2**：**原形**。(should) + 动词原形，should 可省但动词保持原形。
- **Q3**：**B**。省略 if 的倒装还原：Had + 主语 = If + 主语 + had——还原 If we had asked the mouse to watch the shop。
- **Q4**：**现在**。wish + 一般过去时 = 与现在事实相反的愿望。
- **Q5**：**A**。与现在事实相反：主句 would + 动词原形（U08L64）。
- **Q6**：**gave；did not close**。一般过去时谓语用过去式 give → gave（不规则）；否定请 did 助阵：did not + 动词原形 close（U03L20）。
