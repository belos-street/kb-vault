# U05L42：状语从句 II：原因、让步、目的、结果

> 学完本课你能：**能按逻辑关系选对从属连词，避免中文直译病句（because × so 等「不同时现」铁律见 U07L59 收口）**。

---

## 1. 本课目标

今天只学一个点：**按逻辑关系选从属连词**。原因从句三兄弟按语气从重到轻排：because（直接原因）→ since（既然，已知事实）→ as（由于，顺带说明）；让步用 although / though（虽然）；目的用 so that + 从句（「以便」）；结果用 so + 形 / 副 + that（「如此……以至于」）。防病句预告（because 与 so 不能同现——归 U07L59 收口）。最后把状语从句九类连词速查一遍：时间 / 地点 / 原因 / 条件 / 让步 / 目的 / 结果 / 方式 / 比较。

## 2. 课文

- The wolf stays at the little shop for one more hour.
  狼在小店又待了一个钟头。
- The rabbit wants to know the reason why the wolf helped the family.
  兔子想知道狼帮助这家人的原因。
- Since the father helped the wolf years ago, the wolf helps the family now.{★ 原因从句 since：「既然」——原因大家都已知道，语气比 because 轻，把已知事实当理由摆出来}
  既然兔爸爸多年前帮过狼，狼如今也就帮这家人。
- The wolf kept the old box for many years, as it was the father's.{★ 原因从句 as：「由于」——三个原因连词里最轻、顺带说明；because 最重（直接原因），since「既然」次之}
  狼把旧盒子收了好多年，因为那是兔爸爸的。
- The two talk until the moon rises over the mountain.
  两人一直聊到月亮升上山顶。

- Although the wolf knew the family, he did not come to the shop for many months.{★ 让步从句 although：「虽然」——中文「虽然……但是……」进英语只留一个连接词，这句不能再加 but（「不同现」铁律的收口见 U07L59）}
  虽然狼认识这家人，可他好几个月都没来小店。
- The old box is so heavy that the rabbit cannot move it.{★ 结果从句 so … that：「如此……以至于」——so + 形容词 + that，that 从句说结果；与目的 so that 别混}
  旧盒子太沉了，兔子搬不动。
- The wolf works quickly in the garden so that the two can finish before dark.{★ 目的从句 so that：「以便」——主句是手段、从句是目的，从句常跟 can / could / will / would}
  狼在园子里干得很快，好让两人在天黑前干完。
- The news about the wolf travels from door to door.
  关于狼的消息一户传一户。

- Years ago nobody except the father believed the wolf.
  很多年前，除了兔爸爸，没有人相信狼。
- That was the real problem for a long time.
  很长一段时间里，这才是真正的问题。
- The idea surprises the little sheep, too.
  这个想法连小绵羊都吃了一惊。
- The two friends are tired, but the little shop is warm and bright.
  两位朋友累了，可小店又暖又亮。

## 4. 语法点精讲

**规则**：状语从句按「逻辑关系」选连词。**原因**：because（最重，直接原因）/ since「既然」（已知事实）/ as「由于」（顺带说明）。**让步**：although / though「虽然」（可互换，口语常用 though）。**目的**：`so that` + 从句（常跟 can / could / will / would）。**结果**：`so + 形 / 副 + that`、`such + 名词 + that`。**九类连词速查**：时间（when / while / before / after / until）、地点（where）、原因（because / since / as）、条件（if / unless）、让步（although / though）、目的（so that）、结果（so … that）、方式（as / as if）、比较（than / as … as）。防中文直译病句预告（because 与 so 不能同现——归 U07L59 收口）。

例句（✅ 正确 / ❌ 错误对照）：

- ✅ `Although the wolf ran fast, the rabbit escaped.` —— 让步从句已经「虽然」，不再加 but
- ✅ `The box is so heavy that the rabbit cannot move it.` —— so + 形容词 + that 表结果
- ❌ `Because the wolf was tired, so he sat down.` —— because 与 so 不能同现（归 U07L59 收口，此处不展开）

## 5. 练习

### 5.1 理解（选择）

**B1（选择）**：「The old box is so heavy that the rabbit cannot move it.」中 so … that 表示什么逻辑关系？
- A. 时间
- B. 目的
- C. 结果（如此……以至于）
- D. 让步

**B2（选择）**：为什么不能写「Because the wolf was tired, so he sat down.」？
- A. because 拼写错了
- B. because 与 so 不能同现，一句话只留一个连接词
- C. tired 用错了
- D. so 只能放句首

### 5.2 操练（替换）

**P1（操练）**：The wolf works fast. → The wolf works fast ______ the two can finish before dark.（提示：目的连词）

**P2（操练）**：The box is heavy. → The box is ______ heavy ______ the rabbit cannot move it.（提示：程度副词, 结果连词）

**P3（操练）**：The wolf knew the family. → ______ the wolf knew the family, he did not come to the shop for many months.（提示：让步连词）

### 5.3 产出（自判）

**S1（产出）**：用 because / although / so that / so … that 各造一句（写「虽然……但是……」时只留一个连接词），并说出每句的逻辑关系。

## 8. 参考答案与解析

- **B1**：**C**。so + 形容词 + that 表结果「如此……以至于」；表目的用 so that，中间不加形容词。
- **B2**：**B**。because 与 so 不能同现，一句话只留一个连接词（「不同现」铁律归 U07L59 收口，本课不展开）。
- **P1**：**so that**。目的从句「以便」用 so that 引导，从句常跟 can / could / will / would。
- **P2**：**so；that**。结果句式 so + 形容词 + that：so heavy that …——第一空 so、第二空 that。
- **P3**：**Although（或 Though）**。让步「虽然」用 although / though，后面不能再加 but。
- **S1**：参考：**The rabbit is happy because the wolf came. / Although the box is heavy, the rabbit can move it. / The wolf works fast so that the rabbit can rest. / The box is so heavy that nobody can move it.**（逻辑关系与连接词对上、不同现病句避开即可）。
- **Q1**：**B**。although 已经「虽然」，句中不再用 but——「虽然……但是……」进英语只留一个连接词。
- **Q2**：**so**。表目的「以便」= so that + 从句。
- **Q3**：**C**。语气强弱：because（直接原因）最重，since「既然」（已知事实）次之，as「由于」（顺带说明）最轻。
- **Q4**：**that**。结果句式 = so + 形容词 + that（或 such + 名词 + that）。
- **Q5**：**B**。主将从现：时间从句谈将来用一般现在时 grow，主句才用 will make（U05L41）。
- **Q6**：**in（或 at）**。where = in / at which，关系副词拆开就是「介词 + which」（U05L39）。
