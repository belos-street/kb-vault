# 考研英语（二）学习大纲

> 面向考研英语（二）的学习路径骨架，章节内容逐步填充。

---

## 📌 元信息

| 项目 | 说明 |
|------|------|
| **考试定位** | 考研英语（二），满分 100 分（专硕考卷，难度略低于英语一） |
| **整卷结构** | 完形填空 10 分 + 阅读理解 40 分 + 新题型 10 分 + 翻译（英译汉段落，约 150 词）15 分 + 小作文 10 分 + 大作文（图表作文）15 分 |
| **核心能力** | 词汇量（约 5500）+ 长难句解析 + 篇章逻辑 + 写作输出 |
| **教材推荐** | 真题为纲（近 15 年），搭配词汇书与长难句教程 |

## ✅ 阶段验收清单

- [ ] 大纲词汇过完一轮，核心词能辨析常用义与熟词僻义
- [ ] 能在 1 分钟内拆解一个 40 词左右的长难句主干
- [ ] 阅读真题单篇错误 ≤ 1 个（15~18 分钟/篇限时）
- [ ] 翻译真题（15 分制）能拿到 9 分以上
- [ ] 大小作文能限时完成且无模板痕迹
