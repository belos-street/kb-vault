## 目录结构

| 目录       | 定位                                       |
| ---------- | ------------------------------------------ |
| postgraduate-english/ | 考研英语（二）应试主线（题型导向：词汇长难句 → 阅读 → 完形 → 翻译 → 写作） |

## 约定

- 教学文档放 `doc/`，章节用数字前缀 + 中文命名（如 `01-词汇与长难句`）
- 练习题放 `exercises/`，分层命题（基础 / 强化 / 真题级），配合 exam-item-toolkit 出题与审题
- 每个方向目录配 `readme.md` 作为学习大纲或索引
