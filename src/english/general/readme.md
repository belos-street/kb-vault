# 通用英语体系化学习架构（v2）

> 参考新概念英语（NCE）的分级递进理念，从作者当前水平到考研英语二上限。**三册大纲已定稿（v2），详细课程表见各册 readme。**

---

## 🎯 设计理念

1. **起点校准**：作者词汇量 3000+（约高考水平），第一册从「句子工程」切入，**不设字母、音标等零起点内容**
2. **三册递进**：每册锁定一个能力台阶，终点对接 [考研英语（二）](../postgraduate-english/readme.md)
3. **课文为核**：借鉴 NCE 学习闭环 — 精读课文 → 词汇积累 → 语法拆解 → 输出练习，不孤立背单词
4. **语料开发者向**：课文优先选技术 / 工作场景语料，贴近作者日常（见 agents.md 作者画像）
5. **单元制组织**：每册按能力块划分 unit，unit 内按讲推进
6. **能力 / 应试分离**：本目录只管能力建设（读懂、写得出），应试套路归 postgraduate-english
7. **词汇随课文走**：不单设词汇单元（词根词缀等系统方法论除外），每单元自带词汇清单；**精讲唯一 + 自然复现**，由词汇台账管理（见下文）

## 🔁 每讲学习闭环

```mermaid
flowchart LR
    A["课文精读"] --> B["生词与词组"]
    B --> C["语法点拆解"]
    C --> D["复述 / 仿写输出"]
    D --> E["分层练习"]
    E -->|"错题回流"| A
```

> 每讲 = 一篇 md 笔记，五个环节齐全才算完成；**输出环节不可省略**。

### 每讲笔记结构（模板）

```markdown
# 第 X 讲：<课文标题>

> 学完本讲你能：<一句话能力目标>

## 1. 课文精读
- 原文（分段）+ 参考译文 + 关键句解析

## 2. 词汇与词组
- 表格：单词/词组 | 音标 | 释义 | 课文例句 | 拓展搭配

## 3. 语法点拆解
- 本讲核心句法：句子结构图解 + 同类句归纳

## 4. 输出
- 复述：口头/文字复述课文大意
- 仿写：替换要素造句或成段

## 5. 配套练习
- 链接 exercises/ 对应分层题目
- 错题记录：错因 + 回流安排

## 6. 本讲小结
- [ ] 自查清单（对应本讲目标逐条打勾）
```

> 中间 1~5 对应学习闭环五环节；开头「目标」与结尾「小结」保证每讲可自测验收。

## 📖 三册课程大纲（融会贯通）

> 详细课程表以各册 readme 为**单一事实源**（大纲已定稿）；三册按「语法 / 词汇 / 能力」三条阶梯贯通设计，每册毕业验收即下一册入学前置。

- [第一册 · 巩固篇](book-01-foundation/readme.md) — **35 讲** ｜ 语法重建（句型 → 时态 → 从句 → 非谓语被动）+ 高频词群
- [第二册 · 进阶篇](book-02-intermediate/readme.md) — **33 讲** ｜ 长难句工程 + 词根词缀扩词（4200 → 5500）
- [第三册 · 高阶篇](book-03-advanced/readme.md) — **27 讲** ｜ 真题精读 + 翻译图表作文 + 考研衔接

### 三阶梯衔接总览

| 阶梯 | 第一册 巩固篇 | 第二册 进阶篇 | 第三册 高阶篇 |
|------|--------------|--------------|--------------|
| **语法** | 五大句型 → 时态 → 从句 → 非谓语被动（重建） | 长难句工程：嵌套 / 倒装 / 平行（组合应用） | 真题密度下的自动化运用 |
| **词汇** | 3000 → 4200：课文精讲 + 高频词群 | 4200 → 5500：词根词缀 + 话题词群 | 5500 深度化：熟词僻义 + 超纲词带 |
| **能力** | 句子读写准 + 篇章方法入门 | 篇章读得快、段落写得好 | 应试语篇 + 翻译作文 |

> 单元 / 课数约定：每册 4 个单元；每单元课数不固定（5~12 讲，衔接 / 验收类单元可短至 5 讲），讲完即闭环，不为凑数拆分。

## 📒 词汇台账与课文生成

> 课文与练习的批量生成由 [english-lesson-crafter](../../../.agents/skills/english-lesson-crafter/SKILL.md) 工作流执行（触发：「写 L02」「继续下一讲」「生成课文」）：大纲定位 → 台账查重 → 六节模板成文 → 分层命题 → 台账回写 → 五查自审。

### 词汇台账（解决「精讲重复 / 复现缺失」）

- **每册一份**：`book-0X-xxx/vocab-ledger.md`，第一册已初始化（[book-01-foundation/vocab-ledger.md](book-01-foundation/vocab-ledger.md)，13 词）
- **精讲唯一**：词汇表只收未精讲词，同一词不二次进表
- **自然复现**：旧词在后续课文 / 例句 / 练习中反复出现并记录（复现率 ≥ 30%）— 复现是抗遗忘手段，不是重复缺陷
- **升级讲**：旧词新义（熟词僻义等）单独标注，不算新授
- **状态流转**：新授 → 复现中（复现 ≥ 2 次）→ 已掌握（输出中正确使用 ≥ 1 次）

### 与既有 skill 的分工

| skill | 在本体系中的角色 |
|-------|----------------|
| english-lesson-crafter | 课文 + 练习生成、词汇台账维护、交付前五查自审 |
| exam-item-toolkit | 练习命题规范（分层 / 查重 / 双链核验），被 english-lesson-crafter 引用 |
| doc-quality-reviewer | 深度质量审查（六维评分），交付后可选触发 |
| syllabus-designer | 三册大纲设计（已完成定稿），大纲改版时再用 |
