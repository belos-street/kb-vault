# 第三册 · 高阶篇 · 完整课程

> 六级（5500）→ 考研英语二。语料以考研英语二真题为主。
> **难度衔接**：考研二与六级词汇量相当（大纲均约 5500），难在熟词僻义、长难句密度与选项设计深度；初试不考听力，火力更聚焦。本册把第二册的语言能力转成应试语篇能力。
> **前置（第二册毕业）**：词汇 5500、45 词长句可拆、六级作文翻译达标。
> **去向**：毕业验收通过后进入 [postgraduate-english](../../postgraduate-english/readme.md) 真题应试题库。

## 📚 Unit 01 考研词汇深加工

> 单元目标：5500 从「认识」到「会用」：熟词僻义 + 超纲词带 + 语用色彩。

| Lesson | 标题 | 学习目的 |
|--------|------|---------|
| L01 | 熟词僻义 Top 100 | address / act / school / mean 等高频僻义；阅读中不再被「认识的词」骗 |
| L02 | 一词多义网络 | 以 run / call / book 等多义词为中心建义网，按语境定位词义 |
| L03 | 高频超纲词带 | 真题反复出现的约 200 超纲词：能推断词义即可，不死记 |
| L04 | 词汇的语用色彩 | 褒贬倾向、正式度、搭配限制；近义词不再随手乱换 |
| L05 | 短语动词与固定搭配 | come up with / put off / account for 等高频短语动词与介词搭配 |
| L06 | 词网复习法 | 自建词汇笔记的方法论：词群组织 + 间隔复习周期 |
| L07 | 综合实战：真题词汇 40 题自测 | 熟词僻义 + 搭配混合自测，完成单元验收 |

---

## 📚 Unit 02 真题难度篇章精读

> 单元目标：18 分钟 / 篇完成考研二阅读，正确率 ≥ 80%（单篇 5 题 ≥ 4）。

| Lesson | 标题 | 学习目的 |
|--------|------|---------|
| L01 | 英语二阅读文章画像 | 选题来源、题材分布、常见结构（现象 - 分析 - 态度） |
| L02 | 精读三遍法 | 限时速读 → 逐句精读 → 出题点回读；一套可复用的固定流程 |
| L03 | 细节题与选项陷阱四手法 | 无中生有 / 偷换对象 / 过度推断 / 张冠李戴的识别与排除 |
| L04 | 推理题与态度题 | 推理必须有原文依据；态度词库升级到考研级 |
| L05 | 主旨题与例证题 | 例子为观点服务；例证题问意图不问内容 |
| L06 | 新题型：多项对应与小标题 | 段落概括能力；小标题 = 给段落起「一句话名字」 |
| L07 | 精读笔记三件套 | 一篇真题 → 词汇 / 句型 / 结构三份笔记的整理规范（复用第二册拆句法） |
| L08 | 综合实战：近年真题一篇全流程 | 限时做题 + 三遍精读 + 笔记产出，完成单元验收 |

---

## 📚 Unit 03 段落翻译与图表作文

> 单元目标：翻译（15 分）≥ 9 分；图表作文 30 分钟成文；小作文格式全覆盖。

| Lesson | 标题 | 学习目的 |
|--------|------|---------|
| L01 | 英语二翻译评分标准 | 15 分 rubric 拆解：忠实 / 通顺 / 完整；直译与意译的边界 |
| L02 | 翻译 I：定语从句与分词结构 | 前置定语 vs 拆译成句的选择；分词结构的中文处理 |
| L03 | 翻译 II：被动句与代词还原 | 被动转主动的常见策略；it / they / this 指代对象的还原 |
| L04 | 图表作文 I：图表类型与描述句型 | table / bar / line / pie 四类图表各一套描述句型（复用第二册 L05） |
| L05 | 图表作文 II：趋势分析与原因段 | 数据 → 原因 → 结论的论证推进；原因段的展开方法 |
| L06 | 小作文：应用文格式库 | 书信 / 通知 / 备忘录的格式模板与语气分寸 |
| L07 | 综合实战：翻译 + 大小作文限时套训 | 按考试节奏限时完成一套写作翻译组合，完成单元验收 |

## 📚 Unit 04 考研衔接

> 单元目标：能力迁移到应试框架，正式进入 postgraduate-english 题库循环。

| Lesson | 标题 | 学习目的 |
|--------|------|---------|
| L01 | postgraduate-english 全景对接 | 五大题型分值地图（完形 10 / 阅读 40 / 新题型 10 / 翻译 15 / 写作 25）与本体系能力对照 |
| L02 | 能力自评与补差计划 | 用自测定位薄弱题型 → 生成 8 周补差计划 |
| L03 | 应试题库启用 | exam-item-toolkit 分层命题流程上手；进入「做题 → 审题 → 回流」循环 |
| L04 | 全真模拟 I | 完形 + 阅读 + 新题型限时联测（不含写作），建立题感基线 |
| L05 | 毕业验收 | 对照三册验收清单终审；通过后移交 postgraduate-english 主线 |
