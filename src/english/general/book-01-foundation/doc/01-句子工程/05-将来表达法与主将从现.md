# 第 5 讲：将来表达法与主将从现

> **第一册 · Unit 01 · Lesson 05** ｜ 预计用时 70 分钟
> 学完本讲你能：掌握 will / be going to / 现在进行表将来 / 时刻表用一般现在；if / when 从句「主将从现」成为条件反射。

---

## 1. 课文精读

**Next Quarter**

> Next quarter starts on Monday, and our roadmap is almost ready. If the new feature ships on time, we will close the biggest ticket of the year. "What will you do if the API changes?" someone asks. "If it changes, we will adapt the adapter — that is its job," I answer. The script will check every commit; when the tests turn green, we will deploy. The team is going to add two small services, and the intern will shadow me for a month. I am presenting the plan tomorrow morning; my calendar already reminds me. Remember: plans are cheap, but shipping is a superpower.

**参考译文**

> 下季度周一就开始了，路线图基本就绪。如果新功能按时上线，我们将完成今年最大的工单。"要是 API 变了怎么办？"有人问。"它变了，我们就改造适配器——这就是它的本职，"我回答。脚本会检查每一次提交；测试转绿，我们就部署。团队打算新增两个小服务，实习生会跟着我见习一个月。我明早要讲这个计划，日历已经在提醒我了。记住：计划很便宜，交付才是超能力。

**关键句解析**

| 句子 | 拆解 |
|------|------|
| Next quarter **starts** on Monday. | 时刻表/日程用**一般现在**表将来 — 不用 will |
| **If** the new feature **ships** on time, we **will close** the biggest ticket. | 主将从现：if 从句用一般现在，主句用 will |
| The team **is going to add** two services. | be going to = 事先的计划 |
| I **am presenting** the plan tomorrow morning. | 现在进行表将来 = 个人已定的安排 |

## 3. 语法点拆解

### 3.1 将来四件套

| 手段 | 含义侧重 | 课文句 |
|------|---------|--------|
| will | 临时决定 / 预测 | we **will** close the biggest ticket |
| be going to | 事先的计划 / 有征兆 | The team **is going to** add two services |
| 现在进行 | 个人已定的安排（常与人连用） | I **am presenting** the plan tomorrow |
| 一般现在 | 时刻表 / 日程 | Next quarter **starts** on Monday |

### 3.2 主将从现（本册最高频考点）

- **时间 / 条件从句**（when, if, as soon as, until, before, after）用**一般现在**表将来
- 主句才用 will / be going to

| ✅ 正确 | ❌ 错误 |
|---------|---------|
| If it **changes**, we will adapt. | If it **will change**, we will adapt. |
| When the tests **turn** green, we will deploy. | When the tests **will turn** green... |
| I will call you as soon as I **get** back. | I will call you as soon as I **will get** back. |

💡 判别法：从句说的是「条件 / 时间」，不是「预测」— 预测只属于主句。

### 3.3 课文句标注

| 句子 | 拆解 |
|------|------|
| If the feature ships..., we will close... | 从句一般现在 ✅ + 主句 will ✅ |
| What will you do if the API changes? | 疑问句同理：主句 will，从句 changes |
| when the tests turn green, we will deploy | when 从句主将从现 |

## 4. 输出

1. **复述**：用 3 句复述下季度计划（路线图 → if 条件 → 实习生安排），至少 1 句主将从现
2. **仿写（核心）**：写你的下周计划 5 句 — 四种将来各 1 句 + 1 句主将从现。参考起点：
   - will: I will write the design doc tomorrow.
   - be going to: We are going to refactor the auth module.
   - 进行表将来: I am meeting the team on Tuesday.
   - 时刻表: The sprint starts on Friday.
   - 主将从现: If the demo goes well, we will ship it.
3. **自检**：每个 if / when 从句里的动词 — 是不是一般现在？
