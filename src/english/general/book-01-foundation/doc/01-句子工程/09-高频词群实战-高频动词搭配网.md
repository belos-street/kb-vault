## 1. 课文精读

**What Developers Do All Day**

> What do developers actually do all day? We get tickets, take notes, make decisions, and set priorities. We keep the builds green and run the tests. When a bug shows up, we get to the bottom of it: reproduce it, fix it, and take notes for next time. Good teams make time for review and set clear rules; they never get tired of asking why. My butler helps too — it sends me a summary, checks every task, and keeps the scripts running. You get better one small fix at a time: take it slow, make it work, set it free. Keep it simple, run it often, and let good habits compound.

**参考译文**

> 开发者每天到底在干什么？我们领工单、记笔记、做决定、定优先级。我们让构建保持绿色，把测试跑起来。bug 出现时，我们把它查个水落石出：复现它、修掉它、为下次记好笔记。好的团队会留出评审时间、定下清晰的规则；他们从不厌倦多问一句为什么。管家也在帮忙——它给我发摘要、检查每个任务、让脚本持续运行。你每次一小修，就变强一分：慢一点来，让它能用，然后放手。保持简单，经常运行，让好习惯复利生长。

**关键句解析**

| 句子 | 拆解 |
|------|------|
| We **get** tickets, **take** notes, **make** decisions, and **set** priorities. | 四大动词各带一个「万能宾语」— 英语的地道感来自动词 × 宾语的搭配，而非生僻词 |
| we **get to the bottom of** it | get 搭配：查个水落石出（= 彻底弄清） |
| it **keeps** the scripts **running** | keep + 宾语 + doing：让……持续运行（keep 的使役用法，升级讲内容） |

## 2. 词汇与词组

### 2.1 精讲：四大高频动词（各配搭配网）

| 动词 | 音标 | 开发场景搭配网 | 课文例句 |
|------|------|----------------|---------|
| get | /ɡet/ | get tickets 领工单 ｜ get to the bottom of 查到底 ｜ get better 变强 ｜ get tired of 厌倦 ｜ get started 开始 | You get better one small fix at a time. |
| take | /teɪk/ | take notes 记笔记 ｜ take it slow 慢慢来 ｜ take time 花时间 ｜ take over 接管 ｜ take care 保重 | take notes for next time. |
| make | /meɪk/ | make decisions 做决定 ｜ make time 挤时间 ｜ make it work 让它可用 ｜ make mistakes 犯错 ｜ make sense 说得通 | Good teams make time for review. |
| set | /set/ | set priorities 定优先级 ｜ set clear rules 定规则 ｜ set up 搭建 ｜ set a reminder 设提醒 ｜ set free 释放 | and set priorities. |

### 2.2 升级讲专区（已入账动词的深挖 — 不重复入账）

| 动词 | 首次入账 | 升级搭配网 |
|------|---------|-----------|
| keep | U01-L01（词群） | keep the builds green 让构建保持绿 ｜ keep it simple 保持简单 ｜ keep track of 跟踪 ｜ keep + 宾 + doing 让持续… |
| run | U01-L02（词群） | run the tests 跑测试 ｜ run into 遇上 ｜ run smoothly 运行顺畅 ｜ in the long run 长远看 |

> 💡 「弱动词 + 万能宾语」是英语的默认节奏：**make a decision** 比 *decide* 更口语，**take a look** 比 *look* 更自然。学会借力，输出速度翻倍。

## 3. 语法点拆解

### 3.1 搭配的「块状存储」

- 逐词翻译：*做* 决定 → ❌ do a decision
- 块状调用：make a decision ✅（动词与宾语是**固定搭档**，不可互换）

| 高频错误 | 正确搭配 | 记忆点 |
|----------|---------|--------|
| do a decision | **make** a decision | make 造出结果 |
| take a decision（英式正式用法，美式少用） | **make** a decision（通用） | 同上 |
| get notes | **take** notes | take 拿走信息 |
| make up your mind ≠ take up | **make** up one's mind 下决心 | mind 是做出来的 |

### 3.2 keep 的使役结构（升级讲核心）

- keep + 宾语 + doing：**让某物持续做某事**
  - it keeps the scripts **running**（让脚本持续运行）
  - Sorry to keep you **waiting**
- 对照 L01 的 keep it simple（keep + 宾 + adj）：keep 后可接形容词或 -ing，语义都是「维持」

### 3.3 课文复现自查

本讲课文中出现的已入账词：developer / ticket / keep / build / run / test / bug / reproduce / fix / review / butler / send / summary / check / task / script — 共 16 个旧词类型，占课文词形约 33%（≥ 30% 达标）。
