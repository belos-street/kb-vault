## 1. 课文精读

**Why Scripts Beat Memory**

> Developers forget things. Not because our memory is weak, but because we juggle too many tasks. Last month, I forgot to renew a certificate, and the whole service went down for an hour. Since then, my rule has been simple: if a task happens twice, it becomes a script. My scripts now check the backups, run the reports, and keep the logs clean. When something breaks, the pipeline tells me before users do. Nobody remembers everything; good systems remember for us. Writing a script takes ten minutes, but it keeps working for years. The first version was ugly, but it worked. I have improved it week by week, and today it saves me hours every month. Rarely does a small tool pay off so well — small efforts, repeated automatically, turn into big results.

**参考译文**

> 开发者会忘事。不是因为记性差，而是因为我们同时玩转的任务太多。上个月，我忘了续一个证书，整个服务挂了一个小时。从那以后，我的规则很简单：一个任务发生两次，它就变成一个脚本。我的脚本现在检查备份、跑报表、保持日志干净。出问题的时候，流水线比用户更早告诉我。没人记得住所有事；好的系统替我们记。写一个脚本只要十分钟，但它能连续工作好几年。第一版很丑，但它能用。我一周一周地改进它，如今它每月为我省下数小时。一个小工具很少有这么高的回报——小的努力被自动化地重复，就变成大的成果。

**关键句解析**

| 句子 | 拆解 |
|------|------|
| **Since then**, my rule **has been** simple. | since then + 状态持续至今 → 现在完成 |
| **if** a task **happens** twice, it **becomes** a script. | 主将从现（L05）：从句一般现在，becomes 也是一般现在表规律 |
| **Nobody remembers** everything. | 不定代词单数（L06） |
| **Writing a script takes** ten minutes. | 动名词短语作主语 = 单数（L06 一致 + U03 钩子） |
| **Rarely does** a small tool **pay off** so well. | 否定倒装（L07）：还原 = A small tool rarely pays off so well. |

## 3. 语法点拆解（Unit 01 语法线总装）

### 3.1 全篇时态地图

| 时态 | 课文句 | 坐标 |
|------|--------|------|
| 一般现在 | My scripts **check** the backups. | 现在 × 一般（规律） |
| 一般过去 | I **forgot** to renew a certificate. | 过去 × 一般 |
| 现在完成 | my rule **has been** simple / I **have improved** it | 现在 × 完成 |
| 主将从现 | if a task **happens** twice, it **becomes** a script | 条件规律（一般现在承载） |
| 否定倒装 | Rarely **does** a small tool **pay** off | 强调手段，不影响时态 |

### 3.2 标注示范（成分 + 句型 + 时态）

| 句子 | 标注 |
|------|------|
| The first version was ugly, but it worked. | S+V+P ①⑤ 并列 ｜ 过去一般 |
| the pipeline tells me before users do | S+V+O+O ③ ｜ 现在一般（do 代指 tells me） |
| small efforts ... turn into big results | S+V ①（turn into 介宾）｜ 现在一般 |

### 3.3 自主标注区（做练习 1 之前先自己标这 3 句）

1. Developers forget things.
2. Since then, my rule has been simple.
3. Nobody remembers everything; good systems remember for us.

## 4. 输出

1. **复述**：用 4 句复述「脚本打败记忆」的论证链（忘事 → 事故 → 规则 → 回报）
2. **仿写（核心）**：写你自己的自动化小故事 5 句 — 要求覆盖 3 种时态 + 1 句主将从现 + 1 句 nobody / everybody。参考起点：
   - 过去：Last year, I forgot to renew the domain.
   - 现在：My script checks the expiry date every day.
   - 完成：Since then, no service has gone down because of me.
   - 主将从现：If the date is within seven days, it will open a ticket.
   - 不定代词：Everybody on the team has a copy of the checklist.
3. **自检**：对照本讲 3.1 时态地图 — 5 句是否各就各位？
