## 基础层

**1. 选时态**（一般过去 / 现在完成 / 过去完成）：

1. I ___ (join) the team in 2023.
2. She ___ (fix) three bugs so far this week.
3. By the time the alert fired, the backup ___ (finish) already.
4. Our monitor ___ (catch) every error since last month.
5. When I arrived, everyone ___ (leave).
6. The butler ___ (just / check) the logs.

**2. since / for 填空**：

1. The service has been down ___ two hours.
2. Nobody has touched this module ___ 2024.
3. We have followed this playbook ___ the last incident.
4. It has kept running ___ six weeks without a restart.

**3. 改错**：

1. She has saw this error before.
2. When I arrived, they already left.
3. He has finished the task yesterday.

## 强化层

**5. 时间轴写作**：用 3 句写一次小事故 — 句 1 一般过去（锚点）、句 2 过去完成（锚点前）、句 3 现在完成（影响至今）。

**6. 对比造句**：用下列两组时间提示各造一句，体会差异。

1. yesterday + fix（一般过去）
2. since Monday + fix（现在完成）

---

## 答案


**1.**
1. joined — in 2023 具体过去时间 → 一般过去（完成时不与具体过去时间连用）
2. has fixed — so far this week → 现在完成
3. had finished — By the time + 过去锚点（the alert fired）→ 锚点之前 → 过去完成
4. has caught — since last month 持续到现在 → 现在完成；catch 不规则：catch → caught → caught
5. had left — arrived 是过去锚点，离开在锚点之前 → 过去完成
6. has checked — just 是现在完成的标志词（美式口语中也用一般过去 checked；本册取完成时口径）

**2.**
1. for — two hours 时间段
2. since — 2024 时间点
3. since — the last incident 事件 = 时间点
4. for — six weeks 时间段

**3.**
1. She has **seen** this error before. — see 的过去分词是 seen（see → saw → seen）
2. When I arrived, they **had already left**. — arrived 是过去锚点，离开在其之前 → 过去完成
3. He **finished** the task yesterday. — yesterday 具体过去时间，禁用完成时；改用一般过去

**4.**
1. A — 第 1 句：The release has just gone out, and my phone has already buzzed three times.
2. C — 第 2 句：A user says the app has crashed twice since the update.
3. B — 第 5 句：revert first, ask questions later.
4. D — 语法 3.1：现在完成 = have / has + 过去分词，表影响延续、经验、持续，与现在挂钩。
5. A — 语法 3.2 判决规则：过去完成必须有一个「过去的锚点」（过去的过去）。
6. C — 语法 3.1 / 3.3：since + 时间点（持续到现在）→ 现在完成；yesterday / in 2023 / last month 是具体过去时间 → 一般过去。

**5.**（主观题 — 参考要点）
- 要点覆盖：句 1 一般过去作锚点（如 At 9 a.m., the alarm fired）；句 2 had done 描述锚点前的动作（如 The intern had pushed the config the night before）；句 3 have done 讲影响至今（如 We have added a review step since then）
- 自检要点：句 2 的 had done 必须能指出句 1 作为锚点；句 3 不得出现具体过去时间

**6.**（主观题 — 参考要点）
- 要点覆盖：yesterday + fix → I fixed the bug yesterday.（具体过去时间）；since Monday + fix → I have fixed five bugs since Monday.（起点到现在的累计）
- 自检要点：第一句不能加 have；第二句不能写具体星期几的过去点
