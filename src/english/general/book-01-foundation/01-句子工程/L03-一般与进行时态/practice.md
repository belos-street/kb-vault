# L03 练习：一般与进行时态

> 配套 [第 3 讲](lesson.md)。基础层必做，强化层选做。答案在文末，做完再看。

## 基础层

**1. 选时态**（一般 or 进行）：

1. Listen! The build ___ (fail) again.
2. Our team ___ (deploy) every Thursday.
3. She ___ (check) the dashboard right now.
4. The service ___ (need) a restart.
5. Look — the pipeline ___ (run) twice as fast this week.

**2. 状态动词纠错**（下列句子各含一处状态动词误用，改正）：

1. I am wanting a new keyboard.
2. She is seeming tired today.
3. They are owning three servers.

**3. 翻译**（指定时态）：

1. 我们每天开站会。（一般）
2. 我这周正在写登录页。（进行）
3. 这个 API 需要一个新令牌。（状态）

**4. 分类**：把下列动词填入「状态」或「动作」。

know ｜ run ｜ prefer ｜ restart ｜ belong ｜ interrupt

**5. 课文理解与语法**：先读课文，再作答；每题只有一个正确选项。

## 强化层

**6. 晨会汇报**：写 5 句你的真实晨会汇报（3 句一般时 + 2 句进行时，至少 1 句含状态动词）。

**7. 短文判断**：下列 4 处画线部分，判断正误，错的改正。

> Today everyone is agree that the deploy goes well. Lin is knowing the risks, and she checks the logs twice a day. The service is needing more memory, but the dashboard shows everything is fine.

---

## 答案


**1.**
1. is failing — Listen! 提示此刻正在发生 → 现在进行（还原：The build is failing = 失败正在发生）
2. **deploys** — every Thursday 习惯 → 一般现在；team 集合名词作整体 = 单数（L06 意义一致），三单加 -s
3. is checking — right now → 现在进行
4. needs — need 是状态动词，禁止进行式（❌ is needing）
5. is running — this week 现阶段 + Look 提示 → 现在进行（与每周惯例的 runs 区分）

**2.**
1. I **want** a new keyboard. — want 是状态动词，不用进行
2. She **seems** tired today. — seem 状态动词；today 不改变「状态不进行」规则
3. They **own** three servers. — own 表所有关系，状态动词

**3.**
1. We have a standup meeting every day.（或 We hold a standup every day.）
2. I am writing the login page this week.
3. This API needs a new token.（need 状态动词，一般时）

**4.** 状态：know, prefer, belong；动作：run, restart, interrupt

**5.**
1. C — 第 2 句：The team stands in a circle — nobody sits, nobody checks the phone.
2. A — 第 7 句：The dashboard behind us shows real numbers: uptime, errors, response times.
3. D — 第 6 句：\"Not good. It runs slowly because the cache keeps missing.\"
4. B — 语法 3.2 状态动词清单：情感 / 认知 / 属性类动词描述状态，禁止 -ing。
5. A — 语法 3.2 提示：have 表状态（拥有）不进行，表动作（have lunch）可进行。
6. C — 语法 3.2：look（看起来）/ need 是状态动词，描述属性，不用进行式。

**6.**（主观题 — 参考要点）
- 要点覆盖：3 句一般（习惯 / 惯例 / 状态），2 句进行（本周进行中）；状态动词句无 -ing
- 自检要点：进行句必须有 be + -ing；一般句遇到三单主语记得加 -s；状态动词逐个对 3.2 清单

**7.**
1. is agree → **agrees** — agree 是动词，前面不加 is（is + 动词原形不构成时态）
2. is knowing → **knows** — know 状态动词
3. is needing → **needs** — need 状态动词
4. shows ✓（无误）— dashboard 属性用一般时正确
