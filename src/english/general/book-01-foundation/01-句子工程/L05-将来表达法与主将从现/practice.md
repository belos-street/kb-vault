# L05 练习：将来表达法与主将从现

> 配套 [第 5 讲](lesson.md)。基础层必做，强化层选做。答案在文末，做完再看。

---

## 基础层

**1. 选将来手段**（will / be going to / 现在进行 / 一般现在）：

1. Look at those clouds — it ___ rain.（有征兆）
2. The train ___ at 6:40 tomorrow.（时刻表）
3. I ___ having lunch with the client at noon.（已定安排）
4. OK, I ___ help you with that.（临时决定）
5. We ___ to rewrite the whole module next month.（早有计划）

**2. 主将从现填空**：

1. If it ___ (rain) tomorrow, the outdoor demo will be cancelled.
2. I will call you as soon as the build ___ (pass).
3. Before the release ___ (go) out, we will test it again.
4. When she ___ (arrive), we will start the review.
5. If you ___ (not hurry), we will miss the deadline.

**3. 改错**：

1. If it will rain, we will stay inside.
2. We are go to ship on Friday.
3. When I will finish the report, I will send it to you.

---

## 强化层

**4. 计划写作**：写你的下周计划 5 句 — will / be going to / 现在进行 / 时刻表一般现在 / 主将从现 各一。

**5. 条件链**：用 if 写一个部署决策链（3 层）：测试绿 → 部署；部署成功 → 通知；通知发出 → 关工单。

---

## 答案


**1.**
1. is going to — 看云识雨 = 有征兆 → be going to
2. leaves / starts — 时刻表用一般现在（The train leaves at 6:40 ✓）
3. am — 现在进行表已定安排（I am having lunch with the client）
4. will — 说话瞬间才决定 → will
5. are going — be going to + 动词原形：are going to rewrite（计划已久）

**2.**
1. rains — if 从句主将从现（❌ will rain）
2. passes — as soon as 时间从句，一般现在（build 三单加 -s）
3. goes — before 时间从句；release 三单 goes
4. arrives — when 时间从句
5. don't hurry — if 从句否定：don't + 原形（主句 will miss 保持将来）

**3.**
1. If it **rains**, we will stay inside. — if 从句禁用 will
2. We **are going to** ship on Friday. — be going to + 动词原形，go 不能叠加 be going
3. When I **finish** the report, I will send it to you. — when 从句用一般现在

**4.**（主观题 — 参考要点）
- 要点覆盖：will 句 = 即时决定或预测；be going to = 既定计划；进行句 = be + -ing + 将来时间；时刻表句 = 主语是日程/班车/季度类；主将从现句 = if/when 从句用一般现在
- 自检要点：从句逐个检查是否混入 will；进行句是否有 be；时刻表句的主语是否适合用一般现在表将来

**5.**（主观题 — 参考要点）
- 要点覆盖示例：If the tests pass, we will deploy. / If the deploy succeeds, we will notify the team. / Once the notice goes out, we will close the ticket.
- 自检要点：每层前半句是从句（一般现在），后半句主句（will）；不允许出现 if ... will 的组合
