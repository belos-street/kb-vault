## 基础层

**1. 全句标注**：对下列课文句标注「成分 + 句型（①~⑤）+ 时态」。

1. Last month, I forgot to renew a certificate.
2. Writing a script takes ten minutes.
3. When something breaks, the pipeline tells me before users do.
4. Rarely does a small tool pay off so well.

**2. 时态定位**：说出下列句子的「时间 × 体」坐标。

1. My rule has been simple since then.
2. The first version was ugly.
3. Good systems remember for us.
4. I have improved it week by week.

**3. 改错**（每句一处，覆盖前七讲）：

1. Every one of my scripts have a name.
2. If a task will happen twice, it becomes a script.
3. Nobody remember the old config.
4. The build has broke again this morning.

**4. 课文理解与语法**：先读课文，再作答；每题只有一个正确选项。

1. 课文认为开发者忘事的主要原因是什么？
   A. 记性太差
   B. 同时要应付的任务太多
   C. 工作太忙、没时间做笔记
   D. 从不使用自动化工具
2. 作者现在给自己定下的规则是什么？
   A. 一个任务发生两次，就把它变成脚本
   B. 每天备份一次重要数据
   C. 只自动化写代码相关的任务
   D. 每次出错都手动记录原因
3. 当某样东西出问题时，谁会先把结果告诉作者？
   A. 用户
   B. 同事
   C. 流水线（pipeline）
   D. 日志文件
4. 「Nobody remembers everything.」中 remembers 为什么用单数形式？
   A. 因为 everything 是单数，所以前面动词要加 -s
   B. 因为这句话表示过去的事
   C. 因为 remember 是不可数动词
   D. 因为 nobody 是不定代词，作主语时视为单数第三人称
5. 「My scripts now check the backups, run the reports, and keep the logs clean.」中 check / run / keep 都用一般现在时，是因为？
   A. 描述过去一段时间发生的事
   B. 表示将来一定会发生
   C. 描述现在的常规、习惯性动作（现在 × 一般）
   D. 表示此刻正在进行的动作
6. 「If the date is within seven days, it will open a ticket.」中，if 从句为什么用 is 而不是 will be？
   A. 因为从句里不能用 be 动词
   B. 因为 is 是现在完成时的标志
   C. 因为这是对过去事实的假设
   D. 因为主将从现：条件从句用一般现在表示将来

## 强化层

**5. 自动化小故事**：写 5 句（3 种时态 + 1 句主将从现 + 1 句 nobody / everybody），主题：你生活或工作中的自动化。

**6. 合并挑战**（Unit 02 预告）：把每组的两个简单句合并成一个复合句（用 when / because）。

1. The backup finished. The alarm stopped. (when)
2. We trust the pipeline. It checks everything. (because)

## 答案


**1.**
1. Last month(状), I(S) forgot(V) to renew a certificate(O) — ② 主谓宾 ｜ 过去一般
2. Writing a script(S，动名词短语) takes(V) ten minutes(O) — ② ｜ 现在一般（动名词主语 = 单数）
3. When something breaks(状从，现在一般), the pipeline(S) tells(V) me(O·间) the result(O·直) before users do(状从) — ③ 主谓双宾 ｜ 现在一般
4. Rarely(状，否定倒装), does(助) a small tool(S) pay(V) off(动介) so well(状) — ① 主谓 ｜ 现在一般（倒装不改变时态）

**2.**
1. 现在 × 完成（has been，since then 持续至今）
2. 过去 × 一般（was，对过去的描述）
3. 现在 × 一般（remember，普遍规律）
4. 现在 × 完成（have improved，week by week 累计影响至今）

**3.**
1. Every one of my scripts **has** a name. — every one 单数（L06）
2. If a task **happens** twice, it becomes a script. — 主将从现（L05）
3. Nobody **remembers** the old config. — 不定代词单数三单（L06）
4. The build has **broken** again this morning. — 完成分词用 broken（break → broke → broken，L02 形态表）

**4.**
1. B — 定位课文：Not because our memory is weak, but because we juggle too many tasks.
2. A — 定位课文：if a task happens twice, it becomes a script.
3. C — 定位课文：the pipeline tells me the result before users do.
4. D — 规则依据：不定代词（nobody / everybody / someone 等）作主语视为单数第三人称，谓语用单数（L06 一致）。
5. C — 规则依据：一般现在表示现在的规律 / 习惯性动作；三个谓语并列，共享同一时间坐标（现在 × 一般）。
6. D — 规则依据：主将从现（L05）——if / when 引导的时间、条件从句用一般现在，主句用将来时。

**5.**（主观题 — 参考要点）
- 要点覆盖：过去一般 ≥1（讲起因）、现在一般 ≥1（讲规律）、现在完成 ≥1（讲影响）；1 句 if/when 主将从现；1 句 nobody / everybody 开头
- 自检要点：if/when 从句中无 will；nobody / everybody 后谓语单数；三句时态能画出时间轴

**6.**
1. When the backup finished, the alarm stopped. — when 引导时间状语从句
2. We trust the pipeline because it checks everything. — because 引导原因状语从句
- 自检要点：从句是「完整句子」，由连接词挂在主句上 — 这就是 Unit 02 从句体系的入口
