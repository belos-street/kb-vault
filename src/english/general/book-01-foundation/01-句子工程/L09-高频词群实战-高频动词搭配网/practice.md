# L09 练习：高频动词搭配网

> 配套 [第 9 讲](lesson.md)。基础层必做，强化层选做。答案在文末，做完再看。

---

## 基础层

**1. 选词填空**（get / take / make / set，注意形态）：

1. We need to ___ a decision before the demo.
2. She ___ notes during every code review.
3. Please ___ up the test environment today.
4. Did you ___ my point, or should I explain again?
5. The intern will ___ over the maintenance tasks next month.
6. Don't ___ the same mistake twice.
7. Let's ___ a reminder for the release day.
8. He wants to ___ better at debugging.

**2. 搭配判断**（✅ 地道 / ❌ 假搭配，假搭配请改正）：

1. do a decision
2. take notes
3. make sense
4. get the responsibility for this module
5. keep in touch

**3. 改错**（每句 1~2 处）：

1. She makes always notes during the standup.
2. He run the tests yesterday.
3. We need to do a decision now.

---

## 强化层

**4. 我的一天**：用 get / take / make / set / keep / run 各写一句，描述你真实的一天（6 句）。

**5. 弱动词升级**：把下列「be + 形容词/名词」句改写成搭配句。

1. I am responsible for the release.（take ...）
2. The meeting is at 9. Please arrive on time.（make ...）
3. Don't be angry about the bug.（get ...）

---

## 答案


**1.**
1. make — make a decision 固定搭配（make 造出结果）
2. takes — take notes 固定搭配；主语 she 三单
3. set — set up 搭建（set up the environment）
4. get — get my point = 懂我的意思（get it）
5. take — take over 接管
6. make — make the same mistake（mistake 与 make 搭配）
7. set — set a reminder 设提醒
8. get — get better at + 技能（变强）

**2.**
1. ❌ → **make** a decision（do 不与 decision 搭配）
2. ✅ take notes
3. ✅ make sense
4. ❌ → **take** the responsibility（responsibility 与 take 搭配）
5. ✅ keep in touch（保持联系）

**3.**
1. She **always takes** notes during the standup. — 频度副词位于实义动词前；notes 与 take 搭配
2. He **ran** the tests yesterday. — run 不规则过去式 ran（L02 形态表）
3. We need to **make** a decision now. — make a decision

**4.**（主观题 — 参考要点）
- 要点覆盖：6 句各用指定动词的一个**课文或拓展搭配**；不能自造搭配
- 自检要点：逐句回查 2.1 / 2.2 搭配网；形态正确（过去式 get→got、make→made、set→set、keep→kept、run→ran）

**5.**（主观题 — 参考要点）
1. I **take responsibility** for the release. — take responsibility 固定搭配
2. The meeting is at 9. Please **make it** on time. — make it = 赶到 / 做到
3. Don't **get angry** about the bug. — get + 形容词 = 变得（状态变化）
