# L07 练习：疑问句、否定句与否定倒装

> 配套 [第 7 讲](../../doc/01-句子工程/07-疑问句否定句与否定倒装.md)。基础层必做，强化层选做。答案在文末，做完再看。

---

## 基础层

**1. 句型转换**（改为疑问句）：

1. She fixed the bug yesterday.（一般疑问）
2. The pipeline runs every hour.（对 every hour 提问 — 特殊疑问）
3. Lin broke the build.（对 Lin 提问 — 主语疑问）
4. The senior dev knows everything.（一般疑问）

**2. 改错**：

1. How you fixed the cache?
2. Nobody know the answer.
3. I never have seen such a clean log.
4. Who did break the build?

**3. 倒装还原**（把倒装句还原成平装语序）：

1. Rarely does a first draft compile.
2. Never have I deployed on Friday again.
3. Seldom does the log lie.

---

## 强化层

**4. FAQ 写作**：给新同事写 3 条 Q&A（1 条一般疑问 + 1 条特殊疑问 + 1 条含 Never have I 的回答）。

**5. 互转**：平装 ↔ 倒装 双向转换。

1. 平装 → 倒装：I have never trusted a Friday deploy.
2. 倒装 → 平装：Not only did the tests fail, but the build also broke.

---

## 答案

<details>
<summary>点开查看答案（先做完再看）</summary>

**1.**
1. Did she fix the bug yesterday? — 过去疑问用 did + 原形（fixed 还原为 fix）
2. How often does the pipeline run? — every hour = 频率 → How often + does + 原形 run
3. Who broke the build? — 主语疑问不加 did（主语疑问句中动词保留过去式 broke）
4. Does the senior dev know everything? — 三单 does + 原形 know

**2.**
1. How **did** you fix the cache? — 特殊疑问 = 疑问词 + 一般疑问语序；did 后动词用原形 fix
2. Nobody **knows** the answer. — nobody 单数，谓语肯定式三单
3. I **have never seen** such a clean log.（或倒装 Never have I seen...）— never 要放在第一个助动词之后（have never seen）；原句把 never 放在助动词 have 之前是错误语序
4. Who **broke** the build? — 主语疑问不加 did

**3.**
1. A first draft rarely compiles.
2. I have never deployed on Friday again.
3. The log seldom lies.

**4.**（主观题 — 参考要点）
- 要点覆盖：一般疑问句以 Do/Does/Did 开头；特殊疑问句 = 疑问词 + 疑问语序；至少一处 Never have I + 过去分词
- 自检要点：did 后动词是否还原为原形；倒装句能否还原回平装

**5.**
1. Never have I trusted a Friday deploy.
2. 平装：The tests not only failed, but the build also broke.

</details>
