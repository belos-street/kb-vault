# L04 练习：定语从句 III

> 配套 [第 4 讲](lesson.md)。基础层必做，强化层选做。答案在文末，做完再看。

---

## 基础层

**1. 判断类型**：判断下列句中定语从句的类型（① 限制性 / ② 非限制性）。

1. The comment that pins the release steps is the first thing I read.
2. My shortest note, which is only three words, sits above the fold.
3. Readers who open the doc at midnight need a fast answer.
4. We shipped the guide on Friday, which relaxed the whole team.
5. The line that repeats the warning cannot be deleted.

**2. 加逗号变非限制**：把下列限制性定语从句改写为非限制性定语从句（加逗号；关系词 that 换成 which），整句重写。

1. The doc that lists every command is our most popular page.
2. The tip that explains the retry saved us an hour.
3. The header that adds a little context can move to the end.
4. The rule that we quoted in the meeting is one line long.

**3. 改错**：下列句子想表达「补充说明」，改正非限制性从句的错误。

1. The intro, that runs two lines, is enough.
2. My first comment, taught me a lot, is still in the repo.
3. We moved the note to the top, that saved the reader a minute.
4. The glossary, you can find below, uses plain words.

**4. 翻译**（两类型互译）：

1. 解释原因的那条注释最有用。（限制性）
2. 测试一次就通过了，这让所有人都很惊讶。（非限制性，which 指代整句）
3. The style guide, which fits on one card, is easy to follow.（译成并列分句）

---

## 强化层

**5. 判断下列 5 处正误**：正确的打 ✓，错误的改正。

1. The guide, which we rewrote last month, now reads in five minutes.
2. The rule that we always forget is the shortest one.
3. The bug, that hid in the comment, took hours to find.
4. The demo ran over time, which annoyed the client.
5. My notes, you see below, follow the same pattern.

**6. 造句**：以你的文档 / 注释写作习惯为主题写 4~5 句英文，必须含 1 个限制性定语从句、1 个非限制性定语从句（其中 which 指代前面整句）；非限制性从句两头有逗号、不用 that、不省略关系词。写完用「删从句测试」和「拆两句法」逐句自检。

---

## 答案

**1.**
1. ① 限制性。依据一（语法规则）：从句无逗号、紧跟 the comment，作用是限定「哪条注释」→ 限制性。依据二（删从句测试）：删掉后 The comment is the first thing I read 不知道指哪条，指代不明 → 限定必需。
2. ② 非限制性。依据一（语法规则）：从句两头逗号隔开，补充说明 my shortest note 的特点 → 非限制性。依据二（删从句测试）：删掉后 My shortest note sits above the fold 句义不变 → 补充说明。
3. ① 限制性。依据一（语法规则）：who 从句无逗号，限定「哪一类读者」→ 限制性。依据二（删从句测试）：删掉后 Readers need a fast answer 变成所有读者，句义改变 → 限定必需。
4. ② 非限制性。依据一（语法规则）：逗号 + which，补充说明「周五发了指南」这件事带来的结果 → 非限制性。依据二（删从句测试）：删掉后 We shipped the guide on Friday. 独立完整、句义不变。
5. ① 限制性。依据一（语法规则）：无逗号，that 从句限定「哪一行」→ 限制性。依据二（删从句测试）：删掉后 The line cannot be deleted 不知道指哪行，句义改变。

**2.**
1. The doc, which lists every command, is our most popular page. — 依据一（语法规则）：改写为非限制性需两头加逗号，且 that 禁入非限制 → 换 which。依据二（删从句测试）：删掉从句后 The doc is our most popular page 成立 → 补充说明，非限制合法。
2. The tip, which explains the retry, saved us an hour. — 依据一（语法规则）：补充说明「这条技巧」的内容 → 逗号隔开、that 换 which。依据二（改写还原）：The tip saved us an hour 成立，被删的部分只是补充信息 → 非限制性。
3. The header, which adds a little context, can move to the end. — 依据一（语法规则）：非限制性从句两头加逗号，关系词用 which。依据二（删从句测试）：The header can move to the end 成立 → 补充说明。
4. The rule, which we quoted in the meeting, is one line long. — 依据一（语法规则）：非限制性从句不用 that、也不省略关系词，必须补出 which。依据二（删从句测试）：The rule is one line long 成立 → 补充说明。

**3.**
1. The intro, **which** runs two lines, is enough. — 依据一（语法规则）：逗号已标记非限制性从句，that 禁入，只能用 which。依据二（排除法）：去掉逗号改回限制性（The intro that runs two lines...）或换 which 二选一；「逗号 + that」的组合不存在。
2. My first comment, **which** taught me a lot, is still in the repo. — 依据一（语法规则）：非限制性从句的关系词不能省略，须补 which。依据二（改写还原）：补 which 后插入成分自带主谓（which taught me a lot），主干 My first comment is still in the repo 完整。
3. We moved the note to the top, **which** saved the reader a minute. — 依据一（语法规则）：which 可指代前面整句；that 既禁入非限制，也不能指代整句。依据二（拆两句法）：We moved the note to the top. **This** saved the reader a minute. 成立 → which = 整句。
4. The glossary, **which** you can find below, uses plain words. — 依据一（语法规则）：非限制性从句不用省略，补 which。依据二（改写还原）：补 which 后从句自带主谓，主干 The glossary uses plain words 完整。

**4.**
1. The comment that explains the why is the most useful one.（或 The comment that explains the reason matters most.）
2. The tests passed on the first try, which surprised everyone.（或 ..., which surprised the whole team.）
3. 风格指南只有一张卡片那么大，很容易跟着用。（参考译文，措辞不唯一）
- 要点覆盖：第 1 句用限制性从句（无逗号，限定哪条注释）；第 2 句用非限制性从句且 which 指代前面整句；第 3 句把 which 从句译成并列分句，不译成「……的」
- 自检要点：第 1 句删掉从句后「哪条注释」不明 → 限制性用对；第 2 句用「拆两句法」验证（The tests passed on the first try. **This** surprised everyone.）；第 3 句译文里补充信息独立成句（「……，很容易……」）
- 达标线：三句的从句类型与译法全部匹配、主干无错，即通过

**5.**
1. ✅ 正确。依据一（语法规则）：逗号 + which 引导非限制性从句，补充说明 the guide。依据二（删从句测试）：The guide now reads in five minutes 成立 → 非限制合法。
2. ✅ 正确。依据一（语法规则）：无逗号的限制性从句用 that 引导（L02 规则），限定「哪条规则」。依据二（删从句测试）：删掉后 The rule is the shortest one 指代不明 → 限定必需，that 用对。
3. ❌ The bug, **which** hid in the comment, took hours to find. — 依据一（语法规则）：逗号标记非限制，that 禁入，须用 which。依据二（排除法）：要么去掉逗号改回限制性（The bug that hid in the comment...），要么换 which；「逗号 + that」不存在。
4. ✅ 正确。依据一（语法规则）：which 指代前面整句（演示超时这件事）。依据二（拆两句法）：The demo ran over time. **This** annoyed the client. 成立 → which = 整句。
5. ❌ My notes, **which** you see below, follow the same pattern. — 依据一（语法规则）：非限制性从句的关系词不可省略。依据二（改写还原）：补 which 后插入成分自带主谓，主干 My notes follow the same pattern 完整。

**6.**（主观题 — 参考要点，示例句见课文第 4 节）
- 要点覆盖：4~5 句、主题为文档 / 注释写作习惯、含 1 个限制性从句 + 1 个非限制性从句，且非限制性从句中的 which 指代前面整句
- 自检要点：限制性从句无逗号（删掉后「哪一个」不明，用对位置）；非限制性从句两头逗号、无 that、无省略；which 用「拆两句法」验证（换成 this 拆两句成立）
- 达标线：两类从句各一且形式与语义匹配、which 指代整句判断正确、主干无错，即通过
