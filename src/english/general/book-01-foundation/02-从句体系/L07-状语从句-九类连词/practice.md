# L07 练习：状语从句

> 配套 [第 7 讲](lesson.md)。基础层必做，强化层选做。答案在文末，做完再看。

---

## 基础层

**1. 选连词**：从括号中的选项里选最恰当的一个填空（九类语义辨析）。

1. ___ everyone is ready, we will start the demo at two.（① So that ② When ③ Because）
2. ___ the tests pass, we will not release the update.（① Unless ② Although ③ Than）
3. We keep the summary short, ___ everyone can read it in one minute.（① so…that ② because ③ so that）
4. The outage was ___ serious ___ the whole team stayed all night.（① so…that ② such…that ③ as…as）
5. ___ the fix looks simple, we still test it twice.（① Unless ② Before ③ Although）

**2. 主将从现填空**：用括号中动词的正确形式填空（时间 / 条件 / 让步从句谈将来）。

1. If the tests ___ (fail) tonight, we will roll back the update.
2. We will not deploy before the lead ___ (approve) the plan.
3. Although the sprint ___ (end) on Friday, we will keep the branch open.
4. Even if the demo ___ (break) tomorrow, we will stay calm.

**3. 改错**：找出并改正句中的连词或时态错误。

1. Despite the team was tired, we finished the report.
2. When the build will finish, we will start the demo.
3. Because the log is short, so the problem is easy to find.
4. Even although the fix looks simple, we still test it twice.

**4. 翻译**（用括号中的连词）：

1. 除非测试通过，否则我们不会发布。（unless）
2. 我们把检查跑两遍，好让没人漏掉这个 bug。（so that）
3. 尽管事故很小，我们还是写了完整报告。（although，不与 but 连用）

## 强化层

**5. 判断下列 4 处正误**：正确的打 ✓，错误的改正。

1. Unless the tests pass, we will not ship the feature.
2. Although the outage was short, but the report took hours to write.
3. The fix was so quickly that everyone cheered.
4. We keep the dashboard open so that we can catch problems early.

**6. 造句**：以你的发布 / 上线（或考试、交作业）纪律为主题写 4~5 句英文小结，至少含：1 个时间或条件从句（主将从现：从句一般现在 + 主句 will）、1 个让步从句（although / despite / even if，不与 but 连用）、1 个目的从句（so that）；如能再加 1 个结果句（so…that）更佳。写完按「连词三问」自检：从句谈将来用现在时了吗？although 后有 but 吗？so that 是「为了」吗？

---

## 答案

**1.**
1. ② When。依据一（语法规则）：从句回答「何时开始」→ 时间状语从句用 when 引导，主将从现：are 一般现在表将来，主句 will start。依据二（排除法）：So that 表目的、Because 表原因，都答不上「何时」→ 排除。
2. ① Unless。依据一（语法规则）：unless = if…not，「除非测试通过，否则不发布」与主句否定 will not release 正好咬合。依据二（改写还原）：If the tests do not pass, we will not release the update. 句意不变 → unless 用对；Although（让步）、Than（比较）代入后句意不通 → 排除。
3. ③ so that。依据一（语法规则）：从句含情态动词 can、回答「为什么 keep short」→ 目的状语从句 so that。依据二（排除法）：so…that 要求 so 紧贴形容词（so short that…），空格在 short 之后、从句之前，摆不进 so…that 结构；because 表原因则变成「因为能读完才写短」，因果倒置 → 排除。
4. ① so…that。依据一（语法规则）：如此严重「以至于」全组熬通宵 → 结果状语从句 so + adj + that…。依据二（排除法）：such…that 要接名词短语（such a serious outage that…），这里两空夹的是形容词 serious；as…as 表比较且不接 that 从句 → 排除。
5. ③ Although。依据一（语法规则）：「看起来简单，仍测两遍」是让步关系 → although 领起让步状语从句，主句用 still 呼应转折、不再加 but。依据二（排除法）：Unless 代入变成「除非看起来简单，否则测两遍」，句意反转；Before 表时间，答不上「虽然」→ 排除。

**2.**
1. fail。依据一（语法规则）：if 条件从句谈今晚的将来 → 主将从现，从句用一般现在 fail（主语 the tests 复数）。依据二（排除法）：填 will fail 违反「will 只留主句」（U01-L05 规则）→ 排除。
2. approves。依据一（语法规则）：before 时间从句谈将来 → 一般现在 approves（主语 the lead 第三人称单数）。依据二（改写还原）：We will not deploy before the plan is approved by the lead. 语义相同 → 从句确是将来事件、用现在时表达；will approve 排除。
3. ends。依据一（语法规则）：although 让步从句谈周五的将来 → 主将从现，从句用一般现在 ends。依据二（排除法）：填 will end 则从句带 will，主从两个 will 违反主将从现 → 排除。
4. breaks。依据一（语法规则）：even if 让步从句谈明天的假设 → 一般现在 breaks（主语 the demo 三单），将来义由 tomorrow 与主句 will stay 承担。依据二（排除法）：will break 只能留在主句（U01-L05 复习）→ 排除。

**3.**
1. Although the team was tired, we finished the report.（或 Despite the team's tiredness, we finished the report.）— 依据一（语法规则）：despite 是介词，后接名词 / 动名词，不接完整句子；接句子必须换 although。依据二（改写还原）：把从句换成名词短语 Despite the team's tiredness, … 句子成立 → 缺口就在「despite + 句子」。
2. When the build finishes, we will start the demo. — 依据一（语法规则）：when 时间从句谈将来用一般现在（主将从现），will 只留主句。依据二（排除法）：从句 will finish 与主句 will start 两个 will 并存，违反主将从现；换成 finishes 后主从分工恢复（从句现在、主句将来）→ 采纳。
3. Because the log is short, the problem is easy to find.（或 The log is short, so the problem is easy to find.）— 依据一（语法规则）：because 与 so 都是因果连接标志，一句只能留一个。依据二（改写还原）：删 so，或把 because 换成 so（前果后因）改写后句子成立 → 双标志必删其一。
4. Even though the fix looks simple, we still test it twice.（或 Although the fix looks simple, we still test it twice.）— 依据一（语法规则）：英语没有 even although 这个组合，让步加强用 even though（事实）/ even if（假设）。依据二（排除法）：even 只能搭 though，不能搭 although → 换成 even though。

**4.**
1. Unless the tests pass, we will not release.（或 Unless the tests pass, we will not release the update.）
2. We run the checks twice so that nobody misses the bug.（或 We run the tests twice so that no one misses the bug.）
3. Although the incident was minor, we wrote a full report.（或 Although the incident was small, we wrote a complete report.）
- 要点覆盖：三句分别使用 unless（条件）、so that（目的）、although（让步），括号里的连词都用上
- 自检要点：unless 句可还原成 If the tests do not pass…（不再加 not）；so that 后接完整从句、表「为了」；although 后没有 but（如需 but 就删 although）
- 达标线：三个连词全部用对、主从句结构无误，即通过

**5.**
1. ✓ 正确。依据一（语法规则）：unless 条件从句用一般现在 pass 表将来（主将从现），主句 will not ship。依据二（改写还原）：If the tests do not pass, we will not ship the feature. 还原成立且句意不变。
2. ❌ Although the outage was short, the report took hours to write.（或 The outage was short, but the report took hours to write.）— 依据一（语法规则）：although 与 but 都标「虽然…但是」，不能同现一句。依据二（改写还原）：删 but 或删 although 后句子均成立 → 双标志必删其一。
3. ❌ The fix was so quick that everyone cheered. — 依据一（语法规则）：so…that 结果句中 so 后接形容词 / 副词原级；was 后作表语的位置要形容词 quick。依据二（排除法）：quickly 是副词，主系表结构（was + ___）放不下副词 → 排除。
4. ✓ 正确。依据一（语法规则）：so that + 从句（含 can）表目的「为了」，结构正确。依据二（改写还原）：We keep the dashboard open in order to catch problems early. 改写成立 → 确是目的句而非 so…that 结果句（so 后没有 adj / adv，that 后不是「如此……以至于」）。

**6.**（主观题 — 参考要点，示例句见课文第 4 节）
- 要点覆盖：4~5 句、主题为发布 / 上线（或考试、交作业）纪律；至少含 1 个时间或条件从句（主将从现）+ 1 个让步从句（although / despite / even if）+ 1 个目的从句（so that）
- 自检要点：时间 / 条件 / 让步从句谈将来时动词是一般现在（不是 will）；although / even though 后没有 but、despite 后只接名词不接句子；so that =「为了」，so…that =「如此……以至于」没有混用
- 达标线：三种从句各一且连词与时态全部用对，即通过
