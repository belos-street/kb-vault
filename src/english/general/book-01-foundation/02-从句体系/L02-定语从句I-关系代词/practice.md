# L02 练习：定语从句 I

> 配套 [第 2 讲](lesson.md)。基础层必做，强化层选做。答案在文末，做完再看。

---

## 基础层

**1. 缺成分判定**：判断下列句中括号内的定语从句缺少什么成分（① 缺主语 / ② 缺宾语 / ③ 缺定语）。

1. The engineer who wrote this module left yesterday.（从句：who wrote this module）
2. We use a dashboard that shows the real-time metrics.（从句：that shows the real-time metrics）
3. This is the PR which I reviewed this morning.（从句：which I reviewed this morning）
4. The developer whose laptop crashed called support at noon.（从句：whose laptop crashed）

**2. 选关系代词**：从 who / which / that / whom / whose 中选合适的填空（有的空不止一个答案）。

1. Kelly is the colleague ___ leads the migration.
2. We built a tool ___ checks every deploy.
3. Ben is the expert ___ the whole team trusts.
4. Everything ___ runs in production is tested twice.

**3. 改错**：下列句子的关系代词有误，找出并改正。

1. The developer which manages the service is on leave this week.
2. The colleague whom leads the migration is Kelly.
3. The tool checks every deploy is free.
4. This is the best dashboard which I have ever built.

**4. 翻译**（用定语从句）：

1. 管理这个服务的同事下周休假。
2. 这就是我昨天修的那个 bug。
3. 我们上个季度招了一位测试抓到 bug 的实习生。

---

## 强化层

**5. 判断下列 5 处正误**：正确的打 ✓，错误的改正。

1. This is the best ticket that I have ever taken.
2. The manager which hired me left last month.
3. The tool that checks our logs saves us hours every week.
4. The expert whom designed the schema is on leave.
5. The ticket which I took yesterday is still open.

**6. 造句**：以你的团队和工具为主题写 3~4 句，至少含 2 个定语从句（其中 1 个用 whose、1 个关系词作宾语且省略），写完用「缺成分判定法」逐句自检。

---

## 答案

**1.**
1. ① 缺主语。依据一（语法规则）：关系词后紧跟动词 wrote，who 在从句中作主语。依据二（还原法）：**He wrote this module** 成立 → 缺动作发出者（主语）。
2. ① 缺主语。依据一（语法规则）：that 后紧跟动词 shows，that 作主语、不能省略。依据二（还原法）：**It shows the real-time metrics** 成立 → 缺主语。
3. ② 缺宾语。依据一（语法规则）：which 后紧跟「主语 I + 动词 reviewed」，reviewed 是及物动词且后面悬空。依据二（还原法）：I reviewed **it** 成立 → 缺宾语，which 也可省略。
4. ③ 缺定语。依据一（语法规则）：whose 后是名词 laptop，从句主谓齐全（laptop crashed），缺的是「……的」。依据二（还原法）：**the developer's laptop** crashed 成立 → 缺定语。

**2.**
1. who（也可 that）。依据一（语法规则）：先行词 colleague 指人、从句缺主语 → who / that，排除 which。依据二（还原法）：**She leads the migration** 成立 → 缺主语，who 不可省略。
2. which（也可 that）。依据一（语法规则）：先行词 tool 指物、从句缺主语 → which / that，排除 who / whom。依据二（还原法）：**It checks every deploy** 成立 → 缺主语。
3. whom（也可 that / who，或省略）。依据一（语法规则）：先行词 Ben 指人、从句缺宾语 → whom / that。依据二（还原法）：the whole team trusts **him** 成立 → 缺宾语，作宾语时可省略。
4. that。依据一（语法规则）：先行词 Everything 是不定代词 → 关系词优先 that。依据二（排除法）：先行词不是人，who / whom 不行；此处缺主语不能省略 → 只能填 that。

**3.**
1. The developer **who** manages the service is on leave this week.（或 that）— 依据一（语法规则）：which 只指物，先行词 developer 是人。依据二（还原法）：**He manages** the service → 缺主语、指人 → who。
2. The colleague **who** leads the migration is Kelly.（或 that）— 依据一（语法规则）：whom 是宾格，只能作宾语，站不了主语位。依据二（还原法）：**She leads** the migration 成立 → 缺主语 → who。
3. The tool **which checks** every deploy is free.（或 that）— 依据一（语法规则）：关系词作主语时不能省略。依据二（还原法）：还原后是 **It checks** every deploy，从句缺主语，必须补 which / that。
4. This is the best dashboard **that** I have ever built. — 依据一（语法规则）：先行词被最高级 the best 修饰，关系词优先 that。依据二（排除法）：此处缺宾语（I have ever built it），which 不合规范用法 → 改 that（也可省略）。

**4.**
1. The colleague who manages this service is on leave next week.（或 that）
2. This is the bug (that / which) I fixed yesterday.
3. Last quarter we hired an intern whose tests caught a bug.
- 要点覆盖：三句分别覆盖「缺主语（who）/ 缺宾语（可省略）/ 缺定语（whose）」三个缺口，均使用定语从句
- 自检要点：逐句还原验证（**He manages** this service / I fixed **it** / **the intern's** tests caught a bug）；作主语的关系词没有被省略；whose 后紧跟名词
- 达标线：三个从句的关系词与缺口匹配、主干无错，即通过

**5.**
1. ✅ 正确。依据一（语法规则）：最高级 the best 修饰先行词，用 that。依据二（还原法）：I have ever taken **it** 成立 → 缺宾语，that 保留或省略均可。
2. ❌ The manager **who** hired me left last month.（或 that）— 依据一（语法规则）：which 只指物，先行词 manager 是人。依据二（还原法）：**He hired** me 成立 → 缺主语、指人 → who。
3. ✅ 正确。依据一（语法规则）：先行词 tool 指物，that 在从句中作主语。依据二（还原法）：**It checks** our logs 成立 → 缺主语，关系词不能省略。
4. ❌ The expert **who** designed the schema is on leave.（或 that）— 依据一（语法规则）：whom 只能作宾语。依据二（还原法）：**He designed** the schema 成立 → 缺主语 → who。
5. ✅ 正确。依据一（语法规则）：关系词在从句中作 took 的宾语，指物用 which（that 亦可、或省略）。依据二（改写还原）：I took the ticket yesterday 成立 → which 顶宾语位正确。

**6.**（主观题 — 参考要点，示例句见课文第 4 节）
- 要点覆盖：3~4 句、主题为团队与工具、至少 2 个定语从句（含 1 个 whose、1 处关系词作宾语且省略）
- 自检要点：逐句用「缺成分判定法」核对 — 先行词指人 / 指物、从句缺口（主语 / 宾语 / 定语）、关系词与缺口匹配；作主语的关系词没有被省略
- 达标线：每个从句关系词正确，whose 与宾格省略各出现一次，即通过
