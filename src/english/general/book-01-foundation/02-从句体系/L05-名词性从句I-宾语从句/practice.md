# L05 练习：名词性从句 I

> 配套 [第 5 讲](lesson.md)。基础层必做，强化层选做。答案在文末，做完再看。

---

## 基础层

**1. 改正语序**：下列宾语从句误用了疑问语序，把从句改成陈述语序。

1. I don't know what does the flag do.
2. Can you tell me when will the fix run?
3. She asked how long did the review take.
4. We need to check why is the build failing.

**2. 选引导词**：用 that / if / whether 填空（有的空不止一个答案）。

1. I am not sure ___ the deploy will finish today.
2. Please confirm ___ the new API works.
3. Can you confirm ___ the tests passed or not?
4. It depends on ___ we can ship tomorrow.

**3. 时态呼应**：用括号动词的正确时态填空。

1. Yesterday the PM said that the estimate ___ (be) too low.
2. I think that the new API ___ (ship) next Monday.
3. Our mentor said that good tests always ___ (catch) this kind of bug.
4. He replied that he ___ (not know) what the flag did.

**4. that 的省略**：选出括号中 that 的正确处理（① 可省略 / ② 保留更规范）。

1. I believe (that) the fix works.
2. She confirmed (that) the deploy finished on time.
3. He said (that) the estimate was small and (that) we needed more time.（第二个 that）
4. She told me (that) the review would finish today.

---

## 强化层

**5. 判断下列 5 处正误**：正确的打 ✓，错误的写出改正。

1. I don't know what the flag does.
2. She asked me whether the tests will pass or not.
3. It depends on if we can ship tomorrow.
4. He said that good tests always catch this kind of bug.
5. Please tell me what do you need.

**6. 造句 — 会议对话仿写**：以「需求确认 / 表达不确定」为主题写 3~4 句对话（或短文），至少包含 1 个 that 宾语从句（think / believe / know / say / confirm 任一）、1 个 if 或 whether「是否」从句、1 个 wh- 宾语从句（陈述语序）、1 处时态呼应（主句过去 → 从句相应过去）；写完用「盖住主句法」逐句自检。

---

## 答案

**1.**
1. I don't know what the flag does. — 依据一（语法规则）：宾语从句一律陈述语序，从句主语 the flag 在前、谓语 does 在后。依据二（改写还原）：独立问句是 What does the flag do?，进从句后助动词 does 退回谓语位，变成 what the flag does。
2. Can you tell me when the fix will run? — 依据一（语法规则）：when 从句内部是陈述语序，主语 the fix 在前。依据二（改写还原）：The fix will run tomorrow. → when the fix will run；把 will 提前是独立问句的语序。
3. She asked how long the review took. — 依据一（语法规则）：asked 后的宾语从句用陈述语序，且时态呼应（asked → took）。依据二（改写还原）：The review took two hours. → how long the review took。
4. We need to check why the build is failing. — 依据一（语法规则）：why 从句内部主语 the build 在前、is failing 在后。依据二（改写还原）：The build is failing. → why the build is failing；be 动词提前只用于独立问句。

**2.**
1. if / whether。依据一（语法规则）：表「是否」的宾语从句中 if 与 whether 一般可互换，本句无 or not、非介词后、非句首。依据二（改写还原）：独立问句是 Will the deploy finish today?，转述为 I am not sure if / whether the deploy will finish today。
2. that。依据一（语法规则）：从句 the new API works 陈述的是事实，用 that 引导（也可省略）。依据二（排除法）：句意不含「是否」→ 排除 if / whether；what / when 等疑问词会改变句意，排除。
3. whether。依据一（语法规则）：whether … or not 是「是否」的固定搭配，考试一律选 whether。依据二（排除法）：if…or not 仅见于非正式口语、此处正式语体不取；that 表事实不表「是否」→ 只能 whether。
4. whether。依据一（语法规则）：介词后面的「是否」从句只能用 whether，介词后不用 that / if。依据二（改写还原）：独立问句是 Can we ship tomorrow? → It depends on whether we can ship tomorrow。

**3.**
1. was。依据一（时态呼应）：主句 said 是过去时 → 从句一般现在相应变一般过去，be 用 was。依据二（改写还原）：直接引语是 The estimate is too low.，转述后变 The estimate was too low。
2. will ship / ships。依据一（时态呼应）：主句 think 是现在时，从句时态随意；谈计划用一般将来 will ship，按日程表也可用一般现在 ships。依据二（改写还原）：The new API will ship next Monday. 直接装进从句即可。
3. catch。依据一（时态呼应）：客观真理 / 习惯性事实即使跟在 said 后也保持一般现在 → catch。依据二（排除法）：填 caught 就变成一次具体动作，与 always + 事实陈述的句意不符。
4. did not know / didn't know。依据一（时态呼应）：replied 是过去时 → 从句 know 变 didn't know。依据二（改写还原）：直接引语 I don't know what the flag did. → 转述为 He replied that he didn't know what the flag did。

**4.**
1. ① 可省略。依据一（语法规则）：think / believe 类动词后的宾语从句，that 可省。依据二（改写还原）：I believe the fix works. 去掉 that 后句子依旧完整、句意不变。
2. ① 可省略。依据一（语法规则）：confirm 后的宾语从句，that 可省。依据二（改写还原）：She confirmed the deploy finished on time. 成立，主句结构不受影响。
3. ② 保留更规范。依据一（语法规则）：并列宾语从句的第二个 that 一般保留，避免第二个从句被误读成与前面的成分并列。依据二（排除法）：两个 that 都省掉后 He said the estimate was small and we needed more time 容易歧义，正式写作补回第二个 that。
4. ① 可省略。依据一（语法规则）：tell sb that… 结构中 that 从句作直接宾语，that 可省。依据二（改写还原）：She told me the review would finish today. 成立，句意不变。

**5.**
1. ✅ 正确。依据一（语法规则）：what 从句用陈述语序（what the flag does），主句现在时、从句一般现在。依据二（改写还原）：从句可还原成陈述句 The flag does what，主谓顺序正常。
2. ❌ She asked me whether the tests would pass or not. — 依据一（时态呼应）：主句 asked 是过去时 → 从句 will 应变 would。依据二（改写还原）：直接引语是 Will the tests pass or not?，进间接引语后 will → would。
3. ❌ It depends on whether we can ship tomorrow. — 依据一（语法规则）：介词后面的「是否」从句只能用 whether。依据二（排除法）：on 后不能跟 if / that 引导「是否」从句，把 if 换成 whether 后句子成立。
4. ✅ 正确。依据一（时态呼应）：客观真理 / 习惯性事实不受主句过去时影响，从句保持一般现在 catch。依据二（改写还原）：Good tests always catch this kind of bug. 是独立陈述句，直接装进从句即可。
5. ❌ Please tell me what you need. — 依据一（语法规则）：宾语从句一律陈述语序。依据二（改写还原）：独立问句是 What do you need?，进从句后助动词 do 退回谓语位，变为 what you need。

**6.**（主观题 — 参考要点，示例句见课文第 4 节）
- 要点覆盖：3~4 句、主题为需求确认 / 会议沟通、含 that 从句 1 个、if / whether「是否」从句 1 个、wh- 宾语从句 1 个（陈述语序）、时态呼应 1 处
- 自检要点：用「盖住主句法」逐句检查 — 盖住 I think / She asked / Can you confirm 后，从句是陈述语序且时态与主句呼应；带 or not 的「是否」从句用 whether
- 达标线：四项语法要素齐全、从句语序全部正确，即通过
