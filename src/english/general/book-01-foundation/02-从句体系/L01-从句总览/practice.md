# L01 练习：从句总览

> 配套 [第 1 讲](lesson.md)。基础层必做，强化层选做。答案在文末，做完再看。

## 基础层

**1. 判断从句类型（提问法）**：先遮住粗体部分提问，再选它属于哪一类（① 名词性从句 / ② 定语从句 / ③ 状语从句）。

1. I forget **what the flag does**.
2. This is the tool **that saves me hours**.
3. **When the build fails**, read the log first.
4. She asked **why the deploy failed**.
5. The bug **that we fixed yesterday** is gone.

**2. 划分主句与从句**：写出主句、从句各是什么，并标出引导词与从句类型。

1. The docs that describe the structure are long.
2. When the cache is cold, the first run is slow.
3. I do not know what the script does.

**3. 提问法填空**：按括号里的提问判断类型，把答案填在 ___ 上。

1. 「I read the guide **that explains the API**.」问「哪份指南？」→ ___ 从句。
2. 「**When the deploy finishes**, we celebrate.」问「何时庆祝？」→ ___ 从句。
3. 「Tell me **what the flag means**.」问「告诉我什么？」→ ___ 从句。
4. 「I know **why the build failed**.」问「知道什么？」→ ___ 从句。

**4. 翻译**（用括号中的引导词）：

1. 当测试失败时，先看日志。（when）
2. 这就是我拆分长句的原因。（why）
3. 我喜欢描述清楚的文档。（that）

**5. 课文理解与语法**：先读课文，再作答；每题只有一个正确选项。

1. 课文把「遇到长句时该怎么读」比作什么？
   A. 把长句翻译成中文
   B. 把长句当成嵌套函数（nested functions）来读
   C. 把长句里的生词全部查一遍
   D. 先把长句背下来
2. 课文说，从句（a clause）可以起什么作用？
   A. 只能说明构建为什么失败

   C. 描述细节、替代一张任务清单，或说明构建为什么失败
   D. 决定整句话的时态
3. 按课文，把句子各部分拆开后，接下来该怎么做？
   A. 直接翻译成中文
   B. 用问题把各部分连起来，再逐个「执行」
   C. 把从句全部删掉
   D. 记住所有引导词
4. 按课文，判断一个从句属于哪一类，应该看什么？

   B. 看引导词的长短

5. 关于 "…tells you why a build fails."，下列分析正确的是？

   B. that 从句是状语从句，修饰 makes

## 强化层

**6. 造句**：以「读文档 / 写代码」为主题写 3 句：名词性 / 定语 / 状语从句各一，并对每句标注「提问 → 类型 → 引导词」。

**7. 判断下列 3 处正误**：说法正确的打 ✓，错误的写出改正。

1. 「Because the docs are long, so I split them.」是正确的英语句子。
2. 「the logic that makes a complex doc readable」中，that 引导的是状语从句。
3. 「I asked why the build failed」中，why the build failed 是名词性从句。

---

## 答案

**1.**
1. ① 名词性从句。依据 1（提问法）：问「忘记什么？」→ 答「什么」→ 名词性；依据 2（占位还原）：从句整体占 forget 的宾语位，可换成 it。
2. ② 定语从句。依据 1（提问法）：问「哪个工具？」→ 答「哪个」→ 定语；依据 2（剥壳还原）：去掉从句 This is the tool 仍完整，从句只修饰 tool，可换成 this useful tool。
3. ③ 状语从句。依据 1（提问法）：问「何时读日志？」→ 答「何时」→ 状语；依据 2（剥壳还原）：整块可换成 after the failure，主句 read the log first 仍完整。
4. ① 名词性从句（陷阱：why ≠ 状语）。依据 1（提问法）：问「她问了什么？」→ 答「什么」→ 名词性；依据 2（占位还原）：asked 后缺宾语，从句整体填宾语位。
5. ② 定语从句。依据 1（提问法）：问「哪个 bug？」→ 答「哪个」→ 定语；依据 2（剥壳还原）：可换成 the fixed bug，主句 The bug is gone 仍完整。

**2.**
1. 主句：The docs are long｜从句：that describe the structure（定语）｜引导词：that。依据 1（提问法）：问「哪份文档？」→ 定语；依据 2（剥壳还原）：去掉从句主句仍完整。
2. 主句：the first run is slow｜从句：When the cache is cold（状语）｜引导词：When。依据 1（提问法）：问「何时慢？」→ 状语；依据 2（剥壳还原）：整块可换成 with a cold cache，主句仍完整、句意不变（换成 in cold weather 就变成「天气冷」，与原句不是同一件事）。
3. 主句：I do not know｜从句：what the script does（名词性，作 know 的宾语）｜引导词：what。依据 1（提问法）：问「不知道什么？」→ 名词性；依据 2（占位还原）：从句整体填 know 的宾语位。

**3.**
1. 定语（定语从句）。依据 1（提问法）：问「哪份指南？」→ 答「哪个」→ 定语；依据 2（剥壳还原）：that explains the API 可换成 one good guide，主句 I read the guide 仍通。
2. 状语（状语从句）。依据 1（提问法）：问「何时庆祝？」→ 答「何时」→ 状语；依据 2（剥壳还原）：整块可换成 after the deploy。
3. 名词性（名词性从句）。依据 1（提问法）：问「告诉我什么？」→ 答「什么」→ 名词性；依据 2（占位还原）：从句填 tell 的直接宾语位，可换成 it。
4. 名词性（名词性从句）。依据 1（提问法）：问「知道什么？」→ 答「什么」→ 名词性（why 是从句自带的疑问词，不决定类型）；依据 2（占位还原）：从句填 know 的宾语位，可换成 the reason。

**4.**
1. When the test fails, read the log first.（check / look at the log 均可）
2. This is why I split long sentences.（split 后接 into parts / up 均可）
3. I like docs that describe things clearly.（documents / that explain things clearly 均可）

**5.**
1. B — 第 3 句 When you meet one, treat it like nested functions（嵌套调用）——把长句当嵌套函数来读。
2. C — 第 4 句 A clause is a call inside the call — it describes details, replaces a task list, or tells you why a build fails.
3. B — 第 6 句 Split it again, connect the parts with questions, and run them one by one.
4. A — 提问法：从句属于哪类，不看引导词长相，看它在回答什么问题（依据：课文 3.2 提问法）。
5. D — 提问法：问「告诉你什么？」→ 名词性；从句整体作 tells 的宾语，why 是从句自带的疑问词，不决定类型（陷阱一）。
6. C — 提问法：问「什么样的逻辑？」→ 定语；剥壳还原：去掉从句 the logic 仍成立，它修饰名词 the logic。

**6.**（主观题 — 参考要点，示例句群见课文第 4 节）
- 要点覆盖：3 句分别含名词性、定语、状语从句，各一；主题与读文档 / 写代码相关
- 自检要点：每句标注「提问 → 类型 → 引导词」；遮住从句后主句仍能站住（名词性从句除外，它占的是名词位）
- 达标线：三类各一、标注正确、无双引导词同框，即通过

**7.**
1. ❌ Because the docs are long, I split them.（或 The docs are long, so I split them.）— 依据 1（语法规则）：一个分句只留一个引导词，because 与 so 不能同框；依据 2（改写还原）：删 so 后「原因状语从句 + 主句」依旧完整，句意不变。
2. ❌ that 引导的是定语从句（修饰 the logic）。— 依据 1（提问法）：问「什么样的逻辑？」→ 答「什么样的」→ 定语；依据 2（剥壳还原）：去掉从句 the logic 仍成立，它修饰名词而非整句。
3. ✅ 正确。— 依据 1（提问法）：问「我问了什么？」→ 答「什么」→ 名词性；依据 2（占位还原）：从句整体填 asked 的宾语位。
