## 1. 课文精读

**The Night the Deploy Failed**

> Last week we had an incident that delayed our release. Here is the timeline we wrote after the review. The crash occurred at 9:10 p.m., the moment when the dashboard went red.
>
> The reason why the deploy failed was a missing line in the background script. The office where the server sits was empty, so nobody noticed the logs until the engineer arrived.
>
> We wonder about the schedule change that nobody mentioned, and we recall the day when the tests last passed. We explain every incident on one page: the location in which it began, and the time that we spent fixing it. The page then reaches the team.

**参考译文**

> 上周我们遇到一次事故，把发布推迟了。下面是我们复盘之后写下的时间线。崩溃发生在晚上 9:10，也就是仪表盘变红的那一刻。
>
> 部署失败的原因，是后台脚本里少了一行代码。服务器所在的那间办公室空无一人，所以没人注意到日志，直到工程师赶到。
>
> 我们琢磨着那个没人提过的日程变更，也回忆起测试上一次通过的那天。现在我们把每次事故写进一页纸：它发生的地点，以及我们花在修复上的时间。这页纸随后就传到整个团队手里。

**关键句解析**

| 句子 | 拆解 |
|------|------|
| we had an incident **that** delayed our release. | 关系代词对照组：that 在从句里作主语（The incident delayed...）→ 缺主语只能用关系代词。还原介词法过不去：~~delayed our release in the incident~~ 不成立 |
| The crash occurred at 9:10 p.m., **the moment when** the dashboard went red. | 先行词 the moment（时间）；从句 the dashboard went red 主谓齐全 → 关系副词 when。还原验证：the dashboard went red **at the moment** |
| **The reason why** the deploy failed was a missing line in the background script. | why = for which；从句 the deploy failed 主谓完整、缺原因状语 → 关系副词。注意：the reason is **because**… 是冗余错误（见 3.5） |
| ...the location **in which** it began, and **the time that** we spent fixing it. | 前半：in which 是 where 的正式变体（= the location where it began）；后半：the time 是 spent 的**宾语** → 用 that / which，不能用 when（陷阱见 3.5） |

## 3. 语法点拆解

### 3.1 先定义：关系副词 / 关系代词

先给术语定性，再谈规则 — 否则公式没有意义。

| 术语 | 一句话定义 | 课文例句 |
|------|-----------|---------|
| **关系副词**（relative adverb） | 在定语从句里**只作状语**（不作主语、宾语）的引导词：where / when / why | The office **where** the server sits was empty.（where 作地点状语） |
| **关系代词**（relative pronoun，复习 L02） | 在定语从句里**作主语或宾语**的引导词：who / whom / which / that / whose | we had an incident **that** delayed our release.（that 作从句主语） |

> 一句话分野：**从句缺主语 / 宾语 → 关系代词；从句成分完整、缺的只是「地点 / 时间 / 原因」状语 → 关系副词。** 关系副词都等于「介词 + which」，所以它从不站主宾位。

### 3.2 还原介词法（本讲核心工具）

> **还原介词法**（定义卡）：把先行词带上合适的介词短语放回从句（in the office / at the moment / for the reason），看从句是否因此变得完整。放回去成立 → 从句缺的是状语 → 用关系副词；放不回去（从句缺主语或宾语）→ 用关系代词。

**三步操作**：

1. **摘从句**：把定语从句单独拎出来当独立句看（The server sits ___.）
2. **带介词还原先行词**：用「介词 + 先行词」补位（The server sits **in the office**.）— 成立且句意完整 → 关系副词（where = in which）
3. **放不回去就换关系代词**：an incident **that** delayed our release → **The incident** delayed our release，先行词站的是主语位 → that / which

对照一例：

| 课文句 | 还原 | 判决 |
|--------|------|------|
| The office **where** the server sits | The server sits **in the office**. | 成分完整、缺状语 → where（关系副词） |
| an incident **that** delayed our release | **The incident** delayed our release. | 缺主语 → that（关系代词） |

💡 **一眼定位**：从句「主谓齐全」→ 关系副词；从句「缺主宾」→ 关系代词。关系词后面紧跟「主语 + 动词」多是前者，紧跟动词或动词后悬空多是后者。

### 3.3 三大关系副词对应表

| 先行词 | 关系副词 | 等价变体 | 课文例句 | 还原验证 |
|--------|---------|---------|---------|---------|
| 地点 place | where | = in / at which | The office **where** the server sits was empty. | The server sits **in the office**. |
| 时间 time | when | = in / on / during which | ...we recall **the day when** the tests last passed. | The tests last passed **on the day**. |
| 原因 reason | why | = for which | **The reason why** the deploy failed... | The deploy failed **for the reason**. |

> 口诀：**地点 where、时间 when、原因 why；介词跟着搭配走** —「介词 + which」是同一件事的正式写法。

### 3.4 介词 + which 变体（正式语体）

口语与一般写作用 where / when / why；事故复盘、正式报告等书面语倾向「介词 + which」，其中 **in which**（地点）、**during which**（时间段）最常见。

- 课文：the location **in which** it began（= the location where it began）
- 事故复盘常用：the two hours **during which** the dashboard stayed red（= the two hours when the dashboard stayed red）
- 原因变体：the reason **for which** the deploy failed（= the reason why the deploy failed）

⚠️ 介词不能乱配：先看从句里动词 / 形容词的固定搭配，再把介词挪到 which 前面。sit **in** the office → **in** which；pass **on** the day → **on** which；fail **for** the reason → **for** which。where ≠ 永远 in which，用哪个介词由搭配决定。

### 3.5 高频陷阱

**陷阱一：time / moment / day 作从句宾语时，用 that / which，不用 when**

| 句子 | 从句成分 | 判决 |
|------|---------|------|
| **the time that** we spent fixing it | We spent **the time**（宾语被挪走） | ✅ that / which（可省略） |
| ~~the time when we spent fixing it~~ | spent 缺宾语（the time 正是它的宾语），when 只作状语补不上宾语位 | ❌ when 只作状语，不作宾语 |
| the time **when** the tests passed | The tests passed（主谓完整） | ✅ when（= at which） |

**陷阱二：the reason why… / the reason that… 都对；the reason is because… 是冗余错误**

- ✅ The reason **why** the deploy failed is a missing line.
- ✅ The reason **that** the deploy failed is a missing line.（或 The reason is **that** a line was missing.）
- ❌ The reason is **because** a line was missing.（reason 与 because 语义重复 → 删 because 换 that，或直接说 A line was missing.）

> 非限制性从句（逗号 + which、which 指代整句）与 that 的禁入规则是 L04 的内容，本讲先不展开。

## 4. 输出

1. **复述**：用 2~3 句英文复述这份事故复盘（线索：incident → timeline → reason → takeaway）
2. **仿写（核心）**：以你经历过的一次线上事故或工作失误为主题写 4~5 句复盘，至少用 2 个关系副词和 1 个「介词 + which」变体。参考起点：
   - Here is the timeline of the incident.
   - The error occurred at 3 a.m., the moment when the queue stopped.
   - The reason why the job failed was a bad retry.
   - We worked in the room where the logs are stored.（正式写法：the room in which the logs are stored）
   - I still remember the hour that we spent checking the logs.
3. **自检**：用「还原介词法」逐句检查每个定语从句 — 先行词带介词放回从句后是否完整
