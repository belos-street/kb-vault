## 1. 课文精读

**Stating Your Opinion at the Review**

> In the review meeting, the data suggest that our new pipeline saves us time every quarter.
> The dashboard shows that the tests now run faster than before.
>
> But one issue remains: under heavy load（高负载）, the cache still breaks.
> The fact is that the bug returns every time we push a big update.
>
> I argue that we must fix it before we ship.
> Some colleagues disagree; they claim the case is rare.
> I do not think that proves we can wait.
> My point is that we should act now.
> In case the review needs evidence（证据）, I will present the logs.
> So state your point first, and show the numbers that support it.

**参考译文**

> 评审会上，数据表明我们的新流水线每个季度都为大家节省时间。
> 仪表盘显示，测试现在跑得比以前更快了。
>
> 但还有一个问题：在高负载下，缓存依然会崩溃。
> 事实是，每当我们推送一次大的更新，这个 bug 就会回来。
>
> 我主张我们必须在上线交付之前修好它。
> 有些同事不同意；他们声称这种情况很罕见。
> 我不认为那就能证明我们可以再等等。
> 我的观点是，我们应该现在就行动。
> 万一评审需要证据，我会出示日志。
> 所以，先亮出你的观点，再展示支撑它的数字。

**关键句解析**

| 句子 | 拆解 |
|------|------|
| In the review meeting, **the data suggest that** our new pipeline saves us time every quarter. | 骨架①：观点动词 suggest + that 宾语从句（呼应 L05）；data 形式为复数，谓语用 suggest；suggest 表「表明」时以数据 / 事实为主语 |
| **The dashboard shows that** the tests now run faster than before. | show + that 从句：摆事实型观点动词，主语是「物」（dashboard / data / logs）；单数主语配 shows，主谓一致别丢 s |
| **The fact is that** the bug returns every time we push a big update. | 骨架②：观点名词 fact + be + that 表语从句；the fact is that… 把事实钉在句子主干上，比单说 the bug returns… 更有「亮观点」的架势 |
| I do not think **that proves** we can wait. | prove + 宾语从句：that 是指示代词「那」作 prove 的主语，proves 后省略了宾语从句引导词（prove (that) we can wait）；否定前移到 think（I do not think…） |
| **My point is that** we should act now. | 观点名词 point + 表语从句：the point is that… 用来收尾落点；从句必须是陈述语序（we should act，不是 should we act） |
| **In case** the review needs evidence（证据）, I will present the logs. | in case 引出条件「万一 / 以防」：从句一般现在表将来（needs），主句用 will；这是观点句的「留后手」条件框 |

## 2. 词汇与词组

> 本讲词汇（词群实战课特例）：课内精讲 4 词（观点动词）+ 升级讲专区 4 个已入账观点名词（深挖搭配网，不重复入账），不设词群表。

### 2.1 精讲：四大观点动词（各配搭配网）

| 单词/词组 | 音标 | 释义 | 课文例句 | 拓展搭配 |
|-----------|------|------|----------|----------|
| suggest | /səˈdʒest/ | v. 建议；表明 | The data suggest that our new pipeline saves us time every quarter. | suggest that… 建议 / 表明…… ｜ suggest doing sth 建议做某事 ｜ suggest a fix 提出修复方案 ｜ It is suggested that… 据建议…… |
| show | /ʃoʊ/ | v. 表明 | The dashboard shows that the tests now run faster than before. | show that… 表明…… ｜ show the data 展示数据 ｜ show up 出现 ｜ as the data show 如数据所示 |
| argue | /ˈɑːrɡjuː/ | v. 主张；论证 | I argue that we must fix it before we ship. | argue that… 主张…… ｜ argue for / against 赞成 / 反对 ｜ argue the point 论证观点 ｜ argue with sb 与某人争论 |
| prove | /pruːv/ | v. 证明 | I do not think that proves we can wait. | prove that… 证明…… ｜ prove sth to sb 向某人证明 ｜ prove right / wrong 证明对 / 错 ｜ prove yourself 证明自己 |

### 2.2 升级讲专区（已入账观点名词的深挖 — 不重复入账）

| 名词 | 首次入账 | 升级搭配网 |
|------|---------|-----------|
| fact | U02-L04（词群） | the fact that… ……这个事实 ｜ The fact is that… 事实是…… ｜ in fact 事实上 ｜ state the facts 陈述事实 ｜ face the facts 面对现实 |
| issue | U02-L05（词群） | face the issue 面对问题 ｜ raise an issue 提出问题 ｜ The issue is that… 问题在于…… ｜ address an issue 处理问题 ｜ a sensitive issue 敏感问题 |
| point | U02-L01（词群） | The point is that… 重点是…… ｜ make a point 提出观点 ｜ point out 指出 ｜ to the point 切中要害 ｜ get to the point 说重点 |
| case | U02-L07（词群） | in case 万一 / 以防 ｜ in that case 那样的话 ｜ in any case 无论如何 ｜ in this case 在这种情况下 ｜ a strong case 充分理由 |

> 💡 观点句的两种骨架可以组合：先用**观点动词**亮观点（I argue that…），再用**观点名词**落论点（The point is that…）——一句一骨架，段落就有骨架。

## 3. 语法点拆解

> 本节承载观点句的骨架语法与词群规则（词群实战课特例）：两大骨架 → 转述观点语序 → 观点句的收放 → 常见错误对照。

### 3.1 观点句两大骨架

观点句不是「我觉得」堆出来的，而是两个固定骨架撑起来的：**骨架① 观点动词 + 宾语从句**（把观点装进宾语位，呼应 L05）；**骨架② 观点名词 + 表语从句 / in case 条件框**（用名词把观点钉在句子主干上）。

**骨架①：观点动词 + 宾语从句**

| 观点动词 | 语义侧重 | 骨架 | 课文例句 |
|----------|---------|------|---------|
| suggest | 建议；表明（委婉） | suggest that… | The data suggest that our new pipeline saves us time every quarter. |
| show | 表明（摆事实） | show that… | The dashboard shows that the tests now run faster than before. |
| argue | 主张；论证（摆理由） | argue that… | I argue that we must fix it before we ship. |
| prove | 证明（拿证据） | prove that… / prove + 名词 | I do not think that proves we can wait. |

**骨架②：观点名词 + 表语从句 / in case 条件框**

| 名词骨架 | 用途 | 课文例句 |
|----------|------|---------|
| The fact is that… | 陈述事实（表语从句） | The fact is that the bug returns every time we push a big update. |
| The point is that… | 落到论点（表语从句） | My point is that we should act now. |
| in case + 从句 | 万一 / 以防（条件框） | In case the review needs evidence, I will present the logs. |

💡 记法：**动词骨架讲「谁在说」**（suggest 委婉、show 摆事实、argue 摆理由、prove 拿证据），**名词骨架讲「说什么」**（fact 是事实、point 是论点、case 是情形）。

### 3.2 转述观点的语序

转述别人的观点时，主句（claim / argue / state / say）后面的从句一律用**陈述语序** —— 这是 L05「语序陷阱」在观点句里的复用。

| 直接引语（原话） | 转述句 | 要点 |
|----------------|--------|------|
| "The case is rare." | They claim (that) the case is rare. | that 可省；从句保持「主语 + 谓语」 |
| "Why did the fix fail?" | She stated why the fix failed. | 疑问词引导的转述从句也用陈述语序；时态呼应 stated → failed |
| "We should act now." | He argued that we should act now. | 情态动词 should 原样保留 |

- **时态呼应**同 L05：主句过去 → 从句相应过去；客观真理 / 习惯性事实保持一般现在。
- **自检用「盖住主句法」**：盖掉 They claim / She stated，剩下的必须是一个不倒装的完整陈述句。

### 3.3 观点句的收放：先观点后证据

写作中观点句要「先收后放」：**先亮观点（收）**，一句说清主张；**再挂证据（放）**，用数据 / 日志 / 案例支撑。顺序反了，读者翻到段末还不知道你要说什么。

**三步成段**：

1. **立骨架句（收）**：My point is that we should act now. / I argue that we must fix it before we ship.
2. **挂证据（放）**：The data suggest that… / The dashboard shows that… / In case the review needs evidence, I will present the logs.
3. **收尾留后手或让步**：In case… / Even if the case is rare, the bug is real.

💡 一段一个观点：三个观点挤在一句里，读者一个也记不住。观点句放段首，证据跟在后面，段落自然成立。

### 3.4 常见错误对照表

| ❌ 错误 | ✅ 正确 | 记忆点 |
|---------|---------|--------|
| He suggests me to fix the cache first. | He suggests that I fix the cache first. | suggest 不接「人 + to do」，只接 that 从句 / doing |
| The dashboard show that the tests run faster. | The dashboard shows that the tests run faster. | 单数主语 + shows（主谓一致） |
| My point is which we should act now. | My point is that we should act now. | 表语从句用 that，不用 which |
| She stated what does the dashboard show. | She stated what the dashboard shows. | 转述从句一律陈述语序（盖住主句法） |
| In case the review will need evidence, I will present the logs. | In case the review needs evidence, I will present the logs. | in case 从句用一般现在表将来 |

### 3.5 课文复现自查

本讲课文英文共 111 词，词形 type 共 78 个（仅英文词形，中文注释与标点不计）；自然复现已入账旧词 26 个词条（变形归并）：review、pipeline、save、quarter、dashboard、test、run、issue、remain、cache、break、fact、bug、return、push、update、fix、ship、colleague、disagree、claim、case、point、present、log、state（saves / returns / breaks / tests / colleagues / logs / remains 归并到词条；本讲新入账的 suggest / show / argue / prove 不计入分子）。原始分数 **26/78 ≈ 33%**（旧词词条 / 课文词形 type），超过词群实战课 ≥ 20% 的阶段目标，达标。

## 4. 输出

1. **复述**：用 3 句复述这场评审会的观点（线索：数据说明了什么 → 问题在哪 → 论点如何支撑）
2. **仿写（核心）**：以你最近一次评审 / 技术讨论为场景，写 4~5 句观点句：至少 1 个「观点动词 + 宾语从句」、1 个「观点名词 + 表语从句」、1 个 in case 条件句和 1 句转述他人观点，顺序上「先观点后证据」。参考起点：
   - The data suggest that the new pipeline saves us time.
   - My point is that we should fix the cache first.
   - In case the review needs evidence, I will present the logs.
   - Some colleagues claim the case is rare.
3. **自检**：对照 3.4 常见错误表逐句排查（suggest 不接「人 + to do」、表语从句用 that、转述从句陈述语序、in case 从句不用 will），再按 3.3 检查段落是否「先观点后证据」
