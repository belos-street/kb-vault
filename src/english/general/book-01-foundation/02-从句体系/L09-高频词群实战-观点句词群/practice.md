# L09 练习：观点句词群

> 配套 [第 9 讲](lesson.md)。基础层必做，强化层选做。答案在文末，做完再看。

---

## 基础层

**1. 选词填空**：从 suggest / show / argue / prove 中选词，并变成正确形态。

1. The data ___ that our new pipeline saves us time every quarter.
2. The dashboard ___ that the tests now run faster than before.
3. She ___ that we should fix the cache before we ship.
4. One log line does not ___ anything; we need more evidence.
5. These numbers ___ that the bug returns every quarter.
6. Yesterday he ___ that the case was rare.

**2. 观点句骨架判断**：判断下列句子属于哪种骨架（① 观点动词 + 宾语从句；② 观点名词 + 表语从句；③ in case 条件框）。

1. The data suggest that the new pipeline saves us time.
2. The fact is that the bug returns every quarter.
3. In case the review needs evidence, I will present the logs.
4. My point is that we should act now.
5. The dashboard shows that the tests run faster.
6. In case the build breaks, we revert the update.

**3. 改错**：每句 1~2 处错误，改出正确的观点句。

1. He suggests me to fix the cache first.
2. She stated why did the fix fail.
3. My point is which we should act now.
4. In case the review will need evidence, I will present the logs.

**4. 判断下列 5 处正误**：✓ 正确的打勾，✗ 错误的写出改正句。

1. The data suggest that we need more time.
2. He argues me to wait for the next review.
3. The fact is that the cache still breaks under heavy load.
4. My point is that should we act now.
5. In case the logs show the bug, I will open a ticket.

---

## 强化层

**5. 观点句骨架改写（中译英）**：按括号内指定的骨架翻译成英文。

1. 数据表明这个修复为我们节省了时间。（suggest + 宾语从句）
2. 事实是这个 bug 每季度都会回来。（The fact is that…）
3. 万一评审需要证据，我会出示日志。（in case）
4. 我不认为那就能证明我们可以再等等。（I do not think that proves…）

**6. 观点写作**：写一段 4~5 句的评审观点（真实工作场景即可），要求：一个「观点动词 + 宾语从句」、一个「观点名词 + 表语从句」、一个 in case 条件句、一句转述他人观点，并做到「先观点后证据」。

---

## 答案

**1.**
1. suggest — 依据链①（语法规则）：data 为复数形式名词，谓语用原形 suggest；依据链②（改写还原）：把 data 换成 the numbers → The numbers suggest…，还原成立。
2. shows — 依据链①（主谓一致）：dashboard 是单数第三人称，动词加 s → shows；依据链②（排除法）：show 原形只配复数主语（These numbers show…），与本句单数主语冲突。
3. argues（suggests 亦可）— 依据链①（搭配规则）：argue that… 后接完整从句（we should fix…）；依据链②（改写还原）：还原为直接引语 "We should fix the cache before we ship."，转述后成立。suggests 同样接 that 从句、句意亦通（「建议我们修缓存」）。
4. prove — 依据链①（形态规则）：does not 后动词用原形 prove；依据链②（排除法）：proves / proved 都不能跟在 does not 后面。
5. show（suggest 亦可）— 依据链①（主谓一致）：numbers 是复数主语，动词用原形 show；依据链②（改写还原）：换成主语 the data → The data show…，同骨架成立。suggest 语义上也通（数据「表明/暗示」bug 回归），prove 语气过强、需更强证据，不取。
6. argued（suggested / showed 亦可）— 依据链①（时态呼应）：Yesterday 标记过去时 → argued，从句相应过去（was）；依据链②（排除法）：现在时 argues 与 yesterday 的时间标记冲突。suggested / showed 同为过去时、句意亦通。

**2.**
1. ① — 依据链①（骨架定义）：suggest 是观点动词，that 从句整体作它的宾语 → 骨架①；依据链②（排除法）：句中没有「观点名词 + be」主干，也没有 in case。
2. ② — 依据链①（骨架定义）：The fact is that… = 观点名词 fact + be + 表语从句 → 骨架②；依据链②（改写还原）：换成 The point is that the bug returns every quarter.，结构不变，仍是名词骨架。
3. ③ — 依据链①（骨架定义）：in case 引出「万一」条件 → 骨架③；依据链②（排除法）：观点动词 / 观点名词都不在主干位置，主句是 I will present the logs。
4. ② — 依据链①（骨架定义）：The point is that… = 观点名词 point + 表语从句 → 骨架②；依据链②（改写还原）：同义改写 The fact is that we should act now.，骨架一致。
5. ① — 依据链①（骨架定义）：show 是观点动词，that 从句作宾语 → 骨架①；依据链②（排除法）：主干 The dashboard shows… 是「主语 + 谓语」，不是名词 + be 结构。
6. ③ — 依据链①（骨架定义）：in case + 从句引出条件 → 骨架③；依据链②（改写还原）：可改写成 If the build breaks, we revert the update.，仍是条件框。

**3.**
1. He suggests that I fix the cache first. — 依据链①（搭配规则）：suggest 不接「人 + to do」，只接 that 从句 / doing；依据链②（改写还原）：还原直接引语 "I should fix the cache first." 再转述，成立。
2. She stated why the fix failed. — 依据链①（语序规则）：转述从句一律陈述语序（主语 + 谓语），why 从句也不能倒装；依据链②（时态呼应）：主句过去 stated → 从句相应过去 failed（对照 L05）。
3. My point is that we should act now. — 依据链①（引导词规则）：表语从句用 that，不用 which；依据链②（改写还原）：换成 The fact is that we should act now.，同一骨架成立。
4. In case the review needs evidence, I will present the logs. — 依据链①（时态规则）：in case 从句用一般现在表将来，不用 will；依据链②（改写还原）：改写为 If the review needs evidence, I will present the logs.，条件句同规则。

**4.**
1. ✓ — 依据链①（主谓一致）：data 形式为复数 → suggest；依据链②（骨架核对）：观点动词 suggest + that 宾语从句，骨架①成立。
2. ✗ → He argues that we should wait for the next review. — 依据链①（搭配规则）：argue 不接「人 + to do」；依据链②（改写还原）：还原直接引语 "We should wait for the next review." 再转述，成立。
3. ✓ — 依据链①（骨架核对）：The fact is that… 观点名词 + 表语从句，骨架②成立；依据链②（语序核对）：that 从句内部是陈述语序 the cache still breaks…。
4. ✗ → My point is that we should act now. — 依据链①（语序规则）：表语从句内部是陈述语序，should 不提前；依据链②（改写还原）：从句还原成独立句 We should act now.，是陈述句而非疑问句。
5. ✓ — 依据链①（时态规则）：in case 从句一般现在（show），主句将来（will open）；依据链②（骨架核对）：in case 条件框成立，与课文句同构。

**5.**（主观题 — 参考译句 + 三件套）
1. The data suggest that this fix saves us time.
2. The fact is that this bug returns every quarter.
3. In case the review needs evidence, I will present the logs.
4. I do not think that proves we can wait.
- 要点覆盖：四句分别落进指定骨架 —— suggest + 宾语从句 / The fact is that… / in case / I do not think that proves…
- 自检要点：suggest 后接完整从句（不接「人 + to do」）；表语从句用 that 不用 which；in case 从句一般现在（needs）；that proves 后从句为陈述语序
- 达标线：四个指定骨架各用对 1 句且语序 / 时态无误，即通过

**6.**（主观题 — 参考范文 + 三件套）
参考范文：The data suggest that our new pipeline saves us time. The dashboard shows that the tests now run faster. My point is that we should fix the cache first. In case the review needs evidence, I will present the logs. Some colleagues claim the case is rare.
- 要点覆盖：4~5 句中含 1 个「观点动词 + 宾语从句」、1 个「观点名词 + 表语从句」、1 个 in case 条件句、1 句转述他人观点；段落顺序「先观点后证据」
- 自检要点：对照课文 3.4 的五类错误逐句排查；转述句从句保持陈述语序；一段只落一个观点
- 达标线：四类句式齐备 + 无 3.4 常见错误 + 先观点后证据，即通过
