# 第一册 · 巩固篇 · 完整课程

> 高考水平（词汇 3000+）→ **4200（四级高频带覆盖）**。对应 NCE 2 后半 + NCE 3 前半。**核心任务：语法完整重建；词汇 = 课文精讲词 + 高频词群，不背孤立词汇表。**
> **定位依据**：2026-09-08 [水平自测](../00-水平自测.md) — Part A 词汇 4/5（3000-4000，符合自估）；B / C 未测，语法按全量系统教学设计，每讲自查清单兜底校准。

## 📚 Unit 01 句子工程（成分 · 句型 · 时态）

> 单元目标：任何英语简单句都能切成分、判句型、用时态写准。（标 ✅ = 课文与练习已产出）

| Lesson | 标题 | 学习目的 |
|--------|------|---------|
| L01 | [句子成分与五大句型](01-句子工程/L01-句子成分与五大句型/lesson.md) ✅ | 会用三步判型法分析陌生简单句；用「加 be 法」区分双宾与宾补 |
| L02 | [动词形态与时态坐标系](01-句子工程/L02-动词形态与时态坐标系/lesson.md) ✅ | 建立「时间 × 体」二维坐标系，看懂 16 时态地图，掌握 do / did / doing / done 四种形态的变换逻辑 |
| L03 | [一般与进行时态](01-句子工程/L03-一般与进行时态/lesson.md) ✅ | 在开发工作场景中用对一般时与进行时；能区分状态动词与动作动词（know why *I am knowing* 错） |
| L04 | [完成时态专攻](01-句子工程/L04-完成时态专攻/lesson.md) ✅ | 用时间轴攻克 have done / had done；会判断「影响延续至今」与「过去的过去」，修复 G1 / G2 类错误 |
| L05 | [将来表达法与主将从现](01-句子工程/L05-将来表达法与主将从现/lesson.md) ✅ | 掌握 will / be going to / 现在进行表将来 / 时刻表用一般现在；if / when 从句「主将从现」成为条件反射 |
| L06 | [主谓一致](01-句子工程/L06-主谓一致/lesson.md) ✅ | 语法一致、意义一致、就近三原则；插入语干扰下快速定位真正主语 |
| L07 | [疑问句、否定句与否定倒装](01-句子工程/L07-疑问句否定句与否定倒装/lesson.md) ✅ | 会构造一般 / 特殊疑问句与否定句；能识别 Never have I... 类否定倒装并还原语序 |
| L08 | [综合实战：技术短文句析](01-句子工程/L08-综合实战-技术短文句析/lesson.md) ✅ | 对一篇技术短文做全句标注（成分 + 句型 + 时态），完成语法线验收 |
| L09 | [高频词群实战 I：高频动词搭配网](01-句子工程/L09-高频词群实战-高频动词搭配网/lesson.md) ✅ | get / take / make / set 精讲 + keep / run 升级讲：六大高频动词的开发场景搭配网；输出时按词群调用而非逐词翻译 |

## 📚 Unit 02 从句体系

> 单元目标：识别并使用三大从句，能拆解四级难度的复合句。

| Lesson | 标题 | 学习目的 |
|--------|------|---------|
| L01 | 从句总览：句子是怎么"长出"句子的 | 建立「主句 + 从句」框架观；用提问法区分名词性 / 定语 / 状语三类从句 |
| L02 | 定语从句 I：关系代词 who / which / that | 会判断从句内缺什么成分，据此选对关系代词 |
| L03 | 定语从句 II：关系副词 where / when / why | 掌握「还原介词法」判断关系副词；处理 in which / during which 变体 |
| L04 | 定语从句 III：限制与非限制 | 区分两类定语从句的语义差异；掌握 which 指代整句、that 禁入非限制两大规则 |
| L05 | 名词性从句 I：宾语从句与语序陷阱 | 宾语从句一律陈述语序；that / if / whether 的选择与省略条件 |
| L06 | 名词性从句 II：主语从句与 what 的双重身份 | 掌握 what = the thing that 的引导 + 成分双角色；it 作形式主语 |
| L07 | 状语从句：九类连词一张表 | 时间 / 条件 / 让步 / 原因 / 目的 / 结果等连词的语义辨析；主将从现在状语从句的全面应用 |
| L08 | 综合实战：长句合并与拆解 | 简单句 → 复合句合并训练；从技术文章中摘取 10 个从句做成分分析，完成语法线验收 |
| L09 | 高频词群实战 II：观点句词群 | 高频抽象名词（fact / issue / point / case）与观点动词（suggest / show / argue / prove）；读懂观点句、会写观点句 |

## 📚 Unit 03 非谓语与被动

> 单元目标：被动语态全形态 + 非谓语三兄弟（to do / doing / done）自由切换，语法闭环。

| Lesson | 标题 | 学习目的 |
|--------|------|---------|
| L01 | 被动语态全形态 | 八种常用时态的被动式（is built / was built / is being built / has been built...）；能识别不能变被动的动词 |
| L02 | 情态动词与被动推测 | must be done / can't have been done 组合；用被动推测描述技术事故（The bug must have been fixed.） |
| L03 | 不定式：to do 的五大功能 | to do 作主 / 宾 / 表 / 定 / 状；it 作形式主语的迁移规则 |
| L04 | 动名词：doing 作主语与介词规则 | doing 作主 / 宾 / 表；介词后必 doing；look forward to / be used to 类陷阱排查 |
| L05 | 分词 I：作定语的主动与被动 | a running program vs a broken build；单个分词前置、分词短语后置的位置规则 |
| L06 | 分词 II：分词状语与悬垂分词纠错 | 分词状语的逻辑主语一致原则；Having done 完成式；能改错悬垂分词 |
| L07 | 非谓语三兄弟辨析 | 面对空格三步选形态：主动被动？先后关系？固定搭配？一张表解决 to do / doing / done |
| L08 | 综合实战：README 式说明文改写 | 把一篇主动句为主的短文改写为被动 / 非谓语丰富的技术文档风格，完成语法线验收 |
| L09 | 高频词群实战 III：被动与非谓语句式块 | be supposed to / be expected to / have sth done / keep sb doing 等高频句式块整体存储；写作直接调用 |

## 📚 Unit 04 篇章阅读与段落写作

> 单元目标：篇章层面的输入方法与段落输出能力，衔接第二册（四级冲线在第二册完成）。

| Lesson | 标题 | 学习目的 |
|--------|------|---------|
| L01 | 篇章结构：段落骨架 | 看懂「总 - 分 - 总」结构；能快速找到 topic sentence 与支撑句 |
| L02 | 阅读题型 I：主旨题与态度题 | 主旨题三步定位法（首末句 + 高频词）；态度词三档分级（积极 / 中性 / 消极） |
| L03 | 阅读题型 II：细节题与推理题 | 关键词定位 + 同义改写识别；推理题守住「不过度推断」底线 |
| L04 | 逻辑衔接词体系 | 转折 / 因果 / 递进 / 对比衔接词全表；阅读时用连词预判下一句走向 |
| L05 | 段落写作：主题句与展开三法 | 会写 topic sentence；用举例 / 因果 / 对比三种方式展开一个段落 |
| L06 | 从句子到段落：连贯与指代 | this / that / such 承上启下；代词与先行项一致，消除指代不清 |
| L07 | 高频词群实战 IV：衔接词与态度词库 | 建立个人衔接词 / 态度词双词库（呼应 L02 / L04）；限时作文即取即用 |
| L08 | 毕业实战：限时作文 + 全真阅读 | 30 分钟完成 150 词作文；400 词文章阅读 ≤ 10 分钟；对照本册验收清单 |
