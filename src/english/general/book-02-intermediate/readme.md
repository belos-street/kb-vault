# 第二册 · 进阶篇 · 完整课程

> 四级边缘（4200）→ 六级（5500）。对应 NCE 3 后半。**扩词主力册：词根词缀系统扩词 +1300，长难句与议论篇章上强度。**
> **前置（第一册毕业）**：语法重建完成（句型 / 时态 / 从句 / 非谓语被动）、词汇 4200、能写 150 词段落作文。
> **融会贯通**：本册长难句 = 第一册从句 + 非谓语的组合工程；篇章方法在第一册 Unit 04 基础上升维；词根词缀为第三册熟词僻义打底。

## 📚 Unit 01 长难句工程

> 单元目标：45 词长句 90 秒拆出主干；从句 + 非谓语知识的组合应用。

| Lesson | 标题 | 学习目的 |
|--------|------|---------|
| L01 | 长难句的本质：主干与修饰层 | 复用五大句型，建立「先主干后修饰」的剥洋葱式分析观 |
| L02 | 介词短语与同位语剥离 | 快速剥离插入修饰；不被介词短语带偏主语判断 |
| L03 | 从句嵌套识别 | 定 / 状 / 名三大从句作成分时的层次标注法；两层嵌套句能画出结构树 |
| L04 | 分词与不定式插入 | 主干被打断时如何「接骨」；分词短语、不定式插入语的归属判断 |
| L05 | 倒装与强调结构 | 部分 / 完全倒装的识别与还原；it is...that 强调句拆解 |
| L06 | 比较结构与平行结构 | as...as / more than 的比较对象对齐；not only...but also 平行原则 |
| L07 | 五步拆句法流程化 | 找谓语 → 剥修饰 → 提主干 → 理层次 → 回译检查，形成固定拆解流程 |
| L08 | 综合实战：真题级长句 10 句拆解 | 限时拆解 + 翻译回查，完成单元验收 |

## 📚 Unit 02 词根词缀与话题词汇

> 单元目标：系统扩词 4200 → 5500；会用词根推断陌生词义。

| Lesson | 标题 | 学习目的 |
|--------|------|---------|
| L01 | 词缀系统总览：前缀定方向 | 30 个高频前缀（un- / re- / dis- / over- / under-...）如何翻转 / 加强词义 |
| L02 | 核心词根 I：言与思 | dict / log / fer / ceive / spect 等词根，一词根带一族词 |
| L03 | 核心词根 II：动与传 | duc / mit / miss / port / pose 等动作类词根 |
| L04 | 核心词根 III：立与持 | st / sist / val / man / cap 等状态与握持类词根 |
| L05 | 后缀与词性转换 | -tion / -ment / -ify / -able：一个词根滚出四种词性，认后缀定词性 |
| L06 | 话题词群 I：科技与环境 | 六级高频话题词群，按场景成串记忆 |
| L07 | 话题词群 II：教育与社会 | 高频抽象概念词群（cognitive / academic / welfare...） |
| L08 | 话题词群 III：经济与职场 | 商业与职场高频词群（revenue / incentive / layoff...） |
| L09 | 综合实战：词族串记与 5500 自测 | 20 个核心词根覆盖 500+ 派生词；词汇量自测确认达到 5500 |

## 📚 Unit 03 议论与学术篇章

> 单元目标：六级难度议论 / 学术文章读得懂、读得快、抓得住态度。

| Lesson | 标题 | 学习目的 |
|--------|------|---------|
| L01 | 议论文骨架：主张 - 论据 - 让步 | 识别 thesis 与 concession（让步段）；预判作者立场走向 |
| L02 | 作者态度与语气识别 | 态度词表升级到六级级（skepticism / advocacy / ambivalence） |
| L03 | 证据与例证功能 | 数据 / 研究 / 引用在文中承担的论证功能（例证题的底屟能力） |
| L04 | 句间与段间逻辑 | 衔接词之外的语义关系（解释 / 转折 / 递进 / 对照）识别 |
| L05 | 学术语篇结构 | 研究报告式文章（问题 - 方法 - 结论）的阅读动线 |
| L06 | 观点与事实辨析 | claim vs fact；作者引用他人观点时的混合态度处理 |
| L07 | 六级题型串讲 | 选词填空 / 段落匹配 / 仔细阅读三大题型方法 |
| L08 | 综合实战：500 词议论篇章全文分析 | 结构图 + 态度线 + 出题点三件套，完成单元验收 |

## 📚 Unit 04 翻译与写作进阶

> 单元目标：六级翻译与作文达标；为第三册考研翻译打底。

| Lesson | 标题 | 学习目的 |
|--------|------|---------|
| L01 | 六级汉译英：段落主干提取 | 中文段落 → 英文主谓定位；先对齐主干再补修饰 |
| L02 | 汉译英：中国文化话题词库 | 历史 / 节日 / 科技成就等六级翻译高频话题词与句式 |
| L03 | 英译汉预修：切分与语序重排 | 长句切分、定语从句前置 / 拆译选择（衔接第三册考研英译汉） |
| L04 | 议论文三段式框架 | 引出 - 论证 - 结论模板内化；每段功能句备好 |
| L05 | 图表与现象描述 | 数字 / 趋势 / 占比的表达句型库（衔接第三册图表作文） |
| L06 | 写作句式升级 | 第一册非谓语 / 从句知识进写作；长短句节奏控制 |
| L07 | 写作自查清单与纠错流程 | 时态 / 主谓一致 / 冠词 / 搭配四道检查工序，作文交付前必过 |
| L08 | 综合实战：限时翻译 + 作文 | 30 分钟六级作文（150~200 词）+ 篇段翻译限时，完成单元验收 |
