## 1. 背景与目标

课文与练习目前是纯 markdown，只能「读」和「手写」。本平台把 lesson.json 编译成**可交互的学习页**，覆盖「听 → 学 → 拼 → 写 → 测」闭环：

- **听**：课文逐句朗读，练语感与听力
- **学**：词汇总览 + 语法讲解块 + 输出任务（复述 / 仿写自评），补齐 md 中「语法点拆解 / 输出」两节在平台上的呈现
- **拼**：单词 / 句子拼写，把精讲词与课文句子变成主动产出
- **测**：练习题交互化，即时判分即时反馈

原则：**markdown 是唯一数据源**（Obsidian 编辑 + skill 生成），平台只消费 `lesson.json`，不做任何反向编辑。

## 2. 用户与场景

- 唯一用户：作者本人（开发者，语法重建期，第一册）
- 场景：桌面端为主（听完 → 拼写 → 做题一条龙）；手机端能听课文、做客观题
- 使用节奏：每讲学完即练，45~75 分钟学习闭环的「练」环节

## 3. 功能需求

### F1 课文播放（P0）

- 逐句朗读（Web Speech API，浏览器内置零依赖），当前句高亮
- 语速调节（0.5~1.5）、单句循环、上一句 / 下一句
- 中英对照开关（zh 逐句配对来自 lesson.json）

### F2 拼写（P0）：单词 / 默写 / 听写 三子模式（原 F3 听写已并入）

- **单词拼写**：数据 `vocab.core` 精讲词 **+ `vocab.wordGroups` 词群词**（Q4：含词群）；TTS 念词（可重复听）→ 输入拼写；提示分级：看释义 → 看首字母 → 看例句
- **句子默写（意 → 形）**：看中文译文默写英文 → diff 三色比对；可「看首字母提示 / 看原句（计错）」求助
- **听写（音 → 形）**：核心句听音复写 → diff 三色比对
- **推进规则（三模式一致）**：必须输入到**完全正确**才进入下一项；首次对错计入结果，汇总页支持「只重做错项」
- 判分口径：Q2（核心句 = 关键句 + 含精讲词句）、Q3（大小写与标点不敏感）

### F4 练习判分（P0）

- 数据：`practice` 题组（basic / advanced 分层展示）
- 客观题（pattern-choice / judge）：点选即判 + 展开解析
- 填空（fill）/ 改错（correction）/ 翻译（translation）：输入后归一化比对；不一致时展示参考答案并由用户自判 ✓/✗
- 主观题（subjective / annotate）：对照三件套 checklist / 参考标注自评
- 实时正确率计数（判定持久化见 F6）；分讲次「会话结束汇总 + 错题清单」页未实现，记入裁剪

### F5 课程导航（已实现 · 方案 D 目录首页）

- 数据源：`import.meta.glob` 自动发现全部 `lesson.json`（新增讲次零代码接入，构建期 schema 校验）
- 目录首页（Library）：默认落地页，册 → 单元 → 讲三级列表，每讲右侧显示练习进度（未开始 / x/y 题 / ✓ 全对），顶部「继续学习」直达上次讲次
- 学习页头部：上一讲 / 下一讲快捷切换（首尾禁用）；页头「课程库」随时返回目录

### F6 学习进度持久化（P1，已实现简易版）

- localStorage 按讲存储：三练习模式已通过条目 + 练习判分记录
- 已通过项不再重复出题；练习判定跨会话保留，「重置本轮」清空该讲练习记录

### F7 讲解（P0 · L01 试点已实现）

- 数据：schema 新增可选块 `notes`（语法讲解：p / table / tip / steps 通用块模型）与 `output`（输出任务：retell 复述 / writing 仿写 / check 自检，含 reference 与 checklist），缺省 = 本讲无讲解内容（向后兼容旧讲次）
- UI：新增「讲解」tab（课文 → 讲解 → 拼写 → 练习），渲染词汇总览（精讲词 + 词群总览表）、语法讲解块、输出任务卡
- 输出任务卡：textarea 草稿（失焦自动保存）+ checklist 自评勾选，持久化到 localStorage（`notes` 字段，key = `output-<index>`）
- 数据源：L01 已回填 notes / output；其余讲次待试点确认后回填，english-lesson-crafter 同源生成流程同步扩展

## 4. 非功能需求

| 项       | 要求                                                                                                                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 技术栈   | Bun + TypeScript strict 全家桶 + Vite + React + oxlint/oxfmt（沿用 platform 现有配置）                                                                                                               |
| 依赖纪律 | 运行时依赖仅 react/react-dom/zod；不引 md 解析库（数据已是 JSON）、不引状态库、不引 diff 库（自实现 LCS）                                                                                            |
| 语音     | Web Speech API（Q6 正常策略）：优先 en-US Natural 网络声，自动回退任意 en 声；unmount 取消朗读                                                                                                       |
| 部署     | **kb-vault 仓库 GitHub Pages**（公开仓库免费），线上路由 `/kb-vault/lexio/`；push 触发（paths filter：平台代码或课程数据变动），Actions：install → validate → check → build（`--base` 覆盖）→ deploy |
| 数据同步 | 数据更新 = 重跑 `bun run validate` + 重新 build；平台不缓存旧数据                                                                                                                                    |
| UI       | 干净功能性设计，中文界面；移动端可用（F1 / F4）                                                                                                                                                      |
