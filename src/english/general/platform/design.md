## 1. 为什么是 Swiss Minimalist

- **字体即界面**：平台 80% 的内容是句子与单词，瑞士风格的排版驱动设计与「读」的场景天然契合
- **高对比**：纯黑 on 纯白（21:1），长时间阅读不累
- **零装饰**：无圆角、无阴影、无渐变——学习工具要的是「内容说话」
- **响应式策略文档化**：断点行为明确（见 §5），不用自己发明

## 2. 设计令牌（Design Tokens）

### 2.1 颜色（严格四色）

| 令牌         | 值        | 用途                                               |
| ------------ | --------- | -------------------------------------------------- |
| `--c-bg`     | `#FFFFFF` | 画布                                               |
| `--c-fg`     | `#000000` | 正文 / 结构边框                                    |
| `--c-muted`  | `#F2F2F2` | 次级背景（当前句、进度槽、verdict 底）             |
| `--c-accent` | `#FF3000` | **唯一信号色**：错误、当前句指示、主 CTA、Tab 编号 |

> 语义映射：**正确 = 黑（反转/实底），错误 = 红**。不引入绿色，保持严格四色。

### 2.2 字体

| 令牌 | 值                                                                                                      |
| ---- | ------------------------------------------------------------------------------------------------------- |
| 家族 | `Inter`（Google Fonts）→ 回退 `-apple-system, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif` |
| 标题 | 900（Black），拉丁字符大写 + `letter-spacing: -0.02em`                                                  |
| 标签 | 700，`letter-spacing: 0.08em`（小号大写标签用）                                                         |
| 正文 | 400 / 500，句子区 17~19px                                                                               |

### 2.3 形状与结构

| 令牌 | 值                                                    |
| ---- | ----------------------------------------------------- |
| 圆角 | `0`（严格矩形）                                       |
| 边框 | `2px solid #000`（卡片、按钮、输入框）；强调块 `4px`  |
| 阴影 | **无**。深度来自网格纹理，不靠投影                    |
| 纹理 | 24px 网格线（3% 透明度）铺 `#F2F2F2` 区块；正文区不用 |

### 2.4 动效

- `transition: background-color 150ms linear, color 150ms linear, border-color 150ms linear`
- 交互反馈 = **颜色反转**（黑白互换 / 转红），不用缩放和弹性动画

## 3. 组件规格（现有 class → 新行为）

| Class                        | 规格                                                                                                                                           |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `.card`                      | 白底 + 2px 黑边框，padding 20px（移动）/ 28px（桌面）                                                                                          |
| `.tabs` / `.tab`             | 矩形 Tab，2px 黑边框拼合；active = 黑底白字；Tab 前缀红色编号（01/02/03/04）                                                                   |
| `.btn`                       | 白底黑框，hover 黑底白字；min-height 44px（触控）                                                                                              |
| `.btn.primary`               | 黑底白字，hover 转瑞士红                                                                                                                       |
| `.btn.ok`                    | 黑底白字（= 正确语义）                                                                                                                         |
| `.btn.bad`                   | 红底白字（= 错误语义）                                                                                                                         |
| `input / textarea`           | 白底 2px 黑框，focus 边框转红，无 glow；字号 ≥16px（防 iOS 缩放）                                                                              |
| `.nav-head` / `.lesson-item` | 页头行（标题 + 切换课程按钮）；课程树讲条目（块级左对齐，当前讲红左边条，✓ = 练习全对）                                                        |
| `.subtabs` / `.subtab`       | 拼写子模式分段切换（单词拼写 / 听写 / 句子默写），2px 黑框拼合，active 黑底白字                                                                |     |
| `.prompt-zh`                 | 句子默写的中文提示块（灰底、16px）                                                                                                             |
| `.para` / `.sent`            | 课文按**自然段**排版（`reading.paragraphs` 分组，对话体每轮发言一段）；行高 2；当前句 = 灰底 + 2px 红色下边线；`.zh` 行内随句显示（0.82em 灰） |     |
| `.verdict.ok`                | 白底 2px 黑框 + 「✓」                                                                                                                          |
| `.verdict.bad`               | 白底 2px 红框红字                                                                                                                              |
| `.verdict.info`              | `#F2F2F2` 底（参考答案 / 中性提示）                                                                                                            |
| `.diff .missing`             | 红字 + 红色下划线（应写未写）                                                                                                                  |
| `.diff .extra`               | 黑字删除线 + 灰底（多写）                                                                                                                      |
| `.progress`                  | `#F2F2F2` 槽 + 黑色填充                                                                                                                        |
| `.keypoints`                 | 顶部 4px 黑实线分隔，编号红色                                                                                                                  |

## 4. 页面结构

- 页头：`英语练习平台`（Black 900）+ 讲次副标题（muted 灰块承载）+ 红色方块装饰点
- 内容列：单列流式，`max-width: 880px` 居中
- 区块间距：卡片间 16px（移动）/ 24px（桌面）

## 5. 响应式断点（移动端优先）

| 断点           | 行为                                                                                                                          |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| base（<768px） | 单列；Tab 一行等宽四分（触控高 44px）；按钮块级拉伸（`.controls` 内 flex 收缩）；字号正文 16px / 句子 17px；卡片 padding 20px |
| ≥768px         | Tab 改内容自适应宽度居中；正文 17px / 句子 18px；卡片 padding 28px；`.controls` 间距加大                                      |
| ≥1024px        | 句子 19px；页头标题加大；卡片 padding 32px；hover 反转态全量启用（移动端不依赖 hover）                                        |

> 触控目标：所有可点元素 ≥44×44px；`prefers-reduced-motion` 下关闭过渡。

## 6. 可访问性

- 黑白对比 21:1；红字仅用于 ≥17px 加粗或大色块场景（白底红字对比 3.9:1，不做小号正文色）
- `:focus-visible` 2px 红色外框
- 语义标签保持：nav / section / ol / button
