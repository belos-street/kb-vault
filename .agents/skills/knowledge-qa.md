# knowledge-qa

## 触发条件
用户基于知识库内容提问，如 "这个知识点怎么理解"、"帮我总结 xxx 笔记"、"根据我的笔记回答 xxx"。

## 技能描述
以 RAG（检索增强生成）模式工作：先从知识库中检索与问题最相关的笔记，再基于检索结果生成答案。

## 执行流程

1. 分析用户问题，提取关键技术和概念术语
2. 调用 `vault-search` 逻辑检索相关笔记
3. 读取命中的笔记全文（或关键段落）
4. 基于笔记内容生成回答，引用具体笔记文件和段落
5. 如笔记信息不足以回答问题，诚实告知并建议补充方向

## 回答格式

```
> 📄 参考：[笔记标题](相对路径)

回答正文...

> 如果还有其他相关问题，可以继续提问。
```

## 约束
- 只能基于知识库内已有内容回答，不编造信息
- 涉及外部知识时标注 "以下为通用知识，非知识库内容"
