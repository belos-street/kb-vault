# vault-search

## 触发条件
用户提出检索需求，如 "找一下 xxx 的笔记"、"有没有关于 xxx 的内容"、"搜索 xxx"。

## 技能描述
遍历知识库分类目录（`01`~`07`），根据用户查询进行语义或关键词匹配，返回相关笔记列表及内容摘要。

## 执行流程

1. 读取 `agents.md` 获取目录结构上下文
2. 根据查询意图定位可能相关的分类目录（如 Spring 相关 → `02-Frameworks-Middleware/`）
3. 优先精确搜索目标目录，未命中则全库搜索
4. 使用 Grep 进行关键词匹配，或读取 `.md` 文件进行内容分析
5. 返回匹配结果：文件名、所在路径、匹配片段（上下文 ±3 行）

## 扩展策略
- 识别 Obsidian `[[wikilink]]` 并跟踪链接深度 1 层
- 支持中英文混合检索
- 结果按相关度排序（标题匹配 > 内容高频匹配 > 内容低频匹配）
