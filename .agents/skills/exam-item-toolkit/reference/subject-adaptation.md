# 科目适配指南（subject-adaptation）

命题（question-design）与审题（question-review）的**科目实例化层**：两条铁律在数学、408、英语、政治四类科目下的具体手段。新科目接入时按本文件第 0 节的抽象框架补充一节即可。

## 0. 通用抽象（先读这个）

### 0.1 两条铁律的科目无关形式

- **设计即核验**：写出题目的同时，必须用 **≥2 条相互独立的依据链** 得出并确认答案，禁止"先写题、后补答案"；
- **审查即核验**：审题不复用题目自带的解题思路，换一条依据链重做；每条 P0 判定标注验证状态（已核验 / 存疑）。

### 0.2 答案可核验性分级（决定审查深度）

| 级别 | 含义 | 典型科目/题型 | 审查动作 |
|:--:|------|------|------|
| **A 客观可复算** | 存在可独立重做的推导/计算路径 | 数学全部；408 计算题（Cache 映射、页表转换、CRC、时间复杂度） | 换路径复算 + 特值回代 |
| **B 定位可核验** | 答案锚定在可指认的依据上 | 英语阅读/完形（原文定位句）、政治客观题（大纲/教材原文、时政来源） | 逐题标注依据出处，换角度排除二验 |
| **C rubric 可审** | 无唯一答案，按评分标准审 | 英语写作/翻译、政治分析题、408 综合应用的设计说明 | 只审要点覆盖与 rubric 完整性，**不做逐题复算** |

一套题库常混用三级（如英语卷 = B + C），逐题标注所属级别后再选审查动作。

### 0.3 回归验证的科目无关形式

"编号-答案对齐、查重、结构配对"三项目所有科目通用；**格式类检查项按科目替换**（数学查 LaTeX，代码类科目查代码块标注，语言类科目查语法自查声明）。

## 1. 考研数学（数一 / 数二 / 数三）

| 维度 | 约定 |
|------|------|
| 题型结构 | 选择、填空、解答、证明 |
| 核验手段（A 级） | 特值回代（含参题取参数 = 0/1 代回）、双路径互证（消元 vs 公式、性质化简 vs 直接展开、换行法 vs 逐个展开）、不变量交叉印证（秩、迹、行列式） |
| 数字友好性 | 基础题中间结果必须为整数或简单分数；出现丑数先怀疑题目设计 |
| 格式检查 | LaTeX 语法、CJK 字符与 `$` 之间加空格、`$$` 块前后空行、表格内 `\|` 转义 |
| 特殊坑 | 超纲判定（数二不考向量空间/无穷级数等）；解析不得违反配套教学文档的方法口径（如"含参行禁除"） |

## 2. 408 计算机学科专业基础

| 维度 | 约定 |
|------|------|
| 题型结构 | 单项选择题（约 80 分）+ 综合应用题（约 70 分） |
| 核验手段 | 计算类（A 级）：代入具体数值/地址重算（如把帧号、页号代进转换式）、画内存/树/图辅助复核、复杂度用代入法验证递推式；概念类（B 级）：对照权威教材定义反推、**构造反例**排除错误选项、每个干扰项写明错因类型（偷换概念 / 混淆充要 / 忽略边界） |
| 命题要点 | 概念辨析题优先埋"易混淆术语对"（如页 vs 段、碰撞 vs 溢出）；综合题给足题面数据，禁止依赖"考生自己假设" |
| 格式检查 | 代码块必须标语言（```c / ```cpp）；伪代码显式标注；术语与大纲及主流教材口径一致 |
| 特殊坑 | 时效性：API/标准细节随版本变化，优先考稳定概念；图示题（内存布局、状态机）必须自检图与题面数据一致 |

## 3. 考研英语（英语一 / 英语二）

| 维度 | 约定 |
|------|------|
| 题型结构 | 完形填空、阅读、新题型、翻译、小作文、大作文 |
| 核验手段 | 阅读/完形（B 级）：**每题标注原文定位句**，答案必须能从定位句直接支撑；干扰项标注错因（无中生有 / 过度推断 / 偷换对象 / 张冠李戴）；写作/翻译（C 级）：审 rubric 要点覆盖（内容、结构、语言、格式），不做对错复算 |
| 语言自查 | 范文与选项须双路径自查：整体通读 + 逐句语法核查；避免超纲词汇（对照考纲词表） |
| 格式检查 | 无数学公式；阅读材料如引用外部文章须改写并自洽，不得与真题原文雷同 |
| 特殊坑 | 阅读题四个选项中正确项与最强干扰项的区分度必须明确；作文题给出明确的内容指令（不能"自由发挥"到无法评分） |

## 4. 考研政治

| 维度 | 约定 |
|------|------|
| 题型结构 | 单项选择、多项选择、分析题 |
| 核验手段 | 客观题（B 级）：逐题对照大纲知识点原文出处（教材/权威辅导书章节）；**时政题必须标注时效**（"基于 XX 年时政"，并注明过期风险）；分析题（C 级）：审 rubric——原理点清单 + 材料结合要求 + 分层给分点 |
| 命题要点 | 多选题是区分度主力，正确项个数不定（2~4 个）且需在解析中逐项说明；干扰项用"原文改词""张冠李戴""绝对化表述"等经典手法 |
| 格式检查 | 引文与表述必须与权威来源一致，禁止凭印象改写定义 |
| 特殊坑 | 时政类题目有保质期——题面与答案处都要标注时政年份；多选题答案个数分布避免全部 4 项 |

## 5. 新科目接入清单

1. 确定题型结构与分值（按当年真实试卷）；
2. 把该科目所有题型映射到 A/B/C 可核验性分级；
3. 为每级写出 ≥2 条独立依据链的具体手段；
4. 列出格式检查项与特殊坑；
5. 在 SKILL.md 速查表加一行入口。
