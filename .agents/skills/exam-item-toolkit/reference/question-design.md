# 多维度命题流程（question-design）

为考试类科目设计**分层、可核验、答案分离**的练习题库。配套阅读：[difficulty-tiers.md](difficulty-tiers.md)（分层标准、题型标注、配比）；[subject-adaptation.md](subject-adaptation.md)（核验手段与格式检查按科目实例化）；审题验收用 [question-review.md](question-review.md)。

## 0. 前置阅读（动手前必做）

1. **大纲与教学文档**：科目大纲（或 readme 的知识体系、验收清单），确定考点边界与**不考内容**（如数二不考向量空间）；
2. **已有题目清单**：通读目标目录下全部已有练习题（含教学文档文内练习），建立**查重基线**——新题与其零重复；
3. **项目写作规范**（如有）：数学公式 LaTeX 语法、CJK 与 `$` 之间加空格、emoji 克制使用等硬约束。

## 1. 考点-难度矩阵（先设计矩阵，再逐题填充）

| 知识块 | 选择 | 填空 | 解答 | 证明 | 合计 |
|--------|:--:|:--:|:--:|:--:|:--:|
| 知识块 A | B1 | — | S1 | T1 | 3 |
| 知识块 B | B2 | B3 | S2/S4 | T2 | 5 |
| … | | | | | |

矩阵设计时优先补教学文档未覆盖的题型（抽象证明、跨章综合、反求参数）。

> 题型列按科目考纲定义（上表列名为数学示例，见 [subject-adaptation.md](subject-adaptation.md)）。

## 2. 逐题设计四原则

> 本节示例为数学科目；其他科目的命题要点（干扰项手法、rubric 要求、时效标注等）见 [subject-adaptation.md](subject-adaptation.md) 对应小节。

1. **与已有题零重复**：数字、结构、问法三个维度都不与查重基线撞车；同一模型换数字视为重复，换右端/换参数位置才算新题；
2. **对照题**：刻意设计"同系数不同条件"的对照对（如同一系数矩阵配不同常数列，一个无解一个无穷多解），训练辨析而非背题；
3. **陷阱题**：每个强化/真题级题目至少埋一个高频易错点（重根漏讨论、符号翻转、必要条件当充要用），并在解析中点名；
4. **真题改编须标注**：注明改编自哪类真题模式（如"2017 数二真题改编"），保留原题的命题结构。

## 3. 设计即核验（铁律）

> 本节手段是**数学类科目**的实例化。其他科目按 [subject-adaptation.md](subject-adaptation.md) 的"独立依据链"框架（每个答案 ≥2 条相互独立的依据链）执行对应动作。

**写出题目的同时必须独立复算出答案，禁止"先写题、后补答案"。**

- 每题在草稿中完成完整求解，答案与过程记录后才写入题面；
- **含参题必须代特值验证**（如取参数 = 0 或 1 代回原方程检验）；
- **双路径互证**：关键计算用两种方法各算一次（如消元法 vs 分块公式、换行法 vs 逐个展开余子式）；
- **数字友好性检查**：基础题的中间结果应为整数或简单分数，出现丑数说明设计失败，回炉重设；
- 验算中发现答案"不干净"时，先怀疑题目设计而非硬算到底。

## 4. 输出规范

```
<科目目录>/
├── doc/                      # 教学正文（含文内练习，命题时不可重复）
└── exercises/                # 题库层（本流程产物）
    ├── readme.md             # 使用说明：分层标准、限时建议、验收联动
    ├── <ch1-xxx>.md          # 每章一个文件，题目 + 文末答案
    └── mock-comprehensive.md # 综合模拟卷（跨章链路）
```

**题目格式**：

```markdown
**S2（解答）**：设 …（题面，含全部条件与所求）。

## 答案与解析
### S2
（完整解析：方法选择理由 → 关键步骤 → 验算 → 易错点提醒）
```

- 题面标注题型与难度（见 [difficulty-tiers.md](difficulty-tiers.md)）；
- **答案与解析统一放文件末尾**，与题目分离，保证自测不瞟答案；
- 解析必须包含：方法选择依据、完整步骤、**验算**、易错点（A/B 级适用；C 级主观题替换为"要点覆盖说明 + rubric 对照"）；
- 格式遵守科目规范（数学：LaTeX、CJK 与 `$` 之间加空格；其他科目见 [subject-adaptation.md](subject-adaptation.md) 的格式检查项）。

## 5. 回归验证（交付前必做）

1. **编号对齐**：题目数 = 答案数，B/S/T 编号一一对应（用 Grep 按编号模式计数核对，如 `^\*\*S\d+`）；
2. **公式规范**（数学等公式类科目）：扫描 `CJK字符紧邻$` 的违规（如 `，$` `（$`），全部补空格；其他科目按 subject-adaptation.md 的格式检查项替换；
3. **查重复核**：对关键数字/结构 grep 已有题库，确认无重复；
4. **结构完整**：代码围栏配对、公式定界符配对（`$` 与 `$$` 计数为偶，公式类科目适用）；
5. 汇报时注明：每题的核验方式（A 级：特值 / 双路径 / 回代；B 级：依据定位；C 级：rubric 审查），未核验的题目必须显式声明。
