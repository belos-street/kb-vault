# 考题质量审查流程（question-review）

对考试题目/题库（练习题、模拟卷、测验题）做正确性与规范性审查。配套阅读：[difficulty-tiers.md](difficulty-tiers.md)（分层标准，用于难度标定核查）。教学文档的结构审查不在此流程内。

## 0. 先读规范与命题基线

1. 项目写作规范（如有）：数学公式 LaTeX、CJK 与 `$` 空格、emoji 约定；
2. 科目大纲 / 教学文档 readme：考点边界与**不考内容清单**（超纲判定的依据）；
3. 配套教学文档：题目的难度标定、方法口径必须与正文一致（如正文强调"含参行禁除"，题目解析不得违反）。

## 1. 审查流程

> **适用边界**：本流程默认题目答案**客观可核验**（subject-adaptation.md 中的 A/B 级：数学计算、408 计算与概念、英语阅读定位、政治客观题）。**主观题**（英语写作/翻译、政治分析题、408 设计说明类综合题）不适用逐题复算，只审要点覆盖与评分 rubric 完整性（C 级动作），"正确性"维度对主观题的含义相应替换为"参考答案与 rubric 无科学性错误"。

### 第一步：通读并提取清单

把全部题目提取为清单：题号、题型、标定难度、所考考点、答案摘要。用它核对**题目数 = 答案数、编号一一对应**——错位是最低级也最致命的问题。

### 第二步：逐题独立核验（P0 核心，客观题不抽查）

**不复用题目自带的解题思路重做一遍**，用尽可能不同的方法（核验手段按科目实例化，见 [subject-adaptation.md](subject-adaptation.md)）：

- 计算题：换一条路径（消元法 ↔ 公式法、直接展开 ↔ 性质化简）；
- 含参题：代特值（参数取 0、1 等特殊值回代检验）；
- 方程/通解：回代原方程逐式验证；
- 几何/结构结论：用秩、迹、行列式等不变量交叉印证。

每条 P0 级判定必须标注验证状态：**已复算（写明复算路径）**或**存疑**。凭"看起来不对"下的结论不得写入报告——先复算，再定性；被复算推翻的疑似错误也要在报告中说明（体现验证过程）。

### 第三步：六维评定

| 维度 | 审查要点 |
|------|----------|
| 正确性 | 题面条件自洽、答案与解析无误、验算步骤真实（不是装饰性"✓"） |
| 考点对位 | 所考知识点与标定章节一致；**超纲判定**（对照大纲不考清单） |
| 难度标定 | 基础题是否真"套流程可解"、真题级是否真有综合性与陷阱；标定与实际不符记 P1 |
| 解析完整性 | 有方法选择依据、关键步骤、验算、易错点；只有答案没有解析记 P1 |
| 一致性 | 与配套教学文档的口径一致（符号、方法、术语）；题库内部无重复题 |
| 格式规范 | 公式规范（LaTeX、CJK-$ 空格）、答案分离、题目信息完整（所求明确、条件无歧义） |

## 2. 问题分级

| 级别 | 定义 | 示例 |
|:--:|------|------|
| **P0** | 正确性错误 | 答案算错、解析步骤错误、题号-答案错位、条件自相矛盾、把超纲内容标进考纲 |
| **P1** | 标定与结构问题 | 难度标定失真、解析缺验算、与教学文档口径矛盾、与他人题目重复、陷阱题实际无区分度 |
| **P2** | 小瑕疵 | 公式空格、措辞、限时建议不合理、编号风格不统一 |

## 3. 输出格式

```
## 📊 XX 题库质量 Review

**总评：X/10** —— 一句话结论（附核验规模：共核验 N 题——A 级复算 X 题 / B 级定位核验 Y 题 / C 级 rubric 审查 Z 题；发现 M 处问题）。

### 一、规范符合度矩阵
| 检查项 | ch1 | ch2 | … |
|--------|:--:|:--:|---|
| 答案正确（逐题复算） | ✅ | ⚠️ S3 | … |
| 考点对位 / 无超纲 | ✅ | ✅ | … |
| 难度标定合理 | … |
| 解析含验算 | … |
| 编号-答案对齐 | … |

### 二、逐题判定（仅列异常项 + 典型亮点）
**S3（存疑 → 已复算）**：…复算路径…，正确答案应为 ZZZ。

### 三、改进建议（P0 → P1 → P2）
### 四、总体结论
```

## 4. 修改闭环（用户确认后执行）

1. 顺序：P0（正确性）→ P1（结构）→ P2（格式）；
2. 修改保持外科式：只改报告中列出的问题，不顺手优化无关内容；
3. **修改答案类 P0 时必须重新复算**，不能只改数字；
4. 回归验证：编号对齐、公式空格、查重、围栏/LaTeX 配对全部重扫一遍；
5. 汇报：按 P0/P1/P2 分组列出修改清单（文件、位置、改动、复算结论）。
