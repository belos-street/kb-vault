# 交付前自审（lesson-review）

> 生成任何一讲后、交付给用户前必须跑完五查。P0 项不过 = 打回重写，不允许带病交付。

---

## 五查清单

### 查一：结构

- [ ] 六节齐全，顺序正确（目标头部 + 精读 / 词汇 / 语法 / 输出 / 练习 / 小结）
- [ ] 头部三要素：册位（第 X 册 · Unit 0Y · Lesson Z）、预计用时、能力目标
- [ ] 输出环节有参考起点，未空转
- [ ] 尾部下一讲状态正确（未写 = 纯文本 +（待写），已写 = 正确相对链接）

### 查二：词汇（对照台账）

- [ ] 词汇表与台账**零重复入账**（精讲表与词群表均不得重复）
- [ ] 总量 10~14 词（精讲 6~8 + 词群 4~6；词群实战课特例：精讲 4 词、无词群表）
- [ ] 课文旧词复现率 ≥ 本册阶段目标（按册递进，见 [vocab-ledger.md](vocab-ledger.md) 规则二），分子 / 分母精确清点，且复现已回写台账
- [ ] 超纲词有中文注释
- [ ] 状态流转核对：复现 ≥ 2 次的词已推进为「复现中」（回写复现记录时同步推进）
- [ ] 台账统计区数字 = 逐讲表合计（入账数 / 复现中数逐项对得上）

### 查三：语言（双路径自查）

- [ ] **整体通读**：课文连贯、逻辑自然、难度匹配本册定位
- [ ] **逐句语法核查**：时态、主谓一致、冠词、搭配逐句过一遍（与第二册写作自查工序同源）
- [ ] 课文确实覆盖本讲大纲指定的语法点

### 查四：练习

- [ ] 客观题：题目数 = 答案数，编号一一对应
- [ ] 输出类主观题（造句 / 翻译 / 作文）：答案区给「要点覆盖 + 自检要点 + 达标线」三件套，不强制唯一答案（对齐 exam-item-toolkit 的 C 级 rubric 口径）
- [ ] 答案 `<details>` 分离在文末，解析含核验方式（客观题 ≥2 条依据链）
- [ ] 与本册已有练习零重复（数字 / 结构 / 问法）— **落地动作**：对高频错误串（breaked / have saw / do a decision / is agree 等）Grep 扫描本册 `exercises/`
- [ ] 含 ✓ 项的改错题，题干写「判断 N 处正误」而非「找出 N 处错误」
- [ ] 与课文知识点对齐，无超纲考点

### 查五：链接与格式

- [ ] 相对路径正确（课文 ↔ 练习互链、台账路径）
- [ ] 无指向未创建文件的链接
- [ ] 表格未断裂、代码围栏配对、emoji 克制（同段落 ≤ 2~3 个）

---

## 问题分级与处理

| 级别 | 定义 | 处理 |
|------|------|------|
| **P0** | 死链 / 答案缺失或错位 / 词汇重复精讲 / 六节缺失 | 阻断交付，立即修复 |
| **P1** | 模板偏离 / 复现率不达标 / 核验方式未标注 | 交付前修复 |
| **P2** | 措辞、排版、emoji 密度 | 可交付后跟进 |

输出格式：逐查 ✅/❌ + 问题列表（P0/P1/P2 + 修复动作）。

## 深度审查联动

- 自审通过即交付；用户可随时说「review 本讲」触发 [doc-quality-reviewer](../../doc-quality-reviewer/SKILL.md) 六维评分深度审查
- 与六维的对应是**类比映射**（源自技术教程语境）：结构 → 查一、语言正确性 → 查三、练习与应试导向 → 查四；完整六维以 doc-quality-reviewer 自身定义为准，审查结论回流本 skill 的版本迭代
